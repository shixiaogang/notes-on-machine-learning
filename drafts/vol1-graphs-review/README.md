## 从一章扩为一部分

原五个主体section分别成为chapter，各章设章首任务与独立的section“本章小结”。原方法族小节升为section，具体方法升为subsection；subsubsection仅在确有概念层次或方法分支时设置，不将所有paragraph机械升一级。

第1、2章建立对象、表示与查询判据。第3—5章先在需要处说明必要概念，之后按具体方法组织subsection与subsubsection。思想、状态、步骤、算例核验和复杂度属于方法内部的paragraph；方法的实现不能仅写一个算法名称。

## 3.7的概念与方法职责

原3.7入口把极大团、最大团、弦图、单纯顶点、完美消元序与团树挤在同一内容单元。现在增加专门的基础概念入口，并用subsubsection归组、具体paragraph逐一解释，先识别对象，再进入完美序和团树构造。

原3.7.1的第一个paragraph主要写删除算法，但夹入了判别与正确性；第二个paragraph同时装了算例、反例与复杂度。因此它们并非清楚对应“实现”和“验证”。现将该方法分别安排为思想、输入与判别、逐步删除、算例、输出核验及复杂度分析，让读者能辨认：算法怎样产生次序，算例怎样执行，输出次序怎样被独立检查。

一个paragraph围绕一个中心对象或操作，可以包含多个自然段。邻域与度、长度与容量、超边与因子图、连通分量与强弱连通等分别用具体标题，不通过把文字挤进一个长段落来保持标题少。
