## 二、层级和数学形式各自负责什么

| 形式 | 承担的职责 | 读者应能直接找到什么 |
|---|---|---|
| subsection | 一个完整的数学对象、运算或方法问题 | 本节研究什么，最终解决什么。 |
| subsubsection | 主问题下一个可以独立说明的子问题 | 例如卷积的计算、边界、代数性质各是什么。 |
| paragraph | 同一子问题内需要辨认的局部视角或阶段 | 例如按输入累加与固定输出读取；不把每个等式都做成标题。 |
| definition | 对象、运算、符号和约定 | 输入是什么，规则是什么，输出是什么。 |
| theorem | 有条件、可复用、需要论证的核心性质 | 条件与结论在同一陈述内；证明紧接。 |
| lemma | 较长方法中确实需要单独识别的正确性桥梁 | 例如偶奇蝶形恒等式或模重构关系；直接代入可得的小式子仍用正文。 |
| mathproblem | 需要正式固定的所求问题 | 已知输入/核、边界、候选信号类及所求输出；只在必要处使用。 |
| algorithm | 顺序重要、可以照着执行的方法 | 输入、操作步骤、输出；不把性质清单装成算法。 |
| example | 一次完整可复算的使用 | 给定条件→中间计算→最终结果→它回答了哪个问题。 |
| 普通段落与显示公式 | 动机、机制、局部计算、结果解释与过渡 | 为什么此处引入，前后两步如何连接。 |

这些环境已在项目样式中提供。核心定义与性质已有不同的视觉样式，无需先开发新框体。应先解决语义归属：定义里只固定规则；性质和证明分开；示例不再夹在定理陈述内。同一对象、同一语境中的结论避免重复正式陈述，例子展示它怎样使用；推广到新对象时则须重新明确变化后的条件。

读者的阅读可以有两个速度：先看标题与正式陈述即可识别问题、条件和答案；继续读相邻推导与示例，能够复算并理解答案。两种速度使用同一份连续正文，必要中间步骤仍然保留。

### 3.1 信号的对象与表示

先集中回答对象如何确定，再分不同坐标的读取与恢复。“全局傅里叶”完成基本坐标，“选择与调整”解释反射边界与局部观察为什么需要不同读数。

| subsection | 这一小节具体说什么 | 包含内容与内部呈现 |
|---|---|---|
| 信号对象与边界 | 一条信号由哪些信息确定，记录外的值从哪里来？→ 索引及单位、值域/通道、周期和支撑限定对象；有限观测还须声明延拓和输出范围。 | **索引与物理时间；实值、复值与多通道；周期与支撑；有限记录的延拓与裁剪**。定义固定对象，同一短记录展示单位、通道、延拓怎样改变解释与计算。确定/随机路径和复内积槽作为相邻说明保留。 |
| 位置分解与截断 | 怎样由最简单的位置分量恢复记录，少存位置会损失什么？→ 移位脉冲乘读数再相加；截断平方误差就是舍弃读数的平方和。 | **单位脉冲与位置展开；截断与平方误差**。定义→展开/误差结论→三点分解和重建；l2尾和收敛作为有条件推广。 |
| 全局傅里叶表示 | 怎样计算整段或整域的振荡坐标，何时可以恢复？→ 索引域和周期条件决定频率集合、系数算法及恢复口径；多维沿各轴构造同一坐标。 | 四个subsubsection：**有限记录的DFT；周期信号的傅里叶级数；整轴离散序列的DTFT；整轴连续信号的傅里叶变换**。每类讲系数、恢复、条件、平方量和完整例子。多维DFT进入有限记录，连续多维与仿射换元进入连续变换；不另列第五种基本变换。 |
| 频率表示的选择与调整 | 已有全局傅里叶坐标后，边界或局部观察任务为什么还要调整？→ 反射把成对模式合为实余弦；滑动窗口把全局读取变为逐帧读取，各自付出不同代价。 | 两个subsubsection：**反射边界的余弦表示；局部片段的时频读数**。分别明确沿用哪种变换、改变什么、能恢复什么。DCT含二维、截断误差和整数近似；STFT含泄漏、窗口权衡、谱图、梅尔/对数频带。 |
| 多项式坐标与恢复 | 保存系数、点值或余数各读到了什么，何时足以恢复？→ 幂次保存位置，互异点值或互素模余数在次数界内唯一决定系数；可逆不自动稳定。 | **位置系数与多项式；点值表示与插值恢复；余数表示与模分解恢复**。保存什么→唯一性依据→恢复过程→条件边界。保留带余除法、Euclid/Bézout和CRT完整推导。 |

四类基本傅里叶表示各保留一个subsubsection：有限记录DFT、周期信号级数、整轴离散DTFT、整轴连续变换。共同可查信息是输入、频率、系数计算、恢复意义、条件与例子，不复制成每类六个微标题。

多维DFT、逐轴算法、频率方向及离散平移/对称进入有限记录分支；连续多维频率与可逆仿射换元进入连续分支。DCT的二维/整数近似及STFT的窗权衡/Mel在各自调整任务内保留。STFT提供局部频率读数，不能声称完整复频谱丢失位置；频域处使用平方和/平方积分，到比较节再解释能量功率。

### 3.2 信号的比较

这三类提问本来成立，保留三项。连续、多通道、窗口和单位是各指标的条件，紧靠定义和结论；节首用一段固定共同比较范围。

| subsection | 这一小节具体说什么 | 包含内容与内部呈现 |
|---|---|---|
| 信号大小的度量 | 峰值、累计幅值与平方大小各回答什么？→ 三种范数强调不同大小，比较须固定范围、尺度并核对有限性。 | paragraph：**峰值与累计量；范围、有限性与单位**。集中定义三类离散/连续范数，算同一三点例；保留l2不必l1、本质上界、重排不变、多通道尺度与异单位边界。 |
| 信号差异与方向相似性 | 数值接近、方向一致和正交是不是同一判断？→ 距离测差，内积测对齐方向，归一化去掉整体幅值；权重改变实际比较口径。 | paragraph：**内积与数值差异；归一化与方向；对齐与通道权重**。定义、存在性与界；正交但支撑重合、x与2x的成组算例；实/复ρ、零信号、正定/半正定边界。 |
| 累计能量与平均功率 | 持续信号的平方总量发散时怎样比较强度？→ 总能量与长期平均回答不同问题，后者必须有极限；周期可化为一周期平均。 | **能量、平均功率与周期计算；极限存在性与频域核算**。定义→零/周期延拓与正弦完整例；有限能量功率0的结论、交替长块无极限反例；最后调用Parseval，解释归一化。 |

二范数平方与能量的数学联系只解释一次；能量功率分支新增的是累计/长期平均、物理解释及极限边界。Parseval调用已有结论，不重讲变换定义。

### 3.3 信号的基本运算

四项按要计算的输出分工：改变自变量、组合同位置读数、计算邻点变化、比较移动片段。每项有完整手算；卷积和频域实现由卷积节新增解释。

| subsection | 职责：问题→简洁完整答案 | 应有的内容与语义环境 |
|---|---|---|
| 信号的位置变换 | 特征的位置、次序和时间尺度怎样改变？→ 平移、反转及连续时间缩放分别改变自变量的不同部分。 | 固定同一非对称波形；各定义只陈述取值规则；例子给峰值/支撑全过程；集中给换元得到的能量性质。整轴、循环与有限裁剪明确区分。 |
| 信号的幅值运算 | 同一位置的读数怎样组合？→ 标量倍乘、逐点叠加、逐点相乘及通道矩阵混合改变取值，保持该位置的含义。 | 输入位置先对齐；定义规则和通道维度；同一短数组手算；突出能量交叉项、固定窗与可变输入、通道等距条件。 |
| 信号的差分 | 邻点差怎样成为有尺度的一阶、二阶变化读数？→ 指定邻点方向，分别除以步长或步长平方；满足相应光滑条件时近似连续导数。 | 差分定义、常量/二次函数计算、Taylor误差定理与短证明；保留方向、步长与边界。频率响应、Sobel与高斯导数组合交给卷积滤波。 |
| 信号的相关 | 怎样计算一个模板在各位置与信号的匹配读数？→ 模板保持原方向，与对应移动片段作内积，复共轭在模板侧。 | 相关定义、位置索引、完整/有效读数、同一模板逐位置计算、归一化条件；自相关作为模板取自身的特例。卷积改写和FFT计算留卷积节。 |

下级结构保持具体：位置变换分平移、反转、时间缩放；幅值运算分缩放叠加、逐点乘法加窗、通道混合；差分分算子计算与导数近似误差；相关分模板读数与逐位置归一化比较。直接性质紧靠对应运算，不再各造一个“性质”小节。基本运算也可视为映射；两节按先会算、再整体检验的教学职责分工。

### 3.4 信号的映射

标题统一为“信号的映射”。H:X→Y先确定输入输出，信号处理中也常把相应规则称为系统。这里按学习阶段推进，分清性质、实例和分析工具。

| subsection | 主问题→核心答案 | 主要内容及形式 |
|---|---|---|
| 输入输出映射的界定 | 什么才算给定了一条输入输出规则？→ 必须给出输入/输出对象及决定整条输出的规则，所用参数、初始条件、边界和读取范围需固定。 | `definition[信号映射]`；短记录规则例；初始条件与自由响应；系统只是该类规则的常用名称，不改变本节标题。 |
| 映射的性质与检验 | 对给定规则，怎样判断叠加、平移复用或读取过去等性质？→ 每项性质对应不同等式或量词，需要逐项代入检验；它们不是互相替代的分类。 | 线性/平移、记忆/因果两组问题；正式定义、最小反例、同一组三种规则的性质表；线性输入响应加固定非零自由项为何成为仿射映射。 |
| 典型映射的结构与计算 | 不同规则怎样具体产生输出，这些性质在公式中如何体现？→ 有限输入坐标上的线性规则由单位输入响应构成核，扩展到无穷输入另需收敛或连续性条件；输入依赖权重一般破坏线性；形态学依集合包含和局部极值构造。 | 线性核、逐点/输入依赖规则、集合/灰度形态学三个subsubsection。它们是对象明确的规则实例，分别给计算、结构条件和可用性质，不作为穷尽分类。 |
| 给定输入附近的局部线性化 | 非线性规则能否在某条输入附近用线性响应近似？→ 可微时有以该输入为基点的一阶响应和余项；这不是对所有输入成立的固定核。 | 先限定有限向量输入输出，给导数展开及条件；平方映射的精确计算例；展开点依赖与误差范围。它是分析工具，不是第四种映射类型。 |

下级结构：界定使用“输入/输出与固定规则”“初值与自由响应”两个paragraph；检验分线性/平移和记忆/因果；结构与计算分线性核、逐点/输入依赖、集合/灰度形态学三个实例；局部线性化用有限维展开和平方映射例。

线性要求相应向量空间，平移检验要求允许的平移封闭；集合形态学按包含/次序定义，不硬塞进线性/非线性二分。局部线性化限定可微有限维映射及余项，不视为第四种映射类别。LTI固定响应的求和表达交给卷积节建立。

### 3.5 信号的卷积

卷积section按五个学习问题组织：是什么、满足什么规律、怎样换坐标表示、能怎样处理信号、怎样加速。原来的十个subsection把对象类型（连续/多通道）、边界、数学性质、坐标表示和实现方法并列，造成职责交叉；本版将它们归回各自回答的主问题。

| subsection | 这一小节具体说什么 | 内部层级与读完所得 |
|---|---|---|
| 卷积的定义与计算 | 给定输入x和核h，卷积输出是什么，怎样按定义逐项得到？ | **离散卷积与两种直接计算读法；有限记录的边界与输出；连续卷积；多维与多通道推广**。定义固定对象与规则，示例给全过程。连续/多通道是索引域或值域的推广，边界是有限数组如何参与运算的约定，不再单列同级subsection。 |
| 卷积的性质与成立条件 | 哪些等式可以组合、化简卷积，它们在什么条件下成立？ | **代数性质与串并联；支撑与因果性；无穷求和/积分的收敛及范数界**。定理集中陈述条件与结论，证明解释换标/换序，再用串并联例展示用途；矩阵核不能无条件沿用标量交换律。 |
| 卷积的矩阵与频域表示 | 同一个卷积能否写成矩阵乘法，频域为什么变成逐点相乘？ | **Toeplitz与循环矩阵；卷积定理与DFT对角化；频率响应**。矩阵例展示共享滞后，定理建立坐标关系，单频代入解释幅度与相位。这里建立频率响应，下一小节直接调用，不再重复定义。 |
| 卷积滤波与模板匹配 | 怎样选择核来平滑、突出变化或寻找匹配片段？ | **平滑与指数响应；差分与Sobel；LoG与DoG；相关的卷积实现与频域计算**。沿“处理目的→核→时域计算→频响/相关读数→效果与限制”展开。相关定义已在基本运算建立，这里回答怎样借卷积实现、怎样理解核方向。 |
| 卷积的快速计算 | 输入、核、边界与输出已确定，怎样减少代价，怎样选择算法？ | 五种算法作为subsubsection；分块、存储、浮点误差、NTT/整数恢复和路线选择在相应方法或本小节末解释。读者得到可执行步骤、正确性依据和适用条件。 |

这五个subsection分别承担运算建立、数学规律、坐标表示、处理用途和计算实现。它们使用同一贯穿例，但每次增加一个新问题的答案。

### 4.1 定义要回答“这个运算到底算什么”

进入定义前，用已建立的LTI性质说明：位置r的读数会触发一份平移r格、再乘幅值x[r]的响应。现在要把这些响应在同一输出位置上的贡献合起来。

**定义：有限输入的离散卷积。** 设x为整数轴上的有限支撑实或复序列，h为同一整数轴上逐点取有限值的实或复序列，定义

\[
(x*h)[n]=\sum_{r\in\mathbb Z}x[r]h[n-r].
\]

这里n标记输出位置，r枚举输入位置；由于x有限支撑，每个输出是有限和，h不必有限支撑。有限输入的LTI系统可以有无限脉冲响应，指数平滑就是后面的例子。初次手算再选取有限核h=(1,−1)；讨论完整长度m+r−1时明确双方的有限支撑范围。输入最初若只给有限数组，必须先指定其整数轴延拓。双方均无限时的推广在收敛条件处正式说明。

定义之后只解释这条规则：r处输入在n处的贡献是x[r]h[n−r]。将“为什么是n−r”与已知平移式联系起来，不另造无来源的翻转记忆口诀。

### 4.2 例子要让读者看见“怎样一步步算到答案”

**示例：零延拓下x=(1,2,1)、h=(1,−1)的完整卷积。**

按输入贡献排列：

| 贡献来源 | 输出0 | 输出1 | 输出2 | 输出3 |
|---|---:|---:|---:|---:|
| x[0]=1触发的响应 | 1 | −1 | 0 | 0 |
| x[1]=2触发的响应 | 0 | 2 | −2 | 0 |
| x[2]=1触发的响应 | 0 | 0 | 1 | −1 |
| 逐列相加 | 1 | 1 | −1 | −1 |

固定输出位置1重新计算：

\[
y[1]=x[0]h[1]+x[1]h[0]=1(-1)+2(1)=1.
\]

第一种读法跟踪每个输入怎样影响多个输出；第二种读法跟踪一个输出怎样汇总多个输入。二者是同一卷积的两种计算组织。这一小节到这里形成完整结论：定义有含义，公式可计算，结果是(1,1,−1,−1)。

### 4.3 性质要有“等式、条件、理由、用途”

**定理：有限标量卷积的基本性质。** 对整数轴上的有限支撑实或复序列，卷积满足交换律、结合律和对每个输入的线性。特别地，

\[
x*h=h*x,\qquad
(x*h)*g=x*(h*g),\qquad
x*(ah+bg)=a(x*h)+b(x*g).
\]

证明分别说明换标、有限求和换序和分配律怎样产生这些式子。无限序列另附可和条件；矩阵核的次序另行核查。

紧接定理的普通段落解释用途：先经h再经g的两个固定标量滤波器，可合成核h*g；两个分支相加，可合成核ah+bg。这里的“串联与并联”paragraph承接的正是已证明的性质，不能把三条性质压成一句“还满足交换、结合、分配”。

### 4.4 边界和推广各回答一个新问题

“定义与计算”内部的边界部分回答：为什么同样数据会给四项完整结果、两项valid结果或三项循环结果？用同一数据列出索引与折回过程，再给补零定理。

同一subsection内的连续推广回答：离散位置变成连续时间，累加机制怎样变成积分？先算矩形重叠，再用存在性定理给L1与几乎处处的准确条件。

“矩阵与频域表示”回答：同一映射在新坐标下满足什么关系？定理给频域乘积，矩阵例解释结构，例子核对关系。实际FFT执行步骤及补零选择在“快速计算”中展开。多通道推广再回答“矩阵混合通道与沿时间汇总如何组合”。这些问题各自独立，层级使读者知道当前在解决哪一件事。随后快速计算subsection承接已经固定的同一卷积，把定义、性质、计算方法连成完整学习路径。

## 五、另外两种不同性质的内容怎样呈现

### DFT：定义与可逆性分开，计算与解读连在一起

DFT小节的主问题是“怎样得到N个振荡系数，并由这些系数恢复原记录”。definition固定正变换；theorem陈述逆式与条件，proof给正交依据；example完成同一余弦的系数与延迟计算。Parseval单独回答“换坐标后怎样算平方大小”，幅相段回答“位置变化为什么在相位里出现”。这些问题彼此关联，但不让正逆式、能量式和相位式只成为并排公式。

### Haar、量化与形态学：让不同保证的数学角色可辨认

| 内容 | 要凸显的保证 | 条件和依据 |
|---|---|---|
| Haar | 完整系数可逆、能量不变；删细节误差可精确核算。 | 正交成对变换；先定义前向式，再在定理中一次给逆式和能量结论。 |
| 双通道滤波 | 四个核何时能对每个输入完全重建。 | 消混叠项与纯延迟两条充要条件，推导来自明确计算链。 |
| 金字塔 | 保留残差后逐层恢复。 | 残差定义带来的恒等式，不要求粗层是正交投影。 |
| 量化 | 每个输入的误差至多多少。 | 非饱和最近点量化的确定性界，不等同于随机噪声方差。 |
| DPCM | 编码和解码怎样保持同一预测，当前误差是什么。 | 共享重建历史的归纳证明；不同历史另列误差递推。 |
| 形态学 | 结果如何包含、哪些运算重复不再改变。 | 集合/逐点次序、单调与开闭幂等；与卷积的内积和叠加性质分清。 |
