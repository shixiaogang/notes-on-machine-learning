## 二、重点为什么不突出

### 1. 卷积有四类材料，但被一个下级标题包住

1137—1483的“线性时不变条件下的卷积映射”依次容纳：系统动机与定义、有限脉冲展开、l1推广、网格卷积与存在性、连续L1卷积和Dirac、重叠面积、有限卷积与循环边界、Toeplitz矩阵、valid/same、DFT卷积定理、二维补零、频率响应、多通道和无记忆通道混合。

这些材料大多有依据和例子；障碍是读者不知道自己正在回答哪一个学习问题。具体而言，读者在看到有限数组的第一次完整手算之前，已经经过无穷序列连续性、连续积分卷积与广义单位脉冲。严谨性有保留价值，但可以先完成最小有限情形，再明确推广新增了什么条件。

建议把卷积展开成可辨认的教学阶段：

1. 背景：单个输入会触发一段响应，多个输入的影响怎样叠加；这里限定有限输入并说明所需线性和时不变条件。
2. 定义：先固定索引、边界、输入/核与完整输出，给一维有限公式，解释n是输出位置、r是累计位置。
3. 计算：分别从输入贡献与单个输出读取两种方向计算同一例。
4. 性质：线性、交换、结合、分配、单位脉冲与位移；写出实际等式、条件和用途。标量核的交换律不能不加说明推广到矩阵核。
5. 边界：完整、有效、同长、循环；把边界延拓与输出裁剪分开。
6. 推广：连续积分、无限输入、二维和多通道；说明哪些是同一结构，哪些条件改变。
7. 频域：卷积定理与频率响应、快算法与反演；将“换坐标”同“改变系统”区分开。

不要求每段都机械加“背景、定义、性质”标题；标题与段落应让这些阶段能够被读者实际辨认。

### 2. 有性质，但没有充分解释性质的用途

1213—1217用几句话交代交换、结合、分配。读者还需要知道：结合律如何把串联滤波器合成一个核；分配律如何解释并联相加；核和怎样决定常量增益；绝对和怎样控制幅值放大；共轭反转怎样连接相关和伴随。这些关系比再列一组名词更能形成可迁移的理解。

频率响应在1424—1449已有公式和差分核算例，但通带、阻带、均值核、高斯、振铃和反演稳定性到2803—2938才集中出现。建议设清楚“滤波与频率响应”的职责，先完成这些基础，再由采样节调用抗混叠要求。

指数平滑1510—1527是一个较好的现成教学例：有递推、初值、显式核、频响、阶跃响应和记忆长度。但它位于“线性时变”标题之下，零初值固定系数时实际上是固定卷积，应移作固定核/递归滤波例，再对照自由响应。

### 3. 基础与专门算法在主线中拥有近似的展开地位

对象与表示部分在卷积尚未建立时，已进入DCT整数近似、STFT/Mel及多项式带余除法、Bézout和CRT。快速卷积1956—2535又以580行展开五条路线及Strassen、NTT等分支。这里的行数仅用于定位规模，不能单凭篇幅认定不合格；问题是每条路线对第一卷读者的必要性尚未分层。

建议明确核心路线：直接计算作为基线，矩阵化解释组织方式，FFT解释换坐标与补零，可分离核解释结构节省；Toom–Cook和Winograd保留为有目标的拓展，Strassen递归、CRT完整构造、NTT可移补充阅读。保留推导和边界，不通过删去关键步骤取得“简洁”。多项式背景紧接需要它的计算路线更容易建立用途。

## 四、以本章现成例子说明应补的讲解桥梁

当前已算出`x=(1,2,1)`、`h=(1,-1)`的零延拓完整卷积为`(1,1,-1,-1)`。缺的不是再报一次答案，而是把两种算法视角放在一起。

按输入贡献看：第0个输入1触发`(1,-1,0,0)`；第1个输入2触发`(0,2,-2,0)`；第2个输入1触发`(0,0,1,-1)`。逐位置相加得到最终输出。这里核是一个输入在不同输出时刻产生的响应。

按输出读取看：固定输出位置1，只有`x[0]h[1]+x[1]h[0]=-1+2=1`参与。把位置从0移到3，逐次计算全部输出。这解释为何固定输出后核按反方向读取，也为相关为什么不反转原方向模板建立比较基础。

之后再给性质的用途：两个固定标量滤波器串联对应核卷积，两个分支相加对应核相加；遇到有限裁剪、多通道矩阵核或非线性时，要重新检查能否继承相应等式。这比把性质压成一句“还满足结合律与分配律”更能帮助后续使用。

本段是审读中的说明示例，没有写回正文，不能据此关闭O3/O4。
