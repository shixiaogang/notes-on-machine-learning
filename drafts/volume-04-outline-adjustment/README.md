## 统一的组织方式

1. **模型结构。** 从具体问题进入，定义输入、输出、待学未知量及预测规则；参数、超参数和先验条件分别说明。
2. **参数学习。** 建立训练目标，完整推导模型特有的方程、梯度或更新，说明实际求解、停止与新输入使用。对偶、SMO、IRLS、EM、谱分解等放在所服务的学习过程内。
3. **必要的理论分析。** 有重要工作或实质结论时独立展开，写清假设、推导及结论对象；不能把训练下降、全局最优和样本外效果混为一谈。
4. **具体扩展。** 先解释母模型的能力缺口，再给新结构、学习变化及使用条件；关键扩展单列subsubsection。没有真实从属关系的方法可以相邻比较，不能仅按名字或效果建立父子关系。
5. **共同使用。** 校准、决策、评价、数据组织或部署流程按自身任务讲解；不为了形式一致再造一套模型，也不重复每个基本模型已经说明的本地条件。

全卷采用有主要位置的讲解路线，不声称提出互斥且穷尽的模型分类法。每一层明确当前按任务、构造、准则、信息条件还是使用阶段组织；可组合选择在比较中说明。详细依据见[归属说明](organization-map.md)。

## 本轮整体调整

回归章保留Huber、分位数、SVR在线性回归下，基函数紧随SVR。PCR、PLS直接建立自己的模型与学习；MARS回到自适应选基路线；核岭独立建立目标与解；贝叶斯回归与通用区间校准分开。基函数、GLM和GAM分别解释表示、响应链接与可加函数，再说明如何组合。

分类章把PA独立于感知机，把度量学习作为邻域模型的配套学习单元。多分类公共内容集中3.5，概率校准与代价决策集中3.6，半监督信息集中3.7。树与规则的结构、RIPPER/CN2的学习路线、生成后验与补集计分分别交代。SVM内仍由结构进入学习，对偶与SMO服务参数学习，再讨论理论、软间隔、核与专属扩展。

聚类章分别说明代表、密度、图、凝聚/分裂与混合准则，摘要/网格、子空间与部分监督明确自己改变的对象。CURE、二分K-means、DENCLUE和WaveCluster各自完整展开；有限混合与EM建立共同基础；小批量和代表搜索近似回到母模型。层次输出说明合并次序与数值树高的区别，BIRCH给出摘要接入后续带权聚类及恢复成员的具体流程。

降维章按表示构造组织。稳健PCA的低秩加稀疏分离、非高斯低秩分解放在矩阵分解下；核PCA保留为PCA的特征扩展。LLE、Hessian LLE、LTSA同层比较各自局部目标；概率潜变量模型明确状态或函数的先验、积分与点估计对象，统一评价和新点使用另设公共节。

集成章以并行随机化统摄Bagging、随机森林和Extra Trees。LogitBoost独立于AdaBoost；LightGBM先写树加法结构，直方图等进入学习。Blending归Stacking的数据安排，约束、固定成员门控和多层归其扩展；Super Learner说明候选库开发程序，部署子集、动态选择和蒸馏另行组织。
