# 第四卷的分组依据与内容归属

本方案保持六章，重新整理各层的职责与父子关系。具体标题、公式推导计划和逐段安排见[完整大纲](complete-outline.md)；本文件说明为什么这样组织，以及共同内容在哪里讲。以下均为建议，尚未实施到正文。

## 全卷按什么组织

第1章建立阅读所需的共同认识；第2—5章分别围绕数值预测、类别预测、分组与表示展开；第6章复用已有预测器，讨论成员生成、组合学习与部署。任务章和集成构造承担不同职责，六章不构成一张互斥模型分类表。

章内先比较主要构造，再安排可以跨构造复用的学习路线、信息条件和使用流程。每节入口明确当前依据；不能由“都能提高稳定性”“名称相似”“都用特征分解”推出上下位关系。同一方法只有一个主要讲解位置，其与其他路线的联系留在性质比较或准确回指中。

| 内容角色 | 设置依据 | 标题与段落安排 |
| --- | --- | --- |
| 共同基础 | 多个后续模型确实共用的对象、恒等式或推导 | 先定义共同对象和条件；后续模型保留专属目标与更新，不重复一般证明。 |
| 基本模型 | 可以明确给出自己的未知量、输出规则与学习目标 | 先模型结构，再参数学习；有重要结论才独立安排理论分析。 |
| 模型扩展 | 基本模型存在具体能力缺口，扩展保留其核心并改变表示、输出、约束或信息 | 先解释缺口，再给新结构、学习变化和成立条件；关键扩展可独立为subsubsection。 |
| 学习与计算工具 | 为已经明确的模型求参数或控制计算成本 | 对偶、SMO、IRLS、EM、特征分解、抽样与缓存进入参数学习；确需详述的计算扩展仍明确依附哪个模型。 |
| 共同使用流程 | 适用于多种模型的组合、校准、决策、评价或部署 | 单独设置公共单元，先说输入和交付结果，再给构造与条件；不强套“模型结构—参数学习”模板。 |
| 性质比较 | 解释模型之间的等价、差别或可组合关系 | 明确比较对象和成立条件；不由部分等价建立整个模型的包含关系。 |

## 各章各节的分组与归属

### 第1章：任务、常见方法与研究历史

| 节 | 分组依据与所属内容 | 讲解边界 |
| --- | --- | --- |
| 1.1 从任务确定模型的输出 | 先区分回归/分类，再区分聚类/降维，比较标签、输出与用途。 | 同一批输入可服务不同任务，不能从输入相同推断模型任务相同。 |
| 1.2 常见方法 | 简要介绍特征加权、核、邻域、树与规则、概率及集成方法，说明它们可以组合。 | 核的共同定义与一般展开依据在此建立；具体模型的目标和学习仍在后文。 |
| 1.3 研究历史 | 按五个阶段顺次介绍统计估计与多元分析、模式识别与样本学习、灵活建模与计算统计、统计学习与集成、非线性表示与规模化学习。 | 每阶段简述研究背景、代表工作及发展联系；时间为阅读分期，模型机制和推导留在相应章节。 |
| 1.4 本章小结 | 综合任务、结构、准则与算法的分工。 | 回应本章问题，不复述方法名单。 |

### 第2章：先建立预测构造，再讨论贝叶斯学习与共同使用

| 节 | 分组依据与所属内容 | 讲解边界 |
| --- | --- | --- |
| 2.1 线性回归 | 从全局特征加权出发，依次安排OLS、GLS、系数惩罚、PCR、PLS、Huber、分位数、SVR、基函数、MARS、核岭、GLM、GAM，最后比较这些结构的关系。 | 按用户要求保留“线性回归”总题。各项分别改变误差、方向、惩罚、表示或响应结构；GLM均值与GAM函数在原输入上不必线性，各选择也可以组合。 |
| 2.2 基于邻域的回归 | k近邻聚合和LOESS的局部多项式拟合。 | 查询位置决定参与记录与局部问题；Nadaraya–Watson是局部常数特例，距离权重与内积核分清。 |
| 2.3 基于树的回归 | CART递归分区及线性叶扩展。 | 新输入沿树路径到叶；MARS的基函数相加不归入这里。 |
| 2.4 贝叶斯回归 | 贝叶斯线性回归、高斯过程回归，分别对系数和函数设置先验。 | 这是可复用已有表示的学习路线；有条件响应分布的GLM不因此成为贝叶斯模型。 |
| 2.5 回归模型的选择与预测区间 | 完整流程比较、区间概率解释与独立共形校准。 | 校准接收冻结预测器，适用于不同构造；不挂在GP模型之下。 |
| 2.6 本章小结 | 连接预测目标、结构假设、学习条件和使用流程。 | 分开拟合误差、模型内不确定性与覆盖保证。 |

2.1内部不再为Huber、分位数和SVR另造一类。三者各自建立损失、学习与性质；基函数紧随SVR，单独展开多项式、径向基和样条。MARS再说明如何从数据自适应选择铰链基，核岭则说明在隐式特征空间中进行带范数惩罚的平方拟合。

PCR和PLS各自学习成分方向，再拟合响应；系数惩罚则在给定表示下改变目标。PCR截断与岭收缩有可比较的谱作用，但这种联系不使PCR成为“带惩罚项线性回归”的子模型。GLM改变条件响应族和均值链接，GAM进一步组织可加平滑分量；它们可以复用基函数，不与基函数回归合并。

核岭独立建立学习目标与解；只有均值、核和噪声/正则尺度匹配时，才在GP的性质中比较二者点预测。相同点预测不能把GP后验方差一并转移给核岭。

### 第3章：基本分类构造、公共输出处理与新增信息

| 节 | 分组依据与所属内容 | 讲解边界 |
| --- | --- | --- |
| 3.1 基于投影与参数得分的分类 | Fisher、感知机、被动攻击、SVM、Logistic和Softmax分别建立投影、间隔或概率得分。 | 先完成每个模型的训练；Fisher投影与概率判别的条件对应放在性质比较中。 |
| 3.2 基于类条件统计的分类 | 朴素贝叶斯及高斯判别分析，用按类估计的统计构造分类规则。 | NB/GDA的生成后验与补集NB的补集计分分清，不能都直接写成同一生成后验。 |
| 3.3 基于邻域与原型的分类 | k近邻、LVQ、最近质心是预测规则；监督度量学习LMNN/NCA是配套的距离学习。 | 度量学习独立建立目标，说明它原本服务近邻分类，复用时还须匹配具体预测规则。 |
| 3.4 基于树与规则的分类 | ID3、C4.5、CART、LMT、CTree、规则列表、OneR和决策表。 | RIPPER与CN2是规则列表的不同学习路线；树生长、规则覆盖和冲突处理各自说明。 |
| 3.5 从二分类到多分类 | 组合二分类器、联合多类学习、大类别集的结构与训练。 | OvR/OvO/ECOC只完整讲一次；层次Softmax是概率结构，NCE是估计方法，负采样改变目标，三者不混成同一种模型。 |
| 3.6 概率校准与分类决策 | 误判代价、概率校准、温度缩放、完整流程比较。 | 得分、概率与决策是不同对象；各模型保留默认输出，公共校准和阈值推导集中在此。 |
| 3.7 半监督分类 | 自训练/互教、熵最小化、生成式方法、图方法、低密度分离与保守选择。 | 分组依据是未标记记录进入学习的位置；这些机制可与前面分类器结合，不再冒充新的互斥预测构造。 |
| 3.8 本章小结 | 综合分类证据、概率解释、信息条件与使用决策。 | 不把间隔大、似然高或图上平滑直接等同于样本外分类正确。 |

被动攻击有自己的逐步约束优化目标，因此与感知机相邻独立讲。二类Logistic似然配ARD先验的相关向量扩展保留在Logistic下，但限定当前二类模型；不据此概括全部相关向量回归与分类。图半监督下，标签传播/扩散与拉普拉斯SVM分别建模；后者学习带输入函数的流形正则分类器，不能仅作为前者“支持新点”的附项。

### 第4章：分组准则、表示与学习条件分别说明

| 节 | 分组依据与所属内容 | 讲解边界 |
| --- | --- | --- |
| 4.1 代表式聚类 | K-means、K-medians、FCM、K-medoids、AP共同确定代表及归属。 | 分别改变失真、隶属度、代表约束和代表一致性；小批量、CLARA/CLARANS/FastPAM回到各自母模型的计算部分。 |
| 4.2 用局部密度识别群组 | DBSCAN、OPTICS、HDBSCAN、Mean Shift、DENCLUE。 | 区分密集连接、峰吸引域与阈值以上的密度连接；有层次输出不使HDBSCAN脱离密度定义。 |
| 4.3 从关系图发现群组 | 谱聚类与Louvain。 | 分别使用图割松弛和模块度；谱分解只是学习工具，不把全部谱方法都归为同一分组模型。 |
| 4.4 凝聚与分裂的层次聚类 | AGNES、CURE采用凝聚路线，DIANA、二分K-means采用分裂路线。 | 共同基础先区分两条构造；CURE不隶属于本节具体AGNES链接模型，二分K-means也不等同于DIANA更新。 |
| 4.5 生成混合模型 | 先有限混合/EM共同基础，再GMM、伯努利、多项式、重尾与DPM。 | 具体观测模型各有自己的结构和更新；DPM改变混合先验与成分机制，不能移到“选簇数”的评价小节。 |
| 4.6 数据摘要与网格区域 | BIRCH、STING、WaveCluster分别说明摘要、分层网格统计和小波后区域。 | 是以压缩和聚合数据为入口的讲解组，成员准则仍不同；WaveCluster独立建模，不作为STING扩展。 |
| 4.7 子空间与投影聚类 | CLIQUE、SUBCLU、PROCLUS、ORCLUS分别使用坐标子空间、局部坐标或倾斜投影。 | 明确可重叠子空间群组与给定簇数的单分配差别，不能只用“高维”遮蔽输出和目标的差异。 |
| 4.8 让部分监督信息参与分组 | COP、PCK、Seeded/Constrained、MPCK和关系监督谱聚类。 | 硬可行约束、软罚项、初始化、固定标签、度量与图监督进入的位置不同；复用前面结构，讲清增量。 |
| 4.9 选择粒度并评价用途 | 内部准则、参考划分、预测用途与独立验证。 | 共同使用流程；不能把某个指标、自动成分数或稳定结果当成群组真实的充分证据。 |
| 4.10 本章小结 | 连接群组定义、学习保证、表示条件与用途。 | 比较不同结果的含义，不把全部方法排成统一精度序列。 |

代表、密度、图、层次、生成不是数学上两两互斥的全集分类；它们为当前方法提供主要解释位置。后续摘要、子空间和部分监督又改变数据组织、比较空间或信息条件，各节入口直接说明这一变化，避免把不同层面的选择混称为同一模型差别。

### 第5章：表示如何构造，以及怎样用于新记录

| 节 | 分组依据与所属内容 | 讲解边界 |
| --- | --- | --- |
| 5.1 投影与特征变换 | PCA、CCA、ICA、随机投影从投影或成分变换进入。 | 核PCA、核/深度CCA是各自特征扩展；随机投影生成映射，不能说也从样本学习最优方向。 |
| 5.2 矩阵分解与重构 | NMF、稀疏字典、稳健PCA、非高斯低秩分解。 | 分别限制符号、活跃原子、污染和观测模型；批量分解没有自动给出新点编码。 |
| 5.3 距离与局部几何嵌入 | 先共同距离表/图记号，再MDS、Isomap、LLE、Hessian LLE、LTSA、拉普拉斯特征映射、扩散映射、MVU。 | LLE权重、Hessian能量和切空间排列是不同目标，相关方法同层比较；特征分解不是它们的共同模型定义。 |
| 5.4 邻域相似性匹配 | SNE、t-SNE、UMAP分别构造并匹配高低维关系。 | 可用于布局与表示，不能把可视化效果当作真实簇数、全局距离或新点泛化证明。 |
| 5.5 概率潜变量模型 | PPCA/FA对状态给先验，基本GPLVM对生成函数给先验并点估计坐标，贝叶斯GPLVM进一步推断坐标分布。 | 明确各自积分和估计的对象；EM和编码所需后验先在参数学习中推出，再用于更新。 |
| 5.6 评价与新点使用 | 统一评价对象、训练范围、编码与布局、成本。 | 具体模型保留编码/延拓公式；公共节比较其是否有映射、是否传导及其独立验证方式。 |
| 5.7 本章小结 | 综合保留信息、表示对象、识别条件和使用方式。 | 低维、低秩与稀疏限制不同对象，ICA与过完备编码也不必降低坐标数。 |

稳健PCA的低秩加稀疏分离独立放在矩阵分解中，不因名字带PCA就归为正交投影扩展；稀疏PCA仍以PCA式载荷/重构为基础，保留为真正扩展。核PCA保留方差准则并改变特征空间，仍在PCA下完整讲结构、学习和性质。PCA也有重构解释，MDS也可与PCA对应，这些条件关系在比较处说明，不重复安置模型。

### 第6章：成员生成、组合学习与部署变更

| 节 | 分组依据与所属内容 | 讲解边界 |
| --- | --- | --- |
| 6.1 并行随机化集成 | Bagging、随机森林、Extra Trees以并行随机成员和固定聚合为共同入口。 | 自助抽样、候选特征和阈值随机化分别讲；原始全样本Extra Trees不强归自助抽样。 |
| 6.2 基于Boosting的集成 | 先加法模型/前向逐步共同基础，再AdaBoost、GBDT、LogitBoost、XGBoost、LightGBM、CatBoost。 | LogitBoost按二项损失Newton学习独立；直方图、GOSS、EFB等归训练工具，结构先写可用于预测的树加法。 |
| 6.3 学习组合与候选库选择 | Stacking建立元模型及训练安排，Super Learner说明候选库风险选择与组合程序。 | Blending是留出式元训练安排；约束、固定成员门控和多层是Stacking的结构扩展，不能与总框架误作互斥算法类。 |
| 6.4 成员选择与集成压缩 | 静态子集、动态调用、教师到学生分别改变部署对象。 | 与6.3的开发目标区分；门控与动态选择虽都依赖输入，却不自动减少成员调用。 |
| 6.5 本章小结 | 连接成员差异、误差依赖、理论对象与资源代价。 | 成员更多、训练损失更低或组合更复杂，都不单独保证未来收益。 |

Stacking的折外元特征、基成员重训与外层评价只建立一次；Blending说明如何改变训练数据安排。当前门控扩展固定基成员，通过折外预测学习输入相关的组合权重；不将其改写为共同训练专家的另一套模型。Boosting中SAMME保留算法专属多类更新，通用OvR/OvO/ECOC仍回指3.5。

公共理论只集中一般依据，不能删去模型本地所需的条件和逻辑桥梁。章节间的同类词语也不能替代对象区分：核内积与距离平滑核、软隶属度与后验概率、成分数与真实类别数、训练嵌入与新点映射分别说明。

## 段落怎样展开

基本模型开头用一至两个自然段提出问题并定义对象，随后直接进入结构。参数学习中的多个主要步骤可用有标题的paragraph区分，每组自然段依次给目标、推导、实际求解和使用；单一连续推导直接展开，不为凑层级再加标题。

理论分析只收纳值得证明或比较的实质结论；训练中必须先用到的推导放在参数学习，例如FA的后验矩、SVM的对偶与SMO。扩展先说明基本模型为何不够用，再给改动后的表达式、学习变化与效果所依赖的条件。共同流程则按“已有输入—处理步骤—交付结果—使用条件”安排。

各章小结用自然段回答章首问题，联系主体得到的模型差别与理论边界，再落到使用顺序。小结不重复目录，也不引入未经主体展开的新模型。

## 组织判断的核对材料

整体讲解顺序参考用户提供的[《神经网络与深度学习》](https://rmcong.github.io/DLCourse/book1.pdf)，具体结构以本项目与本次要求为准。部分容易混淆的归属另核对原论文或作者材料：核岭与GP关系见[GPML第6章](https://gaussianprocess.org/gpml/chapters/RW6.pdf)，模型外区间校准见[Lei等的共形回归论文](https://www.stat.cmu.edu/~ryantibs/papers/conformal.pdf)，PA的逐步优化见[Crammer等](https://www.jmlr.org/papers/v7/crammer06a.html)，流形正则学习见[Belkin等](https://www.jmlr.org/papers/v7/belkin06a.html)，WaveCluster独立机制见[原论文](https://www.vldb.org/conf/1998/p428.pdf)。这些材料用于核对机制；本方案的分组是面向读者的编排决定，并不声称存在唯一的模型分类法。
