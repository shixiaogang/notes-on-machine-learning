4.8统一采用旧坐标$x=Px'$、$y=Qy'$。相抵得到$Q^{-1}AP$；同一空间采用同一基时相似为$P^{-1}AP$；双线性型同换两个输入时合同为$P^\top AP$。合同本身不要求矩阵对称。此处先说明二次型正负方向在可逆换元下的对应，不提前用特征值定义惯性或承诺完整分类；实对称惯性判据在6.4以谱和二次目标解释。

### 配对、范数和极值的依赖

5.4.2中的欧氏表示由有限维配方归纳建立，不调用6.3的谱定理：半正定矩阵若所有对角项为零，则两坐标二次型强迫全部交叉项为零；否则交换一个正对角项到首位，配方后的余项仍半正定，继续归纳得到$M=L^\top L$。正定时因子可取可逆。这里只证明加权配对能由欧氏系数实现；6.2的Cholesky讨论可执行步骤、三角存储、代价及退化，回用这一原理。

由Gram矩阵非奇异，给定子空间基后可以解坐标方程，将任意向量写成该子空间分量与正交分量。5.4用它建立正交补和直和，不提前讨论最近距离；6.1以勾股恒等式证明这个已存在的分量恰是唯一最近点，再研究计算实现。

5.5.2中先从实数有界序列的收敛子列逐坐标抽取，得到欧氏空间的闭有界子列性质；再以极值序列证明连续函数的极值存在。任意范数先由坐标基和三角不等式得到欧氏上界与连续性，然后在欧氏单位球面取正的最小值，得到反向下界及有限维范数等价。这样既没有以范数等价证明自身的循环，也为随后的诱导范数、商范数及第六章极值问题提供依据。5.5.6用子空间基扩充后的连续坐标约束证明有限维子空间闭性，再保证商范数的正定性。7.2.1只回用尺度比较和闭性，进一步分析柯西序列、完备性与整列收敛。

5.5.5在加权对偶范数中证明对偶度量由逆矩阵给出，因此原度量增大时对偶单位球收缩，得到正定求逆的序反转。这一结论服务于尺度比较，不再放在无约束二次优化下。

5.9的Schur乘积通过两组Gram向量的张量积证明；一般半正定矩阵的Gram因子已经在5.4建立。因此无需借用6.3的谱分解，也不再出现在二次优化中。

### 幂与矩阵函数的依赖

5.8.1从不变方向和子空间引出特征多项式、重数与实可对角化条件；Cayley–Hamilton和最小多项式解决高次幂怎样约化。古典伴随的余子式恒等式在5.7建立，为Cayley–Hamilton的系数比较证明提供依据；它与5.6的内积伴随明确区分。这里不建立一般矩阵的Jordan分类。

5.8各函数的谱计算明确以给定正交谱分解为输入；实对称谱存在与构造在6.3建立。迭代入口给出更新与可检查的初值约束，精确的谱区间、误差递推和极限证明在7.2.8。指数和对数的级数用前面“极限”章的实级数工具给出当前计算所需的绝对收敛条件，7.2.3研究部分和误差和长时间作用，不重复定义矩阵指数。

逆运算与平方根、对数不再合在同一个算法篮子里：逆要核验$AX-I$，平方根要区分分支及零方向，对数要区分矩阵值与标量log-det；各自的输入条件与输出残差分别组织。

## 第六章：方程和优化

| 节 | 未知量要满足什么？ | 组织与论证依据 |
| --- | --- | --- |
| 6.1 子空间最近点 | 内积距离最小的子空间元素 | 先用既有正交分量和勾股恒等式判存在唯一，再用正交化/QR及Gram系统计算；最后解释投影性质。Givens与Householder都在正交化的实现处建立。 |
| 6.2 线性方程：精确求解 | 满足$AX=B$的输入 | 按相容性、唯一性及选解区分形状和秩；依次给直接法、定常迭代、预条件构造、Krylov方法和核验。精确方程允许没有解。 |
| 6.3 最小二乘：近似求解 | 使残差目标或正则化目标最小的系数 | 普通、加权、正则化目标分别判存在唯一；用正规方程、QR、SVD和迭代求解。系数、拟合值、残差分别核验，差异原则属于这里的参数选择。 |
| 6.4 二次优化 | 满足约束且使二次目标最小的变量或方向 | 按无约束、球面/子空间、等式约束分析，再用配方、谱、零空间/KKT和迭代求解。惯性解释目标的有界方向，矩阵乘积保持等无关工具已移出。 |
| 6.5 矩阵低秩逼近 | 满足秩预算或核惩罚的矩阵近似 | 先定目标，比较规模与误差，判存在唯一；随后分别解秩约束与核范数惩罚。秩约束内部再分完整分解与子空间压缩，随机化SVD/Nyström不再与问题类型平铺。 |
| 6.6 张量低秩逼近 | 满足CP、多线性或TT表示预算的张量 | 先定义模型和目标，再区分存在性与非唯一性，最后按模型组织算法和核验。不能把矩阵截断SVD的最优性直接外推到所有张量模型。 |
| 6.7 正交映射逼近 | 最近的正交映射、部分等距因子或定向变换 | 目标与存在唯一性后，直接法和乘法迭代同属“求解方法”；最后统一核验。迭代趋于部分等距不等于自动获得秩亏时所需的任意正交延拓。 |
| 6.8 对称与谱约束逼近 | 满足对称、半正定或谱范数约束的最近矩阵 | 定义Frobenius目标与可行集合，局部证明闭凸条件下的存在唯一；以对称化、特征值截断或奇异值裁剪求解，再核验可行性与目标误差。 |
| 6.9 矩阵方程 | 满足单侧、双侧、Sylvester或Lyapunov等式的矩阵 | 建立矩阵上的线性作用与相容/可逆条件，再用向量化和实Schur块求解。第六章只作代数判据、对称结构和正定结果核验，不提前使用长期衰减定理。 |
| 6.10 本章小结 | 怎样从目标、结构与精度选择方法？ | 连接精确解、残差最小、结构逼近及矩阵方程；计算可执行不等于误差小，速度与敏感度交给第七章。 |

### 求解工具的首次建立与复用

6.1建立QR与Givens更新，6.2的MINRES/GMRES回用小型QR求投影残差问题，不需要先学一般最小二乘的全部理论。6.2.4先讲SOR，6.2.5据此构造SSOR等预条件，6.2.6才使用PCG等方法；原始残差与预条件残差区分清楚。

6.3的SVD构造先证明实对称谱引理：使用5.5的球面极值、有限代数增量和正交补归纳，再对$A^\top A$构造奇异方向。6.4的Rayleigh问题、6.5的最佳低秩逼近随后回用。6.3的数值秩用于方法选择，首次就说明阈值与尺度；6.5再引入稳定秩和有效秩比较表示预算，不重复定义整个谱分解。

6.5的迹配对不等式服务于“固定奇异值时怎样选择方向”；Schatten对偶与秩相关范数比较服务于误差和惩罚的比较。核范数求解回用方向对齐，把剩下的矩阵问题化为逐个奇异值的标量收缩；6.7和6.8再回用同一迹界，不重新证明。

6.6的CP、多线性秩和TT秩各自先定义再谈闭性。固定CP秩上界的集合可能不闭，最佳逼近未必存在；固定多线性秩或TT秩上界可用有限个展开矩阵的秩条件证明闭性，再以有界最小化序列取极限。CP交替方法每次固定其他因子得到线性最小二乘，局部停止不保证全局最优；HOSVD和TT截断给出各自误差预算，不宣称全局最佳。完整非凸优化理论仍留后续最优化章节。

6.8只在当前矩阵集合上解释凸性，以线段性质和平方距离证明唯一性；存在性用5.5的有界化与极值工具。一般凸投影理论及不等式约束优化仍归后续最优化章。

6.9中Lyapunov算子的可逆性与解的对称性是代数问题；通过Cholesky等方法核验所得解是否正定也是有限计算。由系统衰减推出正定解的构造是另外的问题：离散型在7.2.3用矩阵级数证明；连续型的积分构造及稳定性等价定理由微积分之后的微分方程章承担。不能把后面的积分证明借作第六章的前提。

| 7.2.6 最小二乘迭代的收敛 | 系数、拟合值、残差序列 | 分析步长、奇异值、初值零空间分量及CGLS/LSQR有效子空间，再联系含噪半收敛和提前停止。 |
| 7.2.7 谱方向迭代的收敛 | 幂/逆迭代、子空间近似及实QR更新 | 检查主导间隔与初值，区分方向和向量收敛；用7.1.5的扰动界解释小残差能否保证方向准确；实QR检查分块残差和移位边界，不承诺任意移位都收敛。 |
| 7.2.8 矩阵函数迭代的收敛 | 求逆、逆平方根和极因子序列 | 从误差或标量谱递推分析初值区间、缩放、速度、零方向及舍入；有限步多项式仍单独评价。 |
| 7.2.9 长期误差传播与停止 | 初始误差和每步新增扰动 | 展开传播算子累积，说明持续噪声下限与衰减扰动条件，统一数据精度、计算精度与停止阈值。 |

7.3本章小结按运算/求解问题汇总关键矩阵性质、误差放大和长期行为，不再添加新的工具。条件数与长期增长不可替代：$2I$与$I/2$的二范数条件数同为1，幂却分别增长和衰减；非正规矩阵也可能先放大后衰减。

7.2.2中的一般固定幂先处理有界、振荡、增长和非零投影极限，之后才讨论非负矩阵约束带来的额外结构。Perron主方向、不可约、本原和归一化幂分别交代；随机矩阵只在此解释代数质量保持，概率语义留概率卷。实Jordan仅覆盖特征多项式实分裂情形，一般实矩阵用实Schur块，不引入共轭转置或复向量空间。

- 第一章原1.5.7—1.5.9已删除，不能继续假定其逆、迹和行列式内容是前置。逆的线性映射定义在4.5建立，行列式在5.7、迹在5.11建立。第一章保留基本向量矩阵算术；第四章讨论表示含义，第五章增加运算结构与实现，避免逐项例子重复三遍。
- 子空间距离在第五章定义；第六章求最近点；主夹角和投影差的实际计算在第七章用于比较子空间。三个位置承担不同问题。
- 第六章说明方法能否执行、如何更新及核验；第七章证明敏感度与速度。前章不能省略必要适用条件，后章不重写更新教程。
- 随机化算法先给计算流程及确定性残差核验，成功概率与集中界留概率卷；一般核、无限维谱、弱导数留函数空间章。
