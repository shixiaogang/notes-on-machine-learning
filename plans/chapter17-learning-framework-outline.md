# 第17章：数学基础与后续研究

正文入口：[01-mathematics-and-future-research.tex](../tex/01-mathematical-preliminaries/06-mathematics-and-machine-learning/01-mathematics-and-future-research.tex)。本文件记录现行章节职责和标题。

读者已具备前16章的数学工具。本章依次明确学习对象，将机器学习任务写成规范数学语言，再按对象与分析问题归类并连接前文知识。数据包括环境、观测机制与采样；目标包括损失与约束，并明确评价分布；方法包括候选类、参数化、训练目标构造与优化规则。

## 对象与边界

静态环境是结构 $\mathcal E=(S,\Sigma_S,\mu)$，观测核 $K$ 与环境律生成记录分布 $P=\mu K$，采样机制规定整批样本的联合律 $Q_n$，有限数据为 $D\sim Q_n$。确定性观测是点质量核的特例。动态环境另含初始分布与转移核，观测核和策略核共同诱导轨迹律。

完整设定记为 $\mathcal M=(\mathcal D,\mathcal T,\mathcal L)$，分别表示数据、目标和方法配置。训练、验证、测试阶段统一使用下标 $\mathrm{tr},\mathrm{va},\mathrm{te}$。训练映射 $A^{(k)}(D,U)$ 输出候选；固定模型推理是 $x\mapsto h_D(x)$。训练泛函 $F_D$ 与其参数复合 $f_D=F_D\circ\Phi$ 分开，环境时间、计算步和样本量分开。

全章分为对象定义、任务表述、形式化与方法联系、独立小结四节。

17.2承担规范表述的职责。每类任务从现实背景写到明确的数学对象：集合及其所属空间、映射的定义域和值域、泛函的变量、随机对象的联合律、序列的生成算子与极限参照。随后指定固定条件、变化范围和距离、误差、事件或极限，不能仅用“在某对象上进行某分析”的文字代替定义。覆盖信息与表达、优化与训练、泛化与测试风险评估、预测及发布要求、数据与方法及目标变化、跨分布适应和交互任务。

识别采用环境族上的观测映射与目标映射，恢复采用样本到目标空间的估计映射；训练分别给出目标与可行集、解集、更新算子、读出映射和状态序列。配置变化通过集合值解映射、状态映射和候选映射比较。跨分布任务明确允许的来源—目标关系与目标风险估计器；迁移写出来源信息提取和目标学习的复合，离策略评价区分理论轨迹律、实际记录推前与策略价值泛函。每项任务保留对应的数学比较量，17.3再合并相同对象上的分析问题。

17.2.5比较两种学习配置下的解、轨迹与输出，是用于各类任务的变化分析视角；17.2.6研究一次任务中来源观测如何支持目标评价，明确迁移学习、离策略评价、离线策略选择和在线反馈中的不同分布及信息关系。两者可以共同用于适应任务，但不能把训练—测试分布不同直接等同于修改了一次训练。

识别所依据的是完整可观测规律；只有独立重复采样等充分条件成立时，才能仅用单条记录的分布表示全部观测信息。完整目标风险的识别与良好决策的存在分别讨论；统一风险估计与近似最小化规则共同支持超额风险分析。覆盖保证区分固定训练结果后的测试概率与对构造规则随机性取平均的边缘概率。压缩迭代、投影逼近和图消息计算分别保留固定映射、所用范数及图分解条件。

17.2末尾以三列表汇总机器学习问题、接受分析的数学对象与数学问题。同一机器学习问题合并左列单元格，所需的不同数学路线逐行列出；不能将同一任务的不同分析对象再拆成多个机器学习问题。对象名称、数学问题名称及编号与17.3的数学表完全对应，形成任务到问题、问题到方法的联系。第一列统一使用训练样本、验证样本、测试样本、训练分布、测试分布、测试风险等术语；强化学习明确训练轨迹样本、行为策略与目标策略。对象按所研究的性质确定，不按变化来源确定。17.3基于17.2归类并正式表述数学问题。六类对象为观测核、概率测度与经验测度；候选函数、函数类与表示映射；目标泛函、可行集与解集映射；计算算子与迭代序列；学习映射与随机输出律；联合策略、状态转移与轨迹律。各对象分节下再按28个数学问题设置三级标题，标题与两表的问题名称对应，共同对象定义保留在分节导言。每类问题用现实困难与比较量解释公式，再说明条件为什么支持相应工具，连接前1—16章的知识入口；不在本节展开具体推导、误差界或算法结论。末尾将对象、数学问题与相关知识合为一表，跨行合并同一对象及同一问题的单元格，各分析路线注明条件及前文节或小节位置。

存在性、表示、识别、估计、计算、优化、收敛和扰动是各对象上的分析问题。修改同一训练记录后，理想解的敏感性、迭代轨迹的偏差、有限步候选的变化分别归入解集映射、更新算子与序列、学习映射；不同对象可以共享分析思路，但须分别核对成立条件。

方法联系包括训练轨迹的误差传播、数据与方法的响应、目标与约束敏感性，以及区分模型变化和评价分布变化的比较方式。各类问题在17.3内按对象说明，不再另设按分析类型组织的第二轮讲解；具体推导和模型专属结论由后卷展开。17.4为独立本章小结，标签兼容见 [chapter17-retired-labels.json](chapter17-retired-labels.json)。

覆盖范围还包括给定模型的概率推断与生成、结构对称性与信息保留、多目标与尾部风险、内外层学习、计算正确性与资源、采样分布极限、统计恢复，以及主动信息获取。隐式选解、参数测度与随机预测器、结构搜索、数值近似、序贯评估、解释归因和激励条件分别接回上述对象，不按算法名称另设平行门类。

17.2和17.3建立后续已接入正文及范式、应用大纲的通用问题入口；具体模型专门结论由后续主讲章节建立。前置专用公式仍缺少的条目继续由[数学依赖待办](mathematical-dependencies.md)记录，不能将本章中的方法入口视为这些公式已经补齐。
