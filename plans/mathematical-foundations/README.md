# 数学基础五卷目录

本目录保存五卷、十七部分框架，以及当前九十个章目，作为后续逐部分讨论的起点。第一部分“集合”独立设置“集合、关系与映射”“计数”“基数”三章；第二部分“实数与一元函数”设置“实数、复数与函数”“极限与连续”“一元函数的微分”“一元函数的积分”四章。

每个部分一份文件，按讨论进度逐步细化。第一至第十二部分已给出节、小节及自然段提要讨论稿，必要处另标出关键 paragraph 标题；第三部分采用先谱后方程的章序，并补充矩阵函数的扰动分析，明确有限维分析与卷二一般空间、测度积分的分工。第四部分“图”采用六章结构，依次讨论图与连接、结构计算、组合优化、集合函数、图上的动态规划和图上的谱方法；树分解按定义、构造、计算展开，谱方法置于最后，各计算问题按需要区分共同基础、算法与分析检验。

第五部分“概率与统计基础”保留五章，依次研究随机变量与概率分布、随机向量与联合分布、样本与参数估计、抽样分布与估计误差，以及区间估计、假设检验与预测。多元高斯和简单线性回归分别作为第二章、第五章末的综合应用；条件概率先于无记忆性，弱大数定律的截断论证支撑有限二阶矩下的样本方差一致性。

第六部分“度量与测度”按“度量空间—测度—积分—密度与换测度”四章展开。第一章区分连续映射的性质与空间之间的比较；第二章建立测度、可测映射、测度关系及分解；第三章从简单函数积分与逼近完整建立一般积分，比较求和及经典积分，按条件组织积分极限与换元，并讨论累次积分、含参积分与微积分基本定理；第四章集中研究密度的定义、存在性、运算规则，以及离散测度、增量测度和推前测度的密度计算。测度分解不借用密度证明，积分构造不以密度为前提；密度理论在已有测度与积分基础上连续展开。条件信息与概率收敛留到第七部分，分布距离与运输留到第十三部分。

第七部分“概率空间”保留四章，按一般概率模型与随机对象、条件期望与条件分布、同一概率空间上的随机变量收敛、分布弱收敛与极限定理展开。条件期望采用Radon–Nikodym路线，条件分布之前先建立概率核；强大数定律由独立和的最大偏差、级数收敛与截断推出，中心极限定理由特征函数建立。条件均方误差与平均收敛不以前置泛函分析为基础；信息随时间变化、鞅和过程构造留到第十部分，分布族与差异比较留到第十三部分，统计渐近推断与因果识别留到第十四部分。

第八部分“函数空间”调整为六章，依次为函数空间、线性泛函与线性算子、算子谱与算子方程、弱导数与Sobolev空间、再生核Hilbert空间，以及函数与函数类的逼近。第一章先建立共同的范数、完备性与Hilbert几何；第二、三章连续研究泛函与算子的共同性质、方向分解和方程；随后在这些工具之上展开带微分约束、点值观测要求的特殊空间与有限逼近。条件期望只增加投影解释，核空间构造与Mercer表示集中在第五章；一般对偶、弱星紧性及较抽象的推广安排为补充。泛函变分、最优条件、正则化及函数拟合归第九部分，演化与具体微分方程归第十部分，频域表示及采样重建归第十一部分，核均值嵌入与分布比较归第十三部分。

第九部分“优化”细化为九章，依次研究优化问题与解、线性规划、光滑优化、非光滑与复合优化、约束优化与对偶、随机与分块优化、多目标、极小极大与双层优化、函数拟合与正则化，以及泛函优化。线性规划集中建立模型、基本可行解、单纯形与对偶证书，参数敏感性和松弛问题分别展开；函数拟合集中处理观测、正则化及数值选解，泛函优化按微分、最优条件、积分变分、存在性和有限维近似组织。有限维投影先作为邻近映射的特例建立，约束算法调用所需性质，一般Hilbert投影再在泛函优化中推广。函数空间结构由第八部分提供，连续演化与具体微分方程由第十部分承接。

第十部分“过程与轨迹演化”收拢为六章，已补充节、小节和关键自然段。前三章依次研究离散动力系统、常微分方程和偏微分方程，各自集中求解、稳定性与数值计算；第四章建立随机过程与样本路径的共同基础；第五、六章分别研究离散时间和连续时间随机过程。Markov、鞅、停止与长期行为按两种时间情形组织，连续章简短回顾离散结论，再说明新增条件。采样积分和随机逼近分别安排在两章的应用节，过程极限置于连续章末作进阶阅读。优化的算法设计与有限步误差、统计推断的目标识别与不确定性、信号部分的状态估计保持各自职责。

第十一部分“信号与状态估计”按信号的表示与比较、信号系统、采样与信号恢复、随机信号、一般信号估计，以及基于状态模型的信号估计六章展开。随机信号集中建立相关、频谱及其变化；一般估计独立建立目标、信息和均方准则，再研究线性估计、Wiener和自适应方法；状态模型进一步提供预测、校正、平滑与联合轨迹恢复的递推结构。一般估计同样可以处理时间问题并依赖概率模型，过程传播工具仍由第十部分提供。

第十二部分“流形”按六章展开：流形与光滑映射，度量、曲线与几何移动，群、对称与变换空间，流形上的微分与积分，流形上的优化，以及有限观测的几何重构。第一章连续建立对象的定义、基本性质和构造，再讨论切空间、映射与场；第二章集中研究度量、方向比较、测地初值与端点最短路径。第三章把射影与子空间作为商对象集中展开；第四章将体积积分与数值计算相连；第五章将回缩的定义与构造、拉回目标、局部模型及信息搬运集中在迭代计算中，再分方法与综合实例；第六章按坐标、变换、切空间、内在距离和拓扑的恢复问题组织。各自的条件、误差与适用边界跟随相应问题；形式积分、微分算子和一般商结构仍为拟补充范围，正文尚未迁移。

第十三至第十七部分保留章级目录和必要的内容衔接说明。第四部分的六章、第五部分的五章、第六部分的四章、第七部分的四章与第八部分的六章已实施到正文；其余目标安排不表示相应正文已经完成迁移。

章目标识采用“部分号.部分内章序号”，用于讨论定位，不作为当前正文的正式章号。已细化部分的节使用“章序号.节序号”以便阅读。当前十五卷的正文提要仍见[大纲与目录总索引](../README.md)，两者的数量分别统计。
