# 数学基础五卷目录

本目录保存五卷、十七部分框架，以及当前九十个章目，作为后续逐部分讨论的起点。第一部分“集合”独立设置“集合、关系与映射”“计数”“基数”三章；第二部分“实数与一元函数”设置“实数、复数与函数”“极限与连续”“一元函数的微分”“一元函数的积分”四章。

每个部分一份文件，按讨论进度逐步细化。第一至第五部分已给出节、小节及自然段提要讨论稿，必要处另标出关键 paragraph 标题；第三部分采用先谱后方程的章序，并补充矩阵函数的扰动分析，明确有限维分析与卷二一般空间、测度积分的分工。第四部分“图”采用六章结构，依次讨论图与连接、结构计算、组合优化、集合函数、图上的动态规划和图上的谱方法；树分解按定义、构造、计算展开，谱方法置于最后，各计算问题按需要区分共同基础、算法与分析检验。

第五部分“概率与统计基础”保留五章，依次研究随机变量与概率分布、随机向量与联合分布、样本与参数估计、抽样分布与估计误差，以及区间估计、假设检验与预测。多元高斯和简单线性回归分别作为第二章、第五章末的综合应用；条件概率先于无记忆性，弱大数定律的截断论证支撑有限二阶矩下的样本方差一致性。其余部分保留章级目录和必要的内容衔接说明。第五部分的五章已实施到正文；其余目标安排不表示相应正文已经完成迁移。

章目标识采用“部分号.部分内章序号”，用于讨论定位，不作为当前正文的正式章号。已细化部分的节使用“章序号.节序号”以便阅读。当前十五卷的正文提要仍见[大纲与目录总索引](../README.md)，两者的数量分别统计。
