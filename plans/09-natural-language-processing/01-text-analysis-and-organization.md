# 卷9《应用：自然语言处理》：第1部分"文本分析与信息组织"大纲

正文入口：[tex/09-natural-language-processing/01-text-analysis-and-organization/part.tex](../../tex/09-natural-language-processing/01-text-analysis-and-organization/part.tex)。章号按本卷连续编号，以下标题和顺序对应当前入口实际接入的正文。

本部分接入四章，从 NLP 总体图景进入词法、句法、语义、篇章与语用分析，再到实体、关系、事件等信息抽取与知识记录构建，最后落到文本分类、匹配与集合组织。

## 第1章 自然语言处理概述

- **语言处理的需求与应用场景**：以读书会通知等教学案例引入检索、问答、生成、翻译等典型任务，说明任务输入、输出与评测口径。
- **自然语言处理的基本概念**：区分词形、词义、句法、语义、语用等层次，介绍语料、标注、参数与模型在 NLP 中的位置。
- **自然语言处理的研究内容**：梳理从规则方法、统计方法到神经与大模型方法的问题谱系，串联后续章节的技术脉络。
- **自然语言处理的研究历史**：按年代综述机器翻译、信息检索、统计 NLP、深度学习与预训练模型的关键节点。
- **本章小结**。

## 第2章 文本分析

- **词法分析与局部标注**：分词、词性标注、命名实体边界等序列标注问题，含 HMM、CRF 与神经模型对照及手算算例。
- **句法分析**：短语结构与依存句法，PCFG、CKY、转移系统与图模型，给出可复核的句法推导过程。
- **语义分析**：词义消歧、语义角色、语义组合与分布式表示，讨论向量空间与上下文表示的关系。
- **篇章分析**：指代、共指、话语关系与篇章结构，覆盖共指消解模型与话语解析。
- **语用分析**：语境、言语行为与含义推断，说明语用现象如何影响任务建模。
- **本章小结**。

## 第3章 信息抽取与知识构建

- **实体识别与身份确定**：命名实体识别、实体链接与身份消解，含跨文档实体对齐与消歧算例。
- **实体关系抽取**：关系分类与关系抽取流水线，覆盖监督、远程监督与文档级关系抽取数据集。
- **事件抽取**：事件触发词、事件类型与论元抽取，区分句内与跨句事件。
- **事件关系抽取**：事件之间的时序、因果与顺承关系构建。
- **知识记录的构建**：从抽取结果到结构化知识记录的整合、规范化与存储。
- **本章小结**。

## 第4章 文本分类、匹配与组织

- **文本分类与属性判定**：文本分类范式、特征表示与多标签/多类判定，含分类器对照。
- **文本匹配与关系判定**：同义、蕴含、相似度等匹配任务，双塔与交互模型结构。
- **文本集合的组织**：聚类、主题模型与文档集合的层级组织方法。
- **本章小结**。
