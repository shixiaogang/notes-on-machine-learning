# 个性化、搜索、推荐与广告研究课题分类

## 主体任务与问题扩展

本部分以推荐为主线，主体按理解、选择和展示组织：理解当前需求及对象，召回候选并估计响应，形成列表、页面与交互。搜索在这条主线上加入显式查询和相关性条件，广告加入广告主、付费机制、竞价与预算条件。

多目标、长期价值和约束扩展基本任务的目标、资源及时间范围。反馈、信息不足、时效性和探索根据作用对象进入各环节：行为为理解提供证据，训练标签支持评分，拒绝和测试反馈改善展示，日志和实验检验效果。

课题编号继续作为二十项问题的索引，分组和主要讲解位置按当前路线调整。编号不代表章节，同一问题可以影响多个环节；详细安排见[十章大纲](recommendation-and-search-outline.md)，模块关系与演进见[应用架构与研究地图](recommendation-and-search-architecture.md)。

研究课题提供问题索引，章纲在任务之下进一步展开具体模型。重要模型设独立编号，父节说明共同任务与分类关系，小节写输入、计算、训练与使用、例子和边界。DIN、DIEN、DSIN、MIMN、SIM、TWIN等主讲历史理解；MIND、ComiRec主讲多兴趣候选取得；FM、FFM及深层交互主讲给定候选的评分；MTGR、OneTrans和MixFormer主讲完整评分骨干，OneTrans-V2主讲跨阶段共享；MMoE、PLE主讲多行为预估，不替代多目标决策。生成标识、生成列表和文字辅助推荐分别按输出进入任务。具体位置与来源统一由[模型大纲](recommendation-and-search-outline.md)和[文献地图](recommendation-and-search-literature.md)维护。

| 内容层次 | 主要问题 | 课题索引 |
| --- | --- | --- |
| 主体：理解 | 怎样理解需求与对象，信息不足、来自其他场景或已经过时时怎样判断？ | T01、T02、T05—T07 |
| 主体：选择 | 哪些对象进入比较，反馈怎样支持可靠评分与排序？ | T03、T04、T18 |
| 主体：展示 | 多项内容怎样组合、表达和交互，怎样利用拒绝及测试反馈改进展示？ | T14—T17、T08 |
| 问题扩展 | 多目标、有限机会、约束与长期影响怎样改变基本任务？ | T09—T13 |
| 效果评价 | 哪些比较、日志及实验可以支持改进结论？ | T19、T20 |

## 一、理解

理解按用户、对象及两者的匹配关系组织：用户行为支持需求判断，对象内容与关系说明供给，匹配任务建立两者的对应。冷启动及跨场景问题在这里明确缺少什么证据，选择和展示章节再展开相应行动。

| 编号与研究课题 | 要研究的具体问题 |
| --- | --- |
| **T01 用户行为、兴趣与当前需求建模** | 给定截至当前可见的历史与情境，怎样判断现在需要什么？怎样理解行为类型、顺序与时间间隔，并选择、检索或压缩长历史？怎样结合多种兴趣、短期行为和长期历史？怎样将查询、当前操作和情境转为当前请求的匹配依据？ 群组请求怎样聚合成员偏好，时间及空间关系何时提供有效的需求条件？ |
| **T02 对象理解与匹配关系** | 怎样结合文本、图片、视频、属性和交互关系理解商品、内容及广告？怎样区分主题相似、用途相近、替代与互补？怎样把用户的具体要求与对象属性、关系和可用性对应起来？元数据缺失、质量差异、库存变化或素材与真实对象不一致时怎样维持可靠匹配？ 用户社交关系与对象知识关系提供哪些不同证据，怎样与内容及交互共同支持匹配？ |
| **T05 冷启动、稀疏反馈与长尾** | 新用户、匿名用户缺少历史时怎样形成初始候选和排序？新物品、新广告、新商家缺少交互时怎样利用已有内容和有限测试机会？已有用户或对象只有少量交互时怎样处理不确定性，避免被热门先验淹没？怎样分别评价无交互、训练时未见及长期低曝光这些条件下的效果？ 稀疏群组与目标域少反馈怎样借助成员或来源域信息，补充依据何时失效？ |
| **T06 时效性、分布变化与在线适应** | 新行为、热点、供给与环境变化后，怎样发现表示和预测已经过时？画像、历史窗口、候选目录和模型应何时更新，怎样处理反馈滞后？怎样应对需求及响应分布变化，并保留仍然有效的旧信息？怎样评价变化后的恢复、更新延迟与适应代价？ |
| **T07 跨场景信息利用与协同个性化** | 搜索、浏览、推荐、广告及购买行为之间哪些信息可以共享？跨产品、渠道、地区和设备的身份、对象及行为含义怎样对应？什么时候共享信息有帮助，什么时候因目标或人群不同造成负迁移？身份缺失、隐私限制和只能取得聚合数据时，哪些个性化判断仍可完成？ 怎样区分跨目录偏好迁移与共享目录的场景适配，怎样在分散交互图和受限交换下保持有效协同？ |

T01研究当前可用信息怎样形成需求判断，T06研究变化后怎样使判断保持有效。需求和画像更新在理解中展开，目录更新在召回中展开，响应与模型变化在排序中展开，流量及市场变化由广告投放补足；跨时间效果在评价章检验。

## 二、选择

召回决定哪些对象取得比较机会，排序为这些候选估计响应与价值。反馈在这里解决学习目标是否明确、观测机制是否扭曲评分的问题，必要的标签及校正机制随任务建立。

| 编号与研究课题 | 要研究的具体问题 |
| --- | --- |
| **T03 个性化候选召回与融合** | 怎样在大目录中覆盖主要兴趣、次要兴趣和潜在需求？协同、内容、热门、历史、查询等候选来源怎样分配召回数量和去重？怎样兼顾热门、长尾、新物品与新内容，避免后续排序永远看不到某些对象？怎样按目录检索或访问、生成对象标识两个接口比较候选路线，并区分接口、内容与协同证据及具体方法？不同业务目标怎样调节生成候选的分布，共享用户骨干怎样与下游排序协同？怎样在命中、合法对象、目录更新、时延和成本上作出取舍？ 多行为、社交图、VAE交互分布及扩散连续目标怎样接入目录访问，生成训练与标识生成怎样区分？ |
| **T04 个性化排序与响应价值预估** | 应预测点击、观看、购买、满意度还是其他后续行为，各自的标签与时间窗口怎样定义？候选对象、用户历史和当前情境怎样共同决定响应价值？字段交互与历史聚合怎样融合或进入共同评分骨干，参数容量、历史长度与实际计算怎样协调？概率校准、分组误差和候选分布变化怎样影响排序及商业决策？召回、粗排、精排和重排的截断怎样传递误差，共享表示、联合训练和蒸馏怎样协调阶段目标？ 推荐增量与响应概率怎样分别服务排序，不确定性如何支持回退而不被当作校准概率？ |
| **T18 反馈标签、观测偏差与可靠学习** | 没有点击或购买意味着不感兴趣、没看见、没机会还是尚未反馈？曝光、位置注意、位置带来的信任、流行度与从众、点击选择、训练负采样、延迟和追踪缺失分别怎样改变训练数据？显式偏好、行为反馈、人工相关性与伪标签怎样使用，怎样识别误点、刷量和标签污染？哪些校正需要倾向、覆盖或观测机制假设，怎样检查其在实际日志中是否成立？ 受保护更新怎样学习评分，恶意客户端或伪交互怎样改变模型完整性，撤回后怎样移除参数及协同表示中的影响？ |

训练负采样、系统曝光、位置注意和用户选择属于不同机制。多种响应的联合预测提供决策信息，多目标之间的取舍由问题扩展展开；训练标签的可靠性与策略真实效果的识别分别建立。

## 三、展示

展示的决策单位是列表、页面、素材及交互。对象关系、来源、位置与表达共同影响效用，拒绝反馈帮助调整展示，探索曝光用于取得尚缺少的对象价值信息。

| 编号与研究课题 | 要研究的具体问题 |
| --- | --- |
| **T14 列表效用、多样性与组合推荐** | 怎样覆盖不同兴趣、查询方面和选择需求，而不是反复展示相似对象？怎样协调相关性、多样性、新颖性和意外发现？互补、替代、兼容性和组合预算怎样改变整组对象的价值？逐项排序、重排和直接产生列表应怎样比较，并检验组合是否有效和可用？ 列表类别构成怎样对应有证据支持的兴趣分布，怎样区分构成匹配与单纯增加类别数量？ |
| **T15 统一混排与整页决策** | 自然推荐、查询结果、广告、促销及不同内容类型怎样进入同一个展示方案？不同来源的分数和收益怎样形成可比较的决策依据？类型数量、插入位置、间距、栏目和页面布局怎样联合确定？广告与自然结果的重复、替代、互补和注意竞争怎样进入整页效用，怎样协调用户目标与收入及投放约束？ |
| **T16 营销感、重复疲劳与负反馈** | 怎样区分内容无用、密度过高、反复出现、打断任务及素材质量造成的营销感？广告或促销负载应怎样随用户、查询、会话阶段和近期曝光变化？同素材、同商品、同品牌的频次、间隔和轮换怎样控制？怎样联合使用关闭、跳过、快速返回、投诉、主观调查及长期行为评价体验，并利用拒绝反馈调整展示？ |
| **T17 内容、创意与呈现方式优化** | 同一对象的标题、图片、视频、解释和优惠信息怎样影响理解与选择？怎样让素材满足当前需求，同时与对象事实、价格和落地页面一致？怎样从大量素材组合中选择或生成候选，并为新创意取得可靠测试数据？怎样联合决定展示对象与素材，区分内容价值、呈现吸引力、误点和创意疲劳？ 理由是否忠实于实际评分器，反事实解释怎样通过重评分验证，又为何不足以证明用户真实动机？ |
| **T08 探索、主动询问与信息获取** | 什么时候应该展示不确定但可能有价值的对象，而不只利用已有偏好？怎样给新内容、新商品、新广告和新创意分配试验机会？怎样在合适时机询问偏好、澄清查询或收集拒绝原因？取得信息的未来收益怎样与当次体验损失、交互负担和试验成本比较？ 询问与推荐怎样组成会话行动，工具规划怎样取得分散信息，级联检查与单行动反馈分别支持什么探索？ |

### 将“营销感”落实为可研究对象

“营销感消除”可以作为应用目标，但写作时需要说明具体减少什么。付费广告、自然推荐中的促销内容、同品牌集中和重复优惠信息都可能贡献营销感，广告数量只是一个因素。

| 研究对象 | 可以决定或干预什么 | 需要观察什么 |
| --- | --- | --- |
| 密度与连续出现 | 每屏或每段内容中的广告、促销数量，占用面积及连续出现上限 | 找到所需对象、任务完成、消费深度、退出与收入 |
| 重复与频次 | 同素材、商品、品牌的次数、曝光间隔和素材轮换 | 跳过、关闭、响应衰减、负反馈及回访 |
| 位置与打断 | 首屏位置、插入时机、广告间距及自然内容被推后的程度 | 任务耗时、快速返回、误点、退出及用户调查 |
| 相关性与内容质量 | 是否满足查询和情境、信息是否可靠、素材与对象是否一致 | 实际消费价值、投诉、满意度及信任调查 |
| 相邻内容的关系 | 去重、同品牌集中、替代与互补、促销对有用内容的挤占 | 整组选择质量、需求覆盖及广告与自然内容的共同收益 |
| 用户控制与拒绝反馈 | 关闭、减少此类内容、跳过和拒绝同品牌后的策略调整 | 反馈使用率、后续负反馈与体验变化 |

关闭、退出或点击下降各自只能表达一部分体验，不能单独等同主观厌烦。广告识别与打扰感也应分别测量：减少营销感重点在内容价值、密度、重复、位置和用户控制。

列表、布局、表达、负载和营销感在同一章集中讲解。频次和疲劳的定义及具体策略也在这里建立；长期价值课题复用这些状态、行动与结果，分析跨请求影响。

主动询问的信息缺口在理解章建立，询问与推荐组成的会话行动在展示章展开；候选机会在召回章讲，测试流量和曝光在展示章讲，新增信息的未来价值在长期决策中展开。工具规划取得分散信息与真实长期效应需要不同证据。

## 四、问题扩展

在理解、选择和展示建立之后，扩展优化目标、约束和时间范围。多目标改变取舍，有限资源改变可执行方案，长期价值要求分析当前行动对之后需求、信息与收益的影响。

| 编号与研究课题 | 要研究的具体问题 |
| --- | --- |
| **T09 多目标权衡与受约束决策** | 点击、消费、成交、满意度、收入、投诉和任务完成怎样共同参与选择？目标采用权重、阈值还是硬约束，各自表达什么业务要求？目标尺度、冲突程度和用户差异变化时怎样调整权衡？怎样检验整体平均提升是否掩盖某类用户、对象或提供者的损失？ 怎样控制最终推荐集合的平均错误风险，统计保证与每请求质量、兴趣构成匹配怎样区分？ |
| **T10 供给机会、曝光分配与生态** | 怎样在热门、长尾、新供给及不同提供者之间分配有限展示机会？应比较展示次数、位置注意、实际消费还是最终收益？怎样同时满足质量、库存、服务容量、地域和提供者机会要求？展示改变供给行为、价格或内容生产后，怎样评价平台生态和集中程度的变化？ |
| **T11 长期价值与反馈循环** | 怎样协调当次点击、成交与回访、留存、持续满意度和信任？反复展示会强化兴趣、造成疲劳还是缩窄用户看到的内容？当前行动怎样改变之后的需求、行为和可学习数据？怎样取得支持长期结论的证据，避免把下一行为预测或短期提升直接当成长周期收益？ 旧策略形成的训练数据怎样影响下一轮模型，创作者怎样响应机会并改变后续目录，怎样分离数据、兴趣与供给的共同变化？ |
| **T12 搜索中的查询相关性与条件满足** | 结果是仅与查询同主题，还是满足实体、用途、价格、时间、地点及关系条件？精确查询、含糊查询、探索式需求和多轮查询应怎样定义相关性？个性化怎样帮助消歧与偏好选择，怎样避免历史兴趣把结果带离当前查询？什么时候采用过滤、相关性阈值或联合排序，什么时候需要澄清、补充证据或继续检索？ 参考图片与文字修改如何组合，当前查询怎样约束历史个性化，多跳证据何时需要迭代行动或关系访问？ |
| **T13 广告中的竞价、预算与投放约束** | 某次请求中哪些广告满足定向、时间、素材与投放资格？给定广告主价值、收费方式、竞争价格和获胜概率，应怎样出价与分配广告机会？预算怎样跨时间、渠道、人群及潜在机会分配，怎样控制消耗节奏、成本和投产比？怎样处理预算不足、机会变化及多个自动竞价器相互响应，并检查累计约束和实际违反情况？ |

查询相关性需要分级比较，可验证的价格、时间等条件可以明确设约束。预算需要跨请求分配，投放资格、拍卖支付和预算策略分别讲解。搜索与广告专题把这些特有条件同共同任务串起来。

## 五、效果评价

评价检验应用改进是否成立，统一比较条件、策略覆盖、因果增量及实验。各任务章仍需先解释自己的指标和失效条件。

| 编号与研究课题 | 要研究的具体问题 |
| --- | --- |
| **T19 因果增量、归因与真实效果** | 展示某对象造成了多少额外点击、成交或满意度，而不是只预测哪些人本来就会行动？多次曝光、跨设备和跨渠道怎样分别影响路径信用分配与增量识别？自然推荐与广告互相替代时，怎样评价整体增量，而非只计算广告名下的成交？预算共享、竞价竞争及社交传播造成实验干扰时，怎样设计识别条件和对照？ 个体及多处理、多结果的效应怎样估计，追踪受限时带噪归因统计、聚合媒体曲线和实验校准分别支持什么结论？ |
| **T20 评价协议、在线实验与诊断** | 怎样固定预测时点、可用信息、对象目录、候选集合和标签窗口，避免未来信息泄漏？怎样分别评价召回、排序、列表、混排、预算策略和长期体验？离线指标、日志策略评价、随机实验和长期对照分别支持哪些结论？怎样按用户、查询、供给方、内容类型及时间诊断失败，并区分方法收益、更多数据和更多计算资源的收益？ 不确定性、隐私泄漏、数据撤回和生态演化各需什么额外验收，怎样区分基准适应成绩与真实干预效果？ |

归因给路径分配信用，因果增量判断展示造成多少额外变化。离线预测、日志策略评价和随机实验需要不同证据，不能仅以反馈数量或训练损失证明展示策略有效。

## 搜索与广告应用专题

理解、选择和展示提供共同任务，问题扩展补充目标、约束及长期条件，搜索与广告专题仍需完整讲解各自过程。T12、T13登记特有问题的归属；搜索与广告专题分别把这些问题同召回、排序、展示和评价连接起来。专题范围与主要讲解位置以大纲为准。

| 应用专题 | 需要系统展开的任务 | 与共同主体的分工 |
| --- | --- | --- |
| **搜索应用** | 查询意图与限定条件；词项、语义及结构化候选检索；相关性标注和学习排序；个性化搜索；结果去重、方面覆盖和结果组织；会话搜索、澄清与探索；按查询类型评价任务完成。 | 查询输入、相关性及结果组织在专题完整讲。召回、个性化排序和反馈偏差引用共同主体；分词、实体识别、语言理解、对话及答案生成只交代所需接口，原理衔接NLP。 |
| **广告应用** | 关键词、定向和情境匹配及投放资格；点击、转化和价值预估；竞价、拍卖分配与支付；预算节奏、成本和投产比；跨渠道投放；广告与自然内容混排、负载和频次；创意选择；归因与增量效果。 | 广告主目标、收费、拍卖与跨机会资源分配在专题完整讲。通用响应预测、列表、多目标和因果评价引用共同主体，同时补足广告中的转化条件、反馈延迟及竞争干扰。 |

搜索专题需要保留BM25等词项检索基线，并解释怎样与语义、混合和生成标识检索比较；广告专题需要将预测响应、分配展示、收取费用和控制预算分别讲清。两个专题都通过具体场景检验共同方法的适用条件，不能只简写为增加一项约束。

## 经典方法与新研究方向的讲解位置

研究问题决定主体结构，方法小节回答这些问题怎样解决。经典方法及新方向都需要明确的首次讲解位置，不能仅列在历史或章末展望中。当前模型卷没有协同过滤、推荐矩阵分解、FM、FFM的专门讲解；降维章的PCA和NMF也没有建立推荐中的缺失交互目标。因此，这些方法在本应用部分首次出现时应讲齐必要机制，前文只提供已存在的线性模型、损失、正则化与优化基础。

| **协同过滤（collaborative filtering, CF）** | 选择中的T03，3.2.1“基于目录检索的召回”中的协同信息方法；理解中解释证据 | 协同过滤利用不同用户和物品之间的交互关系推测偏好。完整讲用户邻域、物品邻域、相似度、邻域加权及候选构造，再与内容匹配比较；应用的稀疏与曝光条件在T05、T18继续检验。 |

## 后续写作边界

后续章纲按理解、选择与展示组织主体，多目标、约束与长期价值作为问题扩展，搜索和广告专题再串起各自过程。模型与范式部分已经讲过的网络结构、迁移、对比学习、强化学习等只回顾接口；应用方法尚未建立的必要机制须在首次出现时讲完整。查询语言分析、对话生成和内容生成衔接NLP及图像和多模态处理；索引、特征存储、训练服务与监控工程归系统卷。生成式召回、语言模型重排、列表生成和对话选择按各自产生的输出归入相关课题，每章明确主分类维度及共同问题，具体模型下移到相应任务；多轴交叉用坐标表表达，新方向保留角色索引。

本文提供研究范围和分类，章纲已重编为[十章大纲](recommendation-and-search-outline.md)：推荐概述1章，理解1章，选择2章，展示1章，问题扩展2章，效果评价1章，搜索专题1章，广告专题1章。反馈与变化按作用对象分配到各任务，主讲位置以大纲中的覆盖表为准。

章内分类与研究课题索引分工不同：课题记录要研究的问题及跨环节影响，章节通过父子层级组织这些问题。第2章把用户、对象与匹配归入建模任务；第3章在候选生成下比较接口，融合与维护处理共同输出；第4章区分学习目标与评分方案；第5章在展示方案下并列各决策维度。搜索按检索循环组织，广告投放按控制范围组织。条件和方法进入所属任务，完整层级与关系见大纲中的“章内组织关系”表。
