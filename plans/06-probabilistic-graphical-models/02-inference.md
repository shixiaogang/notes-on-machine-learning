# 卷6《模型：概率图模型》：第2部分“推断”大纲

正文入口：[tex/06-probabilistic-graphical-models/02-inference/part.tex](../../tex/06-probabilistic-graphical-models/02-inference/part.tex)。章号按本卷连续编号，以下标题和顺序对应当前入口实际接入的正文。

模型结构与局部概率函数给定后，推断要回答边缘概率、条件概率与最可能配置等查询；完整枚举不可行，价值在于沿局部因子复用中间计算。第5—8章依次给出变量消除、团树传播、变分确定性近似与基于采样的随机近似。四种方法不是精度的简单排序：消元与团树追求精确但成本由树宽和中间因子规模决定，变分以可计算分布换取系统偏差，采样保持渐近目标却带来有限样本波动。阅读时应固定查询、证据、输出量与误差口径，再比较各自复用了哪些局部计算。

## 第5章 基于变量消除的精确推断

正文：[01-elimination.tex](../../tex/06-probabilistic-graphical-models/02-inference/01-elimination.tex)。

本章作为推断部分开篇，先交代模型表示完成后“怎样用模型回答查询”这一问题，并指出对$d$个二元变量直接枚举$2^d$个完整配置不可行，利用局部分解识别并消除重复子计算是精确推断的主线；随后在已知因子和证据的条件下，说明如何减少完整枚举中的重复计算。报警模型连接边缘概率、完整最优解释与边缘MAP；算法正确性由当前乘积的不变式保证，实际成本则取决于作用域、状态基数、函数表示和查询角色。全章沿“替换为何不改变答案、不同查询为何选用不同算子、顺序怎样改变中间作用域”三问推进。

### 5.1 推断问题与因子运算

主要内容：固定证据、查询和消元变量，建立未归一化权重与归一化常数，再说明因子乘积、证据约简和边缘化如何改变输入坐标及数值。

论证与表述逻辑：

1. 从故障后验的已知报警、待答故障和其余未知状态出发，定义O、Q、R，并明确参数学习不属于当前任务。
2. 将有向条件概率与无向势统一为非负因子乘积；区分模型尺度Z、证据权重Z_e与条件分布，保留正有限归一化和零证据边界。
3. 以共享坐标对齐说明乘法，以固定状态的切片说明约简，以未知状态的共同求和说明边缘化。标量、重复因子及公共尺度都必须在完整乘积中保留。

#### 5.1.1 查询、证据与消元变量

主要内容：把诊断中的变量角色转为集合与联合配置，给出后验计算的输入、汇总对象和有效条件。

论证与表述逻辑：

1. 节点集合指定哪些随机变量参与观测、查询或消元，状态向量指定这些变量的一组取值，二者不混用。
2. 证据代入因子积得到F_e；先对R的联合状态汇总为g_Q，再对Q统一归一化。由于Z_e=Zp(e)，后验可以直接从未归一化因子积计算。
3. 连续变量将求和换为积分，观测处的分母解释为边缘密度值；密度正且有限和积分可精确保存是不同要求，为高斯表示留下入口。

#### 5.1.2 因子乘积

主要内容：用作用域和状态编码确定函数乘法的读值方式，说明相同变量必须共享状态，乘积结果依赖作用域并集。

论证与表述逻辑：

1. 由两张表相乘的坐标对齐问题引入作用域；消元时从合并作用域去掉当前变量，余下坐标才是新函数的输入。
2. 在报警的二元表上把一个三元配置投影到两张二元表；两张4项表的乘积为8项，项数由并集的联合状态确定。
3. 因子不必单独归一化，空作用域因子仍保存尺度；相同函数出现两次仍乘两次，因此算法用多重集合保存因子。

#### 5.1.3 因子约简与边缘化

主要内容：区分固定已知状态与汇总未知状态，并以共同坐标约束解释为什么必须先收集相关因子再消元。

论证与表述逻辑：

1. 报警A=1把报警条件表变成原因坐标上的似然切片；该切片须结合先验及其它因子后才形成原因后验。
2. 边缘化累加未知变量的全部状态。若两个因子共享同一变量，先乘再和保留共同状态，分别求和则错误地允许各表选择不同状态。
3. 公共正常数缩放可以在条件分布中抵消，但绝对证据权重须恢复；逐行缩放依赖剩余坐标，会改变查询配置的相对权重。

### 5.2 边缘概率的变量消除算法

主要内容：由报警模型的重复枚举推导求和消元，再推广为一般算法、多目标输出及高斯连续积分。

论证与表述逻辑：

1. 固定概率汇总任务，先识别不随故障状态改变的子计算，用分配律实现复用，再把逐桶替换写成通用程序。
2. 从集合式程序转到预分桶实现时，补足后续桶、最终查询因子池和标量三种去向，保证实现组织与数学乘积一致。
3. 多目标查询保留联合坐标，增加输出存储；连续查询则还要考虑积分结果能否用有限参数精确表示。

#### 5.2.1 从朴素枚举到分配律

主要内容：沿用四个二元变量的报警模型，展示先汇总传感器、再汇总过热如何避免重复访问同一子乘积。

论证与表述逻辑：

1. 列出先验、过热条件表和报警条件表，说明数值为人工教学参数，完整枚举需访问8个三元状态。
2. 先计算不依赖f的τ_S(h)，供两种f复用，再形成τ_H(f)。图中明确查询、证据与待消角色，并逐行显示输入、输出和归一化。
3. 所有状态仍按原权重参与汇总，所以结果与枚举相同；收益取决于中间函数的作用域，不能由输入稀疏直接保证。

#### 5.2.2 变量消除算法

主要内容：将当前相关函数组成桶，对齐坐标、相乘、求和并替换，最后形成查询权重和条件分布。

论证与表述逻辑：

1. 消元序列恰好遍历R一次；桶作用域并集U_t是局部积输入，去掉当前变量后得到输出坐标N_t。
2. 伪码按多重集合重数更新，保留标量，对没有作用域覆盖的未知变量补单位因子；分别说明R为空、Q为空和证据权重为零的行为。
3. 报警例逐桶得到τ_S=(0.0445,0.9045)、τ_H=(0.1305,0.7325)，证据权重0.19070和故障后验约0.384111，解释其它报警原因如何进入分母。
4. 预分桶将仍含待消节点的函数交给最早相应桶，只含查询坐标或为空的函数放最终池。p(f)起初保留、τ_H(f)最终汇入的轨迹说明无可交桶时如何完成结果。

#### 5.2.3 多变量查询

主要内容：保留F、S，仅消去H，计算报警证据下的联合权重表，区分联合输出和单变量边缘。

论证与表述逻辑：

1. 用一格完整乘加示范其余配置的计算，四格共同除以0.19070才是联合后验；逐行归一化会改成给定f后的条件查询。
2. 行列求和分别恢复g_F和g_S，报警后的原因关联保留在联合表中，两个一元后验的乘积一般无法恢复它。
3. 显式保留多个查询坐标还要存储完整联合表，即使此前消元桶较小，输出也可能很大。

#### 5.2.4 连续变量的边缘消除

主要内容：以规范高斯核展示乘法、证据代入和积分的封闭更新，逐项推出Schur参数，并分清局部桶与完整查询分布。

论证与表述逻辑：

1. 一般连续函数积分后未必能有限参数保存；二次指数形式将乘法转为参数相加。展开证据分块二次型，利用对称交叉项解释一次系数变化及纯证据常数的保留。
2. 将桶输入分为待积B与保留A，配方分离平移高斯核和余项；展开余项的常数、一次、二次三类，与原保留项逐项合并，并把积分质量的对数计入c′。
3. 桶参数记J、h，完整当前参数记K、η，全部剩余坐标C可能大于A。局部Schur输出与桶外参数相加才是完整边缘核；用完整二次型证明K′正定，最终组合查询参数后才读取均值和协方差。
4. 局部核exp[-(y-z)^2/2]积分后为常数，另乘桶外z因子才可归一化，说明局部主块正定不等于局部输出整体正定。完整均值的两个块方程再现同一Schur消元，概率计算另外保留积分尺度。
5. 二维核保留原参数、Schur结果、边缘N(1/3,2/3)及逆矩阵交叉核验，并补配方和总质量。最后说明离散潜变量产生混合分量、非二次势及数值求积会改变精确表示边界。

### 5.3 MPE与MAP的变量消除算法

主要内容：把局部聚合改为最大化并保存配置选择，再说明部分目标必须先汇总非目标状态，如何安排可保证正确的顺序。

论证与表述逻辑：

1. MPE优化全部未观测变量，最优值之外还需回溯表；边缘MAP仅优化指定目标，第一阶段求和后只回溯目标坐标。
2. 报警例验证两种输出；二元反例由前章的不可换序认识推进到一般上界与等号条件，为算法和次序约束提供依据。
3. 连续最优查询另查最大值取得、求解精确及密度坐标依赖；结构允许的换序与特定数值偶然成立的换序也须分开。

#### 5.3.1 MPE变量消除

主要内容：依据非负乘法对最大化的分配关系逐桶计算最优权重，并用逆序查表恢复完整相容配置。

论证与表述逻辑：

1. 全部候选共用正常数，找最优配置可比较未归一化函数，报告配置后验才再除证据权重。
2. 最大值表只保存得分，回溯表为每组剩余配置保存达到它的状态；逆序保证索引变量已赋值，并区分一个最优配置和全部并列配置的输出代价。
3. 按S、H、F计算报警MPE，回溯得到(0,1,0)，原权重0.07695、后验约0.403513；最大单项概率与汇总全部解释的后验具有不同含义。
4. 连续版本须另加可达最大值和精确求解。高斯配方在最优中心使负平方项为零，保存仿射回溯函数，参数更新没有积分体积常数。
5. 密度换元包含Jacobian，标准正态经指数变换后的众数为exp(-1)，不同于原众数的映像1，因此连续MPE必须绑定坐标和基准测度。

#### 5.3.2 MAP变量消除

主要内容：先对非目标R求和，再对目标M取最大值，解释换序条件、两阶段程序与目标回溯。

论证与表述逻辑：

1. 从只诊断故障恢复边缘MAP目标，说明MPE是R为空的特例，并限定MAP一词的使用约定。
2. 保留二元表，比较行和最大0.55、列最大之和0.67及最大单格0.40；逐项不等式给一般上界，所有列共用同一个目标X最优状态给等号条件。
3. 第一阶段保留求和后的因子分解，第二阶段采用最大化和回溯，只恢复M。作用域分离可保证提前最大化有效，参数恰好共用最优状态则属数值特例。
4. 当前桶不含待求和坐标时的标准结构有效顺序可有交错；所引同宽目标最后顺序结果说明为什么两阶段族足以描述该消元族的最小宽度，不等于所有MAP算法下界。
5. 报警的单目标和联合目标例落实两阶段选择与回溯；与MPE分量恰好一致不推广为一般保证，查询角色还会限制后续成本。

### 5.4 算法分析

主要内容：证明局部替换保留查询含义，再分析顺序、表示和输出成本，最后给出数值实现与复用条件。

论证与表述逻辑：

1. 当前乘积不变式统一同类求和、积分和最大化，再保持MAP两算子的正确嵌套。
2. 报警与星形说明顺序导致不同中间表，作用域图、基数和矩阵维度分别解释离散与高斯成本，目标角色进一步形成受约束宽度。
3. 实数等式与浮点实现分开检验；轴编码、支持、分解、尺度、奇异空间和缓存依赖决定计算能否按理论条件执行。

#### 5.4.1 算法正确性

主要内容：以当前因子积等于原函数对已消变量的聚合结果为不变式，分别证明同类消元及配置恢复，再处理MAP。

论证与表述逻辑：

1. 从有限报警求和和高斯积分的共同操作进入一般非负函数；说明计数与Lebesgue测度对应的汇总，并区分每步局部有限、最终正有限质量和最大值取得。
2. 定理先列共同节点、函数和桶更新，再分有限求和、积分和纯最大化条件；积分在局部无穷零测集上指定有限可测版本，结论按剩余乘积测度几乎处处成立。
3. 有限和按桶外/桶内分解、分配律与归纳逐行证明。积分分别处理局部例外柱集提升与前步例外截面，再用Tonelli合并积分；最大化依非负性及可达有限最优值合并。
4. 边缘查询归一化、MPE逆序扩展达到最优配置分别收束；MAP先求和再最大化的嵌套不变式保留两个阶段。
5. 舍入、下溢与病态矩阵可能影响数值甚至近乎并列的排名，故证明之后还需实现检查。

#### 5.4.2 消元顺序与计算复杂度

主要内容：以动态作用域预测中间函数，定义诱导宽度与树宽，推导离散、高斯和查询相关成本，再比较排序代理。

论证与表述逻辑：

1. 报警二元桶与三元桶、五节点星形4项与32项对比建立需求；primal graph按因子共同坐标连边，消元补团形成填充，特定参数仍可带来额外分解。
2. 诱导宽度数最大剩余邻居，不含被消节点；树宽优化完整顺序，森林与完全图说明最佳顺序的结构意义。
3. 单桶按c_tD(U_t)计操作；总处理次数O(m+d)与最大状态数相乘得到全程界。输入、临时桶积、保留新因子和回溯表分开计空间。
4. 部分消元保留Q时，D(Q)显式输出也须计入；统一指数同时覆盖w_R+1和|Q|，说明|Q|-1及空集合约定。
5. 最小度、最小填充和最小权重分别代理当前邻域、新边及输出状态数；异质基数例和两个候选的4/8输出、80/16桶访问、4/0填充分数说明目标不同，MAP两阶段还约束候选。
6. 高斯用J_BB=LL^T后的两次三角求解实现Schur更新，逐项解释b^3、b^2a、ba^2及另计装配的成本；表格区分局部可积分与完整可归一化条件。
7. 受约束树宽在两阶段顺序族中取最小值，实际执行仍使用实际宽度；星形中心先求和产生k叶表，比较原树宽1与受约束宽度k，限定为通用结构稠密消元成本。

#### 5.4.3 实现与适用边界

主要内容：把作用域和数值参数落实为数组及稀疏矩阵操作，控制数值尺度，明确退化模型与跨查询缓存边界。

论证与表述逻辑：

1. 转置统一变量轴，广播为缺失坐标补长度1轴；二元支持例解释不同切片非零位置求和后可使输出稠密。
2. 稀疏Cholesky的符号阶段只预测非零模式和填充，数值阶段求系数；两次三角求解替代求逆，正对角的两倍对数和给log行列式，结构和数值缓存各有不同条件。
3. 对数域和log-sum-exp减去最大值控制指数，明确全负无穷和零证据分支。公共尺度方案保存累计对数，标量留在因子集合与取出累计两种约定只择一，2与3的小例保证不重复计入，零标量不取对数。
4. 奇异高斯须指定支持与测度，数值接近奇异要检查尺度、条件数和残差；对角扰动改变模型。资源不够时转向后续变分或采样。
5. 缓存记录原因子参数、证据和已消变量；原S/H顺序不能直接复用来答S。先消H缓存η(f,s)后分别计算g_F和g_S，说明共同坐标、输入不变条件及首桶更大的复用代价，再连接团树消息。

### 5.5 本章小结

主要内容：回到故障诊断，综合查询算子、正确性、资源与数值条件，说明精确消元何时可用。

论证与表述逻辑：

1. 后验约0.384111汇总全部解释，MPE(0,1,0)选择完整最优配置；当前乘积不变式连接局部替换与完整查询。
2. 边缘概率、MPE与边缘MAP分别选择汇总、最大化及有序混合，目标角色改变可用顺序和受约束宽度。
3. 离散状态乘积与高斯块维度决定不同成本，归一化、数值误差和存储条件共同约束执行；重复查询可共享信息，过大作用域需额外结构或明确近似。
4. 扩展阅读以每桶输入、输出作用域和状态组合数作为具体比较任务，指向教材的因子消元与顺序分析。

## 第6章 基于团树传播的精确推断

正文：[02-junction-tree.tex](../../tex/06-probabilistic-graphical-models/02-inference/02-junction-tree.tex)。

本章章首先从变量消除“一次性”、连续多查询会重复局部求和的痛点出发，说明把中间结果连同依赖保存为可复用消息的动机；并用“树边把计算分成内部互不重叠的两侧”解释为何消息在树上可直接划定汇总范围，而含环图须先道德化、三角化、连成团树。点明VE与团树的分工（VE单次消元、团树可复用可增量更新）。

### 6.1 从变量消除到消息传递

主要内容：在同一设备报警证据下，从连续查询故障、过热及故障与传感器失灵的联合后验出发，指出VE逐查询重做局部求和的浪费，说明如何保存以过热状态为边界、并可在证据变化后复用的局部求和结果。

论证与表述逻辑：

1. 恢复二元设备模型的四个局部因子及人工参数，分别消去传感器和故障状态，得到报警侧表u与故障侧表v，说明两张表各自依赖哪些因子和证据。
2. 将两侧按共同的过热状态相乘，区分其求和得到报警概率、归一化得到过热后验这两个操作；说明已被求和的故障与传感器坐标不能从一维表中恢复，其他查询仍需保留相应坐标。
3. 将u、v对应到树状因子图的切边及发送方向，解释边界表是动态规划的子问题结果；含环图则可能从不同路径再次带回同一因子的贡献，留下组织完整边界的问题。

### 6.2 树结构上的消息传递

主要内容：先限定在无环因子图（因子树）上建立消息规则，因为树边天然把图分成互不重叠两部分；保留观测节点并用证据因子（未观测取1、观测取指示函数）形成非负目标，在因子树上建立和积消息、收集与分发、后验恢复及最大积回溯。

论证与表述逻辑：

1. 先规定因子作用域、邻接关系、证据指示函数和总权重，区别未归一化模型中的证据权重与证据概率。
2. 根据切边后的发送侧范围推导两类节点更新，再组织两轮调度读取边缘；所有概率输出都需明确总质量为正及归一化口径。
3. 将累加配置权重改为比较完整配置的最大权重，说明最大边缘与概率边缘、值表与回溯记录的不同职责，并用有限隐状态链展示递推的专门化。

#### 6.2.1 和积消息

主要内容：以变量和因子两类节点分别给出和积更新，解释排除接收方为何能够避免重复计数。

论证与表述逻辑：

1. 固定接收变量的状态，变量节点乘入证据和其他侧消息，因子节点乘入局部函数后对其余作用域坐标求和；输出保留同一变量作为边界索引。
2. 利用树切分后内部变量互不重叠的性质，说明各分支求和可独立完成，接收方消息不能再乘回发送侧。
3. 将规则逐步落实到设备图：先验叶因子先向故障和传感器变量发送先验，变量再向内部因子转发；报警叶变量发送指示表，两处内部因子向过热变量形成原来的u、v。

#### 6.2.2 消息调度与边缘恢复

主要内容：按叶到根收集、根到叶分发完成全部方向消息，形成未归一化的变量表与因子表，并在正总质量下读取后验。

论证与表述逻辑：

1. 每个节点等齐除接收方外的输入再发送，树的每条边只需两个方向各一次；根边缘只需收集，其他位置还需分发补足父侧信息。
2. 组合全部入站消息得到变量表和因子表，说明它们是全局边缘权重；从因子表恢复成对后验时，先对其余变量求和，再明确除以相同的归一化常数。
3. 用设备例核对过热和故障后验，随后区分本次发送使用的本地缩放除数与整侧子树累计尺度。推导两类节点的累计递推，以及由入根尺度恢复总质量的公式，说明不能将全树双向除数重复乘入。
4. 以报警表缩放演示恢复原质量，保留全零消息、零除数禁止及证据不相容的处理；累计尺度也可在对数域中保存。

#### 6.2.3 最大积消息

主要内容：将有限因子树的求和替换为最大化，保存边界条件下的最优值及取得该值的配置，并沿回溯记录恢复完整MPE。

论证与表述逻辑：

1. 分支不重叠且因子非负，使最大化可以在固定边界后按分支分配；因子消息同时记录内部最优选择，最大边缘则表示固定某变量状态时的全图最大权重。
2. 用平局反例说明独立选择各处最大边缘会拼出不相容配置，再完整复算报警模型的两侧最大积、根选择及回溯结果。
3. 为有限隐状态链先建立初始、转移和局部观测的联合分解，再定义固定末端状态的前缀最优权重。由拆出最后转移与观测因子逐步推出Viterbi递推，给出初始化、末端最优状态、固定平局规则和逆向回溯。
4. 说明正观测概率及全零路径的边界，保留完整隐状态MPE与边缘MAP混合求和、最大化顺序的区别，并连接后文时序模型。

### 6.3 团树的构造

主要内容：从含环图上删单边仍可能连通的困难出发，扩大共同计算单元，以极大团及完整分隔集组织一般图上的精确消息。

论证与表述逻辑：

1. 用四环说明不能直接沿用树边两侧不重叠的分支解释；局部消元合并因子时必须留下新函数共同使用的全部变量，由此引出团节点和多变量消息边界。
2. 将构造分成承载原始因子作用域、填充成弦图、提取极大团、选择运行交集连接和唯一分配因子几个相互依赖的步骤；计算组织改变，原因子乘积保持不变。

#### 6.3.1 从原图到弦图

主要内容：按输入图的类型形成承载完整因子作用域的变量图，再由消元填充得到弦图。

论证与表述逻辑：

1. 有向模型先连接共同子节点的父节点再去方向，无向模型直接使用作用域图，因子图则将每个因子的变量两两相连；区别本次保留全部变量与条件独立查询的祖先子图。
2. 消去当前节点前先连接全部剩余邻居，解释完美消元序与弦图的对应以及填充为何只改变计算结构；图论背景通过一次章级语义引用连接卷一。
3. 在同一四环上比较先消2与先消1对应的两条填充边、两组极大团和不同消息索引，说明顺序影响表规模而不改变合法消元的概率答案。

#### 6.3.2 极大团、分隔集与运行交集性质

主要内容：由共享变量沿团间路径不能丢失的要求，引出运行交集性质，并证明相邻团交集就是切边后的完整共同边界。

论证与表述逻辑：

1. 区分极大团与全图最大团，定义相邻团的交集；以三团合法链和错误重排显示共享状态在路径中途丢失的具体情形。
2. 正式定义包含任一变量的团构成连通子树，解释它与路径保留两端交集的等价性；再用双向包含证明两侧变量并集的交集恰为相邻分隔集。
3. 结合分配律说明边界完整为何支持各侧先求和再相乘，并以一致性链因子对照正确总权重2和错误连接得到4，保留反例及稠密表成本边界。

#### 6.3.3 团树构造与因子分配

主要内容：对弦图全部极大团按交集大小构成候选团图，以最大权生成树选择运行交集连接，再为每个原始因子选择唯一的覆盖团。

论证与表述逻辑：

1. 保留空交集零权边统一处理不连通分量，说明最大总交集权与运行交集的对应仅适用于有限弦图及全部极大团。
2. 给最大权Kruskal的排序、平局和防环步骤，在三团链上展示权重1、1、0；以非弦四环的边团反例说明选树不能替代三角化，也不能优化已定的消元顺序。
3. 定义唯一因子分配与无证据团势，解释未分配因子团的单位势及重复存放的后果；设备例给出两团局部输入，最后说明多种合法连接及分配仍有缓存和表规模的不同代价。

### 6.4 团树传播

主要内容：先说明校准后多数查询只需在现成团表上做少量求和；在完整分隔集上执行无除法双向消息计算，分别保存局部输入、汇总势和概率边缘，支持校准、跨团查询及证据更新，跨团相乘时须除掉重复计入的分隔集权重。

论证与表述逻辑：

1. 先明确原始团势与证据的归属，再把因子树单变量消息推广为按分隔集共同状态索引的函数。
2. 两轮传播后验证相邻团边缘一致；单团查询直接边缘化，跨团查询通过子树消元或分隔集比值重构，零概率状态单独处理。
3. 新证据按消息源侧判定失效；路径重算之后还须更新查询团表和总质量，撤回硬证据则从原输入恢复局部势。

#### 6.4.1 团势与团间消息

主要内容：为证据选择唯一覆盖团，解释局部团势、分隔集消息和全树汇总势的不同职责。

论证与表述逻辑：

1. 将硬证据乘入无证据团势，保持全部原始因子与证据各计一次；从可能出错的离散传感器报告引出观测似然，解释似然型软证据提供权重而不直接指定后验，且多变量似然需完整作用域覆盖。
2. 沿一条团边固定分隔集状态，乘局部势与除接收方之外的消息，消去非共享坐标；小作用域函数按共同状态对齐，原局部输入与新消息分别存储。
3. 定义团汇总势和双向消息乘积形成的分隔集势，明确两者是传播结果而非新的原因子；将一般式落实到设备两团，重新得到u和v。

#### 6.4.2 收集、分发与校准

主要内容：用后序收集与先序分发完成双向消息，形成汇总势、总质量和正总质量下的概率边缘，并验证共享分隔集的一致性。

论证与表述逻辑：

1. 伪代码给出定根、两轮发送、形成汇总表和零总权重分支，明确等待入站、空乘积和不相容证据的行为。
2. 将仅依赖分隔集的反向消息提出求和号，推导两团投影等于双向消息乘积；说明校准是共享概率表一致，不能单靠一致性替代与原始模型的全局联系。
3. 用设备例的双向消息、两张完整团表及共同过热边缘核对校准；缩放后的表先归一化再比较概率，证据权重则按本地除数及累计源侧尺度恢复，并保留全零处理。

#### 6.4.3 查询与证据更新

主要内容：从校准团表读取单团后验，组合多团查询，明确零分隔集状态与局部证据变化的恢复过程。

论证与表述逻辑：

1. 单团覆盖查询时在团内求和；跨两团查询时先写各汇总表的局部势与u、v组成，逐项抵消重复分隔集权重，再保留全部数值、联合表及漏除后整体归一化仍错误的反例。
2. 一般跨团查询选连接查询团的子树，吸收外部分支消息后继续内部消元；只保存校准边缘时可在正分母状态用团边缘除分隔集边缘重构。
3. 对零分隔集状态，定根并明确父分隔集、新加入变量和条件表，以根边缘乘各条件表重构联合。零父状态只对相应配置补零，不删除整支；无除法办法与显式输出成本一并保留。
4. MPE另算最大积及分隔集条件回溯；证据更新按源侧是否含变化团标记有向消息。单团覆盖查询只需重算相关路径，但随后必须重建目标团表、得到新总质量并重新归一化，路径外旧团表仍保留失效标记。
5. 设备例分别演示新增正常传感器证据与更换报警证据；撤回硬证据从无证据势和当前观测恢复输入。新作用域超出已有团需重组结构，零总质量则不定义条件后验。

### 6.5 算法分析

主要内容：先强调“校准自洽不等于对应原模型”，再证明消息恰为源侧因子的边缘，将消息与原始模型的子树求和相联系，解释精确性、连续积分边界、变量消除的结构对应和实际传播成本。

论证与表述逻辑：

1. 用运行交集和唯一因子分配证明源侧不变量，推得全局团边缘及分隔集边缘；最大积沿同一分解证明回溯取得根最优值。
2. 连续推广分别恢复局部积分有限性与完整目标可归一化，说明测度及几乎处处版本；再从消元袋父边和收缩过程解释变量消除与团树的关系。
3. 先分开消息输出规模与团状态枚举成本，再展开共享乘积的实现及两轮调度，给时间、持久内存、临时空间和表示方式的适用范围。

#### 6.5.1 正确性与校准

主要内容：证明有限离散模型的消息恰为源侧全部局部势的边缘权重，并明确连续密度推广需要的额外条件。

论证与表述逻辑：

1. 定理列有限非空状态、树覆盖、运行交集、有限非负因子、唯一覆盖分配和未缩放消息等条件，按源侧团数归纳；先证明不同分支内部坐标两两不交且与当前团不交，再使用分配律。
2. 将全部分支纳入同一团得到真团边缘，再消元得分隔集边缘及共同总质量；区分校准一致表可重构一个分布与确认该分布来自指定原因子。
3. 最大积利用非负分配律与相容回溯取得最优配置，零总权重时不定义条件MPE；零表项不破坏有限和证明。
4. 连续情形采用非负可测势和$\sigma$有限乘积基准测度，要求各局部积分在相应边界测度下几乎处处有限并使用有限可测版本；全局正有限质量另行检查。两团反例说明全局可积不能排除源侧发散，高斯积分另要求被积块正定，连续观测需指定观测似然或条件密度口径。

#### 6.5.2 与变量消除的关系

主要内容：点明团树与变量消除是同一套局部计算的两种组织（团树保存VE每步的中间因子及依赖并连成树）；把每步消元的变量集合构造成运行交集袋树，解释如何收缩非极大袋，以及如何反向从团树恢复消元，并比较两种算法在单次查询与重复查询下的取舍。

论证与表述逻辑：

1. 定义当前变量与后继邻居组成的袋。后继非空时选择最早后继所在袋为父，填充保证新因子边界被父袋覆盖；空后继袋作为根，不连通分量用空分隔集连接。
2. 沿父边序号严格增加且共享变量持续保留，得到无环和运行交集。原始因子各分配一次，之后沿包含关系收缩非极大袋，归并局部输入而不破坏共享状态。
3. 用三角形再接一边的具体消元顺序列出四袋及父边，展示收缩成两个极大团后，一条消息可以合并多步消元。反向从叶团消去非父分隔集变量则恢复收集计算。
4. 用设备两团的不同根重现u、v，比较单次查询及时释放中间表与反复查询、局部更新的缓存收益，明确变量消除本身也能使用缓存。

#### 6.5.3 复杂度与适用边界

主要内容：按实际变量基数计算团表与分隔集表大小，说明两轮无除法共享计算的时间界、内存组成及大团限制。

论证与表述逻辑：

1. 小分隔集输出仍可能需要枚举整个大团；逐出站重乘输入会出现度数平方开销，因此固定团状态定义前缀积、后缀积及两次扫描，给含零三输入的例子验证排除乘积无需除法。
2. 收集先算父向消息，分发收到父侧后再共享算子向消息，每状态只有常数次线性度数处理。给完整传播时间界，并区分已建局部势、因子展开成本、持久团/消息表、临时扫描数组和回溯表。
3. 将实际状态乘积界转成所选顺序的宽度界，区分最优树宽；同一四环使用异质基数比较200与40的团表及100与4的分隔集表，保留30个二元变量的8GiB估算。
4. 高斯紧凑表示取决于合法块积分及闭包，混合和非线性势可能增加消息复杂度；大团过大时需改表示或采用近似，含环迭代不继承树分支精确性。

### 6.6 本章小结

主要内容：以“团树是为重复推断而组织的变量消除”为主线，回收完整消息边界、唯一因子分配及计算依赖，说明重复推断能复用哪些工作，以及仍须承担的表规模和输出代价。

论证与表述逻辑：

1. 区分有向模型先道德化与无向/因子模型从作用域图开始，再共同三角化并形成运行交集树，避免将输入类型差别压成同一步骤。
2. 汇总收集分发、团后验、单团和跨团查询、MPE回溯、证据缓存失效和硬证据撤回，保留正总质量及原始局部输入的职责。
3. 明确缓存节省重复消元工作，却不消除最大团状态数、各变量基数和查询输出成本；扩展阅读按边界完整、输入唯一和校准一致三条线索连接既有来源。

## 第7章 变分推断与确定性近似

正文：[03-variational.tex](../../tex/06-probabilistic-graphical-models/02-inference/03-variational.tex)。

本章承接消元和团树的大中间因子瓶颈，在固定模型参数和证据的条件下区分两类近似：分布查询保留概率与不确定性，配置查询为全部未观测变量寻找完整MPE。改写在章首先点明“精确推断成本随诱导宽度指数增长、要不起，故主动用可量化方式换可承受计算”，并把全章明确分成两条主线——限制后验表达形式在好算分布族里找最接近者（变分推断，保留不确定性），与放宽离散配置约束先解连续优化再恢复合法配置（近似MPE，只选一个配置）；两类查询共享局部统计量坐标，但目标、可行域、误差及证书分别解释。各首现近似（平均场、结构化、LBP/Bethe/Kikuchi、EP、拉普拉斯、VMP/SVI/重参数化/摊销、LP松弛/对偶/TRW/图割）均补“它针对前一种做法什么计算瓶颈”的引出。

### 7.1 变分推断的统一视角

主要内容：从报警后的故障概率进入，建立候选后验、反向KL与ELBO，再把局部概率写成统计量期望，以边缘多面体和最大熵说明分布推断与配置优化的共同表示。

论证与表述逻辑：

1. 联合权重易评价不表示归一化常数易计算；明确证据正有限、离散求和与连续积分的口径。候选分布$q$仍定义在同一未知变量上，用它的边缘或期望近似实际查询，候选参数与固定模型参数分开。
2. 由反向KL代入后验、提取固定对数证据，得到可优化的ELBO和恒等式。有限KL、支持与可积性限定等式及拆分，形式上消去证据并不保证期望可算。分开族限制、准则选择和数值优化误差；跨卷只作一次“概率分布”章级语义引用。
3. 由积分权重说明零强制/零回避与模态遗漏直觉；在同一相关高斯目标及独立高斯族下，写出两方向KL有关项及导数。反向KL方差等于条件方差$1-r^2$，正向KL匹配边缘方差；$r=0.8$的$0.36$对$1$展示表达限制，结论不扩大到所有分布族。
4. 查询局部概率引出指示统计量，其期望收集局部表。对数配分函数求导产生矩与协方差；用节点指示之和恒为1说明仿射冗余、零方差方向和最小表示。局部可逆性要求合法有限内部参数及可实现内部矩；边界矩仍合法，但未必由有限参数达到。
5. 期望是配置统计量的凸组合，由此建立边缘多面体。由KL非负得到得分加熵的全分布变分表示，再按同一均值分组取最大熵，解释Gibbs式、边界伯努利例及负最大熵共轭的当前用途；一般基准项与连续情形另有条件，不能直接照搬有限多面体结论。
6. 线性得分的凸组合不超过最大配置得分，而集中于最佳配置可取等，故MPE无熵项。分布近似可能改变表达族、熵或局部可行域；MPE放宽可行域后给最大得分上界，并需恢复离散配置。
7. 人工三角模型沿用全章：两类八配置给$Z=26$，固定边状态对第三变量求和，得到同值边缘$5/26$、异值边缘$4/13$、节点$1/2$和异值概率$8/13$。图中间明确为本例均匀平均场解，右侧全异值边表展示局部一致而全局不可实现。

### 7.2 近似后验分布与边缘概率

主要内容：围绕同一概率查询，依次回答近似对象怎样构造、更新怎样执行，以及结果能否可靠回答所需边缘或期望。

论证与表述逻辑：

1. 构造阶段比较合法因子化分布、局部边缘、矩匹配和局部曲率，各自先说明改变哪个对象，再给更新与边界。
2. 计算阶段按局部期望、数据遍历、难解梯度和新样本重复优化四种成本展开，满足各自条件的办法可以组合。
3. 诊断阶段把合法性、迭代状态、目标证书与实际查询误差分开，不能以一个标量界替代全部边缘精度。

#### 7.2.1 后验分布与边缘概率的近似

主要内容：在保持目标模型不变的前提下，比较不同近似对象与准则，使用同一三角图和可解析连续例子检验保留的信息、代价及失效情形。

论证与表述逻辑：

1. 限制全局分布能保留真实熵与ELBO下界，但可能丢失相关；局部表能保留更多局部依赖，却不一定来自全局分布。
2. 指数族站点替换以倾斜分布的矩为局部目标，众数二阶展开则以密度局部形状为依据；两者不自动继承同一ELBO的单调性或证据界。

##### 7.2.1.1 基于因子化分布的近似

主要内容：从联合表的指数存储量引出平均场，推导循环坐标更新，再用不交块保留选定依赖，区分族最优目标与实际预算下的解。

论证与表述逻辑：

1. 独立乘积以单节点概率替代全联合表，但独立性属于$q$，原模型耦合仍进入期望。固定其余分布，把单坐标目标改写成常数减KL，在归一化常数正有限时得到期望对数联合再取指数的更新。
2. 三角模型直接用未归一化得分计算对数配分函数下界，避免与已归一化模型的零上界混淆。展开独立异值概率、伯努利熵、坐标导数和logit，得到sigmoid更新及邻居$1/4$时的新概率$2/3$。
3. 均匀固定点给下界$3.119162$。由Hessian对角及非对角项、二次型界证明内部严格凹，再用熵导数排除边界最大值，得到本例唯一全局最优；异值概率仍是$1/2$，说明优化到位仍有族误差。
4. 循环算法列有限ELBO初值、正有限归一化更新、正容差和最大轮数，每轮顺序使用最新因子，再计算整轮增量。目标单调有界只推出持续精确更新时的目标值收敛；预算停止、参数收敛、全局最优与并行旧值更新分别说明。
5. 块变分保留块内联合表、跨块作用变期望势，块内树宽和代数结构决定成本。三角图的$q_{1,2}q_3$例逐步验证跨块得分恒定、双向固定点与块熵抵消，得到$\log24$下界；更大合法族的最优ELBO不低，但实际求解仍受优化误差影响。

##### 7.2.1.2 基于局部边缘的近似

主要内容：由合法全局$q$的维护困难转向伪边缘，建立Bethe/LBP、区域自由能/GBP和配分函数TRW，分别解释局部一致性、熵近似、驻点及界方向。

论证与表述逻辑：

1. 恢复有限正因子图上的和积规则；树切边形成互不重复的分支，含环照用时则可能重复信息。局部归一化和因子—节点边缘一致性定义局部多面体，三角图反例说明它可严格大于边缘多面体。
2. Bethe熵校正节点重复计数；在树上构造全局分布、叶端消去并以KL验证最大熵。驻点定理列正性与内部条件；完整Lagrangian、两类表的偏导和正消息乘积消元给两个方向，不除节点度减一，覆盖叶节点。
3. 阻尼先定义候选及$0<\gamma\leq1$，解释log混合和归一化，保留一般收敛限制。三角均匀固定点按边势行和、边熵与得分抵消得到$Z_B=(1+r)^3$；与$2+6r^2$比较展示Bethe可高估或低估，单点正确不等于联合或配分准确。
4. Kikuchi用更大区域检查短环。四方格、四内部边、中心点列出实际交集与计数；外边界可选子区域与零计数另作说明。自由能保持原因子计数一次，近似熵及全局一致性；区域增大会增加表格和通信成本，不保证一般单调改善。
5. 从原区域驻点到父子GBP，解释乘子需重新组合而非直接指数化；列计数校正、实际后代及入边集合，用四方格父子约束展示边缘化、提出消息和约分。含零计数区域保留原约束，不除计数。驻点关系、更新稳定性与全局极小性分别判断。
6. 配分函数TRW以树熵凸组合形成可控上界；明确参与树、边出现率及连通范围，“正温度”在此保留熵且系数为1。树最大熵不低于同边缘全局熵，再扩大可行域给理论最优上界；任意未优化的原始可行目标不能自动作数值上界证书。

##### 7.2.1.3 基于矩匹配的近似

主要内容：以可计算的指数族站点替换难因子，通过空腔、倾斜分布、局部投影和站点写回实现EP，检查矩匹配存在性和分布合法性。

论证与表述逻辑：

1. 除去旧近似站点形成空腔，放回真实因子形成倾斜分布，再投影并以比值更新站点，避免重复计入原近似。有限KL差和内部矩条件支持投影一阶条件，最小正则族下匹配矩并确定参数。
2. 半正态例从标准正态空腔计算半轴质量、均值及二阶矩，再减去空腔的自然参数得到新站点；保留近似高斯仍在负轴放质量、反向KL可能无限的比较。
3. 每轮倾斜目标依赖其他站点，因此不能把普通EP更新说成单调提高固定ELBO。站点可未归一化、精度可负，总体及实际空腔/倾斜分布仍须合法；阻尼与残差属于另行诊断。

##### 7.2.1.4 基于局部曲率的近似

主要内容：在光滑内部主峰附近二阶展开对数密度，以负Hessian给高斯近似，并用Gamma及坐标变换展示局部曲率的支持与坐标限制。

论证与表述逻辑：

1. 定位众数、检查负Hessian正定，写二阶项并积分得到局部高斯和归一化常数近似。
2. Gamma例逐项求导、代峰、取逆曲率，比较真实矩并计算高斯落在非法负轴的质量；log坐标加入Jacobian后重算峰与曲率，变回成为对数正态，说明结果依赖近似坐标。
3. 从局部展开到整体积分还需主峰支配、高阶导数和尾部条件；多峰需寻找相关峰并避免重复计数，一般不提供ELBO最优性或统一证据界。

#### 7.2.2 近似的计算

主要内容：把已有近似更新落实为可执行计算，按局部结构、数据遍历、梯度估计和重复推断四种成本解释组合条件。

论证与表述逻辑：

1. 解析坐标形式不自动使期望可算；共轭结构解决函数形式闭合，小批量减少数据项，采样处理难解期望，共享映射减少每个新样本的优化。
2. 各路线分别核对合法分布、每步代价与误差来源，不把解析、无偏、收敛或摊销速度互相替代。

##### 7.2.2.1 计算局部更新

主要内容：由完整条件指数族形式推导期望自然参数更新，以充分统计量和因子贡献组织VMP，并分析离散与连续局部计算代价。

论证与表述逻辑：

1. 收集与当前变量有关的系数，期望改变自然参数而不改变家族；相关期望可算且更新落合法域是计算闭合的条件。对其他变量非线性不等于能把均值直接代入。
2. 分开因子到变量的自然参数贡献与变量返回的统计量期望。标准共轭VMP利用这些统计量的充分性完成期望，一般非线性项需凭已知族计算或另取所需矩，基准项只计一次。
3. Beta–Bernoulli例从期望对数项收集软计数，并由两状态得分差给局部log odds；保留数值核验。稠密离散表、块树宽、区域表格及高斯矩阵运算分别给规模与成本，低秩或稀疏结构的收益须看具体表示。

##### 7.2.2.2 降低数据遍历成本

主要内容：在全局—局部共轭模型下推导自然梯度及小批量SVI，明确随机方向、每步合法性和渐近收敛的不同条件。

论证与表述逻辑：

1. 固定局部因子，合并全局指数族的期望log密度与熵得到ELBO有关项；逐项求导抵消两个矩项，普通梯度为Fisher矩阵乘参数差。
2. 恢复Fisher局部分布距离和逆矩阵作用，得到自然梯度的参数差形式；局部参数在可行域内部达到光滑最优时才使用这里的包络求导，约束边界、最优解不唯一或不可微情形须另核适用的一阶或包络条件。
3. 均匀小批量以$n/b$缩放样本统计量，先验不缩放。精确局部优化下方向无偏；非均匀抽样要按纳入概率加权，未解完局部问题另有优化误差。
4. 初始参数及小批量目标参数须在合法自然参数域，$0<\rho_t\leq1$利用凸性保持每步合法；明确从$t=1$起及非负延迟的学习率范围，再讨论平方可和等随机逼近条件。保留软计数数值例、单步ELBO可下降和有限预算限制。

##### 7.2.2.3 估计难解期望的梯度

主要内容：对非共轭难解期望，分别从固定噪声与密度求导构造路径导数、分数函数估计器，核对各自的条件与方差含义。

论证与表述逻辑：

1. 将连续样本写成参数化固定噪声，要求采样映射与被积函数具有所需可微性，并以可积函数支配链式导数以交换微分与期望；链式法则保留样本位置移动和显式参数两部分。高斯平方例核验单样本导数的期望，不泛称方差总更低。
2. 离散采样映射的普通路径导数通常不能给正确梯度；切换分数函数时重新给固定有效支持、可微、可积和求导交换条件，有限离散逐项求导与一般积分分开。
3. 展开密度与被积函数的乘积导数，再以归一化证明得分均值零和合法基线；有限方差、连续松弛偏差和支持随参数移动需另行判断。

##### 7.2.2.4 降低重复推断成本

主要内容：学习共享映射直接输出局部近似参数，以训练代价换取测试时较少优化，并分开近似族、摊销限制与实际网络优化误差。

论证与表述逻辑：

1. 小批量仍需逐样本局部优化，因此引入摊销推断。明确它与SVI可以组合，分别减少每批数据遍历和每个样本的优化；训练反向传播和存储仍计成本。
2. 在没有共享随机全局变量的独立潜变量模型中写逐样本ELBO，插入各样本最优与共享映射最优总目标得到三项非负差。未取到最优用上确界解释，网络总目标最优不表示每个样本都优于当前结果。

#### 7.2.3 近似的可靠性

主要内容：以输出对象和实际查询为依据，分别检查合法性、迭代、目标值、概率与期望精度，使用对照方法及重要性权重补充诊断。

论证与表述逻辑：

1. 合法$q$、局部表、高斯近似和配置有不同检查对象；目标收敛、参数收敛、固定点存在及稳定性也不同。有限严格正因子下，用正消息下界构造非空紧凸自映射说明LBP固定点存在，不推出普通迭代吸引性。
2. 目标证书表对比ELBO下界、Bethe/Kikuchi与EP/Laplace无一般界方向、TRW理论最优上界以及MPE对偶界；每种证书均说明不能推出的查询精度结论。
3. 恢复后验$\pi$与TV约定，解释Pinsker到有界函数误差的缩放；提高精确ELBO降低反向KL，不保证每个统计量误差逐步下降，对数证据未知也使绝对KL差通常不可得。
4. 重要性证据估计要求提议覆盖目标；自归一化期望的一致性用目标绝对可积、分子分母大数定律和正证据说明，有限样本仍可有偏。Jensen界针对重复抽样期望，单次log估计可高于真值。
5. 权重ESS衡量本批集中程度，给数值、全零批次和数值下溢处理；不能强行赋均匀权重，也不能由平稳权重断定不存在遗漏模态。后验预测检查把结果接回观测模型，小规模精确对照帮助区分模型失配与推断误差。

### 7.3 近似MPE

主要内容：在原始完整配置查询上构造连续松弛和分解上界，比较特殊能量的精确图割与多标签局部动作，再恢复可行解并解释可计算差距。

论证与表述逻辑：

1. 全部未观测变量同时取值，不能把求和变量上的边缘MAP直接当同一目标；先固定得分及硬约束表达。
2. 保持配置得分，放宽全局可实现性得到LP；分解改变求解方式，特殊结构可使松弛紧，任何取整配置仍须在原因子及约束下重新检查。

#### 7.3.1 完整配置的连续松弛

主要内容：以节点与因子配置指示变量建立MPE整数规划，解释凸包等值、局部LP上界和零温极限。

论证与表述逻辑：

1. 有限配置和有限得分支持线性表示；零势以允许配置或显式约束处理，避免直接对无穷系数套LP/对偶结论。额外约束必须在松弛及对偶中保留。
2. 归一化one-hot及因子—节点一致性使整数解对应完整配置；凸组合线性得分的最大值与MPE相同。去二值而保非负局部约束扩大可行域，理论LP最优给上界；尚未最优的原始分数值可能低于整数最优，不能当证书。
3. 三角分数点给$3\beta$对真实$2\beta$，三角不等式可收紧本例；一般高阶约束仍有计算成本。有限集log-sum-exp夹逼说明精确几何下熵消失极限为MPE，保留局部松弛时则到LP。

#### 7.3.2 松弛问题的分解求解

主要内容：把大局部LP分到可解因子或生成树，保持原得分分解，以共享统计量协调子问题并形成对偶上界。

论证与表述逻辑：

1. 因子分解将各状态的小问题分开，再以乘子惩罚复制变量不一致；树分解保留多条边，但仍须跨树共识。
2. 区分任意分解的有效上界、充分优化后的LP界和真实整数最优，消息迭代状态不能代替最优证书。

##### 7.3.2.1 基于因子分解的求解

主要内容：从局部一致性Lagrangian导出节点/因子最大值之和，解释次梯度更新、强对偶与配置证书。

论证与表述逻辑：

1. 列乘子作用的等式并按节点/因子分组，节点取正、因子取负；同一完整配置下抵消，独立最大化则给上界。
2. 单纯形线性目标取状态顶点；当前最大仿射分支的斜率为两份one-hot之差，由此解释次梯度的协调方向，保留平局和数值不单调限制。
3. 非空有界局部LP的强对偶给最小上界等于LP最优，通常仍高于整数最优；各子问题若共享同一完整最优配置，才形成原MPE最优证书。

##### 7.3.2.2 基于树分解的求解

主要内容：以正权、覆盖全部边的生成树分解得分，推导TRW上界、充分优化与成对LP的关系，并证明树一致证书。

论证与表述逻辑：

1. 每树参数加权恢复原参数，树上最大和/回溯精确求子问题；独立最大值之和形成上界，固定分解可能高于LP界。
2. 引入每树边缘副本，树上局部表可全局实现；重分配参数的对偶要求跨树重复节点/边共识，全边覆盖后消去副本恰剩成对局部约束。因此充分优化所有参数分解给LP最优，单换权重不增加松弛强度。
3. 正温树熵乘趋零系数在有限局部集合上消失，极限仍保留LP松弛。树一致引理的两个方向由完整共同最优配置和正权非负差之和证明；三角三树例说明逐点标签相交不等于全局配置一致。

#### 7.3.3 特殊能量结构的图割求解

主要内容：改用最小化能量口径，说明二元次模的精确割表示和多标签扩展/交换的局部保证，保留特殊有序凸及非次模部分标号路线。

论证与表述逻辑：

1. 显式把得分取负并翻转上下界方向，接有限一元/成对代价；图割容量非负要求将当前能量具体分解。
2. 对一般多标签只精确求当前二元动作，局部停止、全局精确和近似比条件分别交代；其他结构路线说明对象与适用范围。

##### 7.3.3.1 二元次模能量的精确求解

主要内容：从成对四值次模不等式得到非负割边权、一元修正和常数，建立源侧0/汇侧1的容量映射。

论证与表述逻辑：

1. 次模比较同值两项总和与异值两项总和；逐项分解四个值，$w=(V_{01}+V_{10}-V_{00}-V_{11})/2\geq0$，其余项并入一元与常数。
2. 一元移出各状态最小值后成为非负终端容量，源边容量对应标签1，汇边容量对应标签0；中间边只在异标签时切断，因此割容量等于能量减常数。跨卷只用一次“图的表示与计算”章级引用。
3. 两变量例的四能量与图中容量对应，最小割返回合法配置$(0,1)$及能量1；负边权、高阶项超出此直接构造。

##### 7.3.3.2 多标签能量的局部优化

主要内容：将每次扩展或交换编码为二元表，说明度量/次模充分条件、严格改善终止、Potts近似比及剩余方法边界。

论证与表述逻辑：

1. 扩展时每节点保持旧标或改$\alpha$，列四项并以零对角和三角不等式证明该动作次模。循环全部标签并只接受严格改善，在有限配置下达到扩展局部最优，未必全局最优。
2. 交换只激活当前为$\alpha$/$\beta$的节点，每个节点独立二选一；写当前二元次模判据，非参与邻居折为一元项。恢复非负Potts能量，经典两倍保证针对完全扩展局部最优及既定非负口径，能量平移会改变比值。
3. 有序标签的凸标签差代价可用分层图精确求解；一般非次模二次伪布尔能量可由相应松弛给部分标号，其与某个全局最优兼容，未标变量仍需补全。两条原有路线补机制及一手出处，不扩大为任意多标签精确求解。

#### 7.3.4 可行配置恢复与最优性诊断

主要内容：以共同阈值证明二元次模LP紧性，再分析一般取整/搜索、可行解与对偶上界，并区分可观察差距和未知松弛/配置损失。

论证与表述逻辑：

1. 局部边表异值概率不小于节点均值差；共享一个均匀阈值取整使异值概率等于该差，所以某个阈值配置不差于分数解。用于最优LP时得到存在整数最优，平局仍可有分数最优；树图也可由全局实现性证明紧性。
2. 一般分数解可联合取整、局部搜索、切平面或分支定界；逐点标签可能不协调，硬约束下必须检查可行性并在原目标重算得分。
3. 最大化时记最佳合法配置得分$L$、当前原始可行值$P$、理论LP最优$U_{\mathrm{LP}}$和经验证对偶上界$U$，有$U\geq U_{\mathrm{LP}}\geq M\geq L$及$P\leq U_{\mathrm{LP}}$，而$P$与$L$无固定序。$U-P$诊断LP求解，$U-L$控制配置次优损失；三项分解中的真实松弛间隙和配置损失一般不能各自直接观测。
4. 三角例将均匀分数原始值、全零取整、一次翻转和已知最优并列，说明取整改善不消除松弛间隙。证书、计算/存储/通信与达到诊断标准的轮数一起记录；能量最小化时方向反转。
5. 最后分别列出分布查询与MPE的三角基准数值，说明两组界不能混列。一般边缘MAP含求和结构，不能直接当纯MPE的同一整数LP。

### 7.4 本章小结

主要内容：综合概率与配置两条路线，回收近似族、数值计算和实际查询误差，明确每种保证的成立条件及仍需检查的内容。

论证与表述逻辑：

1. 后验线以反向KL/ELBO连接合法$q$与目标，平均场/块分解保持真实熵；局部自由能、EP、Laplace分别改变一致性与熵、局部矩、密度曲率，计算结构与诊断职责不能混同。
2. 共轭消息、小批量更新与摊销映射分别减少局部期望、数据遍历和逐样本优化成本；近似族误差依赖保留的结构。回顾树上局部关系的精确性及含环图Bethe/Kikuchi、区域扩大、EP与Laplace的机制和成本，并要求把优化或固定点性质与概率查询误差分别检查。
3. MPE线以可行配置下界和松弛/对偶上界形成证书，分解便于求解，特殊次模结构可精确恢复整数解；一般概率查询和边缘MAP仍须处理各自的求和与依赖。
4. 扩展阅读引导按近似边缘、最佳配置、配分函数比较目标、可行域和界方向，并考察局部计算保留的依赖。

## 第8章 基于采样的近似推断

正文：[04-sampling.tex](../../tex/06-probabilistic-graphical-models/02-inference/04-sampling.tex)。

章首先把采样定位为与精确消元、变分并列的第三条路线：不显式求后验，而用一批代表性样本的统计量逼近后验积分，代价是随机误差、好处是几乎不依赖模型形式；并按“样本怎么来”预告四种机制——独立直接采样、提议加权（IS）、局部转移的Markov链（MCMC）、随观测递推的粒子系统（SMC）。

### 8.1 采样推断的定义

主要内容：固定模型、观测与查询函数，将后验概率和矩写成目标分布下的期望，区分后验归一化尺度、证据尺度、模型不确定性与有限计算误差。

论证与表述逻辑：

1. 从设备报警后的故障概率进入，给出未归一化目标、有限正归一化常数及查询函数；说明离散求和与连续积分的统一记法，未知正比例常数虽可在后验比值中消去，却不能用于恢复原模型证据。
2. 独立目标样本的均值用于多个查询，指示函数对应事件概率；在可积、有限方差条件下依次给出一致性、无偏性、方差及中心极限定理，并讲清MCSE（有限采样的计算波动，随$n$趋零）与后验标准差（模型固有不确定性）的区别。
3. 用人工设备模型的精确后验作为基准，固定后续方法的查询；说明改用带权、相关链或共享祖先的粒子后，误差分析必须随生成机制改变。

### 8.2 独立蒙特卡洛方法

主要内容：在独立候选框架中，分别通过目标生成、接受筛选和权重修正匹配后验，再用解析结构降低估计的随机波动。

论证与表述逻辑：

1. 先区分先验联合采样与条件后验采样，解释证据筛选和一般包络拒绝的正确性及成本。
2. 从丢弃候选转向保留候选，以密度比推导IS与SNIS，讨论随机分母、支持覆盖与加权矩。
3. 在目标与估计量明确后，解释控制变量、条件平均和图上的局部消元如何保均值、降低何种方差，以及收益受计算成本和相关性限制。

#### 8.2.1 直接采样、祖先采样与拒绝采样

主要内容：说明如何按条件生成规则获得独立记录，以及如何将易生成的候选筛选为目标样本。

论证与表述逻辑：

1. 祖先采样按有向图拓扑次序生成联合记录，每条记录使用新的独立随机输入；固定证据后的祖先生成并不自动等于后验采样。
2. 设备模型用报警筛选得到后验样本，以精确证据概率计算平均尝试次数，并指出多重稀有证据与连续等值事件的困难。
3. 一般拒绝采样用包络常数和均匀接受变量校正候选，推导接受后密度及接受概率；强调可操作的全局包络与高维成本条件。

#### 8.2.2 重要性采样

主要内容：用提议密度与目标密度之比调整候选贡献，明确普通IS与随机分母SNIS的不同保证。

论证与表述逻辑：

1. 从积分换测度得到普通IS；从未知证据的分子、分母均值之比得到SNIS，说明有限样本偏差、一致性及分母有效条件。
2. 在报警例中固定证据并对非证据变量生成候选，以似然权重计算四样本比例，区分加权结果、未加权比例与精确后验。
3. 用同支撑高斯例说明覆盖不等于有限二阶矩：将权重二阶矩写成目标密度平方除以提议的积分，按指数系数正负与临界零值推出提议方差阈值，保留尾部设计边界。

#### 8.2.3 方差缩减

主要内容：利用已知均值或可解析条件结构，减少同一查询估计中的随机性，区分单次方差、比值结构和链长期方差。

论证与表述逻辑：

1. 控制变量先以已知均值中心化，说明固定系数下为何不改变目标均值，以及系数选择与同批估计的边界。
2. 条件期望按保留变量积分掉其余变量，利用塔式与全方差关系解释保均值、独立单次方差不增；设备先验报警概率例将该关系落到可复算数值和成本。
3. SNIS需对分子贡献与分母贡献使用同一提议条件分布的积分；MCMC还须检查改变随机函数后的长期相关，不能把独立单次方差关系当成运行时间优势。

### 8.3 Markov链蒙特卡洛

主要内容：从“高维下找一个覆盖良好的全局提议与求后验同样难”转向只依赖当前位置的局部相关转移；说明链样本不再独立，正确性靠“转移保持目标+长期充分探索”两件事，并分别解释不变性、MH、Gibbs与HMC。

论证与表述逻辑：

1. 用转移核描述从当前状态到下一状态的随机规则，先分清目标不变与从指定初值有效探索。
2. MH以往返概率流校正一般提议，Gibbs利用满条件和图局部结构，HMC利用连续梯度轨迹，三者都须另查可达、返回与有限预算误差。
3. 同一后验任务下比较移动尺度、每轮成本、相关性和失效边界，避免以接受率或轨迹外观替代精度分析。

#### 8.3.1 Markov转移与目标分布

主要内容：明确平稳分布与细致平衡的含义，并把不变性、时间平均收敛和逐步边缘收敛分开。

论证与表述逻辑：

1. 从核的不变积分关系说明平稳性，用原地不动核反证“保持目标便能探索”；细致平衡以双向概率流解释为何是不变性的充分条件。
2. 有限不可约链说明状态互达，轮换两状态例区分时间平均正确与周期边缘振荡；一般状态的正Harris常返解释返回目标正质量区域的用途。
3. 后续方法首先构造保持目标的核，可达性和返回条件仍需对具体模型核查；混合速度连接初值影响、低概率通道和有限链长。

#### 8.3.2 Metropolis--Hastings方法

主要内容：说明MH的核心是“提议可任选、再用接受率校正使链保持目标分布、且不需要归一化常数”；通过接受或拒绝校正非对称提议，保留拒绝后的重复状态，并分析局部与独立提议的探索限制。

论证与表述逻辑：

1. 给出前后方向提议流及其较小值，推导MH接受率和细致平衡；拒绝时仍记录当前位置，避免丢掉停留时间改变目标。
2. 对称随机游走使提议比抵消，一维高斯例建立步长的移动/接受权衡；高维标准高斯例固定每坐标噪声尺度，由负对数目标差、交叉项和平方范数说明维数带来的困难。
3. 独立提议代入MH式得到新旧重要性权重比；当前高权重点难以离开，解释候选独立并不使接受后的链独立。

#### 8.3.3 Gibbs采样

主要内容：作为MH的图模型特例引出——一次只更新一个变量，而满条件因Markov毯往往可直接抽样、故接受率恒为一；利用图条件独立减少计算，并检查强相关与确定性约束导致的慢移动。

论证与表述逻辑：

1. 将单坐标满条件提议代入MH，说明单核保持后验、逐坐标复合也保持，但确定次序复合不一定可逆；以Markov毯和设备三个满条件展示局部运算。
2. 相关高斯例由配方得到条件均值和方差，再代入完整一轮得到AR系数；只有在平稳方差下将其识别为相邻相关系数，解释接受率为一仍会高度相关。
3. 分块联合更新改变移动方向但增加抽样成本；折叠在一致的边缘目标上更新，再条件补抽恢复联合；仅00/11合法的约束例说明单点不可达与联合块的不同。

#### 8.3.4 Hamiltonian Monte Carlo

主要内容：在正光滑连续目标上引入正态辅助动量，以守能、保体积和反向配对构造可校正的整体轨迹提议。

论证与表述逻辑：

1. 高斯动量负对数给动能，与位置势能组成扩展目标；积分动量恢复后验，刷新是精确条件更新，并避免固定能量面限制。
2. 由动能梯度与相反势能梯度配对形成Hamilton方程，沿轨迹求导展示能量变化抵消，再由速度场散度为零解释体积保持，两者共同保持扩展概率。
3. 明确步长、步数和人工轨迹时间，以固定位置/固定动量的可计算子更新组成蛙跳；保留Jacobian三角块和反向翻转证明，将自反保体积映射接入MH接受流。
4. 算法完整列出有效初值和固定参数域，保留拒绝后的重复位置与数值失败说明；一步标准正态例区分积分末动量和翻转后的提议，流程图统一位置记号。
5. 对高斯位置方程再求导得到质量矩阵作用，按本章动量协方差约定说明逆协方差等频；保留预热、自适应、梯度/线代成本、离散/约束边界，并以整周期返回说明精确接受率一仍可能共振不动。

### 8.4 序贯蒙特卡洛

主要内容：针对“观测随时间逐个到来、每来一个就重跑MCMC代价太高”，引入一群带权粒子随时间一起推进；复用粒子路径并递推权重，用重采样汰弱留强、用条件解析消元（RBPF）减少随机维度。

论证与表述逻辑：

1. 由持续传感器读数引入最小状态空间模型，明确转移/观测条件独立和滤波查询，区分真实时间与HMC人工时间。
2. 非物理时间的桥接目标以似然指数/逆温度递增连接先验和后验，相邻指数差给增量权重，移动核保持当前桥接目标。
3. 依次解释路径重要性、后代复制和RBPF条件积分，再在算法分析中分别审查归一化滤波均值与未归一化证据估计的保证。

#### 8.4.1 序贯重要性采样

主要内容：利用路径目标和提议的共同前缀，生成末端状态并递推权重，再边缘化为滤波经验测度。

论证与表述逻辑：

1. 展开路径联合的转移/似然因子和提议前缀，显示上一权重与当前增量的相乘关系，区分初始权重、归一化旧权重和任意公共尺度。
2. 路径函数只依赖末端时，积分忽略旧坐标但保留权重；点质量经验分布与无原子连续目标的TV距离不收敛，以有限位置集合质量1/0解释其与测试函数积分收敛不矛盾。
3. 固定父粒子下的一步最优提议消除当前增量条件方差，但父间差异、零预测似然与可计算性限制仍在；长期权重乘积会退化，数值对数技巧不能解决统计集中。

#### 8.4.2 粒子滤波与重采样

主要内容：按权重复制后代以重分配计算，明确保持的是条件经验均值，并比较多项式、分层和系统方案。

论证与表述逻辑：

1. 后代总数固定、条件期望等于粒子数乘权重，由线性性得到重采样经验积分条件无偏；单次结果仍波动，复制还会共享祖先。
2. 多项式法提供条件方差基线，分层法通过每层各抽一次消除层间均值方差，给出非负差项；系统法共享偏移，保留排列依赖与不保证统一方差优势的边界。
3. 自举滤波算法列出查询、整数规模、阈值及方案接口，解释传播后加权、重采样前输出、复制时同时保存旧粒子，以及未复制时继续保留旧权重。
4. 两状态两时刻例先算精确滤波，再用四粒子、一次系统偏移及祖先图比较加权与复制后结果；区分贫化、权重集中及计算/存储成本，避免把每次复制说成改善本轮估计。

#### 8.4.3 Rao--Blackwell化粒子滤波

主要内容：只采样难以积分的模式路径，每条路径内部维护精确可递推的条件分布，减少随机维度。

论证与表述逻辑：

1. 将联合路径后验分解为模式路径后验和其余状态的解析条件分布，查询对观测后条件分布积分。
2. 权重先使用尚未见当前观测的条件预测分布计算积分似然，连同模式转移/提议比更新；随后加入当前观测得到查询所用的条件后验，明确两种条件集合和次序。
3. 标量线性高斯例先由卷积得到观测预测密度，再用精度和一次项配方得到后验均值、方差与增益；两模式数值展示加权条件均值仍保留不确定性。
4. 条件积分降低随机性仍有协方差存储、矩阵计算和模式退化成本；近似条件滤波会再引入解析部分的近似误差。

### 8.5 算法分析

主要内容：把目标正确性、渐近条件和有限预算诊断分开，对独立、带权、相关链和粒子系统分别说明保证对象。

论证与表述逻辑：

1. 从查询函数的可积性和矩出发，分别分析IS/SNIS、MCMC与固定时刻SMC；对证据估计另保存绝对尺度并推导无偏递推。
2. 有效样本量按权重集中与时间相关区分；MCSE和多链诊断依赖当前查询、矩与长期方差估计，不能证明未探索区域不存在。
3. 固定查询与时间预算比较方法，结合可计算结构、成本、尾部覆盖和探索边界讨论与变分近似的组合。

#### 8.5.1 一致性、偏差与方差

主要内容：在明确矩和起点范围下给出估计极限，并展示SNIS展开与SMC证据无偏所依赖的中间推理。

论证与表述逻辑：

1. 普通IS的矩位于提议下的加权函数；SNIS定义分子/分母均值，一阶线性化显示中心化贡献并得到CLT方差，二阶交叉项与分母平方项给出偏差，保留余项、高阶矩与分母控制的充分条件。
2. MCMC正Harris常返及可积性给所声明类内任意起点的时间平均；几何遍历与高阶矩的CLT先说明平稳启动，再明确一般条件下几乎处处固定起点的扩展。若整类正Harris常返且非周期，则该类每个起点的总变差收敛配合耦合可进一步转移CLT；类外不自动包含，有限预热不替代这些依据。
3. 固定时间SMC的有界/正性条件支持条件方差与归纳的一致性纲要；固定粒子数增加时间不等于固定时刻增加粒子，时间一致界和CLT需额外遗忘、矩及重采样条件。
4. 定义每轮原尺度预测似然因子与证据乘积，用未归一化粒子积分的条件期望递推说明无偏；归一化滤波均值仍可能有偏，依赖因子不能靠逐项无偏相乘，自适应日程及全零权重也须保持相应约定。

#### 8.5.2 有效样本量与收敛诊断

主要内容：从有限随机贡献的集中与时间依赖引出两种ESS，再说明MCSE、经典及现代Rhat、主体和尾部ESS的计算与盲区。

论证与表述逻辑：

1. 权重平方和倒数由等贡献或重复选择同祖先的集中度解释，保留取值边界、四粒子例和CV极限；它不等于任意查询的方差等价样本数，也不等于独立祖先数。
2. 平稳链的自协方差和得到长期方差、积分自相关时间和查询相关ESS；解释截断、批均值、谱方差的操作及条件，并将SNIS渐近方差代入为MCSE，避免直接套到依赖SMC粒子。
3. 多链样本数和链长满足最小域时，以样本方差、链内W和均值差异B构造经典Rhat；解释分裂、秩正态、折叠及取大，并用链内自相关与链间方差合并相关估计，经成对正序列/单调截断得到多链ESS；尾ESS使用两端累计分位指示并取小，不混同小区间概率。
4. 经验阈值只是筛查，所有链可能共同遗漏同一模态；联合查看轨迹、秩、查询MCSE、尾部与HMC积分失败，不把有限诊断当成全局收敛证明。

#### 8.5.3 方法选择与计算边界

主要内容：在同一后验查询与预算下，根据可计算结构、提议尾部、相关性和局部成本选择或组合方法。

论证与表述逻辑：

1. 对直接生成、拒绝、IS、Gibbs、HMC和SMC分别列明输入结构、适用条件及主要代价，保留稀有证据、多峰、维数和祖先退化的限制。
2. 区分IS独立候选的贡献集中与独立MH的长停留，再比较固定时间达到同一MCSE的代价；表格将采样与变分的渐近目标、有限预算、覆盖、并行和诊断放在同一任务下。
3. 变分分布可作重要性或独立MH提议，采样可检验近似分布的尾部覆盖；组合仍需支持、权重矩、核不变性与探索条件。

### 8.6 本章小结

主要内容：综合目标匹配、充分探索与粒子传播，强调正确渐近目标不自动保证有限预算下的可靠估计。

论证与表述逻辑：

1. 回到报警后验查询，归纳独立候选的生成/接受/权重、Markov链不变转移与充分探索、粒子传播/加权/复制分别如何形成估计。
2. 误差依赖查询及对应极限条件，独立矩、带权矩、长期相关和固定时刻粒子数各有范围；方法选择同时检查成本与诊断不能覆盖的盲区。
3. 未知模型参数将使推断统计量进入后续学习；扩展阅读引导进一步核查不变性、遍历、有限混合和估计方差，保留本章与后章的职责边界。
