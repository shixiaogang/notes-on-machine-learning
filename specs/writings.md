# 中文内容与写作规范

本规范适用于正文、大纲、示例、图表说明和边注。目标是让具备前置知识、初次接触本节的读者，能够说明当前问题、跟随推理，并正确使用结论。可验证是指检查者能定位正文、指出依据并复核判断，不是把理解变成字数或标题数量检查。目录完整、句子增加或编译成功均不能单独证明写作合格。

## 一、执行流程

新增、重构和局部修改均按下表执行；仅审读时交付发现，不擅自修改正文。局部任务只处理授权范围，但须包含理解改动所需的前后文，不要求重建整章。

| 步骤 | 执行动作 | 完成依据 |
| --- | --- | --- |
| 1. 确定范围与学习路径 | 阅读实际入口、相关大纲和相邻正文；按第二节确定对象、读者起点、问题分工与概念依赖。 | 能指出本次解决什么、依赖哪里、改动会影响哪些位置。 |
| 2. 完成连贯正文 | 按第三节展开概念、结论、推导和例子；按第四节处理表达、术语和引用。 | 解释已经写入正文，所需条件与依据在使用之前或当前位置可见。 |
| 3. 依次复读三层逻辑 | 按第五节先查章节组织，再查段落关系，最后查句子、公式等具体单元。 | 有可定位的检查范围、发现及判断依据，不以统一勾选“通过”代替复读。 |
| 4. 修订并复核 | 先修技术错误和结构缺口，再修衔接与措辞；把改动放回上下文重读。 | 原问题在最终版本中消除，相关位置没有出现新的跳步、重复或条件错位。 |
| 5. 同步与交付 | 核对大纲，完成适用的工程检查，报告实际完成范围及剩余问题。 | 正文与大纲一致，文字结论和工程检查结果分别说明，未检查部分不宣称通过。 |

工作笔记和审读记录留在任务临时目录，不写进教材或 `plans/`；只保留实际判断所需的信息。工作区、构建与提交按[开发要求](development.md)执行，大纲同步按[计划目录规范](plans.md)执行，公式和版式按[LaTeX规范](latex.md)、[样式规范](design.md)执行，图像制作按[图像规范](figures.md)执行。

## 二、写前确定内容组织

### 2.1 明确读者、对象和问题

写前用简短工作笔记回答以下四项，不要求在正文另设同名栏目：

1. **读者已知什么：** 所需定义、记号和结论在哪里已经建立；当前位置以前尚未出现的知识不能默认掌握。
2. **当前讨论什么：** 数学对象或任务是什么，输入、输出、范围、结构与条件如何限定；读完应能解释或完成什么。
3. **各部分分别解决什么：** 每个主要小节承担哪个子问题，使用什么依据，得到什么结论；共同基础在哪里讲，哪些内容属于补充。
4. **为什么按此顺序讲：** 前一步建立了什么，后一步还需要什么；并列分支如何共同回答上位问题，哪些内容确实存在先后依赖。

不能只把术语清单改成目录。若某个分支没有独立职责，或读者必须借助后文才能理解当前定义，应先调整材料归属和依赖，再写过渡句。

### 2.2 分组、顺序和标题分别判断

| 决定 | 执行要求 | 复核方法 |
| --- | --- | --- |
| 内容分组 | 相同问题下的相关内容集中，不同对象且运算含义不同的内容分别建立。明确共同部分与专属条件。 | 逐项检查归属：偏导数与梯度是否相连；标量微分、向量值微分与矩阵自变量是否分清；运算定义、运算性质与计算例子是否各得其所。 |
| 阅读顺序 | 按概念和证明依赖安排。由定义进入判别、性质与计算时，解释每一步解决什么，不机械套用固定目录。 | 对每项首次使用的概念或结论，能找到此前说明；对范围推广，能指出保留什么、改变什么及为何需要。 |
| 标题层级 | 标题帮助辨认对象、问题或学习阶段，可直接用“矩阵乘法”“偏导数和梯度”等名称。并列分支须有共同依据，连续阶段须有实际推理关系。 | 遮住标题概括本节职责，再与标题核对。不能仅为语法整齐、形式分类完备或增加视角而改名、拆分、合并。 |

教学标题不必等同于覆盖全部适用对象的严格分类。“有限集与Jordan测量”可以保留：它组织从有限集合的计数与相加规则，经区间长度和Jordan测量，再到可数集与可数覆盖的认识过程。正文在转换处说明Jordan测量也适用于某些无限集合，并区分元素个数有限与逼近所用区间数有限，即可兼顾理解路径与数学准确性。

### 2.3 建立章节与段落的衔接

章首用具体问题建立学习目标，路线只解释各部分为何相连，不逐条扩写目录。章末回应这些问题，综合所得认识、成立条件与边界，不新增未经论证的结论。各章保留独立的 `\section{本章小结}` 及语义标签。

每段推进一个中心意思。相邻段落须能说明是在继续推导、改变条件、比较同一问题的另一种情况，还是转入一个并列子问题。仅添加“首先、其次、此外、因此”不能建立这种关系；因果词须有推导依据，比较须有共同对象。

较长证明或更一般的结构可以标为补充阅读；理解或使用主线结论必需的定义、条件和中间步骤仍须保留在正文。不同运算及其条件分别讲清，证明中的临时步骤和例子通常不另设标题，不用碎片化标题代替连续论述。

## 三、各类内容怎样展开、怎样判定

以下要求按实际出现的内容执行。没有相应内容时可记为不适用，并说明原因；不得为填满模板强造动机、反例、应用或历史。

| 内容单元 | 写作动作 | 合格依据 |
| --- | --- | --- |
| 新概念、方法与对象转换 | 从当前对象、现象或推导需要进入，说明已有认识的缺口，再给名称、白话解释和准确形式。改变输入、输出、定义域、测度等结构时，交代转换关系。 | 读者能凭相邻正文回答“为何需要它、它表示什么、与已有对象有什么关系”；不能靠另一个未解释的术语、聊天补充或后文补洞。 |
| 定义与定理 | 前面用一至两句实际引出，标题后不直接接定义、定理环境。正式陈述写清对象、假设、量词、符号与结论；定义性内容、解释和例子分别安排。 | 引出指向具体问题，不只是“下面给出定义”；结论适用的范围与条件完整，必要、充分、充要以及局部、整体、处处、几乎处处未混淆。 |
| 公式、证明与机制 | 公式前说明计算或证明目的，新符号及时解释；展开关键等式、不等式及操作依据，公式后说明它回答了什么。 | 具有前置知识的读者能逐步复述推理。交换极限、改变求和次序或扩大对象范围有适用依据；有限、可数与不可数的操作未混用。 |
| 概念关系与比较 | 明确比较对象、共同问题、条件和判定标准，说明蕴含、等价、强弱与适用范围；逆向不成立且影响使用时给反例或补充条件。 | 不靠连排定义或“更好、更稳定”等词下判断；比较表与关系图汇总的是正文已经解释的关系。 |
| 示例、反例与实验 | 给足输入、过程、结果和设置；优先复用能承担新解释任务的小例子。反例指出具体缺口，实验保留无收益和反预期情形。 | 数值可复算，符号与正文一致；假设数据明确标为教学示例。经验观察不冒充普遍定理，比较交代基准、指标、方向及范围。 |
| 类比、图表与补充材料 | 说明对应的对象和所解释的推理步骤，必要时指出类比边界；图中保留必要标记，详细条件与读法放图注或相邻正文。 | 读者知道应观察什么、它支持哪一步。图注不只重复标题，关键条件不隐藏在边栏，类比或图形直觉不替代定义与证明。 |

说明推广的理由时，反例应回到当前目标。例如狄利克雷函数可以暴露黎曼取样的局限，后续还应说明可测性如何连接集合测量与函数累计，以及收敛定理怎样在相应条件下处理逼近。不能只说新理论“处理更多函数”，也不能宣称它无条件允许极限与积分交换。

证明须区分三种情形：本节完整证明、引用已经成立的一般结论、仅解释特殊情形的机制。引用时给出准确条件与来源；不能把矩形上的推导写成一般区域的完整证明。算法与模型还须说明相应假设、计算或存储代价及典型失效情形；复杂度须明确规模变量与计算对象，改进效果不能替代代价分析。

### 判定示例

以下用于校准检查，不是每节必须重复的写法。

| 待检查内容 | 判断与最小修正 |
| --- | --- |
| “有界集合未必是有限区间并。” | 判断正确仍可能解释不足。说明两种要求的区别，给出如倒数点集的例子，并指出为何原来的有限区间长度公式不能直接计算它。 |
| “将非退化区间看成有限个单点的并，有限可加性就有矛盾。” | 不合格：前提不成立。不得为制造动机改变对象；区分有限、可数与不可数，再用实际反例说明原方法的局限。 |
| “严格凸函数有唯一最小点，所以最小点唯一就意味着严格凸。” | 不合格：还须保证最小值达到，逆向也不成立。保留正向条件，并用绝对值函数等反例检查逆命题。 |
| “定义前已经加了两句话。” | 不能据此通过。回到正文指出这两句实际交代了哪个对象、问题和需要；空泛预告仍须改写。 |

## 四、表达、术语与来源

### 4.1 自然中文

- 说清谁在什么条件下对什么做了什么；使用准确动词，少用长串修饰语和抽象名词。指代可能有多个对象时重复名称。
- 句长随推理动作安排。多层条件与独立结论可拆开，紧密推理保留承接；不按固定字数或“我们”的出现次数检查。
- 自然用“我们”带领观察和推导，“你”用于确需读者操作的尝试；定义、定理和客观结论保持中性。不虚构个人经历、实验或读者反应，不用“相信大家已经明白”替读者下判断。
- 删除重复预告、空泛评价和不增加信息的套话。“显然”“容易知道”若跳过必要依据，应补出那一步；因果、否定和比较关系须能展开成明确判断。
- 用连续段落讲解，列表只呈现真实并列、步骤或比较。首现术语、正式陈述使用相应语义标记，不给普通段落反复加“背景、机制、总结”等标签。

### 4.2 术语、记号与引用

- 引入术语前搜索既有用法；首次写中文名称、常用英文名称与缩写（如有），并解释含义。同一概念不为避免重复而换名，同一符号不无声改变含义。首现术语使用 `\term` 或 `\termalias`，数学粗体按对象类型使用。
- 叙述学习希望达到什么时用“目标”或“学习目标”；讨论可计算准则及其数值时用“目标函数”“目标值”。损失、正则化、约束与回报分别保持准确名称，不混为同一对象。
- 区分定义、假设、证明、直觉、观察、惯例与作者推断。外部事实、历史归因、数据和研究结论核对可靠一手来源；没有证据时保留待核实状态，不编造引文、结果或机制。
- 使用语义交叉引用定位已有内容，当前推理所需的一步仍在本地解释。跨卷引用先说明所用结论、条件及用途，再标注可参考的卷与章；不重复正式定义、定理或证明，同章同一外卷章节只引一次，按语义标签生成位置，不手写章号或列出外卷节号。
- 中文叙述用全角标点，公式、代码和英文内部保持相应格式。中文与行内公式、英文缩写之间不手工补空格；句末文献用 `\scite`，标记置于中文句号前。

## 五、复读、问题处理与交付

### 5.1 三遍复读

复读只使用目标读者的前置知识和当前位置之前的正文。作者常识、聊天说明与后文补释均不能算作当前位置已经解释充分。

| 顺序与范围 | 检查动作 | 留下的依据 |
| --- | --- | --- |
| 第一遍：章、节组织 | 从实际正文重建核心问题、分支职责、依赖及最终回答，再与大纲比较。局部修改说明它在章内的作用。 | 对应正文位置、实际职责与发现；说明章首承诺在哪里兑现、哪些范围未读。 |
| 第二遍：自然段关系 | 逐段概括中心作用，检查前后关系、首次阅读依赖、细节用途及对象转换。 | 段落位置和短引，以及为何承接成立或缺少哪一步；重复、错位和跳步有具体位置。 |
| 第三遍：句子与特殊单元 | 逐句核对对象、条件、动作、依据和指代；复算公式、示例，检查定义、定理、图注和表注。 | 对照第三、四节给出接受依据或问题。连续句子共同完成一个推理动作时可合并记录，但覆盖范围须清楚。 |

记录注明实际文件、版本或快照、读者假设与检查范围。短小修改可以简短记录，但仍要分别判断组织、段落和句子三个层面；未读全文不能称全章通过。只写“通顺”“无问题”“已按规范检查”或复制检查表，不构成证据。单个作者的检查称自查，只有未参与相关改写者实际复读了相应版本，才称独立复核。

### 5.2 发现问题后怎么处理

每项发现至少留下“位置与短引—读者缺少什么或哪里不成立—修改动作—最终版本复读结果”。按影响优先处理技术错误、缺失前提与结构缺口，再处理衔接和措辞。

同一根因影响多处时集中修复，不只在被指出的一句后追加解释。移动内容须检查原位置和新位置；修改概念依赖或章内主线后须整章顺读。超出授权范围的发现单列，不擅自扩大修改。

必须修复的缺口通过两种方式关闭：实际修改后复读确认消除；或在原上下文中给出依据，确认原发现不成立。个人句式偏好不自动构成不通过，须说明它造成了什么理解或技术问题。证据尚缺时写明“待核实”及缺什么，不以更强措辞填补。

### 5.3 交付条件

交付前分别确认以下结果，不再重复逐项抄录前面的写作要求：

1. **文字结果：** 声明范围已完成三遍复读；成立的技术与理解问题已修订或有据撤销。未解决项及未检查范围明确列出，不宣称整体通过。
2. **组织结果：** 按最终正文入口核对大纲的标题、层级、顺序、主要段落内容与边界；内容转移核对两侧，各章独立小结保留。
3. **工程结果：** 执行本次改动适用的构建、引用、资源及成品检查；涉及版面时查看实际PDF。文字、数学和版面验证相互独立，不能互相代替。
4. **交付说明：** 说明实际改动、验证结果、剩余项，以及所在工作区和提交或集成状态；不把“计划修改”说成已经写入正文。
