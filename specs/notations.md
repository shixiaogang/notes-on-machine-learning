# 数学符号与记号规范

## 字形约定

| 对象 | 形式 | 示例 |
| --- | --- | --- |
| 标量 | 小写斜体 | `$a, x, \lambda$` |
| 向量 | `\bm` 加粗小写 | `$\bm{x}, \bm{w}$` |
| 矩阵 | `\bm` 加粗大写 | `$\bm{A}, \bm{W}$` |
| 标量集合 | 大写字母 | `$X, V, E$` |
| 向量集合 | `\bm` 加粗大写 | `$\bm{X}, \bm{Z}$` |
| 矩阵集合 | 花体大写 | `$\mathcal{A}, \mathcal{W}$` |
| 由多个集合组成的结构 | 花体大写 | `$\mathcal{G}=(V,E)$` |

集合和结构的字形应根据其语义确定，而不是只根据字母的大小写确定。例如，图使用 `$\mathcal{G}=(V,E)$`，其中 `$V$` 和 `$E$` 分别是顶点集合与边集合。

## 索引与迭代

- 迭代步使用带括号的上标：`$a^{(t)}$`、`$\bm{w}^{(t)}$`。括号用于区分迭代编号和幂，例如 `$a^{(2)}$` 表示第二次迭代中的值，而 `$a^2$` 表示平方。
- 元素、样本或集合成员使用下标：`$a_i$`、`$\bm{x}_i$`。
- 多维索引之间使用逗号：`$a_{i,j}$`、`$\bm{A}_{i,j}$`，不得写成 `$a_{ij}$`。
- 冒号表示某一维取全部元素：`$\bm{A}_{:,j}$` 表示第 `$j$` 列，`$\bm{A}_{i,:}$` 表示第 `$i$` 行。
- 同时出现迭代和元素索引时，两者各归其位，例如 `$\bm{x}_{i}^{(t)}$` 和 `$\bm{A}_{i,j}^{(t)}$`。
- 索引变量默认使用 `$i,j,k$`；样本数、特征数等规模使用 `$n,d$`。若章节另有约定，应在首次出现时说明。

## 常用运算

- 转置使用 `$\bm{A}^{\top}$`，逆矩阵使用 `$\bm{A}^{-1}$`，伪逆使用 `$\bm{A}^{\dagger}$`。
- 内积使用 `$\langle \bm{x},\bm{y}\rangle$`；范数使用 `$\lVert\bm{x}\rVert_2$`，并显式写出非默认范数的下标。
- 期望、概率、方差等运算符使用直立或统一宏：`$\mathbb{E}$`、`$\mathbb{P}$`、`$\operatorname{Var}$`。
- 优化问题使用 `\min`、`\max`、`\argmin` 和 `\argmax`，变量条件写在下方。
- 函数名和文字下标使用直立体，例如 `$\operatorname{softmax}$`、`$L_{\mathrm{train}}$`。
- 数域使用黑板粗体，例如 `$\mathbb{R}$`、`$\mathbb{N}$`；明确写出张量或矩阵的形状，如 `$\bm{X}\in\mathbb{R}^{n\times d}$`。

## 公式编写

1. 公式中出现的新符号必须在公式之前或紧随其后解释，包含语义和必要的维度信息。
2. 重要公式使用带编号的环境并添加 `\label{eq:...}`；仅用于行内推导的公式不编号。
3. 多行推导使用 `aligned` 或 `align`，等号与不等号对齐；关键变形应在正文中说明依据。
4. 标点属于句子。展示公式后根据语义添加逗号或句号。
5. 不使用 Unicode 数学字符代替 LaTeX 命令；源文件中写 `\alpha`、`\leq` 和 `\times`。
6. 避免只给公式不给直觉。核心公式通常应同时说明变量含义、直观解释、适用条件和可能的边界情况。
