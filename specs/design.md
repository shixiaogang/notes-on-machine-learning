# 书籍样式规范

## 样式职责

全书采用简洁的实色色块、留白和清晰的文字层级。样式由共享模块控制，不在章节中复制版式参数或用局部间距补丁修正页面。数值参数以样式源文件为准，本规范记录设计约束与使用接口。

| 入口 | 职责 |
| --- | --- |
| `tex/preamble.tex` | 书籍元数据与样式加载 |
| `tex/styles/fonts.tex` | 字体、术语与行内代码 |
| `tex/styles/layout.tex` | 调色板、版心、封面、标题、页眉和图表注 |
| `tex/styles/structure.tex` | 卷、部分、阅读指引、目录及书签 |
| `tex/styles/environments.tex` | 数学陈述、代码和算法 |
| `tex/styles/references.tex` | 边注引文与文献格式 |
| `tex/styles/figure-style.tex` | 全书科研图的字体与语义配色 |

项目样式在这些模块中维护；第三方 `tufte-book.cls` 与 `tufte-common.def` 不用于修补单章版面。文件组织、编号、交叉引用、数学记号和编译流程见 [LaTeX 与数学记号规范](latex.md)；图内样式见 [图像规范](figures.md)。

## 字体与配色

| 用途 | 中文 | 英文 |
| --- | --- | --- |
| 正文、`\songti` | 思源宋体 | STIX Two Text |
| 标题、`\heiti`、`\term` | 思源黑体 | Source Sans 3 |
| 数学陈述、引文、边注、图表注、`\kaishu` | 霞鹜文楷 | STIX Two Text |
| 代码 | 霞鹜文楷等宽 | Source Code Pro |
| 图内文字、`\figurefont` | 霞鹜文楷 | Source Sans 3 |
| 数学公式 | — | STIX2 |

中文斜体使用文楷，英文书名和论文标题使用真正的斜体。字体从仓库 `fonts/` 加载，缺失时明确报错；增补字体同时更新许可证和校验清单。STIX2 的 Type 1 数学实现保持与 `\bm` 兼容，不混用 `unicode-math`。

正文使用 `BookInk`，强调与结构使用 `BookTeal`，辅助文字使用 `BookMuted`。数学陈述沿用定义青、定理蓝、引理浅蓝、示例黄的层级。图形使用集中定义的语义颜色，颜色之外还须有文字、形状或线型提示；具体图形约定不在此重复维护。

## 页面、导航与前后页

使用 Letter 纸张和 Tufte 正文加边栏版心。核心论证留在正文，边栏承担补充信息。页脚不放页码；普通页外侧页眉的青色色块显示页码，偶数页显示章号与章标题，奇数页显示节号与节标题。章节起始页、卷首页、部首页、阅读指引和必要的空白页隐藏页眉页码。

全集和单卷共用“封面—内扉页—版权页—前言—数学符号—目录”的前页顺序。封面使用墨蓝底与青色色块，内扉页和版权页为白底。全集显示副标题，单卷显示“卷号：卷名”；作者、年份、版本及许可声明由元数据集中维护，不能在各卷重复写入。

卷首页整页铺满 `BookInk`，只显示卷号及中英文标题；单卷省略卷首页。部首页使用 `BookPaper` 浅灰整页背景和 `BookTeal` 青色编号块，中文标题为墨蓝黑体，英文标题为灰色无衬线体。使用 `\bookvolume` 和 `\bookpart`，不用章节源文件自行绘制标题页。阅读指引使用 `\BookPartGuide`，说明本部分的问题、内容边界与章节组织，不提供推荐阅读顺序，也不进入目录或书签。

目录使用全版心宽度，全集保留到“卷—部分—章—节”，单卷从部分开始。卷条目为青底白字，部分为青色，章为墨蓝，节为灰色；编号、标题与页码各自对齐，卷条目不得孤立在页底。书签层级与正文结构一致，不添加“前页”父级；内扉页、版权页与前言内部小节不生成书签。

前言独立成页，不进入目录；参考资料说明实际查阅用途，教材登记与正文引用由文献库维护，不把条目数量写成设计约束。共享后页依次输出参考文献和索引，两者进入目录及顶层书签。索引显示名称统一为“索引”。正文页码、部首页奇偶及单卷引用回退遵循 LaTeX 规范。

## 数学、代码与算法

数学陈述使用 `definition`、`theorem`、`lemma`、`example`，可选参数为标题，标签写在环境内。采用细左线和浅底色，正文为楷体、标题为黑体，允许跨页。`proof` 不加色块，结尾为黑色实心方块。`mathproblem` 独立编号，标题显示“数学问题”，使用青色左线与浅青底；框内陈述给定对象、条件和所求性质，场景解释与工具分析放在框外。

代码使用 `codeblock`，标题为必选参数，语言和标签通过选项指定，例如 `\begin{codeblock}[language=Python,label={code:step}]{参数更新}`；标签不能写入代码正文。行内代码使用 `\code` 并转义 LaTeX 特殊字符。代码基于 `listings`，支持中文注释和折行，不依赖 shell escape。

算法使用 `algorithm` 与 `algorithmic`，以 `\Require`、`\Ensure`、`\State` 等语义命令表达步骤。代码和算法允许跨页，默认不浮动，标题统一左对齐。不要加载占用同名环境的 `algorithm` 或 `algorithm2e`。

## 引文与图表

文献集中在 `tex/references.bib`，由 Biber 处理。正文 `\cite` 或 `\sidecite` 产生上标与完整边注；一个可选参数为后注，两个为前注和后注。多篇文献在同一命令中列键，逐篇产生编号和边注。书籍、期刊、会议各用相应字段，缺失信息应查证，不编造。

会生成边注的引用命令不放在标题、图注、代码或盒子内；图注注明来源时使用 `\fullcite`。检查密集引用页的边栏容量，必要时调整正文或引用分布，不能通过过度缩小字号或越过页底容纳边注。

`figure`、`table` 占正文宽度，`figure*`、`table*` 跨正文和边注区，以 `\linewidth` 控制尺寸。图表注位于对象下方，标签紧跟图表注。表格使用 `booktabs`，自适应列宽使用 `tabularx`，不用竖线。图注解释对象、视觉编码与必要条件，图内只留识别所需的短标注。

需要跨页的问题地图使用 `BookLongTable`，其列格式作为必选参数，表头和续页表头在内容源中声明。环境采用全版心宽度和普通表格字号，底部表注沿用统一字体、颜色与左对齐。`multirow` 用于合并相同对象或问题的单元格；同一合并组内部禁止分页，组间允许分页，避免跨页合并造成文字错位。

## 样式验收

修改共享样式后检查全集和受影响单卷的最终 PDF：封面与前后页、卷和部首页、目录与书签目标、奇偶页眉、数学陈述跨页、代码折行、图表宽度、边注避让及字体。检查新增样式的代表性页面，不把独立校样中的强制分页带入正式章节。完整构建及成品校验按 [开发要求](development.md) 执行。
