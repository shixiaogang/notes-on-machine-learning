# 框图风格品质参照

![框图的内容与视觉层次](diagram-style-reference.png)

本图保存 2026-10-09 用户认可的框图风格迭代，供新图提示词选取品质参考：outline 语义图标与同色底板、醒目标题与小一档灰色说明、框内同色浅深、适量机制图元与留白。布局按新图内容自主决定，参考图的标签、维度与算法关系不替代逐图事实清单。

模型设计稿的字体与色值是外观近似；正式输出按 [图像规范](../figures.md) 在共享样式和 TikZ 中落实，单独核对科学准确与视觉质量。完整提示词与修订见 [diagram-style-reference.prompt.txt](diagram-style-reference.prompt.txt)。生成工具为 `image_gen.imagegen`，实际模型名、seed 与采样参数未暴露；参考图片仅用于品质方向，没有在此分发外部素材。
