# LaTeX 与数学记号规范

## 文件组织与命名

- `tex/main.tex` 是全集薄入口；六个 `tex/<slug>/main.tex` 是单卷薄入口。薄入口只声明出版模式及当前卷元数据，再载入共享驱动 `tex/book.tex`。
- `tex/book.tex` 统一加载文档类、`tex/preamble.tex`、共享前页、当前版本的正文范围和共享后页。`tex/frontmatter.tex` 与 `tex/backmatter.tex` 分别是共享前页和后页入口。
- 内容按“卷—部分—章”组织：`tex/` 下的带两位序号英文目录表示卷，卷内同样编号的英文子目录表示部分；每章使用独立的 `.tex` 文件。各卷的 `volume.tex` 只声明卷及其部分内容，不承担文档类、前后页或出版模式配置。
- 目录前缀按卷内、部分内顺序从 01 开始，只表示源文件顺序，不等同于 PDF 中显示的编号。
- 每个部分的章节文件按章节顺序使用两位数字前缀，再接描述性的英文小写名称；例如 `01-linear-regression.tex`。部分入口文件固定命名为 `part.tex`，不使用章节前缀。
- 双语索引映射以 `tex/index-terms.tex` 为总入口，按词条在全书首次出现的卷归档到 `tex/index-terms/<slug>.tex`；正文文件不分散维护英文映射。
- 图片存放在 `figures/`，规范和计划分别存放在 `specs/` 与 `plans/`；不得使用机器相关的绝对路径。
- 一个源文件聚焦一个章节或一个可复用组件，避免形成难以审阅的超大文件。

## 出版版本与编号

- 全集由 `tex/main.tex` 构建。卷、部分和章在六卷范围内连续编号，正文页码从 1 开始连续计算；全集保留卷首页和卷级目录。
- 单卷由对应的 `tex/<slug>/main.tex` 构建。单卷省略卷首页和卷级目录，部分、章和正文页码均从 1 开始；卷号元数据仍保留原全书卷次，使 `vol:*` 标签的语义稳定。
- 全集和单卷使用同一组 `volume.tex`、`part.tex` 和章节源文件。不得为局部编号复制正文，也不得在正文中根据输出文件名手工维护两套章号。
- 全集和单卷的每个部首页必须从奇数正文页码开始；必要时补一张无页眉、无页码的空白页。目录、书签和部分标签均指向实际部首页。此规则不依赖文档类的 `openany` 或单双面选项。
- 正文第 1 页必须位于 PDF 的实际奇数页，使正文页码与 PDF 页面序号的奇偶一致；前页结束后必要时补空白页，再重置正文页码。
- 跨卷引用使用 `\BookVolumeRef`、`\BookPartRef`、`\BookChapterRef`、`\BookSectionRef`、`\BookTheoremRef` 或 `\BookEquationRef`。全集显示数字引用并保留链接，单卷在目标不属于当前范围时显示调用处提供的卷名、章名或公式说明。
- 索引页标题、目录条目和 PDF 书签统一为“索引”。`\term{显示词条}` 只在正文阶段写入主题词索引，
  正文显示不附加英文；`\term[排序键]{显示词条}` 用于指定排序键。所有版本载入完整词典，
  但索引范围只由当前版本正文的实际调用决定，最终索引采用两栏排版。

## 标签与引用

统一使用以下标签前缀：

| 对象 | 前缀 | 示例 |
| --- | --- | --- |
| 卷 | `vol:` | `\label{vol:models}` |
| 部分 | `part:` | `\label{part:classical-models}` |
| 章 | `chap:` | `\label{chap:linear-models}` |
| 节 | `sec:` | `\label{sec:least-squares}` |
| 公式 | `eq:` | `\label{eq:normal-equation}` |
| 图 | `fig:` | `\label{fig:decision-boundary}` |
| 表 | `tab:` | `\label{tab:model-comparison}` |
| 算法 | `alg:` | `\label{alg:gradient-descent}` |
| 定义 | `def:` | `\label{def:empirical-risk}` |
| 数学问题 | `question:` | `\label{question:training-convergence}` |
| 定理 | `thm:` | `\label{thm:convergence}` |
| 引理 | `lem:` | `\label{lem:gradient}` |
| 示例 | `ex:` | `\label{ex:squared-loss}` |
| 代码 | `code:` | `label={code:gradient-step}` |

- 标签名使用英文小写和连字符，并在全书中保持唯一。
- 使用 `\ref`、`\eqref` 或项目统一的智能引用命令，不手写章节号、图号或公式号。
- 引用目标可能位于另一卷时，不直接使用裸 `\ref` 或 `\eqref`，而应使用上一节的范围感知引用命令并提供可独立理解的文字回退。
- 图表的 `\label` 紧跟在 `\caption` 之后。

## 宏与依赖

- 重复出现的数学运算符、符号和视觉样式应定义为统一宏，不在各章重复定义。
- 使用宏之前先检查项目是否已有等价定义；新增宏应语义明确，避免单字母命令名。
- 普通双语词条使用 `\DeclareBookIndexTerm{显示词条}{English term}` 集中登记。
  同一中文显示词有不同语义时，使用
  `\DeclareBookIndexTermAlias{语义身份}{显示词条}{English term}` 登记别名，
  正文再写 `\termalias{语义身份}{显示词条}`。两种正文命令都只改变索引写入，不改变显示文字。
- 索引登记值不得包含 makeindex/xindy 保留字符 `@`、`!`、`|` 或 `"`。
  纯英文完整名称和数学词可以不登记，其他正文中文词条必须由审计工具覆盖。
- 新增 LaTeX 宏包前检查是否已由模板加载，并记录引入理由，避免功能重叠或冲突。
- 不修改第三方模板来解决仅属于单章的问题；项目级模板修改应有独立说明和验证。


## 数学记号

### 字形约定

| 对象 | 形式 | 示例 |
| --- | --- | --- |
| 标量 | 小写斜体 | `$a, x, \lambda$` |
| 向量 | `\bm` 加粗小写 | `$\bm{x}, \bm{w}$` |
| 矩阵 | `\bm` 加粗大写 | `$\bm{A}, \bm{W}$` |
| 标量集合 | 大写字母 | `$X, V, E$` |
| 向量集合 | `\bm` 加粗大写 | `$\bm{X}, \bm{Z}$` |
| 矩阵集合 | 花体大写 | `$\mathcal{A}, \mathcal{W}$` |
| 由多个集合组成的结构 | 花体大写 | `$\mathcal{G}=(V,E)$` |

集合和结构的字形应根据其语义确定，而不是只根据字母的大小写确定。例如，图使用 `$\mathcal{G}=(V,E)$`，其中 `$V$` 和 `$E$` 分别是顶点集合与边集合。

### 索引与迭代

- 迭代步使用带括号的上标：`$a^{(t)}$`、`$\bm{w}^{(t)}$`。括号用于区分迭代编号和幂，例如 `$a^{(2)}$` 表示第二次迭代中的值，而 `$a^2$` 表示平方。
- 元素、样本或集合成员使用下标：`$a_i$`、`$\bm{x}_i$`。
- 多维索引之间使用逗号：`$a_{i,j}$`、`$\bm{A}_{i,j}$`，不得写成 `$a_{ij}$`。
- 冒号表示某一维取全部元素：`$\bm{A}_{:,j}$` 表示第 `$j$` 列，`$\bm{A}_{i,:}$` 表示第 `$i$` 行。
- 同时出现迭代和元素索引时，两者各归其位，例如 `$\bm{x}_{i}^{(t)}$` 和 `$\bm{A}_{i,j}^{(t)}$`。
- 索引变量默认使用 `$i,j,k$`；样本数、特征数等规模使用 `$n,d$`。若章节另有约定，应在首次出现时说明。

### 常用运算

- 转置使用 `$\bm{A}^{\top}$`，逆矩阵使用 `$\bm{A}^{-1}$`，伪逆使用 `$\bm{A}^{\dagger}$`。
- 内积使用 `$\langle \bm{x},\bm{y}\rangle$`；范数使用 `$\lVert\bm{x}\rVert_2$`，并显式写出非默认范数的下标。
- 期望、概率、方差等运算符使用直立或统一宏：`$\mathbb{E}$`、`$\mathbb{P}$`、`$\operatorname{Var}$`。
- 优化问题使用 `\min`、`\max`、`\argmin` 和 `\argmax`，变量条件写在下方。
- 函数名和文字下标使用直立体，例如 `$\operatorname{softmax}$`、`$L_{\mathrm{train}}$`。
- 数域使用黑板粗体，例如 `$\mathbb{R}$`、`$\mathbb{N}$`；明确写出张量或矩阵的形状，如 `$\bm{X}\in\mathbb{R}^{n\times d}$`。

### 公式编写

1. 公式中出现的新符号必须在公式之前或紧随其后解释，包含语义和必要的维度信息。
2. 重要公式使用带编号的环境并添加 `\label{eq:...}`；仅用于行内推导的公式不编号。
3. 多行推导使用 `aligned` 或 `align`，等号与不等号对齐；关键变形应在正文中说明依据。
4. 标点属于句子。展示公式后根据语义添加逗号或句号。
5. 不使用 Unicode 数学字符代替 LaTeX 命令；源文件中写 `\alpha`、`\leq` 和 `\times`。
6. 避免只给公式不给直觉。核心公式通常应同时说明变量含义、直观解释、适用条件和可能的边界情况。

## 排版要求

- 使用 LaTeX 的语义环境表达章节、列表、公式、定理、图表和引用，不用空格或连续换行手工对齐。
- 不用强制换行、负间距或随意的 `\vspace` 修复局部版面；先调整内容结构或统一样式。
- 结合 `tufte-book` 的版式谨慎使用边注。补充信息可以放入边注，核心定义、关键推导和阅读所必需的信息必须留在正文。
- 表格避免竖线，表头和单位清晰；数值按小数点或有效位数对齐。
- 代码、伪代码和命令使用专门环境，不使用普通正文模拟格式。

## 编译与检查

构建必须在所属任务的独立 worktree 内执行，使用该目录自己的 `build/` 和 `target/`，
不与主工作区或其他任务共享可写构建目录。同一 worktree 内的构建、监听与清理串行执行。
集成多个任务后，按最终源文件重新构建七个版本并校验成品；详见 [开发要求](development.md)。

每次修改后至少检查：

1. 运行 `bash tests/check-book-editions.sh` 检查结构与最小索引流水线，运行 `make test`
   检查词条提取、映射、别名、索引产物和部首页奇数页分页（含标签与目录页码）。审计不得出现未登记词条、冲突映射或无效别名。
2. `./build.sh build` 或无参数调用只构建全集；`./build.sh volume <slug>` 构建指定单卷，`./build.sh volumes` 构建六个单卷，`./build.sh all` 构建全集与六个单卷。日常验收与交付验收均使用 `all` 覆盖七版。
3. 七个约定产物 `target/machine-learning-notes.pdf` 与六个 `target/volN-<slug>.pdf` 均非空，并直接位于 `target/`。
4. 七份日志均没有未定义引用、重复标签、缺失文献、缺失字形或致命错误；跨卷引用在单卷中显示范围感知的文字回退。
5. 全集目录和书签采用“卷—部分—章—节”，单卷采用“部分—章—节”；顶层前后页书签的标题、顺序、层级和目标页正确。
6. 当前 PDF 的参考文献只包含实际引用或前页显式登记的条目；双语索引只收录当前正文中的
   `\term` / `\termalias`，中文排序键、双语格式、合并页码和超链接正确。
7. 没有影响阅读的 overfull box、图像越界或浮动体错位；七版封面、前言、数学符号、参考文献和索引的最终渲染正确。
8. 新增文件已被共享驱动覆盖的正文入口包含，且所有资源路径区分大小写后仍然有效。

仅编译成功并不代表变更合格；还必须查看最终 PDF，检查分页、留白、图文关系和整体一致性。

`./build.sh watch` 可持续监听修改，不打开新窗口。日常构建使用快速无损压缩，
`./build.sh release` 使用高压缩输出；两种模式均只处理全集，并保留图片分辨率、字体与引用检查。
`./build.sh clean` 清理全集与六个单卷的产物和缓存。
