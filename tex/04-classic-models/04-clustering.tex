客户记录没有类别标签时，消费金额相近的人未必购买相同品类，购买品类相近的人也未必有相同频率。\term{聚类}（clustering）先选定要保留的相似关系，再据此寻找群组；这项选择决定了“同一簇”的含义。给定$\bm{x}_1,\ldots,\bm{x}_n\in\mathbb{R}^{d}$，硬划分记为$\mathcal{P}=\{C_1,\ldots,C_K\}$，其中$C_k$是样本索引集合，$c_i=k$表示$i\in C_k$。通常要求簇非空、互斥且覆盖全部样本；噪声、重叠和软归属方法则采用各自的输出约定。

\emph{聚类与前三章任务的根本区别：没有标准答案。}回归和分类都有带标签样本，模型的预测可以逐条与真实答案对对错，因而存在“哪个预测更接近真值”的客观比较。聚类撤去了所有标签，只给一堆点，要求算法自己把它们分成几堆。同一份数据没有唯一正确的分法——同一批客户，按消费能力分可能得到三堆，按购买品类分可能得到五堆，两种分法各自合理。因此聚类不是在逼近某个隐藏的正确标签，而是在回答一个更主观的问题：“按我们选定的相似标准，怎样分组能让组内尽量接近、组间尽量不同？”这带来两个初学者必须先建立的认识。第一，\emph{“怎样算一类”必须先由方法定义}：是“离同一个中心近”、是“能沿密集样本连成一片”、是“图上彼此强连接”，还是“很可能由同一个概率分布生成”——不同定义会对同一份数据给出不同群组，本章各节正是按这些定义组织的。第二，\emph{没有标签意味着无法用“正确率”评价结果}：簇数$K$、距离尺度、密度阈值都需要人为给定或用间接指标选择，聚出来的组是否“有意义”最终还要回到业务或后续用途检验，低 SSE 并不自动等于找到了正确类别。

\emph{本章的组织线索。}本章按“构造群组的机制”展开：代表式聚类为每组选一个代表并最小化到代表的失真（K-means、K-medians、FCM、K-medoids、AP，第\ref{sec:clustering-partition}节）；局部密度方法按密集连接或密度峰组织群组（DBSCAN、OPTICS、HDBSCAN、Mean Shift、DENCLUE）；关系图用割或模块度寻找群组（谱聚类、Louvain）；凝聚与分裂层次保留“小组怎样合并成大组”的嵌套关系（AGNES、CURE、DIANA、二分K-means）；生成混合模型假设观测由潜在成分产生（GMM、伯努利与多项式混合、重尾混合、DPM）。随后三节分别改变计算条件：数据摘要与网格（BIRCH、STING、WaveCluster）改变数据组织，子空间与投影（CLIQUE、SUBCLU、PROCLUS、ORCLUS）改变各簇的比较空间，部分监督（COP-K-means、PCK-means、Seeded/Constrained、MPCK-means、关系监督谱聚类）改变信息条件；最后集中讨论粒度选择与用途评价。读各节时抓住“它把什么当作一类、为此最小化什么量、这种定义在什么形状的数据上会失效”，就不会被众多方法名淹没。

1950至1960年代，中心划分与层次聚类逐渐形成，K-means成为代表方法。1990年代的数据挖掘推动了DBSCAN等密度方法及大规模、子空间聚类；谱方法则从图关系理解群组。概率混合思想有更早的统计来源，19世纪末已用于分析异质总体\scite{clust-macqueen1967,ester1996,clust-pearson1894}。

所需输出可以帮助缩小方法范围。大样本的数值分组和量化可采用K-means及小批量更新；弯曲的密集区域和噪声识别可采用DBSCAN或HDBSCAN；嵌套粒度与成分后验则分别由层次方法和混合模型提供。比较时还需核对距离、密度尺度与分布假设是否符合数据\scite{classic-clustering-guide}。

\section{代表式聚类}
\label{sec:clustering-partition}

把客户分成 $K$ 组时，可以为每组选择一个代表，并用样本到代表的相异度衡量分组质量。代表式聚类同时确定代表与成员：每个样本归到使自身失真最小的代表，代表再由归属它的样本更新。直接目标是组内拟合，簇间分离由“竞争同一批样本”的分配规则间接产生，并不单独最小化簇间距离。

本节按具体模型并列：K-means最小化硬分配下的平方失真，K-medians改用坐标绝对偏差，FCM学习连续隶属度，K-medoids把代表限制为真实样本，AP则通过代表一致性与对角偏好决定选取哪些代表。核表示、容量约束与计算近似只改变各自的母模型，因此在被扩展的模型处展开，而不是另立一类群组定义。

\subsection{K-means}
\label{sec:clustering-kmeans}

先考虑图像颜色压缩这个具体任务。每个像素由三个颜色分量组成，如果只能保留$K$种颜色，就需要选出$K$个代表，再把每个像素替换成其中一个。若用替换前后的平方距离为失真计分，一个颜色组的均值恰好使该组的总平方失真最小。\term{K均值聚类}（K-means）把这一做法推广到数值向量：同时寻找$K$个均值中心与样本分配，使总平方距离尽量小。它拟合的是给定表示下的位置，而非预先知道的语义类别。

本节采用Lloyd的批量更新：先把所有样本分给最近中心，再重算各簇均值。它与逐个读入样本后立即更新的增量版本使用不同的计算顺序；下面先说明批量过程，再介绍小批量扩展\scite{clust-lloyd1982,clust-macqueen1967}。

\subsubsection{模型结构}

\paragraph{中心、分配与平方误差}

为第 $k$ 个簇配置中心 $\bm{\mu}_k\in\mathbb{R}^d$，其\term{簇内平方误差}（sum of squared errors, SSE）为
\begin{equation}
  J(\mathcal{P},\bm{\mu})
  =\sum_{k=1}^K\sum_{i\in C_k}
    \lVert\bm{x}_i-\bm{\mu}_k\rVert_2^2.
  \label{eq:clustering-sse}
\end{equation}
这里 $\bm{\mu}=(\bm{\mu}_1,\ldots,\bm{\mu}_K)$ 表示中心参数。固定中心后，每个样本应归入距离最近的中心；固定分配后，每个中心应取簇内均值。

\paragraph{最近中心区域与表示边界}

固定一个中心时，到它的距离等于同一个正数的点构成球面（二维中是圆），所以一个中心“管辖”的范围在几何上是一团以它为中心、向各方向等距伸展的紧凑区域。比较两个不同中心时，到二者距离相等的位置则是超平面（二维中是一条垂直平分线）；把一个点判给离它更近的中心，管辖边界正是这样一条条两两平分线围成的凸多边形，称为Voronoi单元。换句话说，K-means 找出来的每一簇都必然是“围绕一个中心的凸团块”。这样的表示适合在中心附近紧凑分布的群组，环形等非凸群组可能被多个中心拆开——一个圆环只有一个几何中心（圆心），但圆心处恰恰没有点，K-means 只能用几个凸团块去硬拼这个环。簇的尺度差异也会影响中心数的分配；这些限制来自几何准则，无需假定样本严格服从球形高斯。对新样本使用已学中心时，归属仍按最近中心计算。

\subsubsection{参数学习}

\paragraph{两个条件子问题的更新}

同时优化中心和分配较难，但两个条件子问题都可直接求解——这是理解K-means（以及后面GMM的EM）的关键：把“每点归哪簇”和“每簇中心放哪”两件耦合的事拆成交替进行的两步，每一步都有简单的闭式答案。

先设想中心暂时固定，那么每个点显然该归到离它最近的中心，无需任何复杂优化。再设想归属暂时固定，那么一组点的最佳代表（平方距离下）就是它们的平均值，这一点下一节会用恒等式证明。

反复执行这两步，就是Lloyd算法。记第 $t$ 轮的分配为 $c_i^{(t)}$，Lloyd 更新写为
\begin{align}
  c_i^{(t+1)}
    &\in\argmin_{1\leq k\leq K}
      \lVert\bm{x}_i-\bm{\mu}_k^{(t)}\rVert_2^2,
      \label{eq:clustering-lloyd-assignment}\\
  \bm{\mu}_k^{(t+1)}
    &=\frac{1}{|C_k^{(t+1)}|}
      \sum_{i\in C_k^{(t+1)}}\bm{x}_i.
      \label{eq:clustering-lloyd-centre}
\end{align}
图~\ref{fig:clustering-lloyd-steps}固定六个样本，分别展示分配与中心更新的作用。中图只重算中心，保留左图的簇标记；右图再比较距离，样本$(1,0)$才由方块簇转入圆点簇。把这两个动作分开展示，才能分别核对每个条件子问题怎样降低目标。

\paragraph{初始化与迭代状态}

平局与空簇需要纳入更新规则。等距时优先保留仍属最优的原分配，初始化则按固定顺序决定；空簇没有均值，下面保留其旧中心。这一教学实现最多返回$K$个非空簇。要求恰好$K$个非空簇时，可采用重启或后文的容量约束，并核对相应的停止条件。

\begin{codeblock}[language=Python,label={code:clustering-kmeans}]{带平局与空簇处理的 Lloyd 迭代}
import numpy as np

def kmeans(X, K, max_iter=300, seed=0):
    X = np.asarray(X, dtype=float)
    n = len(X)
    if not 1 <= K <= n or max_iter < 1:
        raise ValueError("invalid K or max_iter")
    rng = np.random.default_rng(seed)
    mu = X[rng.choice(n, K, replace=False)].copy()
    labels = np.full(n, -1)
    for _ in range(max_iter):
        d2 = ((X[:, None] - mu[None]) ** 2).sum(2)
        new = d2.argmin(1)
        rows = np.flatnonzero(labels >= 0)
        keep = d2[rows, labels[rows]] == d2[rows, new[rows]]
        new[rows[keep]] = labels[rows[keep]]
        if np.array_equal(new, labels):
            return labels, mu
        labels = new
        for k in range(K):
            members = X[labels == k]
            if len(members):
                mu[k] = members.mean(0)
    return labels, mu
\end{codeblock}

代码接受有限的二维数值数组。正常停止时，分配与中心形成不动点；迭代上限提前触发时，返回中心已按当前分配更新，但这些分配可能还需再比较一次最近中心。两种退出情形应分别记录。

\paragraph{计算与初始化}

广播计算临时占用$O(nKd)$空间，样本较多时可分块计算距离。

初值影响最终分组：与前面回归里的凸问题不同，K-means 的目标因为“分配”是离散的而不是凸函数，交替更新只能保证停在一个“两步都不想再动”的局部最优，无法保证找到全局最好的分组；不同的初始中心可能把同一批点聚成很不一样的结果。一个朴素的补救是多试几个起点取最好的，而\term{K-means++}则改进起点本身的选取方式：先均匀选择一个样本，之后按$D_i^2/\sum_jD_j^2$抽取新中心，其中$D_i$是样本到已有中心的最近距离。这个概率正比于“离最近中心的距离平方”，直观上就是越远离现有中心、越没被代表到的点，越有机会成为新中心，从而让初始中心彼此散开、避免都挤在一团。远离已有中心的区域因而更容易获得代表；所有$D_i=0$时，已有中心已覆盖全部不同位置。初始化后继续运行Lloyd，多次重启可在同一SSE下选择较好结果，但不保证全局最优\scite{clust-arthur2007}。

\subsubsection{理论分析}

均值更新为什么能减少平方误差，可以由一个恒等式看清。对非空簇$C$，记其均值为$\bar{\bm x}_C$，则
\begin{equation}
 \sum_{i\in C}\lVert\bm x_i-\bm a\rVert_2^2
 =\sum_{i\in C}\lVert\bm x_i-\bar{\bm x}_C\rVert_2^2
   +|C|\lVert\bm a-\bar{\bm x}_C\rVert_2^2.
 \label{eq:clustering-mean-decomposition}
\end{equation}
展开平方后，交叉项因簇内偏差和为零而消失。第一项与候选中心$\bm a$无关，第二项在$\bm a=\bar{\bm x}_C$时最小；最近中心分配同样逐点最小化固定中心下的误差。

\begin{theorem}[Lloyd迭代的有限停止]
 \label{thm:clustering-lloyd}
 对有限样本，在精确计算下，若等距时保留原来的最优分配，非空簇取均值、空簇保留旧中心，则Lloyd迭代的SSE不增，并在有限轮后停止。
\end{theorem}
\begin{proof}
两个条件子问题都不增加SSE。第一次均值更新后，若分配改变，至少一个样本移向严格更近的中心，所以一轮的SSE严格下降。均值更新后的SSE只由分配决定，分配总数有限，故不能无限次严格下降。分配不变时，中心也不再变化。
\end{proof}

这个结论解释了停止，却没有保证全局最优：不同初值可以停在不同分组。距离还决定何种分组值得寻找。平方距离放大远点的影响，各坐标的量纲会改变最近中心；内外同心圆的均值都在圆心附近，也不能由两个最近中心区域准确分开。应先使距离符合用途，再用多次初始化比较同一目标，不能由低SSE直接推断语义类别正确。
\subsubsection{扩展：非线性群组与核表示}

\paragraph{特征空间中心与核距离}

中心分配的形状也受表示限制。考虑围绕同一圆心的内外两圈样本，两圈的均值都靠近圆心，用两个原空间中心难以按半径分开它们。若以半径平方作为一个新特征，内外圈在该坐标上就落在不同位置。\term{核 K-means}（kernel K-means）采用相同思路，在特征映射$\phi$之后比较样本与簇均值。第\ref{sec:classic-overview-kernel-trick}节的正定核$K$允许我们直接计算这些距离；映射是否适合当前群组，仍由核的选择决定。样本到簇均值的平方距离为
\begin{equation}
 \begin{aligned}
 \lVert\phi(\bm{x}_i)-\bm{\mu}_k^\phi\rVert^2
 ={}&K(\bm{x}_i,\bm{x}_i)
 -\frac{2}{|C_k|}\sum_{j\in C_k}K(\bm{x}_i,\bm{x}_j)\\
 &+\frac{1}{|C_k|^2}
   \sum_{j,l\in C_k}K(\bm{x}_j,\bm{x}_l).
 \end{aligned}
 \label{eq:clustering-kernel-kmeans}
\end{equation}

\paragraph{成员学习与表示收益}

这里$\bm\mu_k^\phi=|C_k|^{-1}\sum_{j\in C_k}\phi(\bm x_j)$。学习时用当前成员计算上述距离，再重新分配样本；特征空间的均值由成员集合隐式保存。对新输入，把公式左侧的$\bm x_i$换成新点，并保持训练簇成员不变，就得到最近核中心规则。模型需要保留这些成员或等价的核展开，计算与存储可能随训练样本数增长。
核公式省去显式坐标，但仍需要计算训练点与簇成员的核值\scite{clust-girolami2002,dhillon2004}。

同心圆的例子可以核验映射带来的收益。对半径分别为$r_1,r_2$的两个完整圆，取$\phi(\bm x)=\lVert\bm x\rVert_2^2$，对应的正定核为$K(\bm x,\bm y)=\lVert\bm x\rVert_2^2\lVert\bm y\rVert_2^2$。两圈分别变为标量$r_1^2,r_2^2$，用两个中心可得到零特征失真，并准确保留“一圈一簇”。若两组半径存在重叠，仅保留这个特征就无法区分重叠位置；若目标按角度分组，它还会把同半径的不同群组混在一起。核技巧让特定非线性关系进入候选范围，效果需要对应目标，而不能由“采用了核”单独保证。

核K-means与归一化割的联系依赖适当的权重和核构造，适用范围需随具体等价关系核对。特征映射可以改变原空间的分配形状，层次结构则改变输出粒度；多层输出见第\ref{sec:clustering-hierarchy}节，局部密度与连接提供了另一种描述弯曲群组的方式。
\subsubsection{扩展：容量受限的联合分配}

\label{sec:clustering-capacity}

用于服务网点分配时，最近中心规则还可能违反容量要求。假设一个网点最多服务100条客户记录，它附近却有150条记录；把这些记录全部分给最近网点可以减小SSE，却使方案无法执行。限制簇大小的方法把每簇的最小与最大容量加入分配条件，再在可行方案中比较距离。Bradley、Bennett与Demiriz研究了带最小簇规模的K-means；加入上界后，固定中心的分配问题可统一写为\scite{clust-bradley2000}。
\begin{equation}
 \begin{aligned}
 \min_{\bm{Z}}\quad&
   \sum_{i=1}^n\sum_{k=1}^K
   z_{i,k}\lVert\bm{x}_i-\bm{\mu}_k\rVert_2^2,\\
 \text{s.t.}\quad&
   \sum_{k=1}^K z_{i,k}=1,\quad z_{i,k}\in\{0,1\},\\
 & \ell_k\leq\sum_{i=1}^n z_{i,k}\leq u_k.
 \end{aligned}
 \label{eq:clustering-capacity}
\end{equation}
整数容量满足 $0\leq\ell_k\leq u_k$，且在没有其他分配禁令时，可行性条件为 $\sum_k\ell_k\leq n\leq\sum_ku_k$。

固定中心时，这个分配问题可以用\term{最小费用流}求解：它是一类组合优化方法，在一个每条边都有容量和单位运费的网络上，求把指定货物从起点运到终点的最低成本输送。把它映射到本问题：每个样本发送一单位流到某个簇，边费用为平方距离，簇接收的流量受$\ell_k,u_k$限制。整数容量使最优分配可以取0或1，无须拆分样本。固定分配后仍以均值更新中心；精确分配和均值更新不会增加同一受约束目标。

平衡K-means把各簇容量设成相同大小，或相差至多1。也可以把中心展开为规定数量的槽，求样本到槽的最小费用指派\scite{clust-malinen2014}。它增加的是共同分配约束，中心仍是向量均值；按到中心的距离逐个贪心填槽并不等价于求出最优指派。

容量约束表达的是一批对象共同满足的分配要求。若目标方案满足给定上下界，它仍在候选范围内；若一个目标簇有150条记录而上界为100，这个簇就必须拆开或让部分记录转组。受约束的最小SSE不小于无约束的最小SSE，增加的失真是满足容量的代价。此时一个样本的归属取决于其他样本占用了哪些槽，不能再把训练划分解释成独立的最近中心区域。对新的一批客户执行相同容量要求，还需要共同求解分配。
\subsubsection{计算扩展：小批量参数学习}

颜色压缩若涉及大量图像，一次中心更新就要重新比较全部像素与$K$个中心，即使中心只移动一点，也要付出一次全量扫描的成本。\term{小批量K均值聚类}（Mini-Batch K-means）改用抽取的$b$个样本估计更新方向，只调整这些样本涉及的中心。Sculley在2010年研究了这一方法\scite{clust-sculley2010}。平方距离目标仍然保留，每轮采用的信息量与计算量则减少了。

设簇 $k$ 累计接收了 $v_k$ 次样本更新。每接收一个分配到该簇的样本，就令 $v_k\leftarrow v_k+1$，并计算
\begin{equation}
 \bm{\mu}_k\leftarrow
 (1-\eta_k)\bm{\mu}_k+\eta_k\bm{x}_i,
 \qquad \eta_k=\frac{1}{v_k}.
 \label{eq:clustering-minibatch}
\end{equation}
这是对历史已分配样本的增量平均，不是当前全体簇成员的精确均值。一轮距离计算降为 $O(bKd)$，但总成本仍取决于迭代次数、初始化和最终全量分配。

随机小批量使每次更新只反映部分样本，逐轮全量SSE可能波动。批量大小、采样偏差和低频簇的覆盖影响最终误差；定理~\ref{thm:clustering-lloyd}针对完整分配与精确均值更新，其单调性前提在这里发生改变。选择计算预算时，应以抽样评价或留出量化误差检查这种近似是否足够。
\subsection{K-medians}

\subsubsection{模型结构}

中心的选择还取决于怎样评价距离。用一个固定簇的单坐标教学例子看：数据为$0,0,0,100$时，平方距离和在均值$25$处最小，绝对距离和则在中位数$0$处最小。极端记录可以把均值拉离多数样本，改用绝对距离就改变了这种牵动。\term{K 中位数聚类}（K-medians）最小化$\ell_1$距离和
\[
 \min_{c,\bm\mu}\sum_{i=1}^n\lVert\bm{x}_i-\bm\mu_{c_i}\rVert_1,
\]
中心仍可在向量空间中取值，改变的是误差准则，而不是把中心限制为原始记录。固定中心时按最近$\ell_1$距离分配，分配与中位数更新必须相配，不能保留欧氏平方分配再单独替换中心。

\subsubsection{参数学习}

固定成员后，总绝对偏差按中心坐标分开，每个坐标的最优位置是该坐标样本的中位数（偶数样本取两中点之间的任一值，按确定规则选取）；交替执行最近$\ell_1$中心分配与逐坐标中位数更新，平局、空簇与停止规则与K-means同类处理。逐坐标中位数不同于以欧氏距离和定义的几何中位数问题。

\subsubsection{性质与使用条件}

在这个例子中，单中心的最小绝对距离和为100，而在均值25处为150；反过来，中位数处的平方距离和为10000，均值处为7500。因而改用中位数改善的是绝对距离目标，不能据此宣称对平方量化也更准确。多维$\ell_1$损失逐坐标相加，适合目标确实要求累加各坐标绝对偏差的情形；它没有利用坐标间的相关方向，也没有为弯曲群组增加新的连接表示。
\subsection{模糊C均值（FCM）}

\subsubsection{模型结构}

最近中心规则只给出一个簇标签，无法表达样本处于两个群组之间的程度。例如，一位客户的购买行为同时接近两类典型客户，略微改变记录就可能使硬标签跳到另一类。\term{模糊 C 均值}（Fuzzy C-Means, FCM）保留各中心之间的比较，用隶属度$u_{i,k}$分配软归属，因而可以表达这种过渡\scite{clust-bezdek1981}。
\begin{equation}
 \begin{aligned}
 J_{\mathrm{FCM}}
 &=\sum_{i=1}^n\sum_{k=1}^K
 u_{i,k}^{q}\lVert\bm{x}_i-\bm{\mu}_k\rVert_2^2,
 \\
 &u_{i,k}\geq0,\quad \sum_k u_{i,k}=1,\quad q>1.
 \end{aligned}
 \label{eq:clustering-fcm}
\end{equation}
非负且和为1的约束使每个隶属度都位于$[0,1]$，$q$控制隶属度的模糊程度。固定隶属度时，中心是以$u_{i,k}^q$为权重的均值；若某簇的权重总和为零，该簇当前对目标没有贡献，均值公式无定义，需按预定规则保留原中心或重新初始化。

\subsubsection{参数学习}

固定中心后，各样本的隶属度可以分别求解。令$d_{i,k}=\lVert\bm x_i-\bm\mu_k\rVert_2$。距离均非零时，在和为1的约束下对$\sum_kd_{i,k}^2u_{i,k}^q$求导，得到各$u_{i,k}$与$d_{i,k}^{-2/(q-1)}$成比例；归一化后，与加权中心更新组成交替学习：
\[
 u_{i,k}=\frac{d_{i,k}^{-2/(q-1)}}{\sum_jd_{i,j}^{-2/(q-1)}},
 \qquad
 \bm\mu_k=\frac{\sum_i u_{i,k}^q\bm x_i}{\sum_i u_{i,k}^q}.
\]
两个中心距离为1和2时，$q=2$给出隶属度$(0.8,0.2)$，$q=3$给出$(2/3,1/3)$。固定距离时，较大的$q$使归属更均匀；完整学习中，中心也会随之调整。

迭代可在目标或参数变化足够小时停止，并用多次初值检查局部解的影响。

\subsubsection{性质与使用条件}

若样本与一个或多个中心重合，可把隶属度集中在这些零距离中心上。隶属度表示模糊目标下的软归属；赋予生成后验含义还需要相应概率模型。医学影像中一个像素混合多种组织的部分体积效应，可为这种软表达提供应用动机。

FCM仍用中心距离决定隶属度：两个距离相等时，软归属也相等。它补充了边界过渡，没有自动增加非凸形状或成分比例的表示；后文GMM则用生成分布定义成分后验。
\subsection{K-medoids}
\label{sec:clustering-kmedoids}

均值适合数值量化，却未必适合展示一个群组的典型对象。客户各项特征的平均值可能不对应任何真实客户；字符串之间可以计算编辑距离，却不能像数值向量一样取均值。\term{K 中心样本聚类}（K-medoids）把代表限制为已有样本，选择使组内总相异度较小的真实对象。这样既能展示一条可以核查的代表记录，也能直接使用字符串等对象的相异度；代价是需要在候选样本之间搜索代表。

PAM是这一目标的代表求解方法，CLARA则通过抽样缩小代表搜索范围\scite{clust-kaufman1990}。

\subsubsection{模型结构}

\paragraph{真实样本代表与分配}

设代表索引集合 $M=\{m_1,\ldots,m_K\}\subseteq\{1,\ldots,n\}$，相异度为 $\delta(\bm{x},\bm{y})$。优化目标为
\begin{equation}
 J(M)=\sum_{i=1}^n\min_{m\in M}\delta(\bm{x}_i,\bm{x}_m).
 \label{eq:clustering-medoids}
\end{equation}
每个 $\bm{x}_{m_k}$ 称为\term{中心样本}（medoid），分配由最近代表决定。给定训练得到的 $M$ 与相异度 $\delta$，新对象选 $\arg\min_{m\in M}\delta(\bm{x},\bm{x}_m)$，前提是该相异度也能用于新对象。典型相异度包括欧氏距离、曼哈顿距离、汉明距离、编辑距离和 Jaccard 距离。目标本身不要求三角不等式，但某些索引加速方法需要这一性质。

\paragraph{极端记录下的比较}

未平方距离随远点的偏移增长较慢，真实样本约束也改变了中心的可移动范围，两者可减弱极端值对SSE均值的影响。具体鲁棒性仍由相异度和污染位置决定：离群点若改变候选代表的相对距离，也可能改变medoid。

图~\ref{fig:clustering-medoid-robustness}固定一维单簇，将最右样本由5移到12。平方距离的最优中心随均值右移，绝对距离的最优中心样本仍为中间观测2。该对照同时改变损失与代表约束，结论限于这组设定；它提供了检查极端值影响的可核算例子。

\subsubsection{参数学习}

\paragraph{建立代表与完整交换}

\term{围绕中心样本划分}（Partitioning Around Medoids, PAM）通常包含 BUILD 初始化和 SWAP 改进。BUILD 贪心增加代表；SWAP 枚举每个当前代表 $m\in M$ 与每个非代表 $o\notin M$，计算
\[
 \Delta(m,o)=
 J\bigl((M\setminus\{m\})\cup\{o\}\bigr)-J(M).
\]
候选 $o$ 来自整个数据集，而不限于 $m$ 所在簇；每次交换后，所有样本都重新选择最近代表。只在固定簇内选取距离总和最小的样本，是另一种交替更新，不能替代 PAM 的 SWAP。

下面从随机代表开始，逐个评价完整交换邻域，以便核对$J(M)$与返回状态。代码省略BUILD初始化和距离差分缓存，适合作为目标及停止判据的教学实现。

\begin{codeblock}[language=Python,label={code:clustering-pam}]{PAM 的完整交换步骤}
import numpy as np

def pam_swap(D, K, seed=0, max_iter=100):
    n = len(D)
    if D.shape != (n, n) or not 1 <= K <= n or max_iter < 1:
        raise ValueError("invalid distance matrix, K, or max_iter")
    rng = np.random.default_rng(seed)
    medoids = rng.choice(n, K, replace=False)
    cost = D[:, medoids].min(1).sum()
    converged = False
    for _ in range(max_iter):
        best, best_cost = None, cost
        outside = np.setdiff1d(np.arange(n), medoids)
        for k in range(K):
            for o in outside:
                trial = medoids.copy()
                trial[k] = o
                value = D[:, trial].min(1).sum()
                if value < best_cost:
                    best, best_cost = trial, value
        if best is None:
            converged = True
            break
        medoids, cost = best, best_cost
    return D[:, medoids].argmin(1), medoids, converged
\end{codeblock}

\paragraph{停止证据与搜索代价}

完整扫描若未发现改进交换，代码把变量\code{converged}置为\code{True}，表明当前代表集合在单次交换邻域中局部最优。迭代上限先触发时，\code{converged}保留为\code{False}，尚未核完下一邻域。严格下降使代表集合不重复，去掉上限并继续扫描时，有限候选集合保证最终停止。

预计算相异度矩阵占用$O(n^2)$存储，距离本身的计算还需另外计入。经典PAM缓存最近与次近代表，一轮完整交换的代价通常为
\[
  O\!\left(K(n-K)^2\right),
\]
教学代码为每个候选重算$K$个距离列，额外重复了这些访问，因此成本更高。

代表必须来自样本，便于展示典型对象，也限制了可选位置。对欧氏距离，固定代表后的最近分配仍有中心方法的形状限制；使用编辑距离等关系时，分组含义随相异度改变。

\subsubsection{计算扩展：代表搜索、抽样与复用}

\paragraph{子样本中的代表候选}

完整交换邻域昂贵时，可以减少候选代表或减少检查的交换。Kaufman与Rousseeuw整理的CLARA在若干子样本上运行PAM，再用全体样本评价候选代表，以减少工作集；抽样未覆盖的小簇可能因此没有合适代表。

\paragraph{交换邻域中的搜索与复用}

Ng与Han在1994年提出的CLARANS把代表集合视为状态，随机抽取交换邻居，减少每轮扫描量\scite{clust-nghan1994}。前者限制本轮代表从哪里来，后者限制本轮搜索哪些交换，两者都需要评价近似搜索的损失。

重复计算也可以在保留交换目标的前提下减少。Schubert与Rousseeuw在2019年的FastPAM工作中复用不同被替换代表之间的计算，减少经典SWAP中随$K$重复的工作\scite{clust-schubert2019}。这种改进主要针对交换评价；关于$n$的距离访问和全量矩阵存储仍需计入，大样本的瓶颈可能继续来自这两部分。
\subsection{近邻传播（AP）}
\label{sec:clustering-affinity-propagation}

K-medoids 必须事先指定簇数$K$，而我们往往连该有几个代表都不知道。\term{近邻传播}（Affinity Propagation, AP）采取一种“竞选”的视角：让每个样本都先成为潜在代表（相当于每个点都有资格当“簇中心”候选人），不预设簇数，而是让所有样本通过反复传递消息、彼此协商，最终自然浮现出若干被大家共同支持的代表，其余样本则归到自己最支持的代表门下。Frey与Dueck在2007年提出了这一方法\scite{clust-frey2007}。

\subsubsection{模型结构}

令$e_i\in\{1,\ldots,n\}$为样本$i$选择的代表索引，$s(i,k)$衡量用样本$k$代表$i$的适合程度。AP希望求解
\[
 \max_{e_1,\ldots,e_n}\sum_{i=1}^n s(i,e_i),
 \qquad e_i=k\ \Longrightarrow\ e_k=k.
\]
约束要求被选作代表的样本也选择自身，使所有归属指向实际代表。对角值$s(k,k)$称为偏好：每选用一个代表，目标中就出现一次该代表的对角值。统一提高偏好会在目标中增加对较多代表的奖励，但消息迭代不保证找到全局最优分组。

直接枚举代表与归属组合成本很高。AP的协商通过两类在样本之间来回传递的消息完成，可以类比为选举中的“邀约”与“应援”：适合度$r(i,k)$是样本$i$发给候选人$k$的话——“比起其他人选，我有多倾向让你代表我”；可用度$a(i,k)$是候选人$k$传回给$i$的话——“除你之外，已经有多少人愿意支持我，我是否适合当代表”。两类消息反复更新，就像选民和候选人互相摸底，直到代表格局稳定。这些量用于协调约束，是带符号的消息值，不是归属概率。

\subsubsection{参数学习}

\paragraph{适合度与可用度消息}

给定相似度$s(i,k)$，其典型更新为
\[
 r(i,k)=s(i,k)-\max_{k'\ne k}\{a(i,k')+s(i,k')\},
\]
\[
 a(i,k)=
 \min\left\{0,r(k,k)+
 \sum_{i'\notin\{i,k\}}\max\{0,r(i',k)\}\right\},
 \quad i\ne k,
\]
而$a(k,k)=\sum_{i'\ne k}\max\{0,r(i',k)\}$。第一式比较当前候选与最佳替代者：若$s(i,k)=-1$、最佳替代者的$a+s=-4$，则$r(i,k)=3$，表示相对优势为3，而非相似度必须为正。可用度累加其他样本愿意选择$k$的正支持，并与$k$自身的适合度共同判断它能否承担代表角色；非对角可用度至多为零：其他支持足够时不再阻止$i$选择$k$，不足时则给出负反馈，最终仍由$a+r$共同决定代表。通常还需把新旧消息加权混合，用阻尼缓解振荡；迭代不保证总收敛\scite{clust-frey2007}。

\paragraph{阻尼、停止与代表恢复}

消息更新后，以两类消息之和比较候选代表，并按预定平局规则选择代表索引
\[
 e_i\in\argmax_k\{a(i,k)+r(i,k)\}.
\]
同一代表对应同一簇，即$C_k=\{i:e_i=k\}$。输出要求代表选择连续若干轮稳定且相互一致：一个样本选择$k$时，$e_k=k$，即代表选自身。中间迭代可能尚未满足这两个条件，此时继续更新或返回未收敛状态，保留当前消息供诊断。偏好控制选取代表的代价，不是对语义簇数的直接估计；采用负平方欧氏相似度时，固定代表后仍是最近代表分配，消息传播没有消除中心表示的形状限制。稠密消息占用$O(n^2)$存储；阻尼用于缓解振荡，不能保证总能收敛，达到轮数上限时应保留未收敛状态，不能把不一致的代表选择直接当作最终划分。

原型方法的共同问题是用少量代表概括对象，区别在于代表的取值、归属的软硬与选取方式。K-means允许中心在向量空间中移动，以平方距离学习均值；K-medians改用$\ell_1$误差、固定成员后取逐坐标中位数；FCM在同一目标上引入隶属度软化归属；K-medoids从真实记录中选代表，允许更一般的相异度，但需要搜索交换；AP则不预设$K$，通过相似度消息与偏好自行选出真实代表。表\ref{tab:clustering-partition}保留K-means与K-medoids两项主要差别。

\section{用局部密度识别群组}
\label{sec:clustering-density}

环形、月牙形和弯曲条带中的样本可能远离同一中心，却能沿密集区域连接。密度方法据此把低密度分隔加入簇定义：一类方法寻找密集区域的连通分量，另一类寻找密度峰的吸引域。同一连通区域可以包含多个峰，因此两种定义会产生不同划分。

DBSCAN 直接用邻域计数判断密集程度，OPTICS 保留不同密度尺度的访问结构，HDBSCAN 再把这一排序组织成可供选择的密度层次，Mean Shift 则沿核密度估计寻找驻点，DENCLUE 在平滑密度上用阈值筛选吸引峰。噪声识别是 DBSCAN 与 OPTICS 的显式输出；基本 Mean Shift 会为起点寻找归宿，并不自动拒绝孤立样本。
\subsection{DBSCAN}
\label{sec:clustering-dbscan}

考虑两条彼此分开的弯曲点带。沿同一条带相邻的样本很近，带的两个端点却可能很远；最近中心分配用到中心的直线距离，而一个中心只能管辖凸团块，无法弯过来贴合整条带，容易把一条带切成两半或把两条带的端点错配到一起。若再有几个孤立点，K-means仍会强行把它们分进某个簇——它没有“这是噪声、不该属于任何簇”的概念。DBSCAN（Density-Based Spatial Clustering of Applications with Noise）换一个“一类”的定义：不再围绕中心，而是把“样本是否足够密集、密集区域是否彼此相连”作为分群依据，用局部邻居的数量判断哪些位置足够密集，再沿相连的密集邻域向外扩展。这样只要两条带内部连通、带间没有密集路径，它们就可以各自形成任意弯曲的一簇，孤立点则保留为噪声。Ester等在1996年提出了这一方法\scite{ester1996}。

\subsubsection{模型结构}

\paragraph{邻域与样本角色}

固定半径 $\varepsilon>0$ 和最小邻域样本数 $m=\mathrm{MinPts}$。这两个参数的含义很直观：在一个样本周围画一个半径为$\varepsilon$的圆，如果圆内（含自己）至少有$m$个点，就认为这里是一个“人来人往”的密集位置。定义索引邻域
\[
 N_\varepsilon(i)=
 \{j:\delta(\bm{x}_i,\bm{x}_j)\leq\varepsilon\}.
\]
本节假定相异度对称、样本到自身距离为零，并在邻域计数中包含自身。样本据此分为三种角色，理解这三个角色就理解了整个算法：\term{核心点}（core point）满足 $|N_\varepsilon(i)|\geq m$，即自身周围足够拥挤，它有资格“向外扩张”、把邻居拉进同一簇；\term{边界点}（border point）自己周围不够挤（不是核心点），但恰好落在某个核心点的邻域内，因而能被核心点“吸收”进簇，却不能再继续扩张；既非核心也非边界的样本是\term{噪声点}（noise point），谁的密集范围都够不到它，最终不归属任何簇。

\paragraph{核心连接与共享边界}

仅有“谁密集”还不足以把点连成簇，还需要规定密集位置之间怎样连通，这正是下面三个“可达”概念要回答的。若 $i$ 是核心点且 $j\in N_\varepsilon(i)$，称 $j$ 从 $i$\term{直接密度可达}（directly density-reachable），可以理解为“站在密集点$i$的圈内能直接看到$j$”。沿这样的有向关系组成有限链，就得到\term{密度可达}（density-reachable）：从一个核心点出发，经过一连串核心点的圈子，最终能看到的点都与它同簇；链上除终点外的点都须为核心点，终点可以是边界点（边界点不继续扩张，只作为簇的边缘）。若存在一个核心点，使两个样本都从它密度可达，则称它们\term{密度相连}（density-connected）——它们可能彼此并不直接相邻，却共享同一个能扩张到它们的“大本营”，因而属于同一簇。

先只看核心点邻接图，可以清楚地区分扩展与吸收：距离不超过$\varepsilon$的核心点相连，每个连通分量提供一个簇的核心，再吸收相邻非核心点。边界点可能同时邻接多个分量；实际DBSCAN通常交给先访问它的簇，从而得到单一标签。DBSCAN 没有独立的样本外映射：新样本参与分组需要与训练点合并后重新运行密度扩展，即把新数据代入原算法；固定核心点直接吸附新点则是额外部署约定。图~\ref{fig:clustering-dbscan}展示了核心点继续扩展、边界点只被吸收的差别。

\subsubsection{参数学习}

\paragraph{邻域查询与核心扩展}

DBSCAN 的主要工作是查询邻域并搜索核心连通分量。代码~\ref{code:clustering-dbscan} 使用暴力距离查询，完整展示暂定噪声被重新吸收为边界点的情况。

\begin{codeblock}[language=Python,label={code:clustering-dbscan}]{DBSCAN 的邻域扩展}
import numpy as np
from collections import deque

def dbscan(X, eps, min_pts):
    X = np.asarray(X, dtype=float)
    if eps <= 0 or min_pts < 1:
        raise ValueError("invalid density parameters")
    labels = np.full(len(X), -1)  # -1 未访问，-2 噪声
    def neighbors(i):
        d2 = ((X - X[i]) ** 2).sum(1)
        return np.flatnonzero(d2 <= eps ** 2)
    cid = 0
    for i in range(len(X)):
        if labels[i] != -1:
            continue
        near = neighbors(i)
        if len(near) < min_pts:
            labels[i] = -2
            continue
        labels[i] = cid
        queue = deque(near)
        while queue:
            j = queue.popleft()
            if labels[j] == -2:
                labels[j] = cid
            if labels[j] != -1:
                continue
            labels[j] = cid
            near_j = neighbors(j)
            if len(near_j) >= min_pts:
                queue.extend(near_j)
        cid += 1
    return labels
\end{codeblock}

\paragraph{查询成本与参数选择}

代码中每个样本至多查询一次邻域，队列则可能保存重复索引。暴力距离计算约需$O(n^2d)$运算。低维数据且邻域规模受控时，空间索引可使实践成本接近$O(n\log n)$；高维或大半径会增加访问量，最坏仍可达到平方级。预存全部邻域还可能占用$O(n^2)$内存。

参数选择可从第 $m$ 近邻距离的排序图入手，近邻计数约定应与是否包含自身一致。曲线的转折提示不同密度尺度，但未必存在清晰肘部。Schubert 等把 $\mathrm{MinPts}\approx 2d$ 作为平滑密度估计的经验起点，而不是一般最优值\scite{clust-schubert2017}。重复样本、噪声比例和有效维数都会影响合理的邻域大小与最小样本数。

\subsubsection{理论分析}

\begin{lemma}[DBSCAN的核心点划分]
 \label{thm:clustering-dbscan}
 固定数据、对称相异度和$(\varepsilon,m)$，DBSCAN在核心点上的划分恰为核心邻接图的连通分量，与访问次序无关，簇编号除外。
\end{lemma}
\begin{proof}
扩展会继续访问每个新发现的核心邻居，因而能沿任意核心路径走完整个分量；边界点不继续扩展，所以不能把两个核心分量连接起来。
\end{proof}

这说明弯曲点带可以成为一簇，也说明密集桥为何会把两群合并。共同半径较小时，稀疏群体可能成为噪声；较大时，稠密群体之间可能被接通。共享边界点的单一归属仍可能依赖访问次序。基本算法输出当前数据的划分；加入新点后若重新计算邻域，核心身份与连通性都可能改变。若只按已有核心点给新点附加标签，应另规定多簇邻接和拒绝规则。
\subsection{多尺度排序：OPTICS}
\label{sec:clustering-optics}

前述两条点带如果疏密不同，DBSCAN的单一半径就不容易选择：半径设小了，稀疏那条带因为邻居凑不够$m$个而被整段判成噪声或拆散；半径设大了，稠密区域之间可能被一条本不该有的窄桥接通而合并成一簇。更麻烦的是，事先往往并不知道合适的半径，反复用不同半径重跑DBSCAN还会重复计算大量相同的邻域查询。OPTICS（Ordering Points To Identify the Clustering Structure）的思路不是替你选定一个半径，而是只扫描一次，就把样本排成一个特殊的次序，并为每个样本记录“要从密集区域到达它，半径至少得多大”；有了这份记录，事后想取哪个半径尺度，就能从次序图上读出对应的簇，相当于一次计算、多尺度查看。Ankerst等在1999年提出的方法先给出这些记录，再由提取规则得到划分\scite{clust-ankerst1999}。

\subsubsection{模型结构}

设搜索半径上限为 $\varepsilon_{\max}$。若样本 $i$ 在该半径内有至少 $m$ 个邻居，则其\term{核心距离}（core distance）为第 $m$ 近邻距离；否则记为 $+\infty$：
\[
 a_i=
 \begin{cases}
 \delta_{i,(m)},&|N_{\varepsilon_{\max}}(i)|\geq m,\\
 +\infty,&\text{其他情况}.
 \end{cases}
\]
由核心点 $i$ 到邻居 $j$ 的\term{可达距离}（reachability distance）定义为
\begin{equation}
 r(j\mid i)=\max\{a_i,\delta(\bm{x}_i,\bm{x}_j)\}.
 \label{eq:clustering-reachability}
\end{equation}
方向来自出发点的核心距离，因此通常 $r(j\mid i)\ne r(i\mid j)$。它表示在确保出发点足够密集的同时覆盖 $j$ 所需的半径。

OPTICS 为每个样本记录访问次序、核心距离和当前获得的最小可达距离。按访问次序画出可达距离形成\term{可达图}（reachability plot）；低谷通常对应容易从内部到达的密集区域，较高的过渡位置提示区域之间的分隔。

\subsubsection{参数学习}

\paragraph{优先遍历与可达记录}

同一未处理样本可能先后接收多个核心点提供的候选距离，因而需要保留其中最小的一个。记未处理样本$j$的可达距离记录为$R_j$，初始取$+\infty$。它只汇总已经处理过的核心点所提供的候选距离，并不是预先对全部样本求出的最小值。处理核心点$i$时，对其未处理邻居$j$执行
\[
 R_j\leftarrow\min\{R_j,r(j\mid i)\}.
\]
其中$r(j\mid i)$由式\eqref{eq:clustering-reachability}计算，所以每个候选同时受出发点核心距离和两点距离限制。

从一个未处理点开始，算法输出该点并查询邻域。如果它是核心点，就用式~\eqref{eq:clustering-reachability} 更新未处理邻居的最小可达距离；优先队列每次取出当前可达距离最小的点，继续同样的过程。队列为空而仍有未处理点时，再开始一个新的搜索。这个过程是按可达距离优先的遍历，而不是普通先进先出的广度优先搜索。

例如，若$j$原有$R_j=0.8$，当前核心点满足$a_i=0.4$、$\delta(\bm{x}_i,\bm{x}_j)=0.3$，则新候选为$\max\{0.4,0.3\}=0.4$，记录降为0.4。以后另一个已处理核心点若给出0.6的候选，记录仍保留0.4。每次重新开始搜索的点没有提供有限候选的前驱，其输出可达距离保持$+\infty$；这与某个已被核心点触达的样本具有较大但有限的记录不同。

\paragraph{从排序提取划分}

给定 $\varepsilon'\leq\varepsilon_{\max}$，提取 DBSCAN 式结构时必须同时使用核心距离。沿排序扫描，若某点的记录可达距离大于 $\varepsilon'$，但核心距离不大于 $\varepsilon'$，它应开启一个新簇；若二者都大于阈值，才暂记为噪声；可达距离不大于阈值的点接续当前簇。只把水平线下的连续段当作簇，会漏掉可达距离很大、却负责开启新簇的核心点。不同提取规则对部分边界点的处理还可能与重新运行 DBSCAN 不同。

图~\ref{fig:clustering-optics-reachability} 将原始样本间距与可达图对应起来。中间一组样本较稀疏，形成的谷底较高；用 $\varepsilon'=0.35$ 提取时它们不构成核心簇，增大阈值才会纳入。次序 1、8、14 对应三次重新开始的搜索，其可达距离为无穷；次序 23 的孤立点也有无穷可达距离，但它的核心距离同样无穷，因而不能开启簇。

低谷也可按相对陡降、陡升的$\xi$规则提取，并结合最小簇规模、前驱关系及嵌套处理。原始OPTICS已讨论陡峭区域，后续工作进一步构造密度层次。这里的自动提取减少人工读图，尺度和粒度仍由提取参数控制。排序在每个样本输出一次后结束，主要成本来自邻域查询和优先队列更新。它保留多个尺度的信息，但没有替读者选定群组：搜索上限外的关系未被记录，同一水平阈值也仍会遇到疏密冲突。低谷、最小簇规模与提取规则应共同说明，不能把可达图上的每个低谷都直接当成业务类别。

\subsection{密度层次：HDBSCAN}

\subsubsection{模型结构}

它的结构由\term{互可达距离}（mutual reachability distance）图、压缩层次和选中的分支组成。固定邻居数$m$，以全数据中第$m$近邻距离$a_i^{\mathrm H}$表示局部尺度，计数仍包含自身。定义
\[
 \delta_{\mathrm{mr}}(i,j)=\max\{a_i^{\mathrm H},a_j^{\mathrm H},\delta(\bm x_i,\bm x_j)\}.
\]
两端的局部尺度给连接距离设置下界，稀疏桥因而不会仅凭两点位置相近就过早连接。算法先计算这些量，再以最小生成树保存各阈值下的连通分量；逐步删除较长边，记录分量的分裂。

\subsubsection{参数学习}

按最小簇规模压缩这棵树时，太小的分支视为成员脱落，足够大的分裂保留为新候选簇。用逆距离尺度$\lambda=1/\varepsilon$计量持续时间，候选簇$C$的常用稳定量为
\[
 \operatorname{stab}(C)=\sum_{i\in I_C}
 [\lambda_i(C)-\lambda_{\mathrm{birth}}(C)],
\]
其中$I_C$为出生时成员，$\lambda_i(C)$记录成员脱落或簇结束时的尺度。从叶端向上比较父簇稳定量与可选子分支的稳定量总和，保留较大方案，并禁止同时选中父簇及其后代；未属于选中分支的点可以作为噪声。零距离导致无穷逆尺度时，需要相应的重复点处理\scite{clust-campello2013}。

这里没有拟合固定维参数，而是在学习关系图、层次和分支选择。邻居数影响局部密度尺度，最小簇规模影响保留哪些群体，两者作用不同。跨尺度持续也不等于抽样稳定或语义正确；基本输出属于当前数据，新点近似分配需另定规则。
\subsection{Mean Shift}
\label{sec:clustering-mean-shift}

密集路径与密度峰回答的是不同问题，先用一个直观情形区分：两个聚集区域之间若有一条足够密集的“走廊”相连，DBSCAN会因为整条走廊密度可达而把它们算作一簇；但人的直觉上这里明明有两个人群中心（两个山头），只是中间有一道缓坡连着。若希望把这两个山头分别识别出来，就需要问“点密度在哪里达到局部最高”，而不是“密集区域是否连通”。\term{均值漂移}（Mean Shift）正是这种找山头的方法：先把离散样本平滑成一张连续的“密度地形”，再让一个搜索点反复朝附近样本最密集的加权平均位置（即密度上升最快的方向）移动，直到登上某个山顶；从不同起点出发、最终登上同一座山的点就归为一簇。平滑尺度（带宽）决定把地形看得多细，会直接改变山头的数量。

这一方法连接密度梯度估计与模态搜索；从起点移动得到终点后，还要规定怎样把终点转换成簇标签\scite{clust-fukunaga1975,clust-comaniciu2002}。

\subsubsection{模型结构}

以径向核估计未知密度。设 $h>0$ 为带宽，核函数为 $\mathcal{K}(\bm{u})=c_k k(\lVert\bm{u}\rVert_2^2)$，其中$c_k$是归一化常数，$k$是剖面函数（profile），规定核权重怎样随距离平方变化。则\term{核密度估计}（kernel density estimation, KDE）为
\begin{equation}
 \hat f(\bm{y})=\frac{c_k}{nh^d}
 \sum_{i=1}^n
 k\left(\frac{\lVert\bm{y}-\bm{x}_i\rVert_2^2}{h^2}\right).
 \label{eq:clustering-kde}
\end{equation}
可以从各样本出发在估计密度上搜索，把趋向同一模态的起点归为一簇。带宽决定平滑尺度，小带宽通常保留细节，大带宽通常合并邻近结构；模态数量的具体变化还依赖维数、核与样本分布。

\subsubsection{参数学习}

\paragraph{密度梯度与位置更新}

令 $g(u)=-k'(u)$，并记 $u_i(\bm{y})=\lVert\bm{y}-\bm{x}_i\rVert_2^2/h^2$。直接对式~\eqref{eq:clustering-kde} 求导可得
\[
 \nabla\hat f(\bm{y})=
 \frac{2c_k}{nh^{d+2}}
 \sum_i g(u_i(\bm{y}))(\bm{x}_i-\bm{y}).
\]
只要权重和为正，梯度便是正系数乘以\term{均值漂移向量}
\[
 \bm{m}(\bm{y})=
 \frac{\sum_i g(u_i(\bm{y}))\bm{x}_i}
      {\sum_i g(u_i(\bm{y}))}-\bm{y}.
\]
因此采用下列自适应步长的梯度方向更新：
\begin{equation}
 \bm{y}^{(t+1)}=
 \frac{\sum_i w_i^{(t)}\bm{x}_i}{\sum_i w_i^{(t)}},
 \qquad w_i^{(t)}=g(u_i(\bm{y}^{(t)})).
 \label{eq:clustering-mean-shift}
\end{equation}
权重来自一元剖面函数的负导数$g$，其自变量是距离平方。高斯剖面$k(u)=\exp(-u/2)$给出与高斯权重成比例的$g$，Epanechnikov剖面$(1-u)_+$在支撑内部给出常数权重，边界按分段规则处理。

式~\eqref{eq:clustering-mean-shift}与第\ref{sec:regression-nadaraya-watson}节的Nadaraya--Watson回归都计算核加权平均。Mean Shift平均输入位置，更新搜索点；核回归平均响应，预测条件均值。相同的平均运算承担不同的估计任务。

\paragraph{轨迹、终点与计算设置}

图~\ref{fig:clustering-mean-shift-modes}固定同一组一维样本，两个起点沿式~\eqref{eq:clustering-mean-shift}分别向左右峰移动，靠近驻点时位移减小。灰线改用更大带宽，两个峰合为一个峰。起点决定从哪里搜索，带宽改变估计密度及可到达的模态，两项选择因而影响不同的对象。

\begin{codeblock}[language=Python,label={code:clustering-mean-shift}]{高斯 Mean Shift 的起点更新}
import numpy as np

def mean_shift_positions(X, h, max_iter=300, tol=1e-4):
    X = np.asarray(X, dtype=float)
    if h <= 0:
        raise ValueError("h must be positive")
    Y = X.copy()
    for _ in range(max_iter):
        d2 = ((Y[:, None] - X[None]) ** 2).sum(2)
        log_w = -d2 / (2 * h * h)
        log_w -= log_w.max(1, keepdims=True)
        W = np.exp(log_w)
        new = (W @ X) / W.sum(1, keepdims=True)
        step = np.linalg.norm(new - Y, axis=1).max()
        Y = new
        if step <= tol:
            break
    return Y
\end{codeblock}

代码返回最终位置。得到簇标签还需合并相近终点，例如构造距离不超过$\rho$的终点图并取连通分量；$\rho=h/2$可作教学起点。这个合并阈值与更新容差用途不同，连通规则可能沿一串近终点把不同模态接在一起，需单独检查。

全部$n$个起点的一轮精确更新约需$O(n^2d)$运算。高斯核覆盖所有样本，因此截断邻域或近似近邻改变了精确更新。大数据实现可分块、减少起点或改用有限支撑核，并分别核对计算节省与位置误差。

\subsubsection{理论分析}

\paragraph{密度上升与收敛条件}

更新朝密度上升的方向移动，但“密度值稳定”和“找到一个有意义的峰”仍是不同要求。对非负、凸、非增且可微的剖面$k$，若$g=-k'$的权重和$s$为正，凸性与加权均值恒等式给出
\begin{equation}
 \hat f(\bm y^{(t+1)})-\hat f(\bm y^{(t)})
 \geq \frac{c_k s}{nh^{d+2}}
 \lVert\bm y^{(t+1)}-\bm y^{(t)}\rVert_2^2\geq0.
 \label{eq:clustering-mean-shift-ascent}
\end{equation}
密度有上界时，其值因此收敛；仅凭位移趋零不能推出位置序列收敛。实际计算需记录位移容差与迭代上限，并检查终点的局部形状，因为特殊起点可能停在非峰驻点\scite{clust-comaniciu2002,clust-aliyari2015}。

\paragraph{带宽改变的估计对象}

带宽改变被搜索的密度本身。过大的带宽可能把两个峰平滑成一个，过小的带宽可能把抽样波动保留下来；增加迭代不能恢复已经被平滑掉的分隔。终点合并阈值还会改变最终簇数，应与带宽分别选择。Mean Shift按上升归宿分组，DBSCAN按密度连接分组，两者即使使用相同数据也未必得到相同群组。
\subsection{DENCLUE}

\subsubsection{模型结构}

Mean Shift按搜索归宿分组时，还需决定如何对待密度很低的驻点。沿同一平滑密度思路，Hinneburg与Keim在1998年提出DENCLUE，把各样本的影响函数相加，以密度阈值排除弱峰，再用吸引点及其连通关系组织簇\scite{clust-hinneburg1998}。网格减少密度计算需要访问的对象，同时要控制省略远处贡献的近似。它另行规定密度搜索、峰的保留与计算组织，高维估计是否可靠仍取决于样本量、表示和核尺度。

\subsubsection{参数学习}

若任务把低于$t$的密度区域视为背景，DENCLUE的阈值允许这部分对象不形成独立簇，比基本Mean Shift保留所有模态更接近该目标。它所保留的区域仍属于指定影响函数产生的平滑密度：两个目标群组之间若在这一密度的$t$水平以上连通，按密度连接合并时就不能把它们分开；一个目标群组的最高密度若低于$t$，则会被整体排除。降低$t$可以保留弱群组，也可能把背景连接一并纳入。
DBSCAN寻找密集区域的连通分量，Mean Shift寻找平滑密度的峰及其吸引域；密集桥可使两峰在前者中合为一簇、在后者中仍分开。OPTICS保存多尺度排序供提取，HDBSCAN建立层次并选择持续分支，回应单一半径难以同时描述疏密群体的问题。DENCLUE再用密度阈值筛选与连接吸引点。它们改变的是簇定义或提取规则，应先确定要保留连通区域、峰还是不同尺度的分支，再选择参数。
\section{从关系图发现群组}
\label{sec:clustering-graph}

社交连接、文档相似度和像素邻接可以直接表示为加权图。图聚类将样本作为顶点、相似程度作为边权，寻找内部连接较强而外部连接较弱的群组。向量距离也可用于建图；边权和邻域规则因此继续决定所保留的相似关系。

仅最小化切边权重，可能轻易切下一个连接少的小块。直觉上，一个只有两三条边的孤立小点本来连接就少，把它切下来“代价”极低，但这并不代表发现了有意义的群组；要公平比较，应该看“割断的联系”相对于“这个簇原来拥有多少联系”的比例，割断一个大簇一半的边显然比割掉孤立点的两条边更重大。对簇规模或连接体积作归一化，就可以比较“割断多少联系”与“簇原来拥有多少联系”。谱聚类再把这一离散搜索松弛为特征向量求解。
\subsection{谱聚类}
\label{sec:clustering-spectral}

弯曲点带还可以用图来表示：先在每个点与它最近的若干点之间连边，边的粗细表示相似度。这样同一条点带内部因为相邻点多而形成密密麻麻的连接，两条带之间只有寥寥几根边相连。于是“聚类”这件事就转化为一个很形象的图问题：割断哪些边，能使各组内部的联系尽量多、跨组的联系尽量少？不过直接寻找最优图划分需要给每个顶点尝试不同的组标签，标签组合随点数指数增长，无法穷举。\term{谱聚类}（spectral clustering）用一个巧妙的绕路解决这个组合爆炸：先暂时允许“簇标签”取连续实数（而不是非此即彼的离散值），把离散的图划分问题放松成一个可以用线性代数（求图拉普拉斯的特征向量）直接求解的连续问题，得到每个点的一组连续坐标；在这个新坐标里，原本弯曲缠绕的群组往往被拉开，最后再用一次普通K-means把连续坐标切成离散的组。它改变了中心方法所使用的坐标，但分组结果仍取决于图是否保留了可信的相似关系：若一开始连边就连错了（把不该相似的点连了强边），再好的谱计算也救不回来。

von Luxburg的教程整理了图构造、归一化及适用条件\scite{clust-luxburg2007}。

第\ref{sec:dim-le}节的拉普拉斯特征映射共享建图与低频谱表示，直接输出连续坐标；谱聚类还需要离散分配。下面以归一化割及多簇谱算法说明这两步怎样衔接。

\subsubsection{模型结构}

\paragraph{相似图与拉普拉斯}

设无向图的非负对称权重矩阵为 $\bm{W}\in\mathbb{R}^{n\times n}$，通常令 $w_{i,i}=0$。向量样本可用高斯相似度 $\exp(-\lVert\bm{x}_i-\bm{x}_j\rVert_2^2/(2\sigma^2))$ 构造边；近邻图则保留部分局部关系。单向近邻关系未必对称，必须明确采用并集对称化还是互近邻规则。

定义顶点度 $d_i=\sum_jw_{i,j}$、度矩阵 $\bm{D}=\operatorname{diag}(d_1,\ldots,d_n)$，以及三种拉普拉斯：
\begin{align}
 \bm{L}&=\bm{D}-\bm{W},\nonumber\\
 \bm{L}_{\mathrm{sym}}
 &=\bm{I}-\bm{D}^{-1/2}\bm{W}\bm{D}^{-1/2},\nonumber\\
 \bm{L}_{\mathrm{rw}}
 &=\bm{I}-\bm{D}^{-1}\bm{W}.
 \label{eq:clustering-laplacians}
\end{align}
归一化所用逆度数要求$d_i>0$，因此先单独处理孤立顶点。$\bm{L}_{\mathrm{rw}}$ 一般不对称，但与 $\bm{L}_{\mathrm{sym}}$ 相似，因而有相同的实特征值。对任意 $\bm{v}\in\mathbb{R}^n$，
\begin{equation}
 \bm{v}^{\top}\bm{L}\bm{v}
 =\frac12\sum_{i,j}w_{i,j}(v_i-v_j)^2\geq0.
 \label{eq:clustering-laplacian-form}
\end{equation}
所以 $\bm{L}$ 半正定，且 $\bm{L}\bm{1}=\bm{0}$；零特征值的重数等于连通分量数，图连通时才为单重。

\paragraph{归一化割与随机游走}

归一化还具有随机游走解释。转移矩阵 $\bm{P}=\bm{D}^{-1}\bm{W}$ 让游走者按边权比例选择下一顶点，且 $\bm{L}_{\mathrm{rw}}=\bm{I}-\bm{P}$。从一个簇出发，若内部连接强而外部连接弱，游走就倾向在簇中停留较久；Meilă 与 Shi 据此研究了聚类的随机游走视角\scite{clust-meila2001}。

设 $\operatorname{cut}(A,\bar A)=\sum_{i\in A,j\notin A}w_{i,j}$，$\operatorname{vol}(A)=\sum_{i\in A}d_i$。\term{归一化割}（normalized cut, NCut）定义为
\begin{equation}
 \operatorname{NCut}(\mathcal{P})
 =\sum_{k=1}^K
 \frac{\operatorname{cut}(C_k,\bar C_k)}
      {\operatorname{vol}(C_k)}.
 \label{eq:clustering-ncut}
\end{equation}
它比较切边与簇内外连接体积，减轻小簇的偏好；同体积的簇可以含不同样本数\scite{clust-shi2000}。\term{比率割}（RatioCut）则把分母换成 $|C_k|$，对应未归一化拉普拉斯的松弛。

\paragraph{离散标签的恢复}

训练输出包含谱坐标 $\bm{H}\in\mathbb{R}^{n\times K}$（每行对应一个训练点）和由 K-means 离散化得到的离散簇标签；给定这些训练结果，使用时直接保存并返回各点的标签，坐标到标签的 K-means 求解在参数学习段说明。若图恰有 $K$ 个连通分量，理想谱空间中每个分量对应同一方向；连接较弱的实际图中，这只是近似结构。

\subsubsection{参数学习}

\paragraph{连续松弛与特征求解}

为把 NCut 改写成矩阵目标，定义 $\bm{F}\in\mathbb{R}^{n\times K}$，其中
\[
 f_{i,k}=
 \begin{cases}
  1/\sqrt{\operatorname{vol}(C_k)},&i\in C_k,\\
  0,&i\notin C_k.
 \end{cases}
\]
簇互不相交给出 $\bm{F}^{\top}\bm{D}\bm{F}=\bm{I}_K$。由式~\eqref{eq:clustering-laplacian-form}，第 $k$ 列的二次型恰为第 $k$ 项归一化割，故目标为 $\operatorname{tr}(\bm{F}^{\top}\bm{L}\bm{F})$。

困难在于每行只允许一个特定的非零值。去掉这一离散约束，令 $\bm{H}=\bm{D}^{1/2}\bm{F}$，代入后 $\bm{F}^{\top}\bm{D}\bm{F}=\bm{I}_K$ 化为 $\bm{H}^{\top}\bm{H}=\bm{I}_K$，而 $\bm{F}^{\top}\bm{L}\bm{F}$ 化为 $\bm{H}^{\top}\bm{L}_{\mathrm{sym}}\bm{H}$，于是得到
\begin{equation}
 \min_{\bm{H}^{\top}\bm{H}=\bm{I}_K}
 \operatorname{tr}(\bm{H}^{\top}
                   \bm{L}_{\mathrm{sym}}\bm{H}).
 \label{eq:clustering-spectral-relaxation}
\end{equation}
Shi--Malik 方法也可写为广义特征问题 $\bm{L}\bm{f}=\lambda\bm{D}\bm{f}$，与归一化变换相联系\scite{clust-shi2000}。取 $\bm{L}_{\mathrm{sym}}$ 最小的 $K$ 个特征值对应的特征向量，即得到式~\eqref{eq:clustering-spectral-relaxation} 的最优解；下文说明这一连续最优值及其唯一性条件。

\paragraph{离散分配与计算使用}

连续解还需离散化。\term{NJW 算法}把 $\bm{H}$ 每一行归一化到单位长度，再对行向量运行 K-means\scite{clust-ng2002}；行归一化消除度数造成的长度差异，这一离散化动作作为训练分配的收尾，按行方向恢复簇标签，图~\ref{fig:clustering-spectral} 展示了这一理想解释。

\begin{codeblock}[language=Python,label={code:clustering-spectral}]{给定相似度矩阵的 NJW 算法}
import numpy as np
from scipy.linalg import eigh

def spectral_clustering(W, K):
    W = np.asarray(W, dtype=float)
    n = len(W)
    if W.shape != (n, n) or not 1 <= K <= n:
        raise ValueError("invalid shape or K")
    if (W < 0).any() or not np.allclose(W, W.T):
        raise ValueError("W must be nonnegative and symmetric")
    degree = W.sum(1)
    if (degree <= 0).any():
        raise ValueError("handle isolated vertices first")
    inv = 1 / np.sqrt(degree)
    L = np.eye(n) - inv[:, None] * W * inv[None, :]
    _, H = eigh(L, subset_by_index=[0, K - 1])
    length = np.linalg.norm(H, axis=1)
    if (length == 0).any():
        raise ValueError("zero embedding row")
    labels, _ = kmeans(H / length[:, None], K)
    return labels
\end{codeblock}

代码复用代码~\ref{code:clustering-kmeans}的K-means函数，处理能放入内存的稠密矩阵。图的连通分量数超过$K$时，所选零特征子空间可能含零行，也可能将多个分量任意合并。应先确定各连通分量是否需要独立输出，再选择谱子空间与分配策略。

稠密建图约需$O(n^2d)$距离运算和$O(n^2)$存储，完整特征分解约需$O(n^3)$。只求部分特征向量时，可用Lanczos或LOBPCG，矩阵乘法成本可按稀疏边数计算；迭代总成本还受特征间隙、精度和迭代次数影响。大规模实现可结合近邻图或Nyström近似，并核对它们对谱表示的误差。

\subsubsection{理论分析}

\paragraph{松弛最优值与子空间唯一性}

连续松弛的最优值是$\bm L_{\mathrm{sym}}$最小的$K$个特征值之和，取对应的正交特征向量即可达到它。当$K<n$且第$K$与第$K+1$个特征值有严格间隙时，所取子空间唯一，但其中的基可以旋转。这个线性代数结论只解决了连续坐标的求解，行归一化与K-means仍承担从坐标到标签的转换。

\paragraph{理想图上的标签恢复}

图恰有$K$个连通分量且各顶点度为正时，零特征空间由分量的度加权指示向量张成。行归一化后，同一分量得到相同方向，不同分量得到不同方向，因而最优K-means可恢复这些分量。实际图的错误边权、弱连接和离散化误差都会改变结果。用特征间隙探索$K$时，也应核对间隙来自目标群组还是孤立点。对独立新点使用模型，还需明确怎样连接到训练图、怎样获得谱坐标及怎样分配，基本训练划分没有自动定义这条路径。
\subsection{Louvain社区发现}

若图记录的是社交联系，高度活跃的顶点本来就会拥有很多边——一个社交达人跟谁都有联系。因此“簇内边多”本身并不足以说明形成了特殊群体，因为即使完全随机地连边，活跃用户也会自然地拥有大量连接。Louvain方法要找的不是“边最多”的组，而是“边的数量显著超过随机情况下所应有的组”。它优化\term{模块度}（modularity），把实际簇内边权与一个保留了各顶点度数的随机基准相比较：实际连接明显多于随机预期，才算真正的社区。它不要求选出典型代表，也不同于直接最小化归一化割。

\subsubsection{模型结构}

沿用非负无向边权$w_{i,j}$与度数$d_i=\sum_jw_{i,j}$，并假设$2m_G=\sum_i d_i>0$，典型目标为
\[
 Q=\frac{1}{2m_G}\sum_{i,j}
 \left(w_{i,j}-\frac{d_i d_j}{2m_G}\right)
 \mathbb{1}\{c_i=c_j\}.
\]
其中$c_i$是顶点$i$的社区编号，$d_i d_j/(2m_G)$是度数基准下的期望边权。对$j$求和得到$d_i$，所以基准保留了顶点的期望度数；一个高度活跃的顶点本来就被预期有较多连接。模块度累加同社区内实际边权减去基准边权的有符号差，再按全图总度数归一化；正差提高模块度，负差降低模块度，并不只保留正的贡献。
\subsubsection{参数学习}

\paragraph{局部移动与社区凝聚}

Louvain交替执行局部移动与社区凝聚\scite{clust-blondel2008}。初始时每个顶点独自成社区；访问一个顶点时，计算把它移入各邻接社区的模块度增量，只接受严格正增益的移动，并按固定规则处理并列候选。反复扫描，直到没有这类改进。随后把每个社区合成一个新顶点。不同社区间的边权相加，原社区内的边保留为自环，并沿用使总度数与原图一致的自环计数约定。凝聚图上的一个社区因此代表原图中的一组社区，其模块度与对应原图划分一致。在凝聚图上重复局部移动；社区数不再缩减且没有正增益时停止。稀疏表示可以减少边访问，但移动顺序与早期凝聚仍影响后续搜索，算法只能保证按这些规则停止，不能保证全局最优。

\paragraph{全图基准与社区尺度}

模块度比较的是相对于全图度数基准的连接富集。记$w(A,B)$为两社区间的边权总和，$v_A,v_B$为其总度数，合并的模块度增量为
\[
 \Delta Q=\frac{w(A,B)}{m_G}-\frac{v_Av_B}{2m_G^2}.
\]
因此同样的局部联系会受到全图总边权影响，小群体可能被并入较大社区——这就是模块度的\term{分辨率限制}：优化模块度本身，并不能保证拆出较小的真实社区，社区尺度还受图规模牵制。

同一关系图可以服务不同目标。谱聚类用归一化割比较跨组联系，再求连续坐标与离散标签；Louvain用模块度寻找超过度数基准的簇内联系，局部移动与合并逐级提高目标。两者分别保留低跨组连接与连接富集，目标值（割、模块度）量纲不同，不能直接比较。图构造、邻域规则与局部搜索也各自影响输出；采用哪条路线，应由群组的用途决定。
\section{凝聚与分裂的层次聚类}
\label{sec:clustering-hierarchy}

探索阶段的群组粒度尚不明确时，可以保留多个层级。一个现实的困难是：K-means、DBSCAN 都要求你先给定$K$或密度阈值，但分析早期往往既不知道该分几群、也不知道该看多细。\term{层次聚类}（hierarchical clustering）不强迫你一次选定粒度，而是输出一棵\term{树状图}（dendrogram），把“哪些样本最先聚到一起、哪些小群后来又合成大群”的整个嵌套过程都记录下来；分析者事后在树的不同高度画一条截线，就能读出不同规模的划分——截得低得到很多细群，截得高得到几个大群。具体截取哪一层，仍由任务用途与证据确定。

凝聚方法从单点向上合并，分裂方法从全集向下拆分。图~\ref{fig:clustering-dendrogram}在同一棵树上读取两种粒度；截线保留已完成的层次决策，不对该粒度重新搜索。

\subsection{基于链接的凝聚：AGNES}
\label{sec:clustering-agnes}

若希望先找出最相近的客户，再观察这些小群体怎样组成较大群体，可以从每个样本各自成簇开始。\term{凝聚分析}（Agglomerative Nesting, AGNES）每次合并当前相异度最小的两簇，把合并次序与相异度保存在树中。我们可以在不同高度截取划分，无须预先固定一个$K$；已经合并的对象则不会在后续分开。Kaufman与Rousseeuw在1990年的专著中将这一长期用于数值分类学的过程与自顶向下的DIANA并列介绍。簇内出现多个样本之后，怎样定义簇间相异度就成为下一步的关键。

链接准则把不同群组偏好写进合并决策：单链接沿最近联系扩展，平均链接综合跨簇距离，Ward在1963年以最小SSE增量选择合并。凝聚方向规定构造顺序，链接准则决定哪种关系先进入树。

\subsubsection{模型结构}

\paragraph{树状输出与链接准则}

初始划分为 $\mathcal{P}^{(0)}=\{\{1\},\ldots,\{n\}\}$。第 $t$ 步选择使 $D(A,B)$ 最小的两个当前簇，替换为 $A\cup B$，经过 $n-1$ 次合并得到根节点。固定相异度和确定的平局规则后，整棵树随之确定。

不同\term{链接方式}（linkage）用不同的簇间统计量：
\begin{align*}
 D_{\mathrm{single}}(A,B)
   &=\min_{i\in A,j\in B}\delta(\bm{x}_i,\bm{x}_j),\\
 D_{\mathrm{complete}}(A,B)
   &=\max_{i\in A,j\in B}\delta(\bm{x}_i,\bm{x}_j),\\
 D_{\mathrm{average}}(A,B)
   &=\frac{\sum_{i\in A,j\in B}\delta(\bm{x}_i,\bm{x}_j)}
   {|A||B|}.
\end{align*}
单链接沿近邻链扩展，可以保留细长形状，也容易被两点之间孤零零的一座“稀疏桥”把本不相干的两群误连成一群（即链式效应）；全链接控制跨簇最远距离，要求两群中\emph{最远}的一对也足够近才合并，因此倾向产生紧凑、大小相近的群组，代价是可能把本属一条长带的两端早早判为不同簇；平均链接考虑所有跨簇样本对的平均距离，不被单个最近或最远点左右，减弱单个极值的影响。这里的平均链接指按样本数加权的 UPGMA。

\paragraph{平方误差合并准则}

若样本处于欧氏空间，Ward 链接以合并引起的 SSE 增量定义相异度：
\[
 D_{\mathrm{Ward}}(A,B)
 =\mathrm{SSE}(A\cup B)-\mathrm{SSE}(A)-\mathrm{SSE}(B).
\]
它与 K-means 共享平方误差准则，但只允许合并已有簇。Ward 的原始工作明确以这种误差增量组织层次\scite{ward1963}。

\subsubsection{参数学习}

\paragraph{合并搜索与树的建立}

实现 AGNES 时，可以维护当前簇间的相异度，并在每次合并后更新相关行列。算法~\ref{alg:clustering-agnes} 省去了不影响定义的矩阵下标管理。

\begin{algorithm}[凝聚层次聚类]
 \label{alg:clustering-agnes}
 \begin{algorithmic}[1]
 \Require 样本相异度、链接方式和确定的平局规则
 \Ensure 包含合并高度的层次树
 \State 建立 $n$ 个单点簇，初始化簇间相异度
 \While{当前簇数大于 $1$}
  \State 选择使 $D(A,B)$ 最小的当前簇对
  \State 记录子簇 $A,B$ 和合并高度 $D(A,B)$
  \State 用 $A\cup B$ 替换 $A,B$
  \State 更新新簇与其他当前簇的相异度
 \EndWhile
 \end{algorithmic}
\end{algorithm}

\paragraph{簇间相异度的递推}

Lance--Williams 递推使多种链接共享更新形式\scite{clust-lance1967}。
\begin{equation}
 \begin{aligned}
 D(A\cup B,C)={}&\alpha_A D(A,C)+\alpha_B D(B,C)\\
 &+\beta D(A,B)
 +\gamma|D(A,C)-D(B,C)|.
 \end{aligned}
 \label{eq:clustering-lance-williams}
\end{equation}
单链接的系数为 $(1/2,1/2,0,-1/2)$，全链接为 $(1/2,1/2,0,1/2)$，平均链接为 $(|A|/(|A|+|B|),|B|/(|A|+|B|),0,0)$。

这些系数可以从已有链接定义直接读出。令$u=D(A,C)$、$v=D(B,C)$，单链接更新要保留两者中较小的一个，全链接则保留较大的一个，而
\[
 \min\{u,v\}=\frac{u+v-|u-v|}{2},\qquad
 \max\{u,v\}=\frac{u+v+|u-v|}{2}.
\]
例如$u=2,v=6$时，绝对差前取负号得到2，取正号得到6。平均链接的权重来自跨簇样本对的数量：新簇与$C$之间有$|A||C|$对来自$A$，另有$|B||C|$对来自$B$，所以
\[
 \begin{aligned}
 D_{\mathrm{average}}(A\cup B,C)
 ={}&\frac{|A|}{|A|+|B|}D_{\mathrm{average}}(A,C)\\
 &+\frac{|B|}{|A|+|B|}D_{\mathrm{average}}(B,C).
 \end{aligned}
\]
这按样本对平均，而不是让两个大小不同的旧簇各占一半。

若 $D$ 直接表示 Ward 的 SSE 增量，令 $s=|A|+|B|+|C|$，则
\[
 \alpha_A=\frac{|A|+|C|}{s},\quad
 \alpha_B=\frac{|B|+|C|}{s},\quad
 \beta=-\frac{|C|}{s},\quad \gamma=0.
\]
软件也可能存储Ward增量的缩放平方根；递推系数应与其距离约定配套。

\paragraph{实现代价}

朴素实现每轮扫描全部簇对，约需$O(n^3)$时间和$O(n^2)$存储。链接结构可减少搜索：SLINK的单链接为$O(n^2)$时间和$O(n)$辅助空间，CLINK提供全链接的紧凑表示；平均、全链接和Ward的最近邻链实现也可达到$O(n^2)$时间，常见实现仍保存平方规模距离矩阵\scite{clust-muellner2011}。采用这些算法时需沿用其链接和平局约定。

\subsubsection{理论分析}

\paragraph{Ward误差增量与中心法的联系}

Ward合并的SSE增量可直接从簇均值算出：
\begin{equation}
 D_{\mathrm{Ward}}(A,B)
 =\frac{|A||B|}{|A|+|B|}
  \lVert\bm\mu_A-\bm\mu_B\rVert_2^2.
 \label{eq:clustering-ward-increment}
\end{equation}
将合并均值代入式\eqref{eq:clustering-mean-decomposition}，两簇原有SSE以外的部分就是各簇均值移动带来的误差，两项相加得到上式。选择最小增量只保证当前合并最好；截取$K$簇后再允许样本重新分配，K-means仍可能降低SSE。

\paragraph{嵌套输出的限制}

完整凝聚经过$n-1$次合并结束。树中两个节点的成员集合只能包含或互不相交，不能同时保存按地区与按购买偏好形成的交叉群组。早期误合并也不能靠后来换截线撤销。树本身只描述当前对象；要接纳新对象，需要另规定插入或分配规则。
\subsection{CURE}

\subsubsection{模型结构}

用单个中心合并两个弯曲或拉长的群组，可能漏掉它们实际相邻的边缘；只用最近样本，又可能被一两个孤立点连接起来。CURE在两者之间取折中，用多个分散代表点覆盖每簇的不同部分，再把这些点向均值收缩，以减弱极端位置的影响\scite{clust-guha1998}。选择代表时，先选离均值较远的点，再逐个选择离已有代表集合较远的点。若原代表为$\bm{r}$、簇均值为$\bm{\mu}_C$，收缩后的代表可写为
\[
 \bm{r}'=(1-\alpha)\bm{r}+\alpha\bm{\mu}_C,
 \qquad 0\leq\alpha\leq1.
\]

\subsubsection{参数学习}

两个簇的代表之间的最近距离用于决定合并。$\alpha=0$ 保留边缘形状，也更易受极端点影响；$\alpha$ 接近 1 时，代表逐渐退化为中心。CURE用抽样和分区减少参与完整层次搜索的对象，成本需同时计入抽样分配、代表更新及实际合并规模。

\subsubsection{性质与使用条件}

CURE增加了描述簇边缘的位置，因而可以在代表覆盖充分时比较细长或弯曲群组的局部间隔。它仍只能看见所选代表，未被代表覆盖的细小分支可能不参与合并判断。收缩也会改变目标间隔：若两圈的均值都为圆心，$\alpha=1$时所有代表都退到同一点，原本分离的两个环便无法靠代表距离区分。多个代表缓解单中心限制，代表数和收缩量则决定保留了多少形状信息。
\subsection{DIANA}

有时我们更关心“整个数据先分成哪几大部分”，而非最先配对的几个样本。\term{分裂分析}（Divisive Analysis, DIANA）从所有样本组成的一簇开始，优先拆分内部差异最大的群组，再继续细分。与AGNES从局部相近关系向上合并相比，DIANA从整体差异向下建立层次；它采用的贪心拆分并不等于反向执行AGNES，早期分开的样本也不会在后续重新合并。

\subsubsection{模型结构}

DIANA 通常用簇直径 $\max_{i,j\in C}\delta(\bm{x}_i,\bm{x}_j)$ 选择待分裂簇。每次把一个非单点簇拆成两个非空子簇；若展开完整树，恰需 $n-1$ 次分裂。若只需少数大簇，也可提前停止。

\subsubsection{参数学习}

对含 $m$ 个样本的簇，非平凡无序二分共有 $2^{m-1}-1$ 种，完整枚举很快变得昂贵。DIANA 用\term{分裂群}（splinter group）贪心构造二分：选取对其余样本平均相异度最大的样本作为种子，令其自成集合 $S$，其余样本组成 $R$。

对每个 $i\in R$，在 $|R|>1$ 时计算
\[
 a_i=\frac{1}{|R|-1}\sum_{\substack{j\in R\\j\ne i}}
 \delta(\bm{x}_i,\bm{x}_j),\qquad
 b_i=\frac{1}{|S|}\sum_{j\in S}\delta(\bm{x}_i,\bm{x}_j).
\]
若最大的 $a_i-b_i$ 为正，就把对应样本从 $R$ 移到 $S$，再更新这些量；否则结束分裂。这样每一步都选择更接近分裂群的最强候选，而非按任意顺序一次扫描。保留至少一个样本在 $R$ 中，避免产生空子簇。每次分裂产生两个非空子簇，完整树因此经过$n-1$次分裂结束；一次分裂中，成员只移入分裂群而不移回，内部搜索也有限。这个停止依据没有保证最优二分。早期分到不同分支的对象以后无法重组，所以DIANA与AGNES都受嵌套结构限制，只是选择保留哪些关系的顺序不同。
\subsection{二分K-means}

\subsubsection{模型结构}

若除了最终的$K$组，还希望看到“先分成哪两大组，再怎样细分”，一次性$K$中心划分没有保留这种关系。\term{二分 K-means}（Bisecting K-means）从全部样本组成的一簇开始，反复选择一个簇作$K=2$划分。分裂记录形成一棵层次树，但早期分开的对象以后不能跨分支重组。Steinbach等在文档聚类中研究了这一方案\scite{clust-steinbach2000}。

\subsubsection{参数学习}

常见实现选择最大SSE的簇，并为每次二分多次重启。最终SSE因而不保证优于一次性$K$分。

\subsubsection{性质与使用条件}

每次最近双中心分裂都增加一个半空间条件，最终叶簇是沿路径得到的半空间交，仍为凸区域。它可以表示不同粒度下相互包含的群组；若某个目标群组跨越了早期切面，后续细分只能把它切成更多片，不能重新组成一簇。因此，层次输出增加了可解释的粒度关系，并未消除原空间中心划分对环形目标的限制。
AGNES从单点合并，DIANA从全集分裂，二者都保留嵌套关系并锁定早期决策。单链接关注局部连接，全链接控制最远跨度，Ward选择SSE增量较小的合并；改变链接会改变树所表达的群组。CURE用多个收缩代表保留形状，改变了合并所依据的代表；二分K-means则反复分裂一个簇，近似得到二元层次，不等同于DIANA的全局分裂。树的粒度可以事后选择，已经丢失的形状或早期错误则不能仅靠截线恢复。
\section{生成混合模型}
\label{sec:clustering-probabilistic}

中心、密度连通与图割都是用某种几何或连接规则直接规定群组，它们都不给出“这个点属于某簇的概率是多少”。有些任务却需要这种不确定性信息：一个落在两团重叠处的客户，硬判给哪一类都显得武断；我们更想说它“有七成像A组、三成像B组”。概率聚类为此换一个生成式的视角：假设数据是由若干个看不见的“来源”（成分）混合产生的——先按某种比例随机选一个成分，再由这个成分对应的概率分布（比如一个朝某方向拉伸的椭圆状高斯云）生成一个观测点。模型的任务是反推：每个成分的中心、形状和占比是多少，以及每个点分别由各成分生成的概率多大。这样就能同时得到分布参数和成分归属后验。

这一路线支持软归属、能预测新点的密度、还能用统一的似然标准比较模型。但要特别警惕：这里的“成分”是统计意义上的混合来源，不必然等于业务上的一个语义类别。一个形状复杂的真实群体可能需要好几个高斯才能近似拼出，因此“拟合密度最合适的成分数”与“真正的类别数”可以不同，成分的含义必须与任务群组核对。
\subsection{共同基础：有限混合与EM}
\label{sec:clustering-em-common}

在分别介绍高斯、伯努利、多项式与$t$成分之前，先建立所有有限混合共享的潜在成分、责任度与交替学习步骤；各成分专属的参数、允许域与M步解，留到对应模型展开。

\subsubsection{潜在成分、观测密度与后验}

\paragraph{有限混合的共同结构}

设样本 $\bm{x}_i$ 由不可观测的潜在成分 $z_i\in\{1,\ldots,K\}$ 决定：先按混合权重 $\pi_k\geq0$、$\sum_{k=1}^K\pi_k=1$ 抽取 $z_i=k$，再由第 $k$ 个成分的条件密度或概率质量 $g_k(\bm{x};\bm\theta_k)$ 抽取观测。边际分布为
\[
 p(\bm{x})=\sum_{k=1}^K\pi_k g_k(\bm{x};\bm\theta_k).
\]
给定当前参数，贝叶斯公式给出样本由成分 $k$ 产生的后验概率，称为\term{责任度}（responsibility）：
\begin{equation}
 r_{i,k}
 =\frac{\pi_k g_k(\bm{x}_i;\bm\theta_k)}
        {\sum_{j=1}^K\pi_j g_j(\bm{x}_i;\bm\theta_j)},
 \qquad \sum_k r_{i,k}=1.
 \label{eq:clustering-responsibility-common}
\end{equation}
分母为正要求至少一个成分对该样本给出非零密度；责任度每行和为1，可作软归属，硬标签取 $\arg\max_k r_{i,k}$ 并按预定规则处理平局。

\paragraph{拟合密度与解释成分}

冻结参数后，新观测按同一公式计算密度与后验。

责任度给出的是当前生成模型中的统计成分归属；它是否对应任务语义上的群体，须回到用途核对——这一边界在章首与第\ref{sec:clustering-evaluation}节分别说明，此处不重复论证。

\subsubsection{有限混合的参数学习}

\paragraph{观测似然与E步}

独立同分布观测下，对数似然为
\[
 \ell(\bm\theta)=\sum_{i=1}^n\log\!\left[\sum_{k=1}^K\pi_k g_k(\bm{x}_i;\bm\theta_k)\right].
\]
对数内的求和使各成分参数相互耦合，无法逐成分独立优化。加入潜在成分指示后，完全观测对数似然按样本与成分相加；E步用旧参数 $\bm\theta^{(t)}$ 按式~\eqref{eq:clustering-responsibility-common} 计算责任度并固定，形成待最大化的固定权重目标
\[
 Q(\bm\theta\mid\bm\theta^{(t)})
 =\sum_{i,k}r_{i,k}^{(t)}
   \bigl[\log\pi_k+\log g_k(\bm{x}_i;\bm\theta_k)\bigr].
\]
M步在固定责任度下最大化该目标，而不是在求导途中继续更新责任度。

\paragraph{权重更新与分布专属M步}

定义有效计数 $N_k=\sum_i r_{i,k}^{(t)}$。在 $\sum_k\pi_k=1$ 约束下对 $\sum_k N_k\log\pi_k$ 引入拉格朗日乘子并求导，由求和确定乘子，得到混合权重更新
\[
 \pi_k^{(t+1)}=\frac{N_k}{n}.
\]
余下部分分别最大化 $\sum_i r_{i,k}\log g_k(\bm{x}_i;\bm\theta_k)$；具体分布决定参数域、充分统计量与解，高斯协方差、$t$尺度等的分母不能由共同框架直接猜出。数值空成分、端点解与先验平滑，都由当前模型另行规定。

\subsubsection{EM的似然上升与保证范围}

\begin{theorem}[精确EM的似然上升]
 \label{thm:clustering-em}
 E步取当前后验，M步在同一参数域内不降低$Q$；在相关概率与期望有限时，观测对数似然不下降。
\end{theorem}
\begin{proof}
记 $\mathcal L(q,\bm\theta)$ 为完全数据对数似然在 $q$ 下的期望加上 $q$ 的熵。对每个样本，观测对数似然等于这一项加上 $q$ 到成分后验的KL散度。E步令 $q$ 等于旧后验，使散度为零；M步固定 $q$ 提高 $Q$，也就提高下界。新似然不低于新下界，因此不低于旧似然。
\end{proof}

上升不等于全局最优：多个初值可能停在不同局部驻点，成分编号置换还会给出密度相同的等价解。精确最大化、广义M步与数值近似的保证强度不同；各分布还须单独检查退化与边界情形。

\subsubsection{成分数选择与共同使用边界}

成分数 $K$ 本身也是待选对象。在相同观测与密度目标下，可用留出对数似然比较，或用信息准则按较小值选择：完整协方差GMM有 $m_K=(K-1)+Kd+Kd(d+1)/2$ 个自由参数，常用
\begin{equation}
 \mathrm{BIC}=-2\ell(\hat{\bm\theta}_K)+m_K\log n,
 \qquad \mathrm{AIC}=-2\ell(\hat{\bm\theta}_K)+2m_K.
 \label{eq:clustering-bic}
\end{equation}
有限混合存在退化与边界情形，不能无条件套用常规渐近解释；所选成分数也未必等于语义类别数\scite{clust-keribin2000}。数据划分与独立验证的公共流程在第\ref{sec:clustering-evaluation}节集中说明。

还需区分四种不同状态：有限EM正常停止于局部驻点、目标无界增大的退化、参数数值退化，以及DPM那样的后验抽样推断；有限次迭代的似然改善不能写成全局最优或类别恢复。

\subsection{高斯混合模型（GMM）}
\label{sec:clustering-gmm}

考虑两个椭圆状的客户群组：一组沿消费金额方向伸展，另一组沿购买频次方向伸展。离两个中心同样远的记录，在前一组的主要变化方向上可能很常见，在后一组的窄方向上却很罕见。只比较中心的欧氏距离没有表达这种区别。\term{高斯混合模型}（Gaussian Mixture Model, GMM）为每个成分设置均值、协方差与权重，用它们共同计算样本的密度及成分归属概率。协方差描述各方向的伸展程度，权重描述成分在总体中的比例；重叠区域内的样本可以同时对多个成分有非零后验概率。现代教材常结合EM说明其估计\scite{bishop2006}。

\subsubsection{模型结构}

\paragraph{高斯成分的参数与几何}

与第\ref{sec:classification-gda}节的 GDA 相比，两者都用高斯密度描述输入，但 GDA 的类别标签已经观测，可以按类直接估计；GMM 的成分归属不可观测，需要作为潜在成分变量推断。具体而言，先按权重 $\pi_k\geq0$、$\sum_k\pi_k=1$ 抽取潜在成分变量 $z_i\in\{1,\ldots,K\}$，再从 $\mathcal{N}(\bm{\mu}_{z_i},\bm{\Sigma}_{z_i})$ 抽取样本。要求 $\bm{\Sigma}_k\succ0$，边际密度为
\begin{equation}
 p(\bm{x};\bm{\theta})
 =\sum_{k=1}^K\pi_k
   \mathcal{N}(\bm{x};\bm{\mu}_k,\bm{\Sigma}_k),
 \label{eq:clustering-gmm}
\end{equation}
其中 $\bm{\theta}$ 汇集权重、均值与协方差。独立同分布样本的对数似然为
\[
 \ell(\bm{\theta})
 =\sum_{i=1}^n\log\left[
 \sum_{k=1}^K\pi_k
 \mathcal{N}(\bm{x}_i;\bm{\mu}_k,\bm{\Sigma}_k)\right].
\]
求和藏在对数内，使每个成分的参数无法独立优化。

给定参数后，一个自然的问题是：某个观测点究竟更可能是哪个高斯云抛出来的？用贝叶斯公式就能算出这个后验概率，称为\term{责任度}（responsibility），即当前模型认为样本由某成分产生的后验概率：
\begin{equation}
 \gamma_{i,k}
 =\frac{\pi_k\mathcal{N}(\bm{x}_i;\bm{\mu}_k,\bm{\Sigma}_k)}
 {\sum_{j=1}^K\pi_j
       \mathcal{N}(\bm{x}_i;\bm{\mu}_j,\bm{\Sigma}_j)}.
 \label{eq:clustering-responsibility}
\end{equation}
责任度每行和为1，可作为软归属；硬划分取$\argmax_k\gamma_{i,k}$并处理平局。概率含义对应当前生成模型中的成分，解释为任务类别还需核对模型与语义的关系。

图~\ref{fig:clustering-gmm-responsibilities}固定两成分模型。上图相加各加权密度，得到观测总密度；下图把各成分贡献除以总密度，得到$\gamma_k(x)=p(z=k\mid x;\bm{\theta})$。对称点$x=0$的责任度各为一半，其他位置连续变化。成分归属与总密度的峰数描述不同结构，两成分混合也可能只有一个峰。

\subsubsection{参数学习}

\paragraph{高斯责任度与条件目标}

EM 的 E步、M步与似然上升已在第\ref{sec:clustering-em-common}节建立；这里只展开高斯成分专属的条件目标与更新。E步用当前参数 $\bm{\theta}^{(t)}$ 计算式~\eqref{eq:clustering-responsibility} 的高斯责任度，M步固定这些责任度，最大化完全数据对数似然的期望\scite{clust-dempster1977}。

忽略与参数无关的常数，高斯项代入共同 $Q$ 后，M步目标为
\begin{equation}
 \begin{aligned}
 Q(\bm{\theta}\mid\bm{\theta}^{(t)})
 =\sum_{i,k}\gamma_{i,k}^{(t)}
 \biggl[&\log\pi_k-\frac12\log\det\bm{\Sigma}_k\\
 &-\frac12(\bm{x}_i-\bm{\mu}_k)^\top
 \bm{\Sigma}_k^{-1}(\bm{x}_i-\bm{\mu}_k)\biggr].
 \end{aligned}
 \label{eq:clustering-gmm-q}
\end{equation}
\paragraph{均值与协方差更新}

M步把责任度看作固定的样本权重，分别重新估计成分比例、均值和协方差。记有效样本量$n_k^{(t)}=\sum_i\gamma_{i,k}^{(t)}$。对于成分比例，在$\sum_k\pi_k=1$的约束下最大化$\sum_k n_k^{(t)}\log\pi_k$；加入拉格朗日乘子后，驻点满足$n_k^{(t)}/\pi_k=\lambda$，再对$k$求和得到$\lambda=n$。对于均值，$Q$中的相关项是责任度加权的负平方Mahalanobis距离。令其对$\bm\mu_k$的梯度为零，消去公共的正定因子$\bm\Sigma_k^{-1}$，就得到加权残差和为零。因此，这两项更新分别为
\begin{equation}
 \pi_k^{(t+1)}=\frac{n_k^{(t)}}{n},\qquad
 \bm{\mu}_k^{(t+1)}
 =\frac{\sum_i\gamma_{i,k}^{(t)}\bm{x}_i}{n_k^{(t)}}.
 \label{eq:clustering-gmm-mean}
\end{equation}
每个样本按其责任度贡献一部分计数与观测值，硬分配中的簇规模和簇均值由此变为有效样本量与加权均值。

再令精度矩阵 $\bm{\Lambda}_k=\bm{\Sigma}_k^{-1}$，加权散布为
\[
 \bm{S}_k=\sum_i\gamma_{i,k}^{(t)}
 (\bm{x}_i-\bm{\mu}_k^{(t+1)})
 (\bm{x}_i-\bm{\mu}_k^{(t+1)})^\top.
\]
把协方差改写为精度矩阵后，$Q$中需要最大化的部分为$\tfrac12[n_k^{(t)}\log\det\bm{\Lambda}_k-\operatorname{tr}(\bm{\Lambda}_k\bm{S}_k)]$。令这一部分的矩阵梯度为零，得到$n_k^{(t)}\bm{\Lambda}_k^{-1}-\bm{S}_k=\bm{0}$；换回协方差，就得到加权散布除以有效样本量：
\begin{equation}
 \bm{\Sigma}_k^{(t+1)}
 =\frac{\bm{S}_k}{n_k^{(t)}}.
 \label{eq:clustering-gmm-covariance}
\end{equation}
更新要求有效样本量为正。加权散布正定时，无约束协方差取得正定域内的有限最优；退化散布则需要协方差约束或其他估计。

\paragraph{初始化、数值计算与停止}

实现以K-means中心初始化，在同一参数域内检查对数似然变化并结合迭代上限停止；空成分在数值上需另行报错或平滑处理。

\subsubsection{理论分析}

\paragraph{无约束似然的塌缩}

上升不等于找到全局最好分组。多个初值可能得到不同局部解，成分编号置换则会给出密度相同的等价解。更严重的是：一个正权重高斯可以把均值放在某个样本上、协方差缩到零，而其他成分继续覆盖其余样本，使无约束似然无界增大。前面的协方差下界防止这种塌缩；也可以用适当先验或正则化，但需要相应改变学习目标。要区分目标无界增大、算法正常达到驻点和参数数值退化三种状态，解决办法是受约束参数域或明确先验，而不是只增加迭代。

\paragraph{小方差极限与K-means}

GMM的软归属、权重与协方差共同定义后验，K-means只使用中心平方距离。固定部分参数并取小方差极限，可以明确两种目标和更新的联系。固定均匀权重 $\pi_k=1/K$ 和共享球形协方差 $\bm{\Sigma}_k=\sigma^2\bm{I}$，则
\[
 \gamma_{i,k}=
 \frac{\exp(-\lVert\bm{x}_i-\bm{\mu}_k\rVert_2^2/(2\sigma^2))}
 {\sum_j\exp(-\lVert\bm{x}_i-\bm{\mu}_j\rVert_2^2/(2\sigma^2))}.
\]
若 $\bm{x}_i$ 的最近中心唯一为 $k^\ast$，则对任意 $j\ne k^\ast$，距离平方差为正，相应指数比随 $\sigma^2\to0$ 趋零，故 $\gamma_{i,k^\ast}\to1$。M 步的均值更新因此退化为 Lloyd 更新；平局时责任度可分散在多个最近中心，不能直接得到唯一硬簇分配。

去掉只依赖$\sigma$的常数，目标$-2\sigma^2\ell$趋向$\sum_i\min_k\lVert\bm{x}_i-\bm{\mu}_k\rVert_2^2$，给出平方误差的联系。这一极限固定均匀权重并缩小共享球方差；自由协方差GMM优化更大的分布族。FCM的软隶属度则来自模糊损失，与生成后验采用不同定义。

\subsubsection{扩展：协方差约束与形式选择}

\begin{codeblock}[language=Python,label={code:clustering-gmm}]{带协方差下界的 GMM--EM}
import numpy as np
from scipy.special import logsumexp
from scipy.stats import multivariate_normal

def gmm_em(X, K, max_iter=100, tol=1e-5, eps=1e-6):
    X = np.asarray(X, dtype=float)
    n, d = X.shape
    if eps <= 0:
        raise ValueError("eps must be positive")
    _, mu = kmeans(X, K)
    pi = np.full(K, 1.0 / K)
    cov = np.repeat((max(1., eps) * np.eye(d))[None], K, axis=0)
    def e_step():
        log_p = np.column_stack([
            np.log(pi[k]) + multivariate_normal.logpdf(
                X, mean=mu[k], cov=cov[k])
            for k in range(K)])
        normalizer = logsumexp(log_p, axis=1)
        gamma = np.exp(log_p - normalizer[:, None])
        return gamma, normalizer.sum()
    gamma, ll = e_step()
    for _ in range(max_iter):
        nk = gamma.sum(0)
        if (nk <= 0).any():
            raise ValueError("numerically empty component")
        pi = nk / n
        mu = (gamma.T @ X) / nk[:, None]
        for k in range(K):
            diff = X - mu[k]
            S = (diff * gamma[:, k, None]).T @ diff / nk[k]
            values, vectors = np.linalg.eigh(S)
            cov[k] = (vectors * np.maximum(values, eps)) @ vectors.T
        gamma, new_ll = e_step()
        if abs(new_ll - ll) <= tol * (1 + abs(ll)):
            break
        ll = new_ll
    return pi, mu, cov, gamma
\end{codeblock}

\paragraph{协方差约束与受限M步}

代码~\ref{code:clustering-gmm}在对数域计算责任度，并用协方差特征值下界$\epsilon$避免塌缩；该截断求解固定约束$\bm{\Sigma}_k\succeq\epsilon\bm{I}$下的M步，每轮任意加常数矩阵则对应另一种估计，需另说明目标。实现以K-means中心初始化，最终重新计算责任度。固定责任度后，把归一化散布$\bar{\bm S}_k=\bm S_k/n_k$作特征分解。受限M步让协方差沿同一组方向取值；每个方向需最小化$\log s+\lambda/s$，其中$\lambda$是该方向的散布特征值，$s\geq\epsilon$。导数为$(s-\lambda)/s^2$，故最优值为$s=\max\{\lambda,\epsilon\}$。这解释了代码为什么只抬高过小的特征值，而不对所有方向统一加常数。

\paragraph{协方差形式的比较}

完整协方差保留全部二阶方向关系；类内有效样本不足时，可采用对角、球形或共享协方差减少自由度。完整形式一轮约需$O(nKd^2+Kd^3)$运算，立方项来自矩阵分解，对角形式的主要成本为$O(nKd)$。K-means++、重启和初始划分协方差可提供不同起点，其结果在同一约束与似然下比较。

\subsection{伯努利混合模型}

\subsubsection{模型结构}

高斯密度不适合直接描述是否购买这类二值观测。对$\bm x\in\{0,1\}^d$，可用成分内条件独立的伯努利模型
\[
 p(\bm x)=\sum_k\pi_k\prod_{j=1}^d
 p_{k,j}^{x_j}(1-p_{k,j})^{1-x_j}.
\]
这里$p_{k,j}$是第$k$个成分中第$j$项取1的概率。

\subsubsection{参数学习}

\paragraph{责任度与发生概率更新}

E步仍按“权重乘成分似然，再归一化”计算责任度，M步更新$\pi_k=n_k/n$及$p_{k,j}=\sum_i\gamma_{i,k}x_{i,j}/n_k$。更换成分后，学习的是各组的发生概率，不再是高斯均值和协方差。

\paragraph{初始化与观测边界}

条件独立仅在同一成分内成立；成分概率的初始化、端点解与空成分处理需另行规定。

\subsection{多项式混合模型}

\subsubsection{模型结构}

文档词频这类总次数给定的计数，可改用多项式成分：令$N_i=\sum_jx_{i,j}$，第$k$个成分的词概率为$\bm p_k$、$\sum_jp_{k,j}=1$，似然为$N_i!\prod_jp_{k,j}^{x_{i,j}}/\prod_jx_{i,j}!$。这里描述给定总次数后的类别计数，不能套给任意计数过程。

\subsubsection{参数学习}

\paragraph{责任度与词概率更新}

E步代入该似然，M步取$p_{k,j}=\sum_i\gamma_{i,k}x_{i,j}/\sum_i\gamma_{i,k}N_i$，即责任度加权的词频占比。

\paragraph{初始化与观测边界}

分母为零的空成分需要处理，平滑则对应额外先验或惩罚。

\subsection{重尾混合模型}

\subsubsection{模型结构}

少量远点可能把高斯成分的尺度撑大。$t$混合把各成分换成尾部较厚的$t$分布，仍以权重相加形成密度：$p(\bm x)=\sum_k\pi_k t_{\nu_k}(\bm x;\bm\mu_k,\bm\Sigma_k)$。这里$\bm\Sigma_k$是尺度矩阵，$\nu_k>0$控制尾部；它不能直接当作协方差，后者仅在$\nu_k>2$时为$\nu_k\bm\Sigma_k/(\nu_k-2)$。

\subsubsection{参数学习}

\paragraph{局部精度与E步}

固定自由度时，可在EM中额外引入每条记录的局部精度。令$\Delta_{i,k}$为当前成分下的平方Mahalanobis距离，其条件期望权重为$u_{i,k}=(\nu_k+d)/(\nu_k+\Delta_{i,k})$。E步计算$t$成分责任度$\gamma_{i,k}$与$u_{i,k}$。

\paragraph{位置与尺度的M步}

M步用$\gamma_{i,k}u_{i,k}$加权更新均值；尺度用同样加权的残差外积之和除以$n_k=\sum_i\gamma_{i,k}$，混合权重仍为$n_k/n$。

\paragraph{尾部假设与异常影响}

远点的$u_{i,k}$较小，因而对位置与尺度的牵动减弱；若同时学习自由度，还要增加数值求解步骤\scite{clust-peel2000}。厚尾处理不保证任何异常污染下都可靠，也不应把重要的小群体自动当成应被减权的远点。
\subsection{狄利克雷过程混合（DPM）}

\subsubsection{模型结构}

有限混合先规定成分数，于是又回到“$K$该取多少”的难题。若希望把成分数的不确定性也交给模型、让数据自己决定该用几个成分，可用\term{狄利克雷过程混合}（Dirichlet process mixture, DPM）。把成分参数写成$\bm\eta=(\bm\mu,\bm\Sigma)$，一份有限GMM等价于从离散分布$G=\sum_k\pi_k\delta_{\bm\eta_k}$抽参数，再由相应高斯生成样本。DPM把固定的$G$改为随机分布：
\[
 G\sim\operatorname{DP}(\alpha,G_0),\qquad
 \bm\eta_i\mid G\sim G,\qquad
 \bm x_i\mid\bm\eta_i\sim\mathcal N(\bm x_i;\bm\eta_i).
\]
$G_0$规定成分参数的先验分布，$\alpha>0$控制复用已有成分与增加新成分的倾向（$\alpha$越大越容易开新簇）；随机$G$几乎必然离散，因而理论上的无限个成分中，有限样本实际只落在有限个参数位置上。

\subsubsection{参数学习}

\paragraph{折叠归属更新}

学习转为推断归属、成分参数及其后验。在基分布连续的共轭设定下，折叠Gibbs抽样可移除一个样本的旧归属，再按“其余成员数乘后验预测密度”选择已有成分，或按“$\alpha$乘先验预测密度”选择新成分。

\paragraph{后验汇总与成分解释}

重复更新并汇总后验样本。非共轭情形需要辅助参数或其他数值推断\scite{clust-neal2000}。先验仍影响使用的成分数，它不等于自动发现语义类别；模型细节可参考\BookChapterRef{chap:pgm-static-directed}{卷6《模型：概率图模型》“静态有向模型”章}。
K-means学习量化中心，GMM学习生成密度与成分后验。固定均匀权重和共享球形协方差的小方差极限连接了两者；自由协方差同时增加方向、尺度与估计成本。伯努利或多项式混合改变观测机制，$t$混合改变尾部，DPM改变成分数的建模方式。密度拟合与语义分组仍是两个目标，应分别用留出对数损失与任务相关证据评价。
\section{数据摘要与网格区域}
\label{sec:clustering-summary-grid}

大样本的点对访问可能超过预算：反复扫描上百万条记录、保存全部相异度矩阵都不现实。本节先改变用于计算的数据组织，而不是另定一种群组定义：BIRCH把邻近对象汇为可合并的数值摘要，STING在固定网格上预存层次统计供反复查询，WaveCluster则把网格计数当作多尺度信号再提取区域。三者分别明确保存什么、据此执行哪种后续操作、又丢失了什么信息。

需要先区分摘要与群组：BIRCH的CF树只负责压缩，最终群组由后续带权聚类产生；STING由查询条件筛选区域；WaveCluster由变换、阈值与网格邻接形成区域。代表模型的小批量更新、抽样搜索等计算近似，仍回到第\ref{sec:clustering-partition}节各自的母模型处说明，不在本节重复。

在进入各方法前先建立共同的网格表示：给定坐标范围与划分粒度，把样本映射到单元索引，累加计数并规定单元邻接、边界处理与原记录映射。STING在此之上增加层次统计与查询，WaveCluster在此之上对计数作多尺度变换，各自保留专属数据结构与计算。

\subsection{层次摘要：BIRCH}

\subsubsection{模型结构}

若直接保存全部对象及大量点对距离，数据装不进内存时后续聚类就难以执行。Zhang、Ramakrishnan与Livny在1996年的BIRCH中先把邻近对象汇为可合并的摘要，再对摘要作聚类。它主要减少进入后续搜索的对象数，可以搭配相应的凝聚过程，而不是另定一种群组定义。它用\term{聚类特征}（clustering feature, CF）记录样本数、向量和与平方范数和\scite{clust-zhang1996}。这些摘要写为
\[
 \mathrm{CF}(C)=
 \left(|C|,\ \sum_{i\in C}\bm{x}_i,\
 \sum_{i\in C}\lVert\bm{x}_i\rVert_2^2\right).
\]
这些量可相加，也可恢复均值和簇内平方误差。CF树将邻近样本汇入摘要，再对叶摘要聚类。

\subsubsection{参数学习}

\paragraph{CF树的增量建立}

插入新样本时，沿最接近的摘要下降到叶层；若吸收它后的半径或直径不超过阈值，就更新该摘要，否则新建条目。节点容量不足时分裂并向上调整。阈值控制压缩程度，分支容量控制树的存储组织。树高和摘要规模受控时，扫描成本近似随$n$线性增长；摘要阈值、插入顺序及压缩损失共同影响最终划分。

\paragraph{带权聚类与压缩评价}

最终对叶摘要聚类时保留其样本数作为权重，再把原样本映射到对应的最终簇。CF对均值与SSE是充分的摘要，却不是对簇形状的完整表示。以一维教学例说明：$\{-1,-1,1,1\}$与$\{-\sqrt2,0,0,\sqrt2\}$都得到$\mathrm{CF}=(4,0,4)$，前者集中在两个位置，后者集中在三个位置。若各自被压成一个叶摘要，后续只读取CF就无法区分这两种结构，更不能根据其中的间隔重新拆出目标群组。保留更多叶摘要可以增加空间细节，同时增加内存和后续搜索。
\subsection{网格统计：STING}

对同一批地理位置记录，我们可能反复查询不同区域内有多少对象、哪些地方足够密集。如果每次都读取所有记录，许多统计会被重复计算。\term{统计信息网格}（STatistical INformation Grid, STING）把空间分成大小不同的层次单元，预先保存每个单元的计数、均值等统计，查询时先排除无关区域，再向需要细查的单元下钻。Wang、Yang与Muntz在1997年提出了这一方法\scite{clust-wang1997}。它主要改变数据访问方式，单元大小同时限定了直接从摘要读出的空间精度。

\subsubsection{模型结构}

STING通常用于低维空间的矩形层次网格。二维单元可分为四个子单元，$d$维完整二分则产生$2^d$个子单元。实现可只保存有记录或需要查询的单元，以控制空单元的存储。

单元摘要包含计数、各维均值、标准差、极值与分布类型估计。计数、和及平方和可由子单元相加，得到父单元的矩统计。分布类型则属于近似描述：子单元合并后形成混合，父单元可能超出原分布族。

\subsubsection{参数学习}

\paragraph{网格统计的构建}

构建阶段扫描样本，确定最细单元并更新统计，再自底向上汇总。固定维数和网格规模时可按 $O(n)$ 扫描成本理解；更完整地计入维数与 $G$ 个已存单元，代价包含 $O(nd+Gd)$，还取决于定位单元的数据结构。

\paragraph{区域查询与精确回查}

查询时，从某层网格出发，依据摘要估计单元满足条件的可能性。例如，对密度条件使用计数，对属性范围条件使用极值或分布近似；排除不相关单元，对保留单元继续下钻。最终可以把满足密度条件且相邻的单元连成区域，必要时回到原始样本作精确检查。固定摘要上的单元访问约按$O(G)$计，初始读入与统计仍需前述样本扫描。精确查询若最终检查$n_{\mathrm{scan}}$条原始记录，也应另外计费。基于估计概率的排除可能漏检；需要完整结果时，筛选规则须能证明被排除区域无法满足查询。统计汇总在固定网格上由有限次累加完成。查询只读摘要时，不能区分同一单元内未被摘要保留的位置关系；细化单元提高空间精度，也增加内存和查询工作。分布近似可以帮助筛选，却不等于精确记录：若要求不漏检，排除条件必须保证整个单元都不满足查询，否则就需回查原始样本。
\subsection{WaveCluster}

\subsubsection{模型结构}

细网格能够分开邻近群组，却也会留下细尺度计数波动。Sheikholeslami、Chatterjee与Zhang在1998年的WaveCluster中把网格计数作为离散信号，在不同小波尺度寻找密集区域，并抑制部分高频噪声\scite{clust-sheikholeslami1998}。它与STING共享网格摘要的输入方式，另外增加了变换与区域筛选，并不是保留原查询目标的计算加速。扩展后的表示是网格计数的小波系数及选定的连通区域。以一维相邻两格计数$u,v$为例，Haar变换可用平均$a=(u+v)/2$和半差$b=(u-v)/2$表示它们；$u=a+b,v=a-b$，所以完整变换不丢信息，舍弃细节才改变结构。计数$(8,10,0,0)$的第一层平均为$(9,0)$，保留这层可忽略前两格的小差异，同时保留前后区域的分隔。

\subsubsection{参数学习}

学习过程先统计网格，再执行指定小波变换，在所选尺度筛选密集单元、连接相邻单元，最后按变换与原网格的对应把区域标签交回样本。尺度、阈值和边界处理都是方法的一部分；系数不是样本标签，也不是原始整数计数。过度平滑会丢掉真实的小间隔，因而这项扩展以空间细节换取对部分计数波动的抑制。

BIRCH改变输入规模：CF树只保留计数、线性和与平方和这类可合并摘要，供后续带权聚类使用，均值与SSE充分却不保留簇形状。STING改变数据访问方式，以层次网格摘要支持反复查询，查询只读摘要时无法区分单元内的位置关系。WaveCluster在计数上作多尺度变换，改变提取区域的方式。三者都先改变计算所依据的数据组织，再套用相应的聚类或筛选操作；比较时应分别核对摘要损失、网格精度与变换尺度对最终群组的影响。
\section{子空间与投影聚类}
\label{sec:clustering-subspace}

一组客户可能在购买频次和金额上很集中，年龄却遍布较大范围；若全维距离同时计入年龄差异，这个群组的紧凑性就被无关方向稀释。另一个群体可能恰恰依赖年龄，因此一次全局降维不能替每个群体选择相关比较空间。高维分布还会使最近与最远距离的相对差异减小，让距离失效；是否发生这种集中，仍取决于数据结构与表示。

本节按输出和表示分工：CLIQUE与SUBCLU搜索多个坐标子空间中的密集区域，允许同一样本获得重叠解释；PROCLUS在给定簇数下为各簇选择相关坐标并给出单一归属；ORCLUS再为各簇选择可旋转的线性方向。它们都把分组与相关空间相连，但选择目标与成员规则分别定义；这里的投影是为分组寻找紧凑方向，与第\ref{chap:dimensionality-reduction}章以方差或重构为目标的PCA不是同一件事。

\subsection{坐标子空间：CLIQUE}
\label{sec:clustering-clique}

全维距离同时计入年龄差异，会掩盖“频次集中但年龄分散”的群组；预先删除年龄又可能漏掉另一组按年龄集中的客户。CLIQUE（CLustering In QUEst）因此在不同坐标子集中分别寻找密集区域，让不同群组使用不同的相关特征。Agrawal等在1998年提出的方法把各坐标离散成网格，并逐层搜索包含密集单元的子空间\scite{clust-agrawal1998}。

\subsubsection{模型结构}

每维划分为 $\xi$ 个区间，区间边界采用统一的半开约定，并把最后端点纳入最后一区间。对特征索引集合 $S\subseteq\{1,\ldots,d\}$，一个单元 $U$ 是所选坐标上区间的笛卡尔积。定义支持计数
\[
 n(U)=|\{i:\bm{x}_{i,S}\in U\}|.
\]
若 $n(U)\geq\tau$，则称 $U$ 为\term{密集单元}（dense unit）。跨维沿用同一计数阈值$\tau$，固定样本比例阈值在样本数相同时等价。按单元体积定义的密度改变了跨维比较尺度，需另设阈值与剪枝条件。

同一子空间内，两个单元若仅沿一个坐标方向相邻而其他区间相同，就视为邻接；密集单元的极大连通分量构成簇。输出是“子空间与簇”的集合，同一样本可以在不同子空间出现于多个簇，也可以未被任何簇覆盖。图~\ref{fig:clustering-subspace} 表示高维单元投影后样本计数只会增加的关键性质。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=72.912mm]{figures/04-classic-models/00-shared/tikz/clustering-subspace/figure.pdf}
  \caption{CLIQUE 的投影计数示意。二维高亮单元含三个样本，其在横轴区间上的投影还包含其他纵坐标范围的样本。取共同阈值 $\tau=3$，二维单元密集必然推出对应一维单元密集，反方向则不成立。}
 \label{fig:clustering-subspace}
\end{figure}

\subsubsection{参数学习}

CLIQUE 借鉴 Apriori 的逐层候选生成——这是频繁项集挖掘里的一条剪枝思路：若一个大集合满足“计数足够多”，它的每个子集也一定满足，因此反过来，子集不密集的集合无需再验证。扫描数据找到一维密集单元后，把具有兼容低维区间的单元连接成更高维候选；只有所有低一维投影都密集的候选才继续计数验证。重复直到候选为空或达到搜索维数上限。

在保留下来的子空间中，算法连接相邻密集单元，形成簇，并可用轴对齐区域的析取式压缩簇描述。原始方法还包含选择子空间和简化描述的步骤；若使用额外启发式筛选，完整性应相对于筛选后的搜索范围表述。

\subsubsection{理论分析}

高维单元中的每个样本，在去掉部分坐标条件后仍落在相应低维投影内，所以
\begin{equation}
 I(U)\subseteq I(U|_{S'}),\qquad n(U|_{S'})\geq n(U).
 \label{eq:clustering-clique-projection}
\end{equation}
这里$S'\subset S$，$I(U)$是落入单元的样本索引集。在一致网格和共同计数阈值下，高维密集必然推出低维密集；逆向不成立，因为不同低维投影可以由不同样本填满。这正是先剪枝、再验证高维计数的理由。

搜索最多进行到$d$维，但大量投影都密集时，候选数仍可能指数增长。固定网格还会把小群体分散到多个未达阈值的单元中；更细的网格增加边界精度，却减少每格样本数。若设置最高搜索维数或额外筛选，输出只覆盖被保留的范围。基本CLIQUE给出子空间区域及其成员，新对象可以检验是否落入这些区域，也可能同时符合多个区域。
\subsection{密度子空间：SUBCLU}

\subsubsection{模型结构}

固定网格可能把弯曲点带切散到多个未达阈值的单元。SUBCLU在坐标子集中使用DBSCAN：输出仍为“坐标子集、密度连通簇及其成员”，但区域由邻域连接形成。它保留了不同子空间的重叠解释，也保留半径、核心计数与稀疏桥的限制。

\subsubsection{参数学习}

学习时逐层生成候选子空间，在候选上查询邻域并构造簇，再利用投影后的密度关系减少搜索\scite{clust-kailing2004}。

\subsection{簇相关坐标：PROCLUS}

\subsubsection{模型结构}

CLIQUE允许重叠解释；若每条记录必须只有一个归属，可采用\term{投影聚类}（projected clustering）。PROCLUS为每簇保留一个代表样本及相关坐标集合$S_k$，按所选坐标上的平均绝对偏差比较样本与代表，再给出单一簇归属或标记为离群点。

\subsubsection{参数学习}

训练在候选代表搜索、局部坐标选择与全样本分配之间交替：局部变化较小的坐标用于描述该代表附近的紧凑群体。代表数和平均子空间维数需要预先选择，最终根据重估的相关坐标重新分配，并用代表的影响范围筛出离群点；这一分配并不等于CLIQUE的密集单元搜索\scite{clust-aggarwal1999}。

\subsection{倾斜子空间：ORCLUS}

\subsubsection{模型结构}

ORCLUS进一步允许倾斜方向。它为簇$k$保留中心$\bm\mu_k$和列正交矩阵$\bm U_k\in\mathbb R^{d\times q}$，用
\[
 d_k^2(\bm x)=\lVert\bm U_k^\top(\bm x-\bm\mu_k)\rVert_2^2
\]
衡量投影距离。

\subsubsection{参数学习}

固定成员后，中心取均值，投影方向取簇内散布矩阵较小特征值的方向，以表示变化较小的相关关系。算法从较多初始簇出发，交替分配、估计方向和按投影误差合并，逐步降到指定簇数与子空间维数\scite{clust-aggarwal2000}。例如沿$y=x$伸展的点带在方向$(1,-1)$上变化很小，选择单个原坐标无法直接表达这条关系；一个线性子空间仍不能描述任意弯曲流形。
CLIQUE寻找不同坐标子集中的密集区域，SUBCLU把区域改为密度连通簇，均允许对象获得多份子空间解释。PROCLUS给出单一归属或离群标记，并为各簇选择坐标；ORCLUS还学习任意线性方向。选择时应分别确定是否需要重叠输出、坐标解释或倾斜关系，再权衡近邻查询与矩阵计算的代价。
\section{让部分监督信息参与分组}
\label{sec:clustering-semisupervised}

未标注数据也可能附有部分领域知识。虽然没有逐条的类别标签，但专家常常能给出更便宜、更局部的判断：他不必回答“这条记录整体该怎么分”，只需指出“这两条来自同一对象，应放一起”或“那两条明显属于不同群体，必须分开”。\term{半监督聚类}（semi-supervised clustering）将这些信号用于以未标注样本为主体的分组。在用户画像里，这类信号可能来自同一设备的多个账号、已知不同的门店，或少量被人工确认的典型样本。

第\ref{sec:classification-semisupervised}节的半监督分类利用未标注输入改进预先定义类别的预测，本节则用少量类别标签或关系先验共同决定分组。两者都改变可用监督信息，却保留不同的任务目标。

实例级信号常写为\term{必连约束}（must-link）和\term{勿连约束}（cannot-link）：前者要求两个样本同簇，后者要求异簇。记其索引对集合为 $M$ 和 $B$，以免与簇 $C_k$ 或划分 $\mathcal{P}$ 混淆。这两种信号的性质并不对称，后面会看到：必连是可以沿链条传递的（朋友的朋友也算同组），勿连却不能传递（$a$不同于$b$、$b$不同于$c$，不代表$a$不同于$c$）。信号既可作为硬约束（违反即不可行），也可带权违反（违反就扣分）；少量关系判断是否比逐点类别标签更容易获取，取决于实际标注任务。

这些信号与几何结构共同确定群组。需要检验的是先验是否消除了原模型的歧义，覆盖了哪些样本，以及是否与基础几何发生冲突；信号质量和作用范围决定其可能收益。
\subsection{COP-K-means}
\label{sec:clustering-cop}

例如，两条记录来自同一对象的不同时间，专家要求它们同组；另两条记录已知属于不同群体，要求它们分开。普通K-means只比较到中心的距离，无法保证这些关系。COP-K-means把关系作为硬条件，每次只从不违反已有关系的簇中选择最近中心。Wagstaff等在2001年提出了这一方法\scite{clust-wagstaff2001}。平方误差目标保留，但一些距离更近的分配会被排除，约束是否可行与样本访问次序也需要处理。

\subsubsection{模型结构}

目标仍为式~\eqref{eq:clustering-sse}，可行域增加
\begin{equation}
 c_i=c_j\quad((i,j)\in M),\qquad
 c_i\ne c_j\quad((i,j)\in B).
 \label{eq:clustering-cop}
\end{equation}
必连关系还会推出没有直接标注的关系。例如，若样本$a$必须与$b$同簇，$b$又必须与$c$同簇，那么$a$与$c$也必须同簇；只满足前两对而把第三对分开是不可能的。把所有这样沿必连关系链能够推出的同簇关系补齐，就是求must-link的传递闭包。若把样本当作顶点、已知必连关系当作边，沿这些边能够互相到达的样本构成一个\term{约束块}（chunklet），同一块必须整体分配；没有必连边的样本则各自形成单点块。若cannot-link的两端落在同一块内，约束立即矛盾；但不存在这种矛盾还不足以保证给定$K$下可行。

为了检查块之间能否分配，再把每个约束块当作顶点、块间的cannot-link当作边。用一种颜色代表一个簇标签，要求每条边的两端颜色不同，这就是该图的$K$着色问题；颜色至多有$K$种。因此，块的簇分配需要同时满足全部相邻顶点的异色要求。着色只检查关系能否在这些可用标签内满足；若另要求$K$个簇全部非空，还需同时检查非空条件。例如三个两两cannot-link的块不能放进两个簇，即使没有任何must-link冲突。块级SSE可利用前面的均值分解，写成块内常数加上“块大小乘以块均值到中心的平方距离”，因此整体分配也能利用摘要。

\subsubsection{参数学习}

\paragraph{约束块分配与中心更新}

COP-K-means 按某个顺序处理样本或约束块，对候选簇按距离排序，接受第一个与已固定分配相容的簇。若没有候选，就报告本次贪心分配失败；更新步则对每个非空簇取均值。

\begin{algorithm}[COP-K-means 的约束块分配]
 \label{alg:clustering-cop}
 \begin{algorithmic}[1]
 \Require must-link 闭包、块间 cannot-link、当前中心
 \Ensure 本轮可行分配，或本轮贪心失败
 \State 清空本轮簇分配，选定约束块访问顺序
 \For{每个约束块 $U$}
  \State 按 $\sum_{i\in U}\lVert\bm{x}_i-\bm{\mu}_k\rVert_2^2$ 排序候选簇
  \State 选择不与已分配邻块冲突的最近候选
  \If{候选不存在}
   \State 返回本轮失败
  \EndIf
  \State 把 $U$ 的全部样本分给所选簇
 \EndFor
 \end{algorithmic}
\end{algorithm}

\paragraph{贪心失败与求解边界}

贪心失败可能来自顺序，而非约束本身。以cannot-link路径$a-b-c-d$和$K=2$为例：按$a,d,b,c$访问，若$a,d$先取簇1，$b$只能取簇2，$c$便无可行选择。整体划分$\{a,c\}$与$\{b,d\}$却满足全部关系，说明局部已定选择阻碍了后续分配。

逐块贪心未精确求解固定中心的整体约束分配，Lloyd的下降前提在这里需要重新建立。可从已有可行解出发，只接受可行且降低目标的块移动；也可精确求解受约束分配，再更新均值。前者搜索范围较小，后者增加组合优化成本。普通COP实现可用迭代上限、失败记录及重启或回溯处理这些情况。硬约束改变当前样本允许的划分。正确关系可以排除不合用途的分组，一条错误关系也可能排除整个目标分组。成功返回时应逐项检查关系；失败时应区分信号冲突、给定$K$下不可行与贪心访问次序失败。约束没有自动规定独立新点的关系，若新点只按最近中心分配，这条附加规则仍受原有中心几何限制。
\subsection{PCK-means}

\subsubsection{模型结构}

若先验允许出错，PCK-means 在 SSE 上增加
\[
 \sum_{(i,j)\in M}w_{i,j}^{M}\mathbb{1}\{c_i\ne c_j\}
 +\sum_{(i,j)\in B}w_{i,j}^{B}\mathbb{1}\{c_i=c_j\},
\]
以软惩罚权衡几何和约束。有限权重不保证零违反，但避免因单条错误关系直接拒绝整个问题。

\subsubsection{参数学习}

模型仍保留$K$个中心和一个硬标签向量，只是目标多了关系违反费用。固定其他标签与中心后，比较把一个样本移入各簇的完整目标变化，接受改善的移动；固定标签后，中心仍取簇均值。关系项使分配相互耦合，不能只找最近中心；同样也不能把局部移动误称为全局最优分配。
\subsection{Seeded与Constrained K-means}
\label{sec:clustering-seeded}

成对关系告诉我们哪些对象应该合在一起，却不一定告诉我们群组的名称。若每类已有少量带标签的典型记录，就可以用这些种子确定初始中心，或在整个学习过程中固定它们的类别。Basu、Banerjee与Mooney在2002年研究了Seeded K-means与类别标签约束的Constrained K-means\scite{clust-basu2002}。前者只用种子引导起点，后者让种子的类别持续参与分配条件；后者与第~\ref{sec:clustering-capacity}节限制簇容量的同名方法含义不同。

\subsubsection{模型结构}

设种子索引集合为 $S$，类别标签为 $\ell_s\in\{1,\ldots,K\}$，并记 $S_k=\{s\in S:\ell_s=k\}$。当每类都有种子时，初始化为
\[
 \bm{\mu}_k^{(0)}
 =\frac{1}{|S_k|}\sum_{s\in S_k}\bm{x}_s.
\]
缺少种子的簇需另外初始化。Seeded 版本只在初始化时使用类别标签，之后种子可以移动；Constrained 版本始终要求 $c_s=\ell_s$，把种子类别标签作为硬事实。二者都优化同一个平方误差目标，只是初始化与可行域不同。

\subsubsection{参数学习}

\paragraph{种子初始化与Seeded更新}

Seeded 版本随后直接运行 Lloyd。

\paragraph{固定种子标签的更新}

Constrained 版本在分配步冻结种子，其余样本独立选择最近中心；更新中心时同时计入种子和非种子。由于冻结限制彼此不耦合，逐点分配仍是固定中心下的精确最优解，因此可沿用定理~\ref{thm:clustering-lloyd} 的下降论证与平局条件。每簇都有固定种子时，还自然避免了空簇。Seeded版本改变搜索起点，固定标签版本还改变可行分配；两者都保留中心和平方距离。种子有代表性时能指明群组的位置与名称，错误种子若被固定则会持续牵动结果。未标注对象仍按最近中心分配，少量正确标签也不能自动消除不合适的距离或群组形状限制。

\subsection{MPCK-means}
\label{sec:clustering-mpck}

继续以客户金额、频次和年龄为例。专家认为两名年龄相差很大的客户应归为一类，普通欧氏距离却仍把年龄差异计入下一轮判断；仅强制这两人的标签相同，没有告诉模型其他客户应怎样比较。MPCK-means（Metric Pairwise Constrained K-means）还学习各方向在距离中的权重，使成对关系能够改变后续的几何判断。Bilenko、Basu与Mooney在2004年提出的方法同时优化分配和簇相关度量，让约束既影响标签，也影响方向与尺度\scite{clust-bilenko2004}。

弱监督可以进入不同环节：关系限制可行分配，种子确定初始位置或成员，成对约束还可学习方向与尺度。这些形式对应不同的先验内容和可信程度，可按信号实际支持的判断选择。

\subsubsection{模型结构}

\paragraph{簇相关距离与关系代价}

为簇 $k$ 配置正定矩阵 $\bm{A}_k\succ0$，定义平方 Mahalanobis 距离
\[
 d_{\bm{A}_k}^2(\bm{x},\bm{y})
 =(\bm{x}-\bm{y})^\top\bm{A}_k(\bm{x}-\bm{y}).
\]
正定性既保证非退化距离，也使 $\log\det\bm{A}_k$ 有定义。可以把这种距离看作先做坐标变换 $\tilde{\bm{x}}=\bm{A}_k^{1/2}\bm{x}$，再计算欧氏距离。图~\ref{fig:clustering-metric-constraints} 给出了一个固定变换的例子：压缩水平方向、拉伸竖直方向后，must-link 对变近，而 cannot-link 对变远。实际 MPCK-means 需要根据全部样本与约束优化 $\bm{A}_k$，并非预先知道图中的变换。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=97.331mm]{figures/04-classic-models/00-shared/tikz/clustering-metric-constraints/figure.pdf}
  \caption{度量如何改变成对关系的几何表达。四点为 $\bm{u}=(-2,0.5)$、$\bm{v}=(2,0.5)$、$\bm{w}=(-2,-0.5)$、$\bm{z}=(2,-0.5)$。实线连接 must-link 对，虚线连接 cannot-link 对。这里人为设定 $\bm{A}=\operatorname{diag}(1/16,4)$；右图的距离等于左图的 Mahalanobis 距离，不表示一次真实训练的结果。}
 \label{fig:clustering-metric-constraints}
\end{figure}

记在该度量下全数据的最大距离平方为
\[
 D_k=\max_{p,q\in\{1,\ldots,n\}}
 d_{\bm{A}_k}^2(\bm{x}_p,\bm{x}_q).
\]
对违反 must-link 的样本对，惩罚同时作用于两端所属簇；对违反 cannot-link 的样本对，惩罚其相对于本簇度量下最远样本对的接近程度。具体写为
\begin{align}
 f_M(i,j)
 &=\frac12\left[
 d_{\bm{A}_{c_i}}^2(\bm{x}_i,\bm{x}_j)
 +d_{\bm{A}_{c_j}}^2(\bm{x}_i,\bm{x}_j)\right]
 \mathbb{1}\{c_i\ne c_j\},\nonumber\\
 f_B(i,j)
 &=\left[D_{c_i}
 -d_{\bm{A}_{c_i}}^2(\bm{x}_i,\bm{x}_j)\right]
 \mathbb{1}\{c_i=c_j\}.
 \label{eq:clustering-mpck-penalty}
\end{align}
因此cannot-link惩罚非负，must-link惩罚也不因交换样本对的书写顺序而改变。固定当前度量，若$D_k=10$，一个违反cannot-link的同簇样本对距离平方为1，它的惩罚便是9；距离平方增为8时，惩罚减为2。这个例子说明，此处惩罚的是已被放到同簇的异类对象过于接近，而不是简单地把距离越大都罚得越重。

冻结已学度量后，对没有成对关系的新对象，可比较
\[
 s_k(\bm x)=(\bm x-\bm\mu_k)^\top\bm A_k(\bm x-\bm\mu_k)
                -\log\det\bm A_k
\]
并选得分最小的簇。训练对象还受关系惩罚，该独立新点规则不等于完整训练分配步骤。

\paragraph{度量尺度的约束}

联合学习距离还需要控制度量的整体尺度。先固定分配与中心，假设所有度量都取$\bm A_k=t\bm I$，其中$t>0$。几何平方距离、违反must-link的两端距离，以及违反cannot-link时的$D_k-d_{\bm A_k}^2$都会随$t$成比例缩小。若目标只有这些费用，令$t$趋零就能把它们一起压低，实际分组却没有因此改善。为避免模型只靠缩小度量降低费用，在每条样本的几何项中加入$-\log\det\bm A_k$。当$\bm A_k=t\bm I$时，这一项等于$-d\log t$，随$t\to0$趋向正无穷，因而会惩罚这种整体塌缩。

这一尺度项也可与前面的高斯模型联系起来：若把$\bm A_k$看成协方差的逆，一个高斯成分的负对数密度包含半个距离二次项与负的半个对数行列式。略去与参数无关的常数，并把这两部分统一乘以2，就得到这里的几何项；后面的成对惩罚另外表达关系监督\scite{clust-bilenko2004}。总目标为
\begin{equation}
 \begin{aligned}
 J={}&\sum_{k=1}^K\sum_{i\in C_k}
 \left[d_{\bm{A}_k}^2(\bm{x}_i,\bm{\mu}_k)
       -\log\det\bm{A}_k\right]\\
 &+\sum_{(i,j)\in M}w_{i,j}^{M}f_M(i,j)
  +\sum_{(i,j)\in B}w_{i,j}^{B}f_B(i,j).
 \end{aligned}
 \label{eq:clustering-mpck}
\end{equation}
权重均非负，每个无序约束对只计一次。负对数行列式为行列式趋零增加代价；在其他特征值保持有界时，某个特征值趋零也会使这一项发散。但它不能单独阻止矩阵某些方向无限放大，也不能单独排除不同特征值向相反方向变化而保持行列式不变的情形；数据退化时仍需约束或正则。

\subsubsection{参数学习}

\paragraph{成员与中心的交替更新}

固定中心和度量时，对一个样本的各簇候选计算完整目标变化，包括几何、行列式及所有相关关系惩罚，再接受不增目标的变更。由于关系项耦合样本，单独比较到中心的距离不足以完成这项选择。

固定分配和度量时，约束项不含中心。对中心求导给出
\[
 2\bm{A}_k\sum_{i\in C_k}(\bm{\mu}_k-\bm{x}_i)=\bm{0},
 \qquad
 \bm{\mu}_k=\frac{1}{|C_k|}\sum_{i\in C_k}\bm{x}_i.
\]
同一簇共用的$\bm{A}_k$在驻点方程中消去，中心因而取普通簇内均值。若需按样本重要性加权，还要在目标中另加相应权重。

\paragraph{度量矩阵的分段优化}

度量步中，固定分配和中心，几何项为$\operatorname{tr}(\bm A_k\bm S_k)$，其中$\bm S_k$是簇内散布。每个关系距离也可写成$\operatorname{tr}(\bm A_k\bm V_{i,j})$，$\bm V_{i,j}=(\bm x_i-\bm x_j)(\bm x_i-\bm x_j)^\top$。若当前最远对$(p_k,q_k)$在更新后仍实现$D_k$，把违反must-link且一端在$k$的集合记为$\mathcal M_k$，违反cannot-link且两端在$k$的集合记为$\mathcal B_k$，则关系贡献为
\[
 \bm P_k=\frac12\sum_{(i,j)\in\mathcal M_k}w_{i,j}^M\bm V_{i,j}
 +\sum_{(i,j)\in\mathcal B_k}w_{i,j}^B
 (\bm V_{p_k,q_k}-\bm V_{i,j}).
\]
每个无序对只计一次，must-link的一半贡献分别进入两端所属簇。子目标为$\operatorname{tr}[\bm A_k(\bm S_k+\bm P_k)]-|C_k|\log\det\bm A_k$。对正定矩阵求导，在$\bm S_k+\bm P_k\succ0$时得到候选
\begin{equation}
 \bm A_k=|C_k|(\bm S_k+\bm P_k)^{-1}.
 \label{eq:clustering-mpck-metric}
\end{equation}
\paragraph{停止与新点分配}

这个式子只适用于最远对保持不变的分支。更新若改变最远对，就必须重新评价真实目标；不能固定旧对后无条件接受该矩阵。直接保留$D_k$对矩阵的最大值依赖时，固定分配的度量子问题凸但通常分段光滑，可在$\alpha\bm I\preceq\bm A_k\preceq\beta\bm I$、$0<\alpha<\beta$的域中数值求解。各步检查同一目标下降，结合目标或参数变化的容差停止；空簇须另行处理。

完整矩阵需要估计$d(d+1)/2$个数。监督较少时，可把$\bm A_k$限制为正对角矩阵，只学习坐标权重；或要求各簇共享一个矩阵，采用同一坐标变换。两种简化都在相应限制下重新优化目标，分别舍弃旋转方向或簇间几何差异。
\subsubsection{理论分析}

不同簇采用不同矩阵时，两簇得分差是二次函数，边界比共享度量下的线性中心分界更灵活。

\subsection{关系监督下的谱聚类}

\subsubsection{模型结构}

如果已知某两条记录应当同簇，或另一对记录应当异簇，就可以让这些关系改变谱聚类所用的图。Kamvar、Klein与Manning的Spectral Learning研究了将监督信息纳入谱表示；一种直接做法是提高应同簇样本对的边权、降低应异簇样本对的边权，再对修改后的非负对称图求谱表示\scite{clust-kamvar2003}。

\subsubsection{参数学习}

边权调整改变谱偏好，最终分配仍由整张图和离散化决定。即使删除应异簇样本对之间的边，两端也可能通过其他强边共簇。修改后的非负对称图可按其新拉普拉斯分析，但谱间隙、连接及统计条件需重新核对。关系传播还能扩展局部监督，同时可能扩散错误信号。
COP-K-means用硬关系限制分配，PCK-means以惩罚允许关系违反；种子方法则改变初值或冻结部分标签。MPCK-means进一步学习比较样本的几何。信号进入的位置不同，就会改变不同的对象：可行集合、搜索起点、距离或图边权。可靠关系可以缩小歧义，错误关系也会牵动分组；应同时报告几何目标和关系违反，并单独验证未标注或未来对象上的用途。
\section{选择粒度并评价用途}
\label{sec:clustering-evaluation}

同一批数据在不同准则下会得到不同群组，而不同模型的原始目标值（SSE、模块度、似然）量纲与对象都不同，不能拼成一张统一排行榜。评价前先明确用途：是数值压缩、密度拟合、语义分组，还是服务后续决策；用途不同，证据也不同。

\subsection{内部准则、参考划分与预测用途}

留出量化误差检验代表式方法的压缩效果：冻结中心后，用未参与训练的样本计算到代表的失真。留出对数密度检验生成混合的拟合质量，即新观测在估计密度下的似然。这两类都在固定表示、数据与指标方向下比较，区分训练集上的优化值与未来对象的使用结果。

没有参考标签时，可用内部准则比较同一距离下的紧凑与分隔。\term{轮廓系数}（silhouette coefficient）比较簇内与其他簇的距离：令 $a_i$ 为到本簇其他点的平均距离，$b_i$ 为到其他各簇平均距离的最小值，则
\[
 s_i=\frac{b_i-a_i}{\max\{a_i,b_i\}}.
\]
至少需要两个非空簇；单点簇及分母为零时通常记为0。它偏好相应距离下的紧凑分隔，不能据此评价所有非凸群组\scite{clust-rousseeuw1987}。

有独立参考划分时，可用\term{调整兰德指数}（adjusted Rand index, ARI）比较两份划分对样本对是否同簇的判断，并扣除固定簇规模下随机安排成员所产生的一致性。它不使用距离，交换簇编号不改变数值；负值表示低于该随机基准。较高轮廓系数与较高ARI回答不同问题，不能互相替代\scite{clust-hubert1985}。参考标签只评价它所定义的类别关系；统计成分与语义类别不同、非凸群组被内部得分低估等情形，都说明较高内部得分不能替代任务证据。

若群组直接服务下游决策，则应在冻结划分后检验下游损失或收益，而不是只报告内部得分。

\subsection{参数选择与独立验证}

粒度由不同对象控制：$K$、密度半径与最小邻域计数、带宽、网格粒度、容量上下界、先验浓度等，分别改变不同模型的输出，不能把所有超参数等同为一个“簇数选择”。以 $K$ 为例，代表式方法可观察SSE随 $K$ 下降的曲线，在继续增加中心只换来很小改善处取“肘部”作为候选；这只是启发式候选，须与同一留出准则下的结果比较。密度、带宽等参数同理，应按各自模型的尺度含义选取。

用于发现结构、选择表示与调参的数据称为\term{发现数据}（discovery data）；冻结规则后，再用未参与选择的\term{验证数据}（validation data）检查用途。参考标签一旦参与选择，便不能继续充当独立检验。重采样的重复性检查的是稳定性，与明确的随机生成基准比较检查的是结构是否超出该基准；二者都不能单独证明语义正确，且应把表示与调参过程纳入评价\scite{clust-ullmann2022}。

新数据部署还需明确规则：独立预测、拒绝、共同分配还是重新聚类，取决于模型实际保存了什么；当前数据上的划分不能直接视为通用预测器。比较时记录尺度、预算与输出约定（硬划分、软归属、噪声标记、重叠解释）。

\section{本章小结}
\label{sec:clustering-summary}

回到章首的客户分组：按消费金额相近与按购买品类相近可以得到不同结果，关键在于所用关系是否服务于既定用途。数值压缩需要控制替换误差，生成拟合需要解释新观测，语义或决策分组则需要与用途相符的独立证据，三者不能由同一内部得分相互代替。

本章按“怎样算一类”展开。代表式聚类为每组选一个代表并最小化到代表的失真（K-means、K-medians、FCM、K-medoids、AP）；局部密度方法按密集连接或密度峰组织群组（DBSCAN、OPTICS、HDBSCAN、Mean Shift、DENCLUE）；关系图用割或模块度寻找群组（谱聚类、Louvain）；凝聚与分裂层次保留嵌套关系（AGNES、CURE、DIANA、二分K-means）；生成混合模型假设观测由潜在成分产生（GMM、伯努利与多项式混合、重尾混合、DPM）。摘要与网格（BIRCH、STING、WaveCluster）改变数据组织，子空间与投影（CLIQUE、SUBCLU、PROCLUS、ORCLUS）改变各簇的比较空间，部分监督（COP-K-means、PCK-means、Seeded/Constrained、MPCK-means、关系监督谱聚类）改变信息条件。

综合本章的条件判断：距离与尺度决定哪些差异进入比较，密度和图关系决定哪些连接被保留，成分假设与监督信号又改变允许的解释。增加表示、约束或计算近似时，要同时检查新的学习过程、可行条件与信息损失；训练目标下降只支持对应优化问题，不能单独证明找到了任务需要的群体。投入使用前应冻结表示、粒度与分配规则，再对未用于选择的数据检验误差、覆盖或下游收益；重采样稳定和超过某个随机基准也只是各自条件下的证据。

第\ref{chap:dimensionality-reduction}章将学习低维表示，这会同时改变距离、密度与邻接。图上更清楚的分隔可以提出新的群组假设，但其用途仍需在相应表示与独立证据下检验；可视化不能替代这一判断。

进一步阅读可围绕同一数据问题，分别写出几何分组与概率成分的定义、学习目标和新样本评价，比较不同假设怎样改变最终群组\scite{bishop2006,hastie2009}。
