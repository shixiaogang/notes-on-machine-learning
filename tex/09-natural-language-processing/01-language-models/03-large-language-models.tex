\chapter{大语言模型}
\label{chap:nlp-large-language-models}

上一章的GPT已经展示了一条路线：在无标注文本上训练一个仅解码器的自回归模型，再把参数用于下游任务。本章回答的问题是，当语料、模型与计算预算同时扩大几个数量级时，怎样构造并学习这样一个模型。\term{大语言模型}（large language model, LLM）指在大规模语言材料上训练、能把同一套参数用于多种语言活动的模型；“大”没有适用于所有时期和结构的固定参数阈值。\term{预训练}（pre-training）指先用广泛材料建立可复用的参数，再以它们作为后续学习的起点。文本本身提供预测目标，但材料中出现什么、模型能看见什么、哪些预测被计分，仍然要由人来规定。

规模扩大以后，小模型上可以忽略或靠试错解决的问题都变成了需要专门设计的环节：

\begin{itemize}
  \item 原始网页、代码和文档不是训练分布本身，需要筛选、去重、词元化和配比；
  \item Transformer解码器每一层的运算、张量形状、参数量与计算量需要能逐项核算；
  \item 全注意力的计算随长度平方增长，推断时保存的历史状态随长度线性增长；
  \item 想增加参数而不按比例增加每词元计算，需要稀疏专家及其负载控制；
  \item 几十上百层的网络需要稳定的残差与归一化组合；
  \item 预训练目标要与网络结构和生成方式配套；
  \item 有限计算下要决定模型与数据的规模、可迁移的超参数、优化器、学习率与批次日程，并防止数值不稳定；
  \item 预训练结束后，还要针对新领域、新语言和更长上下文继续学习，同时保持原有能力。
\end{itemize}

本章按一次预训练的依赖顺序回答这些问题。训练分布先于一切，第\ref{sec:nlp-llm-data}节从原始材料出发，得到可以直接送入模型的词元序列。有了输入，第\ref{sec:nlp-llm-computation}节写出一层解码器的完整计算，并以LLaMA-3-8B的公开配置手算参数量与计算量；这组数字是后面讨论资源代价的共同基准。全注意力和稠密前馈层分别在长度和参数两个方向上限制规模，第\ref{sec:nlp-llm-long-context}节与第\ref{sec:nlp-llm-experts}节各自处理一个方向：前者压缩、稀疏读取或递归汇聚历史状态，后者让每个词元只经过部分参数。层数加深后，信号与梯度能否稳定穿过整个网络取决于残差和归一化的位置，这是第\ref{sec:nlp-llm-layer-composition}节的内容。结构确定之后，第\ref{sec:nlp-llm-objectives}节比较自回归、去噪与掩码扩散等目标怎样决定可见条件和计分位置。第\ref{sec:nlp-llm-optimization}节回到预算：给定数据、结构和目标，怎样分配规模、设置超参数和日程并让训练不中断。最后，第\ref{sec:nlp-llm-continuation}节检查预算终点得到的参数，在需要时继续预训练，并整理交给下一阶段的产物。

阅读本章需要第\ref{chap:nlp-classical-models}章的语言模型与上下文预训练，以及注意力、多头、旋转位置编码、RMSNorm等Transformer基本结构。这些通用结构在各节首次使用时给出简短说明和卷五的引用位置，本章只写大语言模型特有的配置、推导与比较。“读书会改到周五下午两点举行”这一教学短句只在数据处理、目标构造和阶段检查等确有帮助的地方使用；讲结构与算法时改用张量形状和小型数值算例。固定参数后的生成过程在第\ref{chap:nlp-model-inference}章展开，推理能力怎样跨阶段形成在第\ref{chap:nlp-reasoning}章讨论。

\section{本章小结}
\label{sec:nlp-llm-summary}

回到开篇的问题：规模扩大以后，预训练得到的参数由四类决定共同产生。语料处理决定训练分布，即模型实际反复看到哪些事件；网络结构决定从上下文到下一词元概率的计算及其资源代价；预训练目标决定哪些预测被计分、模型能看见哪些位置；优化决定有限预算内参数怎样变化。四者必须相容，例如因果预测不能泄露目标之后的信息，掩码扩散目标要配套定义从受损序列恢复文本的生成过程。

结构上的改动要放回它节省的资源来理解。键值压缩减少每个历史位置的表示量，稀疏读取减少每次访问的位置数，递归汇聚把历史并入固定大小的状态；三者保留信息的方式不同，对精确回读远处内容的能力影响也不同。稀疏专家把总参数与每词元激活参数分开，代价是路由和负载均衡；残差与归一化的位置控制信号跨层传播。缓存更小或激活参数更少，都不能单独推出任务更好或端到端更快，需要在相同数据与评价下比较。

优化环节把这些选择落到预算上。缩放律给出固定计算下参数量与词元数的分配，计入推断成本后常把较小的模型训练更久；$\mu$P让超参数在宽度变化时可以迁移；AdamW与Muon给出两种更新方向；WSD日程与临界批次规模说明学习率与批次怎样随训练安排；混合精度、z-loss、QK归一化与回滚则保证训练在有限精度下不中断。这些结论多数是经验拟合或局部近似，系数随数据和结构变化。

预算终点之后，继续预训练用回放与重新预热补领域和语言缺口，用位置插值、NTK感知插值或YaRN配合长样本扩展上下文，同时检查旧能力是否保持。交给下一阶段的是参数、词元化与位置配置、训练材料记录和检查结果的组合。预训练模型会续写，却不一定按指令回答；第\ref{chap:nlp-supervised-finetuning}章用示范回答约束这种交互行为，固定参数后的生成在第\ref{chap:nlp-model-inference}章展开。

\paragraph{延展阅读}
DataComp-LM与FineWeb在共同的模型、预算与评价下比较语料筛选和去重方案；Chinchilla工作追踪固定计算预算下模型规模与词元规模的取舍；DeepSeek-V3技术报告把稀疏专家、多词元预测、FP8训练与多阶段日程组合在同一次训练中；MDLM提供不同于自回归预测的离散扩散目标。阅读时宜把数据、结构、目标和优化分别列出，再判断论文中的收益能归因到哪一个可核对的训练环节\scite{nlp-llm-dclm2024,nlp-llm-fineweb2024,hoffmann2022chinchilla,deepseek2024v3,nlp-llm-mdlm2024}。
