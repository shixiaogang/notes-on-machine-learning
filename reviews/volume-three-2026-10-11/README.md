# 卷三正文重写与审查记录

本目录保存2026-10-11开始、2026-10-12继续完成的卷三写作修订。范围是卷三实际入口递归接入的29章、三个部分阅读指引和拆分正文，共48份文件；其中卷入口没有改动，47份文件有正文变化。作者角色由root及三位分工代理承担。完整章级C、段级P、句级W阅读按先后分遍执行，公式、算法、数例、表和图注纳入特殊单元；程序只用于定位、哈希、结构及符号检查，不生成语义接受判断。

`baseline-before-prose/`是开始本轮文字重写时的固定输入，已经包含先前经用户授权的章节与图像调整。“本轮保持章节结构”的比较基准是该快照，不能据此声称整个优化任务从Git基线起没有结构变化。`prose-stage-source/`保存完成写作修订及局部修复后的正文检查点；`prose-stage-after-pdf-repairs/`保存书页复查所发现的图注及旁注问题修复后的稿件。两份均在等待卷二远端更新及后续跨卷核对之前冻结，不代表后续引用协调已经完成。

## 复核与后续修复

`independent/`保存另一个代理执行的实际审读及发现关闭。独立复核覆盖神经网络概述、概率图模型概述、Transformer、结构学习、能量模型等声明范围；不声称全卷每一章都由独立审稿人审过。生成模型的追加阅读须结合其报告中的上下文作者关系披露判断独立性。

`integration-repairs/`保存集成后发现的证明闭合缺失、索引身份恢复、长公式行宽、参考文献分页循环和独立阅读发现的实际修订。每次有正文改变，旧稿完整覆盖仍绑定旧固定稿，新增记录单独覆盖变动单元及连续上下文；没有把最后一次局部修订写成又完成全章三遍。新的条件、量词和关系均经实际复读，构建成功不能替代文字结论。

参考文献分页循环由同一作者相邻条目的作者破折号与分页判定互相影响造成。修复关闭作者重复替换选项，保存相邻轮次的辅助文件差异与诊断；没有提高重跑上限或忽略编译失败。

`boundaries-*.json`与`theory-analysis-structure.json`仅保存行政检查。前者核对入口、标题、标签、文献身份、图源、引用和公式变化；公式或引用不同必须结合相应人工记录解释。后者定位表达能力、收敛性、泛化性三项分析，标题存在本身不证明理论分析充分。

`delivery-scope-audit/`记录重复文件的逐字节核验与可恢复移动。729个无引用副本或当前渲染中间导出已移到任务工作区忽略的`build/volume-three-refinement/excluded-redundant-inputs/`，正式图源和历史记录保留；HMC缺失的规范元数据先恢复并保存完整旧记录。文件名与哈希只能支持副本判断，未将其成因断言为iCloud冲突。

## 验证状态

正文审读、来源核验和图源检查按各记录的真实范围读取。最终七卷构建、书页检查、提交及与远端卷一/卷二的协调结果另由验证记录保存；本说明不提前把尚未完成的跨卷协调或远端推送写作已完成。
