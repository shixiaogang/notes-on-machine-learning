## 第一遍：章级覆盖

### C1 核心问题

开篇以四变量局部约束为立足点，提出“连接结构能保存什么、不能保存什么，以及怎样据此做路径查询、局部拆分、约束选择和函数汇总”。它明确区分图结构与边长、容量、相似度、因子值和概率语义。读者所需的集合、逻辑与线性代数背景均在前章；四变量CNF的实际前文也已核对。核心问题具体，入口可用。

### C2 章节分解与阅读顺序

1. “图的对象与表示”先区分二元边、高阶因子、矩阵表示和重编号等价，回答关系怎样编码及编码会丢什么。
2. “图中的路径与连接关系”由邻接扩展到路径、连通与条件分离，回答连接关系怎样判定。
3. “图的遍历、分解与简化”把关系判据变成遍历、分块、弦化、消元和等价转换，回答怎样执行或改写结构以及保留什么。
4. “图上的约束优化”加入边长、容量、连通、互斥和配置成本，回答在不同可行约束与目标下怎样选择并认证最优性。
5. “图上函数的变换与查询”先区分顶点函数与配置函数，再讲谱变换、数值传播、离散标记细化、半环消元和树消息，回答函数定义域不同会怎样改变运算。
6. “本章小结”综合结构、算法条件、松弛边界与函数语义。

顺序总体按“表示对象 -> 判定关系 -> 执行结构计算 -> 增加优化语义 -> 增加函数值语义”推进。需要重点复核的高密度依赖链为：活跃路径 -> 祖先道德化 -> 全部分离关系等价；分隔集 -> 树分解 -> Helly性质 -> 树宽 -> 弦图 -> 消元；图拉普拉斯 -> 谱松弛 -> 图傅里叶 -> 多项式滤波/扩散；因子作用域 -> 半环 -> 消元 -> 树消息。
