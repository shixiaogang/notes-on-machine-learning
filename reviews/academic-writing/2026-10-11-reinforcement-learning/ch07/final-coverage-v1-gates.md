# CH07 最终独立复核：专项门槛

## 七项门槛

1. **可检验命题：接受。** “最优”“稳定”“零样本”“支持”“可利用性”和
   “复杂度”均绑定对象、允许类、信息权限、预算或计数单位；无裸露能力判断。
2. **压缩表达拆解：接受。** “团队最优”“联合覆盖”“平均策略”“最坏情形”
   和“未见参与者”均在当地展开评价对象、方向和范围；环境库名不代替任务配置。
3. **新对象转换：接受。** 单人MDP到联合核、阶段动作到完整策略、状态到历史
   增广核、固定参与者到留出参与者等转换均说明固定项与变化项。
4. **解释时序：接受。** 新概念先由通道、匹配硬币、隐藏牌、按钮或循环策略
   暴露缺口，再命名、定义、计算和给边界；未依赖后文倒补。
5. **局部入口：接受。** 31个主要小节均有本地场景、数学对象、反例或待证明
   命题；入口详情见下表。
6. **公式双门槛：接受。** 联合边缘、极小极大、重要性比、COMA、响应梯度、
   策略梯度、CFR、偏离间隙和资源式均说明候选集合、运算方向及用途。
7. **回指与范围：接受。** 回指第1--6章时恢复当前所需命题；扩大到多步、
   历史策略、参与者变化和具体基准时均重列附加条件。

## 方法依赖链

| 链 | 任务→缺口→对象→误差/目标→求解与条件 |
|---|---|
| 诱导单人过程 | 固定他人下评价→边缘分布可能依赖自身动作/历史→`P_i,R_i`→独立性与充分状态→条件边缘化 |
| 团队最优 | 共享回报→集中信息不可部署→分散可行集→共同`J`→集中模拟给上界 |
| 零和控制 | 抵御利用→平均对手不足→最坏收益→矩阵LP/阶段值→有限混合、双线性及后续收敛条件 |
| 一般和稳定 | 福利不保证维持→单方偏离→Nash/CCE/CE→偏离约束→阶段到完整策略需重新定义 |
| 联合重加权 | 旧版本/群体日志→目标来源比例不同→联合轨迹分布→密度比→绝对连续及真实联合概率 |
| 联合评论家 | 多方动作共同决定长期后果→局部输入不足→`Q_i,V_i`→TD残差→充分`x`、真终止和同接口`x'` |
| COMA | 团队信用不清→即时差分不足→候选动作价值→策略平均基线→条件动作分布与停止梯度 |
| 值分解 | 联合枚举昂贵→局部执行须一致→局部效用/联合值→联合TD目标→单调或更一般IGM结构 |
| 伙伴建模 | 固定未知类型→当前动作频率不够→类型信念→似然/条件价值→可见证据与继续辨识 |
| 响应建模 | 对方会因自身改变→固定对手漏项→响应后回报→复合梯度→可微、评价点和数据分布条件 |
| 多方梯度 | 联合轨迹改策略→局部得分和集中后果分工→`J_i`梯度→占用期望→可微、固定支持及相关策略重推 |
| CFR | 完整策略数巨大→局部普通条件价值受自身到达影响→反事实价值/遗憾→局部累积→有限完全回忆及正确平均 |
| PSRO | 当前对手响应遗忘历史→需有限策略库→元博弈收益/响应→库上求解和新增响应→表误差、响应误差、库外边界 |
| 参与者适配验证 | 人数/伙伴/对手变化→训练成绩不能定位能力→留出任务与偏离/资源指标→固定预算测试→范围仅到实际留出类 |

## 范围转换

1. 单智能体联合核前文 → 多参与者联合反馈核；保留奖励、观测、终止相关性。
2. 独立随机化 → 公共信号相关联合策略；只在给定信号后分解。
3. 固定状态条件对手 → 历史/类型对手；须增广充分信息。
4. 阶段动作偏离 → 序贯完整策略偏离；阶段CE不自动给序贯稳定。
5. 行为群体/版本 → 目标群体/版本；需伙伴分布及联合动作比。
6. 当前观测/状态 → 历史充分信息`x`；增广核必须传播获准反馈与消息。
7. COMA当前候选比较 → CFR前序到达反事实；用途和权重不同。
8. 当前策略 → 历史平均行为策略；完全回忆下按自身到达概率平均。
9. 当前双方 → 策略库元博弈 → 完整策略空间；每次扩大都增加响应范围。
10. 固定参与者 → 跨规模；重编号不等于人数变化。
11. 共同训练伙伴 → 新伙伴；严格零样本不使用伙伴反馈辨识。
12. 固定对手 → 反应型对手；固定类型保证需改为响应协议。
13. 训练收益 → 偏离、留出和资源验证；一个指标不能替代其余三项。
