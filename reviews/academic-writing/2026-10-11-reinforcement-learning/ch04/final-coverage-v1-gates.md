| 校准项 | 触发检查 | 判断依据 |

| E4 多重否定 | 检查“不等于、不能自动、未必、无须” | 紧邻正向范围或反例；未发现作用域不明的嵌套否定 |
| E5 有限数据→候选模型集合 | 检查行为模型、集成模型、一致模型集合 | 拟合模型不冒充唯一环境；L1105以后正式给总体相容模型集合及非空条件 |

| E7 远程回指未恢复 | 检查“沿用前章/前节” | 当地恢复时域、占用归一化、动作概率比、模型误差或评价对象；未仅给章节名 |
| E8 抽象节首判断 | 检查全部section/subsection首段 | 均先有任务、日志、数学对象、反例或待证问题；未触发 |
| E9 “最不利/最大/下确界”集合不明 | 检查max/min/inf/sup/ess sup | 合法动作、候选策略、函数类、一致模型和`nu`支持均定义；方向由回报、损失或排序给出 |
| E10 局部扰动→一般变化 | 检查当前观测→历史、固定策略→选后策略、固定模型→模型内优化 | 原范围、新范围、扩大理由和不可继承结论完整 |
| E11 新风险/评价记号突入 | 检查`Y,K,b,q,C_pi,w,J_DR,d^pi,M,I_T` | 首次公式前说明用途，符号在紧邻定义或解释中出现 |
| E12 指标方向与基线含混 | 检查价值差、损失、悲观下界、基线改进和识别宽度 | 回报越大、误差/损失越小、`pi1-pi2`正值和相对基线方向均明确 |

## 方法依赖链

| 方法族 | 任务→旧缺口→评价/预测对象→误差/残差→目标→经验目标→求解与条件 | 判断 |
|---|---|---|
| 信念滤波与控制 | 部分观测→当前画面非马尔可夫→状态后验/反馈分布→Bayes更新→最优历史价值→已知联合核→信念Bellman；有限已知模型、正概率反馈 | 完整 |
| Kalman/LQG | 连续状态→逐状态信念不可存→高斯均值协方差→创新→条件均值/控制成本→线性观测→矩阵递推/反馈；线性高斯、独立、可逆及分离附加条件 | 完整 |
| 学习型记忆 | 模型未知→精确后验不可算→递推/注意力表示→预测或价值误差→控制充分表示→序列片段→DRQN/R2D2/GTrXL；边界与burn-in一致 | 完整 |
| IS/PDIS | 固定日志评价目标策略→分布错位→有限时域回报→概率比方差→`J_H(pi)`→行为轨迹→重加权；已知机制、支持、矩条件 | 完整 |
| FQE/DR | 长轨迹比高方差→拟合固定策略价值/残差修正→Q/V与Bellman残差→目标价值→日志转移→反向回归/交叉拟合；覆盖或一侧正确条件 | 完整 |
| DICE | 不显式拟合行为概率→需占用校正→`d^pi/nu`→流量矩残差→无限折扣价值→数据转移和初态→对偶/矩匹配；支持与丰富函数类 | 完整 |
| 行为约束离线RL | 新策略走出日志→价值外推→执行动作/备份动作→行为距离→预测回报受约束最大→数据动作→TD3+BC/BCQ/BEAR等；尺度和覆盖重查 | 完整 |
| 保守价值/IQL | 数据外动作高估→备份或提取不可信→Q/V/执行策略→保守正则或expectile残差→固定数据改进→日志转移/动作→CQL/IQL；不自动给逐点/真实改进保证 | 完整 |
| 生成式动作/轨迹 | 多模态动作或长计划→简单行动者/枚举不足→候选动作/轨迹→去噪、价值或模型误差→价值引导选择→固定日志→梯度生成/重采样/搜索；不增加后果证据 | 完整 |
| 模型离线RL | 学习模型会外推→规划器利用错误→模型奖励/转移与访问占用→模拟价值差→悲观模型回报→真实日志+模型滚动→MOPO/MOReL/COMBO；误差上界需覆盖候选 | 完整 |
| 性能控制与SPIBB | 选择后估计提升可能失真→需统一误差/基线行为→真实性能差→共同事件/计数置信→容许损失或严格阈值→独立评价日志→选择/受约束规划；候选适应性处理 | 完整 |
| 离线POMDP识别 | 隐藏状态且日志固定→行为可能依赖未记录线索→历史策略价值/识别集合→模型歧义→点/部分识别或保留未知→完整历史日志→历史IS/共同模型优化；随机化与支持条件 | 完整 |
