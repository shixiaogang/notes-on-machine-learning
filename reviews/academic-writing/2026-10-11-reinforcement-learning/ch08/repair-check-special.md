## 方法依赖链

| 方法 | 任务→缺口→对象/误差→求解与条件 |
| --- | --- |
| 静态CVaR | 抑制最差延误→均值抵消→损失上尾与有限尾样本→轨迹得分和阈值次梯度；需正则、可交互和留出验证 |
| 累计增广 | 已知模型求事前尾部→物理状态丢累计量→$(t,s,z)$与终端超额→固定$\eta$反向规划，连续近似另计误差 |
| 嵌套风险 | 历史后按条件规则重评→静态目标不一致→条件风险映射与状态信息→合法Markov递推及压缩条件 |
| 鲁棒模型 | 每个允许环境保收益→标称或平均漏坏核→核族、矩形性和内层残差→局部优化外层决策；不适用于任意耦合 |
| 观测攻击 | 指定权限下耐输入误差→有限测试漏动作切换→`\iota_t`、局部代理与搜索误差→投影搜索和策略更新；特权训练另标 |
| 执行模型 | 实际动作不等请求→状态丢队列/通道→增广核或误差集合→固定通道积分或最坏后继；两者条件不混 |
| CMDP | 限平均危险暴露→普通回报最大化不筛成本→占用/评论家/乘子→已知模型LP或轨迹原始--对偶；最终按原成本验收 |
| CPO | 候选新占用改变成本→旧策略代理有偏差→代理和TV余项→局部步仍须保留不利误差 |
| 机会约束 | 限整回合失败概率→次数或折扣成本不对应→失败标记、概率价值和条件预算→采样或模型递推；CVaR替代需事件编码 |
| 硬保护 | 全允许轨迹保持→当前合法不等下一步可行→保护集合、误差集和备份→屏蔽/投影/CBF/预测过滤；退化时明确失效 |
| 证据推断 | 判断交付对象达标→点值、选择和稀有样本不足→回合统计及覆盖误差→二项反演、离线界、预设查看 |
| 多要求组合 | 同时保收益、尾部和安全→单准则可互相违反→模型族、策略类和可行交集→逐模型上下确界；交集可空 |
