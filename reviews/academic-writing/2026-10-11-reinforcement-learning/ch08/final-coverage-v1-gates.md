# CH08 最终独立复核：专项门槛

## 七项门槛

1. **可检验命题：接受。** 风险、鲁棒、安全和可靠性声明均绑定交付对象、
   运行协议、允许集合、阈值、证据或误差事件；无裸露“安全/可靠”能力判断。
2. **压缩表达拆解：接受。** “最差尾部”“最坏模型”“安全输入”“达标”
   均给对象、指标方向、候选集合和判定阈值。
3. **新对象转换：接受。** 固定模型到模型集合、物理状态到队列/失败/预算增广
   状态、候选策略到受保护系统、行为概率到置信覆盖均明确说明转换依据。
4. **解释时序：接受。** 两损失分布、时间不一致树、共享参数反例、制动延迟、
   高速边界和零失败记录均先暴露缺口，再引入术语、定义与方法。
5. **局部入口：接受。** 各主要小节都有本地场景、数学对象、反例或待证明命题；
   详情见下表。
6. **公式双门槛：接受。** CVaR阈值、风险动作最小化、鲁棒内外层、执行误差
   下确界、成本预算、事件预算和组合上下确界均说明候选集合、方向和原因。
7. **回指与范围：接受。** 回指第1--7章时恢复当前所需的占用、梯度、覆盖、
   任务推断或联合行为条件；扩大时域、环境、策略类或交付对象时重新列条件。

## 方法依赖链

| 链 | 任务→缺口→对象→误差/目标→求解与条件 |
|---|---|
| 静态CVaR | 累计尾部→均值遗漏严重回合→损失分布/阈值→超额损失目标→轨迹梯度或状态增广 |
| 动态风险 | 历史条件下要重评→静态准则时间不一致→条件风险映射→嵌套Bellman→单调、平移等变和充分状态 |
| 机制鲁棒 | 物理参数在集合内变化→概率平均无统一下界→最坏回报→局部内层最小值→矩形、紧集和对手权限 |
| 观测鲁棒 | 传感器可被有限修改→有限攻击不证明最坏→扰动规则集合/内层差距→投影搜索→信息权限、预算及误差界 |
| 执行鲁棒 | 请求动作不等实际动作→队列/误差影响后继→实际执行分布→下确界与噪声期望→队列增广或固定通道边缘化 |
| CMDP | 平均危险暴露预算→奖励权重不能代替硬预算→占用/成本→线性约束和拉格朗日→随机策略、覆盖及最终验证 |
| CPO | 旧分布代理不等新策略成本→占用变化→奖励/成本代理→TV/KL余项→只有代理加余量达标才支持可行 |
| 机会约束 | 至少一次失败→重复计数错误→失败事件/标记→概率递推或预算分配→完整事件、时域和模型 |
| 硬安全 | 每步不得越界→当前合法不足→不变/可恢复集→一步保持条件→准确状态、扰动覆盖、非空输入和备份 |
| 保护过滤 | 候选可能危险→需在线修正→保护输入集合→最近点/屏蔽/备份→取到、时限及退化报告 |
| 可靠性推断 | 优化目标不等交付保证→需独立证据→回报/尾部/事件/证书→置信或模型误差→冻结对象和协议 |
| 组合优化 | 三类要求并存→单一平均分不足→多模型风险/回报/成本→上下确界和交集→策略类、阈值及可行性 |

## 范围转换

1. 平均回报 → 累计损失分布；先选损失和上尾方向。
2. 事前静态风险 → 历史条件动态风险；概率质量和目标改变。
3. 固定模型 → 允许模型集合；轨迹随机性仍留在各模型内部。
4. 全局耦合模型 → 状态--动作矩形集合；只有合法自由组合时局部最坏可继承。
5. 机制扰动 → 观测扰动 → 执行扰动；三者进入闭环的位置和信息权限不同。
6. 物理状态 → 延迟队列增广状态；旧请求决定本步实际动作。
7. 期望累计成本 → 整回合事件概率；严重度与是否发生分开。
8. 单步事件 → 整回合事件 → 训练期事件；样本空间与时域逐层扩大。
9. 当前允许状态 → 鲁棒不变集/可恢复集；存在安全动作的量词新增。
10. 候选策略 → 策略与保护层组合；请求与实际动作、干预原因必须入日志。
11. 点估计 → 单侧界/联合界；行为随机性与推断错误率分开。
12. 确定候选路线 → 随机策略类；可行最优可能改变。
13. 单项要求 → 多模型多要求交集；每项上下确界方向分别保留。
