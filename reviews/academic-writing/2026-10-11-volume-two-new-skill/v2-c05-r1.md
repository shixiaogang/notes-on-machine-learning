## 第一遍：章级覆盖

### C1 核心问题

章首用“两个阈值在训练邮件上相同、在新邮件上不同”的具体冲突建立核心问题：算法看过样本后从候选空间选择假设，怎样用有限样本排除期望风险高却碰巧拟合样本的候选。随后把问题扩大为三个层次：有限类和无限类需要多少样本；数据相关复杂度、压缩和集成怎样形成保证；统计存在性之外，学习器是否可计算且高效。章首明确沿用前章的 i.i.d. 二分类、零一损失与 PAC 量词，并标出本章新增工具，目标读者具备进入正文所需前置知识。判断：接受。

### C2 章节分解

1. “可实现的有限假设空间”从单个坏假设的一致概率出发，用并集界得到可实现 PAC 样本量。
2. “不可知的有限假设空间”从固定假设偏差转向全类一致收敛，再把一致收敛转成 ERM 的超额风险保证，并连接 SRM。
3. “无限假设空间”用生长函数和 VC 维替代成员计数，经 Sauer--Shelah 引理、对称化和无免费午餐得到二分类基本定理及最优样本复杂度边界。
4. “估计期望风险”从最坏情形容量转向依赖当前样本的 Rademacher 与高斯复杂度。
5. “样本压缩”从函数类整体控制转向输出可由少量样本重构的算法结构。
6. “集成学习”依次区分投票条件、弱学习与提升、经验风险、PAC 可学习性和间隔风险估计。
7. “可计算 PAC 学习”把统计存在性分成程序停机、有效 VC 维、优化误差和多项式时间。
8. “本章小结”综合统计容量、输出结构和计算要求。

同层划分按“有限类基线—无限类容量—数据/算法相关保证—组合学习—计算实现”推进，依赖顺序成立。判断：接受。

### 方法依赖链

- 有限类 ERM：二分类风险比较 → 数据依赖选择缺口 → 零一错误 → 期望/经验风险 → ERM → 可实现并集界或不可知一致收敛；完整。
- VC 路线：无限类不能按成员求和 → 有限样本预测向量 → 经验与期望偏差 → 零一损失类上确界 → 对称化、随机交换、生长函数；B052 的随机交换概率空间待修，见 F04。
- 随机复杂度路线：当前样本上的函数波动 → 得分/损失对象 → 低估偏差 → 经验均值和期望 → 对称化、收缩、集中；完整。
- 压缩路线：全类控制之外的输出结构 → 重构假设 → 零一错误 → 一致条件 → 固定重构与未保留样本检验；完整。
- 集成路线：多个预测的组合 → 共同错误或训练波动 → 投票/平均得分 → 条件错误率、零一风险或间隔损失 → AdaBoost 经验目标与加权更新 → 生长函数或 Rademacher 风险界。入口需先区分评价口径，见 F02；弱学习调用量词见 F01。
- 可计算路线研究“是否存在停机程序”和资源复杂度，不以新的统计损失或经验目标替代前文零一风险；因此完整的“损失动机—经验目标—求解器”链只在可计算 ERM、近似 ERM 与布尔合取处适用，其他有效维度段落不适用求解器环节。

### F05（中）：把条件独立误述为“互不相关”
