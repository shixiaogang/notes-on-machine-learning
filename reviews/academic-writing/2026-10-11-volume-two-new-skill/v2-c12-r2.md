### 方法依赖链

- 风险检验：任务变化 → 固定测试环境/扰动 → 任务损失 → 环境风险与增加量 → 置信比较。链条主体成立，抽样和同时推断条件见 R05。
- 局部认证：标签保持邻域 → 有限攻击搜索不足 → 分数变化上界/平滑概率界 → 样本级证书 → 认证准确率。链条成立，类别选择推断见 R06。
- TRADES：随机增强漏高损失点 → 内层寻找预测分布最大偏离 → 外层自然损失加稳定项 → 近似求解 → 独立测试/认证。链条成立，训练期望来源见 R08。
- DRO/组DRO：平均风险忽略小群体 → 允许分布集合 → 最坏分布风险 → 任意组混合化为最大组风险 → 正则化与独立验证。链条成立。
- 拒绝/OOD：全自动处理缺证据 → 异常分数 → 验证集阈值 → 误拒/误接纳 → 接纳风险、处理比例和成本。链条成立。
- 测试时适应：新环境信息 → 无标签代理或少量标签 → 状态更新 → 与冻结模型比较 → 回退。缺少最终接受/回退判据，见 R09。

## 发现与最小修复

以下行号均为基线 `65de1f9ae4eacde76fdb27a832e1214f386623d5` 行号。依用户要求未修改正文，因此所有发现状态均为“待修改”，没有伪造修订或复读关闭记录。

### R01（高）：扰动风险公式尚未形成可判定的鲁棒性要求

- 原文（L22--29）：“如果这些变化保留标签 \(y\)，可以用最不利变化下的损失评价模型：\(R_{\mathrm{pert}}(f)=\mathbb E_{\mathcal P}[\sup_{\bm x'\in U(\bm x)}\ell(f(\bm x'),y)]\)。”
- 触发规则：七项门槛1、6；E9；W3、W5；`specs/writings.md` 的公式前置和评价标准要求。
- 问题：段落定义了 \(U(\bm x)\)，但未就地说明 \(\mathcal P\) 是哪个评价总体、\(\ell\) 沿用何种损失，也没有解释为何平均扰动损失不足而必须覆盖集合内每一点。公式只产生一个风险值，没有给容限或相对基线，读者无法据此判定“鲁棒”。
- 后果：允许集合、总体和通过标准可被任意选择；不同工作即使报告同名 \(R_{\mathrm{pert}}\)，也可能回答不同问题。
- 最小修复：在公式前补一句“平均扰动会掩盖少量高损失允许点，因此对每个样本取 \(U(\bm x)\) 内损失上确界”；就地说明 \(\mathcal P\) 与 \(\ell\) 的来源；公式后给预先约定的容限 \(\rho_{\mathrm{pert}}\) 或明确的参考风险比较。
- 状态：待修改。

### R02（高）：从局部邻域到环境风险的范围转换缺少总体和允许集合

- 原文（L32）：“局部扰动并未涵盖全部分布变化……对于回归或分类器 \(f\)，环境 \(e\) 中的风险记为 \(R_e(f)\)。”
- 触发规则：七项门槛3、7；E10、E11；P3、P5；W1、W3。
- 问题：正文从单样本集合 \(U(\bm x)\) 跳到“环境 \(e\)”和 \(R_e(f)\)，没有定义环境对应的联合分布 \(\mathcal P_e\)、允许环境集合 \(\mathcal E\)，也没有说明哪些对象保持不变（任务损失/标签语义）、哪些对象改变（边缘分布、组比例或条件规律）。“输入比例改变”也未说明比例针对何种输入分组。
- 后果：读者无法把局部鲁棒性与分布鲁棒性放在同一评价框架中，也无法判断“所有允许环境”的量词范围。
- 最小修复：用一至两句定义 \(e\mapsto\mathcal P_e\)、\(\mathcal E\) 和 \(R_e(f)=\mathbb E_{(\bm x,y)\sim\mathcal P_e}\ell(f(\bm x),y)\)；说明扩大范围是为了覆盖组比例、输入分布或 \(P(y\mid x)\) 的变化，并写明沿用同一任务损失。
- 状态：待修改。

### R03（高）：风险变化的方向写反且基线迟到

- 原文（L32）：“也可以要求相对于原环境的下降不超过给定幅度。绝对风险和下降幅度需要一起看：一个始终表现很差的模型，也可能几乎没有下降。”
- 触发规则：七项门槛1、2；E12；W4、W5。
- 问题：当前对象是风险；模型退化通常对应风险相对参考环境“增加”，不是“下降”。“原环境”和差值符号直到 L96/100 才被定义为 \(\widehat\Delta_e=\widehat R_e-\widehat R_0\) 与“增加量”。
- 后果：读者可能把较低风险误当成退化，或采用相反号的阈值；同一章前后术语不一致。
- 最小修复：把两处“下降”改为“风险增加/退化”，在此就地定义参考环境 \(0\) 与 \(\Delta_e=R_e-R_0\)，说明要求是 \(R_e\leq\rho\) 且/或 \(\Delta_e\leq\delta\)；保留“始终很差但变化小”的反例。
- 状态：待修改。

### R04（中）：不确定性“先于准确率失效”不是可检验比较

- 原文（L85）：“变化还可能使不确定性表达先于准确率失效。”
- 触发规则：七项门槛1、2；W2、W4、W5。
- 问题：“不确定性表达”“失效”和“先于”没有对应指标、阈值或变化强度顺序。后句列准确性、概率评分和校准指标，但没有建立哪个指标在什么判据下先失效；该句容易把特定实验观察写成一般时间/强度顺序。
- 后果：读者无法复核该比较，也可能误以为所有分布变化都先破坏校准、后破坏准确率。
- 最小修复：收窄为“在某些构造变化中，校准误差或概率评分可能在准确率变化较小时已经恶化”，并说明比较随变化强度的曲线；若要保留“先于”，给出引用支持的具体判据。
- 状态：待修改。

### R05（高）：环境风险置信上界缺少抽样与同时推断口径

- 原文（L91--100）：“用未参与训练与调参的 \(n_e\) 个带标签样本估计……应把相应风险置信上界与 \(\rho\) 比较……不能把相关的变体当成相互独立的样本计算区间。”
- 触发规则：七项门槛1、6；W5；技术内容规则中的抽样单位、独立性和不确定性要求。
- 问题：正文正确排除了把同一原样本的多个扰动当独立样本，却没有说明原样本如何从 \(\mathcal P_e\) 抽取、存在会话/机构聚类时如何处理、配对 \(\widehat\Delta_e\) 如何利用协方差，以及同时查看多个环境、强度和群体时置信上界是逐项还是联合有效。
- 后果：读者可能用错误的独立同分布假设得到过窄区间，或在多环境筛选后仍把单项置信度解释为整体保证。
- 最小修复：在 L100 后补充：区间须匹配独立样本单位或聚类/时间抽样设计；配对差值保留配对；若声明多个预定环境/群体同时满足容限，使用联合控制，否则明确各区间仅逐项有效。可准确回指可靠性章的相应统计程序。
- 状态：待修改。

### R06（中）：随机平滑的类别选择与概率估计条件写成可选而未封闭

- 原文（L148）：“选类别与估计概率可以使用独立采样，界不足以分离类别时则拒绝认证。”
- 触发规则：七项门槛1、6；W4、W5。
- 问题：若先用同一批蒙特卡洛样本选择类别，再只为所选类别构造普通单类置信界，选择会改变覆盖率。独立采样是一条有效路径，但“可以”使读者以为不用独立样本也无需任何选择调整。
- 后果：标称失败概率可能低估真实证书错误率，破坏后文的样本级或联合保证。
- 最小修复：改为“类别选择与概率估计应使用独立采样，或使用对选择步骤仍同时有效的概率界”；保留界不足时拒绝认证。
- 状态：待修改。

### R07（中）：无标签一致性中的“输出接近”缺少评价对象和距离
