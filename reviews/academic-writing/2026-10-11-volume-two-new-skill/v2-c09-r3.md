### C1 核心问题

章首由“旧月份训练、部署到新月份”的邮件分类场景提出分布变化问题，随后明确拆成两个可检验的上位问题：

1. 现有观测是否足以识别目标域标签规律；

## 关键单元汇总

### 新节和方法入口

- 数据与评价目标：同分布部署缺口 → 可见信息不同 → 三种评价设定 → 正式 PAC 定义。
- 分布偏移与可识别性：条件机制可能保留/改变 → 偏移定义 → 覆盖与同观测反例 → 不可学习性。
- 领域自适应：目标输入可见但标签不可见 → 风险桥梁 → 假设空间级或输出级有限样本控制。
- 领域泛化：目标输入也不可见 → 固定允许目标域或随机环境总体 → 两类不同保证。
- 各 paragraph 方法入口均先恢复前一结果的缺口；未出现以方法名直接替代问题的入口。

### 方法依赖链

- 分歧路线：二分类目标风险 → 无标签可观察假设分歧 → `H△H` 散度 → 共同错误 `lambda` → VC 统一估计 → 有残余项的风险上界。
- 重要性加权路线：共享条件标签机制 → 输入覆盖/密度比 → 加权总体风险 → 加权 ERM → 有限类或 Rademacher 保证 → 未知密度比与条件变化残余项。
- 稳定性路线：同一加权目标 → 原损失稳定性被 `kappa` 放大 → 经验优化误差 → 期望超额风险 → Markov 高概率保证。
- PAC--Bayes 路线：Gibbs 预测 → 分歧/共同错误恒等式 → 源域 PAC--Bayes 项 → 跨域残余项。
- 逐目标域泛化：训练域混合 → 共享 `eta` 和贝叶斯分类器 → 条件超额损失 → 目标/混合覆盖 → 有限类 ERM。
- 环境平均泛化：环境总体 → `K` 个独立块、每块 `n` 个样本 → 环境层和块内层偏差 → ERM；输出级路线以环境块稳定性替代全空间一致收敛。

### 范围转换

- 同分布风险 → 跨域风险：原假设空间复杂度仍可用，但新增可识别性与覆盖条件。
- 协变量偏移 → 标签机制变化：风险恒等式变为含 `b_cond` 的近似关系。
- 自适应 → 泛化：移除目标输入后，分歧/密度比不可再由目标样本估计，需改用允许目标域或环境分布。
- 逐目标域 → 环境平均：评价对象由固定 `R_T` 改为 `R_Q`，概率由训练样本扩展到环境抽样。
- 固定表示 → 数据学习表示：复杂度对象由预测头扩大到表示与预测器组合。

### R3-F04：标签偏移的“最小奇异值”条件没有定义承载算子

- 严重度：高
- 原文版本：同上
- 位置与原文：L441，“恢复映射的最小奇异值必须在允许分布族上一致远离零，或等价地控制其条件数”。
- 问题：前文只讨论抽象的类条件概率分布及其线性独立，没有选择有限特征、矩条件、混淆矩阵或从类别比例到目标观测统计量的线性算子。“最小奇异值”和“条件数”只对指定的有限维矩阵或合适的有界算子有定义；当前也没有说明使用何种范数。因此这条有限样本条件不能被复核，“等价地”也缺少成立对象。
- 违反规则：专项门槛 1、2、3、6；W1、W3、W5；`content.md` 关于公式/技术条件必须定义对象、定义域和成立条件；项目 `writings.md` 关于技术性质需写明条件。
- 理解后果：读者无法判断该条件是针对类条件密度矩阵、黑盒分类器混淆矩阵、某组矩特征还是无限维混合算子，也无法据此理解样本误差怎样被放大。
