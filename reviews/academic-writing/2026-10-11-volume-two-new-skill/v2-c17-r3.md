## 第一遍：章级覆盖 C1--C4

### C1 核心问题

章首用“月份变化导致普通失效”与“攻击者改写邮件逃避检测”对照，建立核心问题：当变化由有目标、受能力与预算约束的攻击者选择，并可沿模型、接口和执行链传播时，怎样定义损害、取得脆弱性证据、布置防御并限制残余损失。邮件分类、归档、检索和发送形成贯穿场景。读者所需的三层可信性框架、分布偏移、稳定性和隐私泄露均给出前引；梯度、优化和概率属于既定前置知识。进入条件总体成立。

### C2 章节分解

1. “基本概念”按攻击操作、损害目标、攻击者能力三组相互交叉的维度建立共同基础。
2. “脆弱性的评估”先统一对象、条件、指标和程序，再按被测对象分为推理输入、训练过程、供应链、模型内部、查询接口、交互执行链六类。分组依据一致，顺序由局部输入逐步扩到训练、制品、接口和完整系统。
3. “攻击防御与损害控制”改按干预位置分为来源、模型训练与修复、输入输出、执行权限、监测恢复；这与评估节不是一一同名，但共享“攻击路径上的位置”这一组织依据。
4. 小结回到邮件系统，综合操作、损害、能力、证据和干预位置。

分解整体成立。需要修正的局部缺口是：基本概念中的“模型窃取”未及时建立可检验判据（F01）；威胁模型把若干仅在特定系统中适用的字段写成无条件最低要求（F03）。

## 核心公式单列

| 公式 | 当前问题 → 使用理由 → 符号 → 运算依据 → 回答 | 判断 |
|---|---|---|
| 经验 ASR | 多少完整试验达成目标 → 需要频率口径 → `n,s_i` → 成功指示求平均 → 给定分母下的经验成功比例 | 内容接受；术语 F07 |
| `R_adv=sup E L` | 能力范围内最坏期望损害 → 单次成功率不含严重度 → 策略集、完整随机性、损失 → 对固定可实施策略取上确界、对试验随机性取期望 → 规定信息接口下的最坏期望 | 接受 |
| `1-(1-p)^k` | 重复独立尝试至少一次成功 → 单次比例不代表服务预算 → `p,k` → 独立失败概率相乘取补集 → 固定独立模型下累计成功 | 接受 |
| FGSM | 线性化损失在 L-infinity 球内最大方向 → 一步快速搜索 → 梯度、扰动、预算 → 对偶范数/逐坐标端点 → 线性化目标最优扰动 | 接受 |
| 一般输入最大损失 | 统一允许集合上的反例搜索 → 从单步推广 → `U(x),f,y,ell` → 最大化损失 → 找高损失候选而非证书 | 接受 |
| PGD | 多步更新重算梯度 → 单步近似不足 → 迭代点、梯度、步长、投影 → 增损后回可行集合 → 迭代候选 | 投影定义 F05 |
| CW | 饱和概率使原搜索失效 → 换用类别打分差 → `z,c,k,kappa` → 扰动代价加目标罚项 → 目标类优势候选 | 接受 |
| 投毒目标 | 污染经训练随机性影响模型 → 需显式学习者响应 → `D,D~,P,T,xi,Q,L_target` → 外层最大化期望目标损失 → 白盒、种子事前未知设定的攻击目标 | 接受 |
