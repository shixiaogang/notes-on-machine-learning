| F118–119 | 检测并减少可预测属性 → task损失减lambda*group损失，任务最小/对手最大，交替两向动作 → 限定对手类、样本、求解，标签内对抗才对应EO，独立对手再查 |
| F121–127 | 直接准则违规 → 条件矩拆方向，F中Q混合与非负乘子sup，违规代价归约成本敏感学习，迭代留混合 → 经验约束与求解条件，独立总体审计；个体/因果另用距离/结构 |
| F130–133 | 无法重训的失准或错误差 → 区间残差改分数，或组ROC共同可达点、独立阈值混合 → 两种修改分开验；验证记录上的期望率同不保证一次实现或部署率同 |
| F139–140 | 差缩小可因低组变好或高组变坏 → 同独立资料报原新TPR/FPR/名额和处理风险负担 → 实际机会与服务后果，不靠拒答降自动错判改善 |
| F144–146 | 结果只在获选者可见 → 特征属性给定选择独立于z(1)、正性、一致性时 IPW E[rz/e|a]=E[z(1)|a] → 可识别培训潜在均值，零选择组不可恢复，小概率高方差 |
| F147–149 | 多机会不必更好状态 → 成功p、+1/−2净益3p−2，固定其它人的状态 → p=.5新增者平均损害；均值变好不证明每人变好 |

每种方法从具体缺口、评价对象和差异/残差进入。群体/个体/因果/内容判定不是学习算法，不强加求解器；其中检查的是可测关系及证据条件。训练干预由总体公平要求转经验目标后求解，明确候选、错误代价、混合和独立验收。内容方法为标注与受控检验，不凭空给统计损失；结构不可识别时只报告模型敏感性，不补造因果真值。
