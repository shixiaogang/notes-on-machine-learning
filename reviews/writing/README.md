# 写作审查记录

本目录按用户要求保留可回查、可复核的文字审查证据。记录与正文和现行内容大纲分开；当前待修改项随正文修订继续维护，历史版本优先由 Git 保存。尚未保存到版本历史的受审草案须保留必要输入，不能只留下摘要。执行要求见 [中文写作规范](../../specs/writings.md#可追溯的审读记录)。

## 记录要求

每份记录包含实际正文版本及文件 SHA-256、标签与范围、读者背景、实际读出的主线、段落作用及衔接、具体发现与状态。声明逐句检查时，提供每句话的短引、定位和判断；无问题的句子给出具体接受理由，不能统一填写“通顺”。公式、示例和图注单独计入覆盖。

正文和记录均注明受审版本及可恢复位置。问题编号连接原文、缺口、修改动作、实际改后位置与原文以及上下文复读证据。状态区分待修改、已修改待复读、复读未通过、复读通过和有据撤销。修订关闭须有改后原文及对应版本复读依据，误报撤销须有原文反证和上下文核验；聊天示例不视为已经写回正文。

复核者核对受审版本和原文，检查覆盖与判断依据，并分别给出记录结论和正文结论。正文变化后重审受影响部分，旧记录不能直接证明新版本通过。复核范围以实际读取内容为准，未核查的前置章节、文献、图源或版面必须说明。
