# 信号章真实图像教学配图

这一组图用**同一张**确定性生成的灰度场景（天空、山坡、小屋、树）解释信号处理概念，
全部数值操作只用 NumPy 完成，不依赖 scipy / skimage，可完全复现。

## 复现

```sh
python3 scene.py                  # 生成 scene.npy 与 scene.png
python3 make_real_image_figures.py # 生成六组 figure.{pdf,png,svg}
```

- 场景由解析形状按 $256\times256$、固定随机种子 `20261023` 渲染（见 `scene.py`）。
  平缓的天空/山坡提供低频，屋檐、门窗、树干提供高频边缘，细颗粒提供散在外围的能量。
- `scene.npy` 是六组图共用的唯一输入；脚本从它做 DFT、下采样、卷积、DCT、量化与形态学运算。

## 图与对应正文位置

| 文件 | 概念 | 正文小节 |
| --- | --- | --- |
| `real-image-spectrum` | 二维 DFT：低频在中央、边缘对应外围高频 | 20.1.4.5 多维信号的傅里叶表示 |
| `real-image-dct` | 只留左上角低频 DCT 系数的压缩式重建 | 20.1.4.6 反射边界下的余弦表示 |
| `real-image-filter` | 均值平滑（低通）与 Sobel 边缘（高通） | 20.3.5 网格变化的差分计算 |
| `real-image-downsampling` | 直接隔点抽取与先平均再抽取（锯齿/抗混叠） | 20.3.6 分辨率改变下的多尺度映射 |
| `real-image-quantize` | 连续灰度归到少数几档 | 20.3.7 离散幅度下的信号表示 |
| `real-image-morphology` | 二值化后的膨胀与腐蚀（填洞/扩洞） | 20.3.8 局部集合与灰度的形态映射 |

场景为教学示意，不是真实照片，也不表示某个具体地点。
