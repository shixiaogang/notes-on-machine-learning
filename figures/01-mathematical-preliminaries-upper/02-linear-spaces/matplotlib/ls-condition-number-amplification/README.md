# 条件数放大

回应第 7 章“数值线性代数”中“b 上很小的误差为什么会在 x 上被放大”的读者问题。所有椭圆由固定矩阵对单位圆精确作用求出，是教学构造，不是实验数据。

## 图中元素含义

- 左 panel（良态）：灰虚线为单位圆 `‖z‖=1`；蓝椭圆为它在 `A1=[[1,.2],[.2,1]]` 下的像，半轴即奇异值 `σmax=1.20`、`σmin=0.80`，`κ(A)=σmax/σmin=1.5`。
- 右 panel（病态）：`A2=[[1,.85],[.85,1]]` 的像被拉成细长椭圆，`σmax=1.85`、`σmin=0.15`，`κ=12.3`；细红线为误差圆盘（半径 ε=0.1）的像。
- 误差放大：`Δx=A^{-1}Δb`，最长半轴 `ε/σmin`——良态 0.12，病态 0.67，相差约 7 倍。

## 关键精确值

- `σmax(A1)=1.2000`，`σmin(A1)=0.8000`，`κ=1.5`。
- `σmax(A2)=1.8500`，`σmin(A2)=0.1500`，`κ≈12.33`。
