# 学习框架图

当前正文使用两个可编辑 TikZ 源文件：

- `static-learning-framework.tex`：区分分布构造、采样、目标构造、优化与独立评价。
- `interactive-learning-framework.tex`：行为策略与学得执行策略分阶段连接同一个环境节点，观测/历史与行动使用双向路径。与静态图对应，分别显示轨迹律、经记录映射推前的记录分布、独立采样的可见训练/测试轨迹、目标构造、优化与风险估计；虚线区分总体期望定义和统计分析。图示采样以完整运行之间独立、轨迹损失可由记录计算为条件。

图中文字、数学符号和连线由 LaTeX 编译，沿用共享图像样式。复现方式是在任务工作区运行 `./build.sh all`，图无外部数据依赖。2026-10-08 随第17章的数学对象与问题分类修订重绘。

同目录的历史 PNG 与生成提示词保留为旧版本来源记录，当前正文不再载入这些 PNG。其旧核验记录仅描述历史版本。
