# 图论：读者问题与关系对照

2026-10-06。本组服务于图论章的具体理解难点：关系图为何不保留因子的阶数，消元为何产生填充边，弦如何使邻居成团，条件查询为何需要不同祖先图，流/割如何给出同值证书，匹配如何通过撤回和换边增广，二值割为何只计正向跨割弧，以及局部细化为何不能区分所有整体结构。

八张少量节点的简单数学关系图使用原生 TikZ，直接嵌入正文。每个图源只含正文给定的顶点、边和数值，布局距离不表示边长或容量；其完整关系清单见 [sources.json](sources.json)。共同样式在 [diagram-style.tex](diagram-style.tex) 中局部设置，复用第二卷颜色和字体，普通节点白底、主路径 1.1 pt、轮廓 1 pt、辅助路径 0.6 pt、常规字重。按正文 112 mm 宽度安排，不使用整体缩放或缩字塞图。

谱坐标图使用 Matplotlib，因为四个顶点坐标是拉普拉斯特征方程的精确数值。[spectral-coordinates.py](spectral-coordinates.py) 保存矩阵、解析方向、显示归一化和残差核对；[spectral-data.json](spectral-data.json) 保存全部四点及参数。PDF/SVG/PNG 都由该数值生成，不是统计实验。两方向共同按欧氏范数 2 显示，NCut 的数学问题仍使用度加权内积。

生成环境：Python 3.12.14，NumPy 2.5.3，Matplotlib 3.11.2；沿用 [plot_style.py](../plot_style.py) 的仓库字体、数学字形和第二卷色板。
