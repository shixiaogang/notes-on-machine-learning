# 卷三 TikZ 架构与机制图

本轮按用户明确要求，将48幅原位图架构、流程与机制图重新绘制为原生TikZ，统一20幅已有TikZ示意图。用户要求优先于技能默认的复杂图生成路线。保留图1.1、3.2、13.1的情境插画，以及17幅独立数据图；混合图的自然照片、手写数字和人物场景作为独立局部素材嵌入，框、箭头、文字和机制关系由TikZ绘制。旧图及其生成记录保留以供追溯。

`architecture-manifest.json`登记原资源身份、当前图源、正文位置、引用宽度和字体缩放。`architecture-style.tex`集中维护8pt主体、7.5pt说明、低饱和语义色、模块1.35mm与分组1.7mm圆角、线条和箭头。模块或真实分组保留框；标题和说明不额外套框，不加顶部色带。

首轮统一图元过度简化，未达到原图保真要求；该阶段保存于`aaab22a2`，不作为视觉验收结果。本次修订逐幅恢复真实样本、原有网络层数与可见节点数、叠片、圆柱容器以及具体对象的结构，避免用通用轮廓图标替代复杂图案。网络共享可配置的原生TikZ绘制方法，层数和分组颜色依据原图设置。信封、信纸、脑形电路、文件夹、机械臂等采用可复用的细节图元，照片和人物情境仍仅作为局部素材嵌入。

少量辅助符号取自固定版本的[Lucide](https://lucide.dev/)，原始SVG、源版本、派生说明和许可证均在`icons/`。极短圆端点线在PDF导出中展开为等价圆点，避免转换器丢失骰点、鸟眼或日历点。无需重新下载即可构建。

字体实际加载仓库中的思源黑体Normal、霞鹜文楷Regular和FiraMath，版本、校验值及许可证见`figures/00-shared/academic-drawing/font-manifest.json`和`fonts/`。独立导出以STIX Two补充实际使用的花体及少量缺字，不改变书籍正文字体。两个新生成的Matplotlib面板保留解析数据与独立脚本，以真实字体字形轮廓输出，避免CFF字体的Type42渲染问题。

复现时先运行图11.3、11.6所在目录的`render-panel.py`，再运行本目录的`render-architecture.py`；不带参数导出全部68幅，亦可给出一个或多个图键。工具在当前worktree的`build/volume-three-tikz-redraw/`串行编译，输出各图旁的PDF、SVG、PNG及物理尺寸记录，并检查缺字和导出期间的源文件变化。

`compare-architecture.py`读取重绘前的资源快照（缺省时从基线提交恢复），输出逐图对照PDF；两列采用同一实际引用宽度，重绘侧保留矢量内容。加`--checkpoint aaab22a2`可生成“原图—首轮—保真修订”三列对照，`--keys`可限制图键。每图的局部样本来源、自审和复读记录与图源同目录；书页验收记录放在`reviews/academic-drawing/2026-10-18-volume-three-tikz/`，不以编译通过替代视觉检查。


用户后续指出连线端口与局部样式仍有漏项。本轮从`689bef96`继续修订，逐幅检查实际输入/输出、汇流与反馈，而非仅对齐旧图。普通网络维持原接口；`\VLayerNetTall`在保留每层节点数和圆形节点的同时增大纵向间距，适用于原图中需要较高比例的网络。局部修订与实际书页记录见`reviews/academic-drawing/2026-10-18-volume-three-tikz/connection-followup-summary.json`。

对照工具默认在页首及每个版本栏头标出醒目的图号。示例：`compare-architecture.py --checkpoint 689bef96 --checkpoint-label 上次修订`，以原图、上次修订与本次版本并排比较；可继续用`--keys`限定图组。
