# dim-pca-objective

比较同一组八点在水平方向和实算 SVD 主方向上的正交重构；平均平方残差为 0.8125 和 0.25。

在项目根目录运行 `python3 figures/07-classic-models/00-shared/matplotlib/dim-pca-objective/generate.py` 复现图像、数值数据和检查记录。图像原生尺寸与正文引用均为 159 × 72 mm，主体字号为 8 pt；沿用项目公共色板与真实字体，不改共享绘图工具。

输入与计算结果见 `data.json`，数值断言见 `checks.json`，生成环境与字体见 `generation.json`，来源与校验值见 `provenance.json`。独立图已目视检查，最终书页检查由完整构建完成后补充。
