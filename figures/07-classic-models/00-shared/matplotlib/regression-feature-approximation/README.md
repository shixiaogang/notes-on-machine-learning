# regression-feature-approximation

Compare the entire affine and quadratic candidate spaces with the fixed target x² under Uniform[-1,1]. The affine optimum follows from exact orthogonal projection; neither curve is a fitted sample result.

Reproduce with `python3 figures/07-classic-models/00-shared/matplotlib/regression-objective-figures.py`. The generator uses the actual project fonts and shared palette. The PDF and SVG are vector exports; the PNG is a 220 dpi preview. `data.json` stores the exact example and `generation.json` stores its checks.
