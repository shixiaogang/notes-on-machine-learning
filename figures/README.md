# 图像资源索引

资源采用与 `tex/` 相同的卷、部分目录，再按制作方式分为 `tikz/`、`matplotlib/` 和 `generated/`。输出格式不决定分类：TikZ 的 PDF、SVG 和 PNG 预览仍随图源保存；采样数据与其生成脚本随实际使用它们的图组保存。

跨部分复用的图组、生成器及记录位于各卷 `00-shared/`；跨卷工具可放入根级 `00-shared/`。数学卷共用的 Matplotlib 字体与配色入口为 `01-mathematical-preliminaries/00-shared/matplotlib/plot_style.py`。复杂图组的子目录按内容命名，保留源文件、数据、生成参数与预览。跨部分生成器旁的 `assets.json` 指明各成图的实际归档位置，由 `figures/00-shared/resource_paths.py` 解析；各部分独用的成图不会因为共用脚本而留在共享目录。

## 现有资源

- `01-mathematical-preliminaries/`：六个部分的数学示意图与分析曲线；跨部分生成器位于 `00-shared/`。
- `02-foundations/`：机器学习基础、学习理论、可信性三部分的 TikZ、Matplotlib 与生成式素材。
- `03-models/`：经典模型、神经网络、概率图模型三部分的图源与插画。
- 第四至第六卷目前没有独立图像资源；新增时按实际使用的卷、部分建立目录，不创建空占位目录。

## 使用与追溯

- 以正文实际的 `\input`、`\includegraphics` 和数据路径确认图的用途；所有路径相对项目根目录。
- `generated/` 保留大模型生成素材、提示词、模型信息及修改记录。旧文件名中的 `volume1`、`v1rN` 指旧五卷版本的基础卷，现归第二卷，不是当前数学卷的编号。
- `records/` 中的阶段图号、页码、日期与哈希只描述记录时的版本。迁移后文件路径已更新，历史校验值不代表当前源文件；当前验收使用完整构建和成品清单。
- 当前图的源文件、数据、导出预览和提示词随图保留。已被替换且正文不再调用的素材不留在资源目录；历史记录中的旧素材链接指向清理前的 Git 版本，可在那里追溯。新增资源遵循 `specs/figures.md`。
