# 卷七图源与重绘

当前正文接入113张图：69张简单TikZ图、20张Matplotlib数值图、22张模型无字背景与真实字体排字图、2张混合图。混合图保留原生概念面板与Matplotlib矢量面板。逐图路径、正文位置和物理尺寸见 [redraw-manifest.json](redraw-manifest.json)。未再接入正文的旧TikZ保留作科学内容与修订历史依据，不作为当前成图。

所有命令在任务worktree运行。脚本按祖先中的`build.sh`定位项目根目录；不修改共享书籍字体。

- 原生图：`python3 figures/10-reinforcement-learning/00-shared/tikz/redraw.py --batch <图源.tex> ...`。输出同目录PDF、PNG及尺寸/源哈希记录。混合图先导出`*-mechanism.tex`，再导出组合图。
- 数值图：`python3 figures/10-reinforcement-learning/00-shared/matplotlib/redraw.py`。输出各部分`matplotlib/`中的矢量PDF、300ppi预览、解析式/教学数据和样式记录。模型、坐标范围、采样点和统计聚合由代码与JSON明确；不把教学数据称为实测实验。
- 生成图排字：`python3 figures/10-reinforcement-learning/00-shared/generated/typeset.py`。各图目录保留实际传入的参考、完整提示词、原始/修订背景、坐标配置、可编辑TeX、透明文字层、最终PNG及栅格PDF。排字只合成真实字体文字层，不重画或清理模型背景。模型名称未由内置工具暴露，生成记录如实标注；背景不保证重新随机生成逐像素相同，保留背景后的排字可以重放。
- 字体及许可证：[font-provenance.json](00-shared/tikz/font-provenance.json)。中文主字思源黑体Normal，辅助说明霞鹜文楷；英文数字与数学Fira Math，仅缺失数学字形用STIX Two Math。代码色值依项目低饱和度色板；模型背景以此为目标，实际像素有近似偏差。
- 多智能体动态的六组121点保存在`00-shared/matplotlib/matching-pennies-data.json`，逐点来自保留TeX递推的实际宏值，包含原舍入及平局处理；两幅图共用该份数据。网格价值与占用量复用有理数模型，不从图片反推数值。
- 历史图使用卷四至六实际时间线作构图参考：曲线路径、交错事件、年份层级和主题插图。六个代表年份以正文原始文献为依据，路径不按时间比例，不表示思想之间的直接因果或替代。

资源一致性检查：`python3 figures/10-reinforcement-learning/00-shared/validate.py`。它检查正文绑定、实际参考、源文件和透明排字层哈希、字体及许可证、物理尺寸以及关键教学数值；人工科学与书页检查仍由本轮报告记录。

独立成图的科学关系、标签与字体检查之外，必须检查当前卷PDF中的实际缩放、图注、浮动位置和边注。图内短标注不能替代正文的假设与解释。当前页码和检查证据随本轮审查报告保存，不把旧PDF的通过记录当作当前验收。
