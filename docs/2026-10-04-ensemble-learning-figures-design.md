# 集成学习章节补图设计

## 目标

为集成学习章补充关键机制图，使读者能够从图中看清成员怎样产生、训练信号怎样传递、近似发生在哪里，以及训练与评价数据怎样隔离。保留现有三张总览、OOB和OOF图，新增八张单一职责图。所有图使用TikZ、项目全局色板与语义颜色，不承载未经来源支持的实验数字。

四张比较表在各自浮动环境内设置 `\parindent=0pt`，取消单元格首行缩进，不修改全书表格样式。

## 视觉规则

- `FigureInput`表示数据或观测，`FigureModel`表示成员或模型，`FigureOutput`表示组合输出，`FigureLoss`表示损失、权重和筛选条件。
- 颜色之外同时使用位置、节点标题、实线或虚线区分语义。
- 正文宽图控制在约112 mm，跨栏图控制在164 mm以内；最小线宽0.6 pt，图中文字不小于脚注字号。
- 图注说明图是机制示意，不把教学构造误写成实验结果。
- 跨栏图附近避免密集边注文献；必要引用放在图后正文。

## 验收

1. 运行带Homebrew Biber与TeX Live的 `./build.sh`，完成XeLaTeX、Biber和PDF生成。
2. 新章日志区间无未定义引用、缺字、Overfull或影响阅读的Underfull。
3. 渲染全部新增图所在页面，逐图检查裁切、遮挡、箭头方向、文字可读性和边注冲突。
4. 300 dpi页面预览通过academic-drawing验证器，源文件保留为可编辑TikZ。
