## 主要发现

### CH05-C-R1：PRINCE未区分全部出边与允许删除的边

- 严重程度：主要。
- 状态：已核实问题。
- 维度：内容与论证正确性。
- 位置：第418—428行，`sec:rs-prince`，PDF物理130页。
- 原句：“设$A_u$为可删除的用户出边”；“论文的分解将删除子集后的分差符号化为剩余贡献之和”。
- 问题：正文没有说明$A_u$须是用户的全部出边，读者可以合理地把它理解成全部出边中的可删部分。按此解读，辅助图仍保留不可删边，但后续求和漏掉这些边的贡献，剩余和的符号不再保证对应真实PPR分差。第428行泛称“依赖……可删边范围及归一化条件”，没有给出可检查的条件。
- 一手证据：[PRINCE原论文](https://arxiv.org/abs/1911.08378)§3明言“A be the set of outgoing edges of a user u”；§4定理4.1—4.2、式8—11以全部出边构造辅助图，并利用删边后共同的正归一化因子消去分差比例。定理同时声明用户无自环、所比较推荐节点不属于用户出邻居。实际读取缓存`build/recommendation-writing/sources/r112-full.txt`第190—306行，不是仅核摘要。
- 独立反例：取节点`u,n0,n1,n2,a,b`，`u→(n0,n1,n2)`的权重为`(0.6,0.3,0.1)`，`n0→a,n1→a,n2→b,a→a,b→b`的权重均为1，返回率0.15。只允许删`u→n1,u→n2`，固定`u→n0`。按正文辅助图，两条可删边贡献为0.255和-0.085，删除第一条后剩余和为负；实际重归一化并求PPR却得到`p(a)=0.6192857`、`p(b)=0.1032143`，没有换序。可复核程序为`build/survey-review/ch05-c/check_examples.py`。
- 影响：读者若据此实现对部分历史行为的解释搜索，会把没有改变首选的删除集合当成成功解释。正文教学例的两条边权重和为1，因而未暴露该问题；本发现不反驳原论文算法，也不否定该教学例的算术。
- 最小修订：将本节明确限定在原定理条件，区分全部出边集合与实际删除子集，说明删边后剩余权重的归一化、辅助图处理和比较候选条件，并保留重新求PPR的成功核验。若要允许存在不可删出边，应另外计入其贡献并核验扩展分解，不能直接沿用当前求和。

定级依据是换序判据会产生错误结果，而不是修订字数。缺口只影响这一机制的条件与推理，不要求重构全章。
