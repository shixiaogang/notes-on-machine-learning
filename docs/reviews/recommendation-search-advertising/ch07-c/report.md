## 发现

### CH07-C-R1：低回报的更新方向需要明确相对基准

- 严重程度：次要；状态：已核实问题。
- 维度：内容与论证正确性、结构与文字表述。
- 位置：正文284—290行，`sec:rs-topk-reinforce`，PDF物理168页。
- 短引文：“高回报行动得到更大的概率提升，低回报或低于基线的行动则相反。”
- 问题：紧邻公式使用`G_t`而未减去基线。单条记录中，较低但仍为正的回报仍可提高该行动概率，不能直接和“低于基线”的负优势更新等同。若这里意指多条样本合成后的平均更新，需要明确相对于同状态平均回报的比较。
- 证据：两行动logistic策略中，设被采样行动概率为0.5、回报0.1，则该条记录对其logit的梯度为`0.1(1-0.5)=0.05>0`。步长0.01时，概率变为约0.500125。正文的梯度公式本身没有错误。
- 影响：初学者可能把“回报较小”误当作单条更新为负的条件，混淆原始回报、基线与优势。
- 最小修订：区分正回报的强化幅度、负回报的反向更新，以及减去状态基线后的相对优劣；不必增加新小节。

### CH07-C-R2：可补明理论采样与原论文服务采样的区别

- 严重程度：次要；状态：建议增强，不认定包含率公式错误。
- 维度：深度理解与洞察、结构与文字表述。
- 位置：正文276—305行，`sec:rs-topk-reinforce`，PDF物理167—168页。
- 短引文：“方法从$p_\theta$独立有放回抽样$K$次，再删除重复物品。”
- 观察：本段准确讲出了理论抽样；282行只说明采样softmax的训练近似，尚未明示原服务过程与全目录抽样不同。
- 证据：[Top-K原论文](https://arxiv.org/abs/1812.02353)第4.3节PDF5页给理论包含率；第5节PDF6页说明先以近邻检索取得`M`项并重新归一化，实际还保留`K'`个确定性高分项，再从其余项抽样。
- 影响：补出这一区别，有助于读者把概率公式接到可执行大目录策略，并理解为什么截断、混合和下游排序都需要重新核验覆盖与概率。
- 最小增强：用一两句标明理想化采样及服务近似；索引实现仍留系统卷，不展开完整服务工程。
