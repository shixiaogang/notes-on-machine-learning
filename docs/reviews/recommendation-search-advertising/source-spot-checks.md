# 主代理定点证据复核

本记录用于解决独立评审中的高影响发现及分歧，不替代三位审阅者的完整七维评审。仅记录实际读取的材料与复核结果；不将来源缓存等同于已读全文。

## 第02章：会话基础路线

- 文内读取：`02-user-item-understanding.tex`1—175行，含模型接口表、GRU4Rec、SASRec、BERT4Rec、SR-GNN和DIN开头。
- 外部来源：Ludewig与Jannach，*Evaluation of Session-based Recommendation Algorithms*，https://arxiv.org/pdf/1803.09587v1.pdf 。实际读取本地原文提取`build/survey-review/ch02-a/session-evaluation-2018-v1.txt`270—330、640—830行，对应§3.2、§4的调参和数据说明、§5.1表3。
- 机制证据：§3.2.2以当前整个会话与历史会话比较，取相似会话后按其中物品加权；这与§3.2.1以物品共现寻找物品近邻不同。两者不能只因都叫近邻就互相替代讲解职责。
- 实验证据：表3的RETAILROCKET上，s-sknn的MRR@20为0.3450，GRU4Rec为0.2427；RSC15上GRU4Rec的HR@20为0.6827，s-knn为0.6213。方向依任务和指标不同，并不支持近邻普遍胜过循环模型。
- 条件：除RSC15-S外，报告五个切片平均；GRU层宽及SMF因子数限制为100，其他参数随机搜索100次；简单近邻使用相同验证集人工调整邻居数和样本数。因此修订宜写成有条件的竞争证据，不能只移植胜负数字。
- 裁定用途：支持“应补会话近邻/转移等基础路线的入口及持续竞争证据”；不要求展开所有非神经模型，也不据此否定已有神经模型机制。

## 第02章：TOP1正则动机

- 文内位置：`02-user-item-understanding.tex`76—88行，式`eq:rs-gru4rec-top1`后：“避免只靠整体抬分降低相对比较项。”
- 代数检查：对任意公共常数\(c\)，\(\sigma((s_j+c)-(s_{i^+}+c))=\sigma(s_j-s_{i^+})\)。共同抬分不会降低该项；公式本身无需因此改变。
- 外部来源：Hidasi等，*Session-based Recommendations with Recurrent Neural Networks*，https://arxiv.org/abs/1511.06939 。实际读取`build/recommendation-writing/sources/r10-full.txt`275—335行，§3.1.3。
- 原文解释：优化正例分数使其上升，但有些正例同时充当其他样本的负例，分数会持续上漂；作者加入使负例靠近零的正则。它描述训练中的分数漂移，并没有声称公共平移改变相对次序损失。
- 裁定用途：接受为局部已核实的机制解释错误。最小修订是改动机说明，保留现有TOP1公式；严重程度待与全章发现一并综合。

## 第04章：BPR分差与不确定性
