## 主要发现

### CH02-A-R1：会话建模缺少非神经基础与竞争路线

- 严重程度：主要；状态：已核实问题；维度：全面性与无偏性、演进脉络。
- 位置：34—68、98—157行，`sec:rs-user-understanding`；表2.1与表2.2（38—62、504—525行）亦体现相同选材。
- 短引文：“先比较常用模型的完整接口”；“匿名访问没有可用的长期用户向量，但当前会话中的连续点击仍然提供了线索。”
- 问题：本节从GRU4Rec进入21个神经模型，却没有介绍会话近邻、简单转移/序列规则及马尔可夫混合路线，也没有给出其中会话近邻路线仍有竞争力的实证。重点讲神经网络可以成立，但这组遗漏会影响读者对匿名会话可选方法及神经模型出现背景的认识，不只是少引一篇论文。
- 证据：[SASRec原文](https://arxiv.org/abs/1808.09781)引言及§III-G明确讨论MC与RNN的取舍，并给出FMC/FPMC退化关系；[序列综述](https://arxiv.org/pdf/1802.08452v1)§4、表3及§4.3保留这些路线。[Ludewig与Jannach的直接比较](https://arxiv.org/pdf/1803.09587v1.pdf)§3.2.2以当前会话寻找历史会话近邻；表3中RETAILROCKET的s-sknn MRR@20为0.3450，GRU4Rec为0.2427；同时RSC15的GRU4Rec HR@20为0.6827，高于s-knn的0.6213。其GRU调参有维度≤100及100轮随机搜索等条件，不能外推为近邻普遍胜出。
- 跨章排除检查：第03章54—107行讲用户/物品邻域，110—153行讲MF；ItemCF访问历史物品的邻域，不等于以会话为比较单位的session-kNN。无需重讲CF/MF，但当前跨章分工没有补上这一缺口。
- 影响：方法空间被缩为神经网络内部选择，早期路线及其持续竞争不可见。
- 最小修订：在GRU4Rec前补一段转移统计/马尔可夫与会话近邻的机制定位，在比较表补一至两行；给一个带数据条件和相反结果的实证对照。FPMC/Fossil在上述会话评测中表现较弱，可作历史与假设边界的背景链接，不必各新增长节。

### CH02-A-R2：用训练配方复核具体化“公平比较”

- 严重程度：次要；状态：建议增强；维度：深度理解与洞察。
- 位置：109—136、801行，`sec:rs-bert4rec`。
- 短引文：“模型擅长何种历史条件，应由同一信息边界下的比较确定。”
- 观察：SASRec单负例BCE和BERT4Rec目录交叉熵已正确讲出，但还可解释比较架构时怎样隔离损失函数、负例数和收敛预算。现有文字没有声称双向模型必胜，因此不判为技术错误或主要证据缺口。
- 证据：[Turning Dross Into Gold Loss](https://arxiv.org/pdf/2309.07602v1)§3—5、表2：ML-1M的NDCG@10由原SASRec的0.1341变为使用目录交叉熵的SASRec+的0.1821，BERT4Rec为0.1537；但Steam仍是BERT4Rec更高。原文采用全目录评价，并分别说明最大训练轮数、早停与负例设置。
- 影响/最小修订：补一段带条件的复核案例，将“固定信息”扩为分别控制架构、目标、损失、负例和训练预算；不把该结果改写成“单向普遍优于双向”。

### CH02-A-R3：给选择性状态空间路线一个入口

- 严重程度：次要；状态：建议增强；维度：全面性与无偏性、演进脉络。
- 位置：228—412行，重点401—412行，`sec:rs-longer`。
- 短引文：“因而长上下文能力要同时检查信息粒度、训练范围与服务预算，不能仅用最大输入长度衡量。”
- 观察：本章已覆盖递推记忆、检索、哈希、簇及层内压缩；现代选择性SSM可以说明另一种改变序列计算算子的路线，但章节没有承诺穷尽架构，故仅建议增强。
- 证据：[Mamba4Rec v1](https://arxiv.org/pdf/2403.03900v1)§2—3以输入相关选择性状态空间模块建模，§4报告设置与效率。其最大序列长度为50/200，不能凭这些实验宣布比本章工业超长CTR方案更优。
- 影响/最小修订：补一行路线定位或延伸阅读，区分“改变序列算子”与“先选历史/压缩历史”；无需扩展为新模型长节。
