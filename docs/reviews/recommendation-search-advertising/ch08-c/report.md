## 已核实问题

### CH08-C-R1：未转义百分号使KuaiRec段落失文

- 严重程度：次要。维度：结构与文字表述、内容与论证正确性。
- 位置：`08-evaluation.tex:L177`，`sec:rs-evaluation-kuairec`；PDF物理183页，纸面171页。
- 原句：“报告的交互覆盖约为99.6%；仍有用户屏蔽作者等造成的缺口，因此‘近全观测’更准确地描述实际反馈范围。”
- 证据：ASCII `%`未写作`\%`，其后整行被LaTeX当作注释。已放大观察PDF，该段实际止于“报告的交互覆盖约为99.6”，没有百分号、缺口说明或句号。KuaiRec原论文表1及§3.1.1确认99.6%及屏蔽原因（[原文](https://arxiv.org/abs/2202.10842)）。
- 影响：成书读者看不到比例单位，也看不到本段对“近全观测”的关键解释；不能以源文件有这段话视为已经交付。
- 最小修订：仅转义该百分号，保留后半句；由后续修改者重新生成PDF并确认整句恢复。本次未编译。

### CH08-C-R2：AUC不变性的条件应为严格递增

- 严重程度：次要。维度：内容与论证正确性。
- 位置：`08-evaluation.tex:L65`，`sec:rs-evaluation-prediction`；PDF物理179页。
- 原句：“严格单调变换不会改变这个次序。”
- 证据：一个正例得分0.8、负例0.2时AUC为1；施加严格递减变换`f(s)=1-s`后，得分变为0.2与0.8，AUC为0。反例直接符合前句的AUC定义。
- 影响：将“保序”误扩展到所有严格单调变换。相邻教学例子与AUC、交叉熵、Brier计算均正确，问题局限于该性质的限定。
- 最小修订：将“严格单调”收窄为“严格单调递增”。

### CH08-C-R3：DR动机段提前把IPS的加权结果称作残差

- 严重程度：次要。维度：结构与文字表述、内容与论证正确性。
- 位置：`08-evaluation.tex:L284`，`sec:rs-evaluation-dr`；PDF物理188页。
- 原句：“IPS减少这类建模依赖，但稀少行动的残差会被大权重放大。”
- 证据：本章式(8.9)、L238—244的IPS贡献是`w_n y_n`，没有结果预测器或残差；式(8.12)才引入`y_n-m_hat(x_n,a_n)`。Dudik等原论文§2.1—2.2也作此区分（[原文](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/02/double_robust.pdf)，PDF第3页）。
- 影响：首次阅读时，读者可能误以为IPS已经需要结果模型，削弱从直接预测、IPS到DR的机制对照。后文公式和图8.1没有同样错误。
- 最小修订：此处称“观测结果”或“估计贡献的波动”，再在DR定义中引入残差；无需调整小节结构。

## 补充建议

**CH08-C-R4：把实验完整性原则落实为一次样本比例检查。**

- 严重程度：次要。维度：全面性与无偏性、深度理解与洞察。状态：建议增强。
- 位置：`08-evaluation.tex:L350—354`，`sec:rs-evaluation-randomized`。原句：“记录计划行动和实际执行。”
- 证据：正文已讲超时删样和处理后筛选，但没有说明如何从实验日志发现这些问题；全书对应统计入口也未给实验样本比例失配检查。Microsoft ExP的[一手说明](https://www.microsoft.com/en-us/research/articles/diagnosing-sample-ratio-mismatch-in-a-b-testing/)记录了机器人过滤删掉高参与处理用户、导致效果方向反转的案例，并介绍按设计比例检查用户计数的方法。
- 价值：将已有原则补成读者可以执行的诊断，不改变章内分类，也不是因漏引某篇论文而判覆盖不足。
- 最小方向：增加一小段说明按独立分配单位核对设计与实际入样比例，报警后追查分桶、执行、回传、连接和筛选；明确无报警不证明所有偏差消失，不机械沿用某平台阈值。
