## 发现

### CH03-C-R1：可为目录路线补一处横向导航

- 严重程度与状态：次要；建议增强。
- 维度：结构与文字表述、深度理解与洞察。
- 位置：正文L38、L46—405，`sec:rs-directory-retrieval`。
- 原句：“一个候选模型必须同时交代输入、学习目标、分数和访问方式。”“下列模型的机制并不互斥。”
- 观察：19个目录实现各自讲清了机制，但预计算对象、在线访问和更新代价的横向比较散在多个小节。标识路线有表3.3，目录路线没有同类导航。
- 证据：本底稿同级职责矩阵；正文L130的偏置增广、L217的同预算比较、L248的图更新、L267的树裁剪、L392—405的生成输出与代价。其职责和交叉关系均成立，不是分类混列。
- 影响：初读者需要跨多页自行整理“学到什么、如何访问、何时刷新”的对应关系，回顾时查找负担较高。
- 最小方向：在目录路线末尾增加短导航或紧凑小表，复用已有结论。无需改动父子层级、扩写模型或增加装饰图。

### CH03-C-R2：可增加可学习线性邻域作为简短对照

- 严重程度与状态：次要；建议增强。
- 维度：全面性与无偏性、演进脉络。
- 位置：正文L95—113或L336—348，`sec:rs-itemcf`、`sec:rs-mult-vae`。
- 原句：“物品邻域表可以离线预计算，共现计数或评分变化后再更新。”“只要用户已有少量行为，就可以由共享编码器直接计算其潜在状态。”
- 观察：现有内容覆盖固定相似度邻域、因子和非线性集合重建，但没有明确展示“学习物品间线性权重”这一连接前后两类方法的简洁对照。
- 证据：[EASE原文](https://arxiv.org/pdf/1905.03375v1)§2—3，式1—8：以交互向量乘物品权重矩阵评分，学习时限制零对角；§3.4明确讨论矩阵能否放入内存的条件。实际读取PDF物理1—3页，不以摘要或未经核验的实验数字证明优越性。
- 影响：补充后有助于读者理解“可学习”并不必然意味着低维因子或深网络。本章没有宣称深模型必胜，故现状不构成关键遗漏。
- 最小方向：补一个短段及一条EASE引文，说明目标、零对角约束和目录矩阵代价。无需另开长节或追补全部后续工作。
