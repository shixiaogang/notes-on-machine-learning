## 第一遍：重建内容

以下保留第一遍形成的观察及当时待核点；最终处理见第二遍台账、排除项和第三遍判定，不将早期疑点视为未完成任务。

主线：从“不能逐件精看大目录”出发，先区分资格、取得与展示，再研究不同模型怎样产生可访问分数或标识；各路输出经过集合与状态管理才成为候选。训练对照不是拒绝证据，离线命中也不是完整用户价值。结论适用于已定义目录、请求时间、名额和资源条件，不承诺真实偏好识别或无偏决策效果。
