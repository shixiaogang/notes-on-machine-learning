# 推荐、搜索与广告：综合评审

总体结论：部分通过，需修订后复核。十章各由三个独立subagent完成评审，共30份完整七维报告；主代理完成证据复核、逐章综合与跨章去重。

## 范围与方法

送审对象是中文机器学习教材的十章教程式综述，领域时间边界为2026-10-05。源文件、书目、大纲、图源与323页应用卷PDF按[冻结清单](manifest.json)识别；各审阅者另记实际检索日期和来源访问范围。正文所在工作树为`.worktrees/latest-main-20261005-3`。

按用户要求，每章安排三个独立subagent，共30个任务。A侧重领域覆盖、演进与分类，B侧重技术条件、推导与来源，C侧重读者理解、章节职责和图表；每个人都须完成三遍正文阅读、独立相关工作检索和完整七维评审。每份评审保留报告、底稿与结构化发现，职责矩阵、论证链及适用图表行列检查是结构判断的前提。任务与独立代理ID见[登记表](task-registry.json)，具体要求见[评审说明](README.md)。

主代理按原文承诺、直接证据和缺陷影响复核、去重并裁定分歧，不按三人多数票决定。主代理的[定点来源复核](source-spot-checks.md)和[跨章接口检查](cross-chapter-notes.md)是补查，不算第31份完整评审。本文评教材的代表性、机制与边界，不要求穷尽增量论文，也不以此前编译或写作自查通过作为质量证据。

## 去重与分歧处理

- 同一根因在三人报告中重复出现，只计一次。第04章与第08章的保序条件合并为X02；严格递减会反序，非严格变换还可能产生并列，不能仅补“严格”二字。
- 第06章三组EF1反例合并为一项。A将章级正确性判为不通过，综合判部分通过：反例否定该方法保证，但不否定已有直接核验的其他协调机制。该问题仍须修复。
- 第08章采纳B提出的推断条件缺口，尽管A/C原判通过。主代理独立复算了辅助量均一致、偏差仍主导标准误的例子，保留正确DR与方差公式。
- 第02章会话近邻、第03章融合完整操作例、第05章方面覆盖与二维布局均保留具体增强建议。它们能改善教学，但现有正文没有由这些缺口推出被证伪的普遍优越性或等价性；不一律升级为确定的方向遗漏。
- 第09章三人均指出RF/PRF缺失；A另要求把真实结果综合列为主要问题，综合将后者保留为优先增强。BEIR等证据已复核，但现有教程的机制、标签和访问条件已支持具体取舍，不因缺少成绩表便否定主要洞察。
- 第10章ESCM²采纳B的主要等级；其余审阅者的较轻或通过意见不能排除直接梯度反例。延迟路线采纳A的主要覆盖意见，理由是两条路线改变可用观测与监督选择。MinPacing按正式定理修正漏掉的对数因子。
- 主代理新增的SEATER历史输入和标识生成评价协议问题单独标明来源，不回写成某位独立审阅者已经发现。

## 建议增强与修订顺序

增强项集中在三个方面：增加有任务、调参与指标边界的强基线或负面实证；补完融合、方面覆盖及页面布局等操作例；收拢模型导航与跨章回指。各章已经保留来源和选材理由，不建议把检索得到的全部论文都加入正文。

修订先处理FairRec保证、PRINCE判据、LONGER结构、ESCM²梯度与DR推断。随后补概述的解释与历史依据、搜索反馈和广告延迟路线，再统一局部条件、标签与跨章口径，修正MinPacing界，恢复第08章因未转义百分号丢失的正文。最后按阅读收益选择增强项，并在实际修改后复核公式、图表、引用和PDF，包括第10章章末孤行。本轮仅交付诊断，没有执行正文修订。
