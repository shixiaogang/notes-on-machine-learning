## 主要发现

### CH04-C-R1：保序需要严格递增，不能泛指任意单调

- 严重程度：次要。状态：已核实问题。维度：内容与论证正确性、结构与文字表述。
- 位置：第12行，`sec:rs-ranking-task`。
- 原句：“任意单调变换都保持排序次序，却会改变概率解释。”
- 证据：对分数`(1,2)`施加单调递减变换`g(s)=-s`会反序；单调不减但非严格递增的变换可能合并名次；恒等变换不改变概率。正文未预先将“单调”限定为严格递增。
- 影响：这是概率与次序的首次区分，量词过宽会使读者误记保序条件；不影响这一段要区分两种评价的正确目的。
- 最小修订：明确“严格递增变换保留次序”；把概率变化改为“经sigmoid后的概率值通常改变，校准仍须单独检验”，避免新的全称断言。

### CH04-C-R2：分差降低不等于次序更不确定

- 严重程度：次要。状态：已核实问题。维度：内容与论证正确性、结构与文字表述。
- 位置：第123行，`sec:rs-bpr`，式`eq:rs-bpr`之后。
- 原句：“分差越小，正负次序越不确定，$-\log\sigma(\Delta)$越大。”
- 证据：正文定义的是有符号分差。`Delta=0`时偏好概率0.5、二元熵约0.693；`Delta=-10`时偏好概率约0.0000454、熵约0.000499，模型更确信相反次序，损失却增至约10.000。反例及数值存于底稿和`numeric-results.json`。
- 影响：混淆“对正例领先的支持降低”“确信排错”和“比较不确定”；损失随分差降低而增大的结论以及后续梯度更新均正确。
- 最小修订：改为“分差越小，模型给予正例领先的概率越低，损失越大”；若保留不确定性解释，另说明分差接近零时两种次序最难区分。

### CH04-C-R3：可用实际竞争证据补强模型比较

- 严重程度：次要。状态：建议增强。维度：全面性与无偏性、深度理解与洞察。
- 位置：第343—361、576—580、1083—1087行；`tab:rs-feature-models`、`sec:rs-finalmlp`、`sec:rs-scoring-evaluation`。
- 原句：“不同共享限制没有脱离数据条件的统一优劣次序。”
- 证据：正文详细比较18种字段模型，FinalMLP也解释了双分支机制；但比较主要停留在机制、成本和应采用的协议。[BARS-CTR](https://arxiv.org/pdf/2009.05794v6)实际读取§3.2.6—3.3，提供统一协议和重调后模型差异缩小的证据；[FinalMLP](https://arxiv.org/abs/2304.00902)实际抽样式(1)—(9)及实验表2—3，提供MLP、DualMLP强对照。
- 影响：读者已能比较计算结构，但仍需自行寻找“为何先做好简单基线”的经验依据。因为正文已经明确禁止无条件性能外推，本项不定为关键遗漏或“复杂模型必胜”的错误。
- 最小增强：在字段比较或FinalMLP之后加一小段实证综合，注明数据、指标、调参协议与结论边界。无需扩充模型清单，更不能由这些实验反推MLP普遍最优。

### CH04-C-R4：表4.2可显式标出联合骨干示例组

- 严重程度：次要。状态：建议增强。维度：图表呈现、分类整理。
- 位置：第644—652行，`tab:rs-scoring-reuse`；PDF物理102页。
- 原文行名：“分离模块融合”“MTGR”“OneTrans”“MixFormer”。
- 证据：首行是组织类别，后三行是另一类别的具体模型；第596行已明确将后三者归入联合骨干。真实PDF中各行及列内容完整清晰，没有错误父子关系或裁切。
- 影响：单独阅读表格时，需要回正文恢复类与实例的层级；结合正文后比较仍成立。
- 最小增强：给后三行加“联合骨干示例”组名，或在组织列中标明该上位类别，不必改变正文分类。

### CH04-C-R5：校准段宜补主讲位置导航

- 严重程度：次要。状态：建议增强。维度：结构与文字表述。
- 位置：第944—955行，`sec:rs-score-calibration`。
- 原句：“概率校准要求预测值与同类机会中的响应频率对应。”
- 证据：本段说明校准的含义与检查，随后具体方法是PRU不确定性估计。本轮实读CH10第346—386行，已有校准拟合、ILPS与字段修正；卷二`02-reliability.tex`第154—187行已有独立校准集与温度缩放。不是全书缺少校准机制。
- 影响：首次学习本章的读者知道要校准，却不容易找到怎样拟合校准器；可能误把后接的PRU当作操作示例，虽然第964行已明说PRU不是概率。
- 最小增强：在校准定义后加通用校准或CH10主讲位置的准确交叉引用，并保留“校准与不确定性不同”的现有说明。
