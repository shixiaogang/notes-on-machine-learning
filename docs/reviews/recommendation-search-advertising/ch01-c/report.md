## 主要发现

### CH01-C-R1：核心比较依赖后文才解释的术语

- 严重程度：主要。
- 维度：结构与文字表述。
- 位置：正文L108—133，`sec:rs-development`；关联L70、160、164。PDF物理19、21—23页。
- 短引文：“FM和FFM通过潜在向量共享交互参数”；表1.2列出“字段交互”“评分骨干”“响应头”“梯度路径”；L133直接比较“召回、粗排和精排”。
- 问题：这些并非可跳过的文献标签，而是本章要求读者据以判断“方法改变了什么”的坐标。FM/FFM未给中文名称，字段没有例子，粗排与精排未在当前阅读位置说明；前沿中的集合错误风险、聚合媒体响应曲线也缺少最短解释或准确入口。
- 证据：全章前三节只建立一般分数、排序和候选。第04章L188、196、221、970才分别解释字段、FM、FFM和粗排精排；第06章L329—369才定义集合错误与平均风险；第10章L1305—1307才引入媒体组合模型。前四卷及本卷前两部分的定向检索未找到FM/FFM或推荐字段的此前定义。底稿K01和跨章边界表保留了实际读取范围。
- 影响：首次接触推荐的读者可以读懂“不能等同”的结论，却难以说明被比较对象究竟是什么，削弱章首“能够指出输入、输出或学习关系变化”的学习目标。
- 最小修订：在关键对比前用当前商品例解释字段与评分骨干，给FM/FFM中文名称，简述粗排/精排的预算差别并链接主讲节。对风险和聚合测量只留一句可理解的目标说明及入口；不搬入模型推导，也不继续加模型清单。
- 状态：已核实问题。

### CH01-C-R2：基础路线有机制分类，缺少历史锚点与转折证据

- 严重程度：主要。
- 维度：演进脉络。
- 位置：正文L103—139，`sec:rs-development`，尤其L106—112；PDF物理21—22页。
- 短引文：“方法的发展可以沿几个长期并存的问题理解”；“后来加入的深层网络”；“目录规模推动了另一条路线”。
- 问题：按问题组织并存路线是合理的，但基础四段没有对应的代表工作、时间定位或直接来源，读者难以将变化放回可追溯历史。本节的具名详解集中在OneTrans/V2与OneRec，只有V2在正文明确年月；表1.2主要是改动范围检查表，不能代替发展证据。
- 证据：原文L106—112没有引文或主讲节交叉引用；独立读取的[GroupLens原文](https://www.presnick.people.si.umich.edu/papers/cscw94/GroupLens.htm)有1994年来源及与Tapestry、内容过滤的比较；[libFM作者页](https://www.libfm.org/)定位FM的ICDM 2010及后续变化；[FFM原文](https://www.csie.ntu.edu.tw/~cjlin/papers/ffm.pdf)§1—3交代PITF、2012竞赛背景与2016年的系统整理；[YouTube原文](https://storage.googleapis.com/pub-tools-public-publication-data/pdf/45530.pdf)§3开头明确其候选模型与原矩阵分解方案的承接。均可提供少量有据锚点，而非推测历史动机。
- 影响：现文足以解释“有哪些改动”，却只部分回答“这些问题与方法怎样发展”；新方法有具体身份，基础和并行路线则停留在泛称。这里是历史证据缺口，不是已发现年代错误，也不等于全书没有这些基础方法。
- 最小修订：保留问题驱动结构，在主要路线各补少量“时期/代表工作—原问题—改变及保留限制”的锚点，并链接后续主讲节。说明年份是代表工作的时间，不是路线唯一源头；无需扩成年表或增加大量增量论文。
- 状态：证据缺口。

### CH01-C-R3：图1.3的“交接结果”图注与动作节点不一致

- 严重程度：次要。
- 维度：图表呈现。
- 位置：正文L151—157，`fig:rs-interface-comparison`；图源`figures/rs-interface-comparison.tex` L9—24；PDF物理23页。
- 短引文：“框中的对象是实际交接结果”；图内实际写有“目录访问”“逐候选评分”“列表组织”“核验与展示”。
- 证据与问题：已直接观察渲染图，而非只读图源。框内混合输入、处理动作和输出，第一行也未像后两行那样标出历史与条件。其作为流程示意可读，但不能完全按图注声称的数据交接图理解。
- 影响：读者需要自行推断箭头传递的是候选、分数、代码还是列表。此问题不推翻三种配置的技术区分，也不构成遮挡或排版失败。
- 最小修订：统一节点与箭头的职责，例如框保留处理动作、箭头标交接产物，并补一致的请求/目录输入；同步修正图注。无需新增图或改变三行代表配置。
- 状态：已核实问题。
