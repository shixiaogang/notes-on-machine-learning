- 机制缺口：去重使“对方稍后所选项”不一定仍在自己的允许集合里，不能逐轮把自己的选择与对方选择直接配对。原论文Proposition7.1和Lemma7.2.1也使用这一配对依据；原文声明不是该保证成立的充分证据。
- 影响：破坏6.2.3.2的用户侧保证及428行总结，不推翻产品侧计数保证或本章全部协调原则。
- 最小方向：撤下无条件EF1结论及当前配对说明；明确引用论文的声称与本章实际可验证保证，若要保留EF1须改用有证明的分配机制并重新验证。
