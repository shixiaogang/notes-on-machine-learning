# CH05-a 推荐展示独立评审

## 范围与总体判断

审阅`tex/05-applications/03-recommendation-and-search/05-presentation.tex`全文1—674行，完整三遍；观察既有应用PDF物理117—140页中的全部3幅图、3张表。送审正文、书目和PDF哈希与manifest一致。研究时间边界2026-10-05，实际检索2026-10-06。按中文教材教程式综述评审，不要求穷尽论文。

本章的五维结构、方法输入输出边界和多数机制讲解成立，未发现已核实的技术或算术错误。主要问题是两项已经进入本章范围的内容没有展开到可操作程度：**显式方面覆盖**与**二维页面组织**。这不是“少收了几篇新论文”，也不需要推倒五维框架。用户体验的竞争实证可以补强，但现有谨慎结论不因此成为错误。

## 主要发现

### CH05-A-R1：方面覆盖缺少对应的显式选择机制

| 字段 | 评审结果 |
| --- | --- |
| 严重程度/状态 | 主要；已核实问题 |
| 维度 | 全面性与无偏性、深度理解与洞察 |
| 位置 | `05-presentation.tex` 54—125、321—374行；`sec:rs-content-organization`、`sec:rs-mmr`、`sec:rs-calibrated-recommendations`；PDF物理119—121、127—129 |
| 原文 | “方面覆盖则要求照顾当次需求中的多个部分”；“最大相似度只惩罚某一种重复，不保证所有需求方面都有代表” |
| 问题 | 正文正确提出差异与需求覆盖不同，却只展开相似惩罚、集合体积和兴趣比例匹配，没有给出按“尚未满足的方面”计算选择增益的显式覆盖机制。读者知道MMR不保证什么，但不知道该需求该用怎样的模型回答。 |
| 证据 | MMR式(5.3)与DPP式(5.4)围绕关系差异；两种校准围绕比例散度。独立读取[Kaya/Bridge 2018](https://www.cs.ucc.ie/~dgb/papers/Kaya-Bridge-2018a.pdf)“Intent-aware diversification”式(2)/(5)及SPAD部分，直接展示方面权重、方面相关性、未覆盖乘积与继续浏览假设的不同作用。底稿S07/S08、覆盖矩阵有对照。 |
| 跨章排除 | 第3章210—219、622—633行讲多兴趣候选和类别增益，并明确类别差异不等于需求差异；第9章790—812行又回指本章MMR；第6、8章没有补出该组织机制。 |
| 影响 | 领域地图容易把“需求覆盖”实际收缩成“差异或历史比例”，无法比较覆盖一个方面与按比例多次满足该方面两种不同目标。 |
| 最小修订 | 在内容组织内增加一个显式方面覆盖的代表机制，说明输入、剩余方面增益和假设，用现有背包例手算一次选择，并与MMR及比例校准对照。不必新增大节或穷举xQuAD/SPAD等全部工作。 |

### CH05-A-R2：二维页面组织停留在变量说明

| 字段 | 评审结果 |
| --- | --- |
| 严重程度/状态 | 主要；已核实问题 |
| 维度 | 全面性与无偏性、深度理解与洞察 |
| 位置 | `05-presentation.tex` 377—394行，`sec:rs-position-allocation`；范围承诺见17、35行；PDF物理129—130 |
| 原文 | “位置还包括二维布局和模块密度”；“应记录真实区域、行列、滚动位置和可见范围” |
| 问题 | 本节走通了固定位置价值下的指派，也解释其不足，但对二维页面仅比较首屏广告占比和提出日志要求。没有展示栏目/模块怎样形成、栏目之间与栏目内部怎样安排、跨栏目重复和语义一致性怎样影响选择。此前整页广告例固定自然内容与版位，不能代替这一展开。 |
| 证据 | 式(5.16)固定可加对象—位置价值；392行指出更一般的整组求解但未继续展开。独立读取[Full-Page Recommender 2025](https://dl.acm.org/doi/pdf/10.1145/3705328.3748753)§1—3.3，核到物品评分、集合/栏目构造和栏目布局的不同任务，以及栏目内一致性与跨栏目差异。此文仅作为问题分解实例，不作为成熟最优方法或必须纳入的增量论文。 |
| 影响 | 读者能交换单列对象，却仍无法从已有分数形成一个体现模块关系的简单页面。图5.1的“模块与首屏范围”缺少相应的教学求解例。 |
| 最小修订 | 补一个两栏目、每栏两项的小例：明确栏目候选、可见/浏览假设、同页重复及栏目一致性，比较两种可执行布局；可以复用现有组合求解，不必引入复杂工业网络。 |

### CH05-A-R3：用人类研究补强代理与体验的区别

| 字段 | 评审结果 |
| --- | --- |
| 严重程度/状态 | 次要；建议增强 |
| 维度 | 全面性与无偏性、深度理解与洞察 |
| 位置 | `05-presentation.tex` 658—664行，`sec:rs-display-experience`；另见336、402、491行；PDF物理140 |

| 影响/建议 | 能让“不能等同”的边界更具体。选一项正负并存的研究，说明任务、人群、干预、观察量及未证明什么；不需要在本章重复第8章统计协议。 |

## 关键遗漏与修改顺序

1. 补齐R1显式方面覆盖机制。缺口是方向展开，不是指定论文缺席；同时可简短区分列表差异、用户新颖性与意外且有用的发现。
2. 补齐R2二维模块组织的小型求解与比较例。保留现有指派式的适用条件，不把所有布局都强行化为独立位置收益。
3. 按R3加入一项有边界的人类实证对照，再调整相关过渡或表5.1摘要。无需增加增量模型清单，也无需改动本章五维结构。
