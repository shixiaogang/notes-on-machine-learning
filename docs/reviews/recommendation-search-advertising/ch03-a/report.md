## 发现

### CH03-A-R1：DCGR的金额标签应明确为订单均价档位

- **级别/状态/维度：** 次要；已核实问题；内容与论证正确性、结构与文字表述。
- **位置/原句：** `tex/05-applications/03-recommendation-and-search/03-candidate-retrieval.tex` L485—487，`sec:rs-dcgr`，PDF物理68—69页：“消费金额还依赖前面的购买信息，放在后续位置。”
- **证据：** [OneTrans-V2](https://arxiv.org/abs/2609.28589) §4.2.1、PDF p7明确将`z_oc`定义为order count档位，将`z_aov`定义为“average order value”“the value range of each order”；特意不用单一GMV标签，以区分多笔低价订单与一笔高价订单。本次已读取原文，缓存为`build/survey-review/ch03-a/onetrans-v2.pdf`。
- **影响：** “购买/消费金额”的泛称不能恢复原方法的数量与单价分解，读者可能把依赖标签实现为交易总额。并行前缀、联合束搜索和软偏置的主体讲解仍成立。
- **最小方向：** 首次出现改用“购买数量档位”和“订单均价档位（AOV）”，补一句两者与总交易金额的区别；不需重构本节。

### CH03-A-R2：可补TIGER原生冷启动回退与LIGER的短对照

- **级别/状态/维度：** 次要；建议增强；全面性与无偏性、演进脉络、深度理解与洞察。
- **位置/原句：** 同一正文L466，`sec:rs-tiger`；关联L575—579：“新物品若具有可用内容，可以编码，但能否在既定解码策略下被生成还取决于训练、消歧和候选覆盖。”
- **证据：** [TIGER原文](https://proceedings.neurips.cc/paper_files/paper/2023/hash/20dcab0f14046a5c6b02b61da9f13229-Abstract-Conference.html) §4.3会将与预测码共享前三个语义词元的新物品加入候选，并用epsilon限制新物品最大占比；不是要求新物品完整四位码必须被直接生成。[LIGER作者稿](https://arxiv.org/abs/2411.18814) §2.4讨论这一安排，§3算法1则显式合并冷启动集合后作稠密比较。两篇相应正文均已读取。
- **影响：** 现有谨慎结论正确，但读者尚不清楚两种实际“补新物品”策略的区别；容易只记住LIGER解决了代码生成的可达性问题，忽略原路线已有受条件约束的回退。
- **最小方向：** 在TIGER末段增加一两句原生前缀扩展与占比条件，LIGER处回指。不要直接比较不同冷启动协议下的百分点，也不必新增模型小节。

### CH03-A-R3：可用一个学习型线性物品关系模型补充基础对照

- **级别/状态/维度：** 次要；建议增强；全面性与无偏性、深度理解与洞察。
- **位置/原句：** 同一正文L95—107，`sec:rs-itemcf`；关联L333—365：“物品邻域表可以离线预计算，共现计数或评分变化后再更新。”
- **证据：** [EASE](https://arxiv.org/abs/1905.03375) §2—3以零对角约束和正则化重建学习物品间权重，§5.2提供简单模型的竞争性证据；§3.4明确以矩阵能装入内存为条件。其机制不等同于直接计算共现余弦，也不是低维MF。原文相关章节已读取。
- **影响：** 本章已充分保留经典CF/MF，故不判重要方向缺失；但在19个目录实例与14个标识实例之间，补一个学习型线性关系对照，有助于避免读者把基础路线理解为只有手工相似度或低维因子。
- **最小方向：** 在ItemCF与集合重建的衔接处用一个短段说明学习权重的选择，可提SLIM作为历史关联；同时保留EASE密集物品矩阵的二次存储限制。不要求新增一串论文或断言简单模型普遍更好。
