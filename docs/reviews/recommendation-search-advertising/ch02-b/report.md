## 实质问题

### R1：LONGER被概括为后续逐层缩短序列

- ID：`CH02-B-R1`；严重程度：主要；状态：已核实问题。
- 维度：内容与论证正确性、图表呈现。
- 位置：正文401—406行，`sec:rs-longer`；表2.2第516行，`tab:rs-behavior-extensions`。
- 短引文：“再逐层降低后续的序列规模”；表中“局部合并、逐层压缩”。
- 证据：[LONGER原论文](https://arxiv.org/abs/2505.04421) §3.4、§3.5.1—3.5.4，式7、11、12。实际读取 `r80-full.txt` 188—316行。式12是 `CrossAttn(O,R) -> SelfAttn(.) × N`，并分别标为“compress long sequence”和“high-order interactions”；后续层在采样后的短序列上做自注意力，没有给出逐层继续减少位置数的操作。
- 影响：读者会把合并及首层查询压缩误当成深度方向持续减长，误判网络保留信息的位置和后续层成本，也会误读与输入前检索的比较。
- 最小修订：将标题、首段和表行统一为“合并与首层查询压缩”一类准确表述；明确首层之后在压缩序列上继续编码。保留正确的 `mn` 关系数说明，不需重写全部算例。

### R2：TWIN-V2未准确说明类别特征取自代表物品

- ID：`CH02-B-R2`；严重程度：次要；状态：已核实问题。
- 维度：内容与论证正确性。
- 位置：正文394行，`sec:rs-twin-v2`。
- 短引文：“类别属性按组成保留为聚合特征”。
- 证据：[TWIN-V2原论文](https://arxiv.org/abs/2407.16357) §3.3.2，式5—7；实际读取 `r79-full.txt` 178—217行。数值特征取簇内均值，类别特征则“adopt the closest item to the centroid ... to represent cluster”，直接使用该代表物品的类别字段。
- 影响：现句容易被理解为保留全簇类别组成，掩盖实际的代表物品选择及其信息损失。簇大小修正并不能补回其他成员的类别字段。
- 最小修订：直接写明数值字段取均值，类别字段取簇中心最近物品的对应字段；保留正确的 `a+log n` 权重解释。

### R3：TOP1正则的动机违反共同平移不变性

- ID：`CH02-B-R3`；严重程度：次要；状态：已核实问题。
- 维度：内容与论证正确性。
- 位置：正文88行，`sec:rs-gru4rec`，紧接式 `eq:rs-gru4rec-top1`。
- 短引文：“避免只靠整体抬分降低相对比较项”。
- 证据：对任意共同平移c，`sigmoid((s_j+c)-(s_++c))=sigmoid(s_j-s_+)`。正负得分0.8、0.2同加10也完全不改变该项。[GRU4Rec原论文](https://arxiv.org/abs/1511.06939) §3.1.3，实际读取 `r10-full.txt` 309—320行，解释为正例抬分而某些物品同时充当负例，导致分数不断上漂，再用负例趋零项稳定训练。
- 影响：损失公式本身正确，但这句话错误解释了排序损失与分数尺度的关系。
- 最小修订：改为约束负例接近零、抑制训练中的分数漂移；删除共同抬分能降低相对比较项的说法。

### R4：用已检验反例具体化“同信息比较”

- ID：`CH02-B-R4`；严重程度：次要；状态：建议增强。
- 维度：全面性与无偏性、深度理解与洞察。

- 短引文：“比较模型时，先固定证据再改变处理方式”。
- 证据：[Buffelli等，2023](https://arxiv.org/html/2308.08354v1) §5、§5.1，为非元学习模型提供相同支持标签后比较DeepFM、DropoutNet与MeLU等；实际读取临时 `cold-meta-html.txt` 544—588行。[Zhou等，2025](https://arxiv.org/html/2508.05377v1) §2.2、§3.1—3.2，比较KNN/SLIM和多模态模型，并移除或替换模态；实际读取临时 `multimodal-critical.txt` 492—620、671—780、852—891行。
- 影响：正文已有谨慎边界，缺的不是另一批模型，而是让读者看到“增加复杂度或模态并非必然带来增益”的可核验对照。当前未声称这些模型普遍最优，因此不判为确定遗漏。
- 最小修订：补一小段或边注，要求相同支持标签、调参预算、候选集和数据划分；明确非元模型输入经过适配，多模态复核包含随机划分及LOO采样协议，不能概括为“元学习/多模态无效”。会话近邻或Markov仅列延伸对照即可，不扩写模型清单。
