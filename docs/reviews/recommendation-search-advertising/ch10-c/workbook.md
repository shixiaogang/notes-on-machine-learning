## 第一遍：主线复述与逆向提纲

实际问题不是“哪个网络CTR高”，而是在当前资格、竞争和跨期资源条件下如何选择广告，并避免将记账值误作增量。概率和价值提供输入，分配支付形成实际支出，支出改变未来资格；创意提供可选对象，测量决定下一轮可用证据。结论受成熟窗口、条件支持、市场反应和执行硬限制约束。
