## 已核实问题

### CH04-A-R1：保序命题缺少递增与严格性条件

- 严重程度：次要。维度：内容与论证正确性、结构与文字表述。状态：已核实问题。
- 位置：源文件L12，`sec:rs-ranking-task`。
- 原句：“任意单调变换都保持排序次序，却会改变概率解释。”
- 证据：令两个分数为0.2、0.8，单调递减函数`g(s)=-s`会反转降序排名；非严格递增的常数映射会合并原本不同的分数。若保持原比较规则及全部严格次序，应要求严格单调递增。恒等映射也说明“会改变”不宜无条件表述。
- 影响：读者可能把递减映射或合并并列也当成完整保序操作；不影响本章“排名不等于概率”的主论点。
- 最小修订：限定为严格单调递增，并把概率解释表述为“保持次序不保证保留概率刻度”；若讨论非严格校准，另说明并列与次序规则。

### CH04-A-R2：BPR损失增大不等于次序更不确定

- 严重程度：次要。维度：内容与论证正确性。状态：已核实问题。
- 位置：源文件L123，`sec:rs-bpr`。
- 原句：“分差越小，正负次序越不确定，$-\log\sigma(\Delta)$越大。”
- 证据：正文L116定义`P(i>j)=sigmoid(Δ)`。当Δ从0降至-10时，正向概率从0.5降至约0.0000454，模型更确信反向次序，损失却从约0.693升至10.00005。不确定性在Δ接近0时最大，而不是随Δ单调减小。[BPR原文](https://arxiv.org/abs/1205.2618)§4.1与正文损失一致；本地反例见数值附件。
- 影响：混淆“模型不支持所给偏好”和“模型不知道次序”。损失、梯度和教学更新本身正确。
- 最小修订：改成“分差越小，模型越不支持正物品领先的偏好，损失越大”；需要解释不确定性时，限定为分差接近0。

### CH04-A-R3：字段模型的基础对照偏薄

- 严重程度：次要。维度：全面性与无偏性、演进脉络。状态：建议增强。
- 位置：源文件L187–189及L193–486，`sec:rs-feature-interaction`。
- 原句：“线性模型$s=b+\bm w^\top\bm x$为每个特征赋予固定贡献……”随后展开18种字段交互实现。
- 证据：[He等2014](https://www.herbrich.me/papers/adclicksfacebook.pdf)§3.1、图1和表1明确给出树叶规则编码接LR的响应评分路线，§3.2解释分批树训练与在线LR的更新分工。它不是FM类低秩交互。[BARS-CTR](https://arxiv.org/html/2009.05794v6)§3.2–3.4及表3–4显示，在Criteo/Avazu固定协议和充分调参后，若干深度模型差距缩小，部分较新模型并不领先。
- 影响：读者能理解各神经算子，却较难把它们放回传统响应评分基线和实测竞争证据中。正文已有固定预算及无普适优劣的提醒，故不是无偏性的重要缺口。
- 最小修订：补一个短段定位LR、树式规则编码与FM的差异，并用BARS作为“需充分调参”的具体例子。第9章L546–569已有树排序机制，第10章L103–114已有LR/GBDT应用，不要求复制；本章可定点导航。BARS采用匿名字段、随机切分，不能外推否定长历史或新骨干的效果。
