# 第一轮隔离修订稿预检

本文件只记录主代理对隔离草稿的工程预检和指定页面目视，不代表第一轮读者复读通过，也不替代第二轮正式数学准备卷PDF的全卷视觉检查。正式17章仍与`source-version.json`一致。

## 编译范围

使用`build/math-restructure-round1-drafts/draft-chNN.tex`载入各章草稿，输出在同目录`proofNN/`。沿用项目模板、字体、书目与词典。局部`latexmkrc`只把共享索引样式路径解析为绝对路径，使嵌套输出目录能够运行同一索引程序；没有修改项目构建配置、取消错误或绕过索引。

执行形式：

```sh
latexmk -r build/math-restructure-round1-drafts/latexmkrc -xelatex \
  -interaction=nonstopmode -halt-on-error \
  -outdir=build/math-restructure-round1-drafts/proof08 \
  build/math-restructure-round1-drafts/draft-ch08.tex
```

第13章因latexmk保留首编的索引失败状态，在路径修正后使用一次`-g`重建索引及全部校样目标，随后正常增量构建。以下十一章全部完成XeLaTeX、Biber、索引与PDF生成，最终日志的overfull、underfull、缺失字形、缺失文献和致命错误均为0。
