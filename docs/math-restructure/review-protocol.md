# 数学准备卷审读与验收

本文件规定本次整卷重构的实际审查任务，不是已经通过的检查结果。依据为用户要求、阅读结构和项目规范。正文作者完成后，先由一名独立代理串联，再执行两轮审查。

## 串联任务

一名独立代理通读17章的章首、正文依赖、章末及作者报告，必要时展开证明和例子所在的完整节。允许修改正文衔接和跨章引用；不得改变已确定的标题层级、删减证明或压缩成提要。报告记录实际读取的文件与范围。

- 检查新旧20章到17章的映射，尤其是合并后的内部结构，不能只是旧章整块降级。
- 核对各概念的主要讲解位置，区分首次正式建立、当地简短回顾和后文预告。跨章引用不能代替当前推理所必需的一步。
- 概率、随机过程和统计材料在“随机变量”内重组；Brownian定义与二次变差归该章，随机逼近的平均ODE与Poisson方程归“行动和状态”。
- 图傅里叶与图滤波归图章，信号章使用给定核，完整状态核归状态章；图算法的条件不能沿用规则时间索引的默认设定。
- 动力、控制、价值与博弈共用温度例时，核对状态、行动、观测、信息时序、噪声及目标；多方版本明示模型扩展。固定点、均衡、动态稳定、最优性与无遗憾不能互相替代。
- 兼容标签必须与原有数学对象对应；章标签附在章开头，合并后保留别名。新的词条与文献必须集中合并后检查。

## 第一轮：三名读者

三名独立代理按本科理工科毕业生视角阅读，合计覆盖整卷。分工根据最终篇幅均衡，明确记录每人的连续章节范围；涉及边界依赖时同时读取被引用的前文。三人不同时改正文，各自提交概念清单与问题报告，主代理统一修订，避免一个人的修订改变另一个人的检查版本。

概念清单按章逐项记录，不能只提取`\term`。包括定义、符号对象、算法、性质、比较准则、证明工具、无术语标记的核心概念，以及在例子或图中首次承担解释作用的对象。熟悉的本科概念可记录为“已有背景，但本书已回顾用途”；只预告后文且尚未用于推理的名词单独标明。

| 字段 | 记录要求 |
| --- | --- |
| 概念 | 正文采用的准确名称；同义词合并并标出 |
| 首次位置 | 文件、节标签与实际行号；保留短引文便于修订后定位 |
| 为什么引入 | 正文已给出的具体问题或前一步留下的缺口 |
| 当地解释 | 是否紧接白话含义、对象及正式条件 |
| 理解支撑 | 实际例子、计算、反例或图标签；没有时如实记录 |
| 依赖与比较 | 依赖是否已建立；相近概念的差别是否说明 |
| 判断与修订 | 已清楚／局部费力／阻断理解／技术疑点；提出具体最小修改 |

报告须分别说明遗漏动机、概念依赖倒置、直觉不足、算例不可复算、比较对象混淆、技术条件缺失与语言费解，不能用“建议更详细”概括。每一项问题留有处理记录；修改后从前一段开始复读，覆盖后续衔接。机械标题检查通过不算读者审读通过。

## 第二轮：一名PDF检查者

第一轮修订完成并构建卷一后，另派一名代理检查实际PDF。检查者读取本轮成品路径与SHA-256，记录实际覆盖页码；正文页码和PDF页面序号分开写，不能将基线PDF当作交付版本。

- 检查目录、五个部首页、17个章首页、页眉、正文首页与部首页的奇偶。
- 渲染并查看本轮全部新增或重排的图表、复杂公式、数学环境和边注密集页；通过全卷页面扫描定位其余可疑页，再逐页放大核对。
- 检查图文对应、下置图注、文字可读性、线条与数学符号、标签遮挡、裁切、正文和边栏侵占。
- 检查长标题、公式折行、表格宽度、环境分页、浮动图远离首次引用、边注互相覆盖和异常留白。
- 每个问题写明PDF页面序号、正文页码、源文件/标签、可见症状和修订建议；报告附渲染证据路径。文本抽取和日志扫描只能辅助定位，不能代替目视。

视觉修订后重建，重新检查受影响页面；成品改变后，旧SHA-256的结论不能直接充当最终验收。

渲染工具 `scripts/render_pdf_review.py` 使用已安装的PyMuPDF，不依赖浏览器或Pillow。下面的第一条命令生成全卷缩略页；第二条按PDF实际页面序号生成放大图，检查者须将示例页码换成实际目标。输出按成品SHA-256隔离，清单记录页面范围与图片哈希，默认状态为“未审读”，不能把渲染完成当作视觉通过。

```sh
python3 scripts/render_pdf_review.py target/vol1-mathematical-preliminaries.pdf --output build/math-restructure-visual
python3 scripts/render_pdf_review.py target/vol1-mathematical-preliminaries.pdf --output build/math-restructure-visual --pages 1,8-15,23 --only-detail --dpi 160
```
