# 第02章独立评审报告 C

## 主要发现

### CH02-C-01：语义相似检索已列入范围，但解法与比较仍主要按实例检索展开

- 严重程度：主要。
- 维度：全面性与无偏性；深度理解与洞察（比较与综合）。
- 状态：已确认的覆盖与适用范围缺口，不是对所列实例检索算法的否定。
- 位置：`tex/04-applications/02-image-processing/02-image-recognition-and-retrieval.tex:479-508,525-573`；`plans/image-processing-outline.md:371-413`。
- 原文短引：484行区分“找类似的红色汽车”和“找同一辆车的其他照片”；506行随后概括为“检索训练需要知道哪些图拍到了同一实例”。
- 问题：正文正确说明两类相关性不同，但后续训练正例、困难负例、局部对应、几何重排及具名基准都围绕同一实例。没有把类别或属性相似的正例定义接入一种图像到图像检索过程，也没有明确指出该分支不应以同一物理表面的几何一致性作为必要条件。506行的主语尤其容易把实例检索的监督要求泛化到全部检索。
- 可核验证据：Barz与Denzler的《Content-based Image Retrieval and the Semantic Gap in the Deep Learning Era》[原文](https://arxiv.org/html/2011.06490v1)，第1节明确区分实例与语义检索，第3节在ROxford及MIRFLICKR-25K上的对照显示，所测实例检索改进没有自动转为语义检索改进；第4节讨论类别、层级和文字语义的监督来源。本次直接读取第3至6节，不把该文2020年的实验外推为2026年全部模型的结论。
- 反向复核：34、57-69行已有区域分类与属性机制，508行也给出DINOv3候选基线，因此不能说“没有语义表示”。但它们没有在2.4节组成语义检索的正例、评分与核验流程。第8章35-43、80-93行承接图文排序与条件核验，未替本章实现图像间语义相似检索；486行也只将“文字查询”交给后章。
- 影响：读者能解释两种查询的区别，却容易为同类不同实例的正例继续使用实例级困难负例或几何筛除，无法据此选择合适的检索证据。
- 最小修订：将506行限定为当前GeM实例检索例子；复用已有分类、属性或图像表示，补一个图像间语义检索例子，明确类别或属性相关的正例与核验规则。用同一小图库对照两种相关性下不同的正确排序，说明几何核验在哪个分支适用。不必新增完整模型小节。
- 核验置信度：高。

### CH02-C-02：未知相机的几何恢复缺少经典求解与学习预测的实质对照

- 严重程度：主要。
- 维度：全面性与无偏性；演进脉络；深度理解与洞察（比较与综合）。
- 状态：已确认的大纲落实与综合缺口，不是声称书稿完全没有几何约束。
- 位置：`tex/04-applications/02-image-processing/02-image-recognition-and-retrieval.tex:450-474`，连同428-441、549-563行；`plans/image-processing-outline.md:355-369`。
- 原文短引：453行“经典流程先寻找对应，再估计相机和三维点”；大纲357行要求用经典匹配与几何求解说明新方法“替代或保留了哪些环节”。
- 问题：经典流程只保留一句概括；本章没有接通多图对应、相机注册、三角化、重投影误差联合优化以及向已知相机MVS传递结果的关系。因而“成对点图后对齐”与“多视图前馈预测”的比较成立，但它们相对观测几何求解的变化、代价和组合方式仍不清楚。
- 可核验证据：《Structure-from-Motion Revisited》[正式论文](https://openaccess.thecvf.com/content_cvpr_2016/papers/Schonberger_Structure-From-Motion_Revisited_CVPR_2016_paper.pdf)第2节及图2解释注册、三角化和束调整的依赖，式(1)以二维重投影残差联合优化相机与点。《DUSt3R》[原文](https://arxiv.org/html/2312.14132)第1至2节明确将其三维点图对齐与重投影误差束调整区别开。《VGGT》[原文](https://arxiv.org/html/2503.11651)第1至2节同时讨论传统SfM、学习组件、可微束调整及前馈预测后再做BA，说明这不只是旧方法被新方法替换的单线演进。
- 反向复核：相机投影、已知基线、MVS代价体、RANSAC、DUSt3R多对对齐和VGGT可选优化均已出现，不能重复要求这些内容。缺的是它们之间的具体职责对照。第4章318行反向依赖本章的相机与重建方法，不是经典求解的后续讲解入口。全书定向搜索亦未找到视觉SfM或束调整的现成讲解。
- 影响：读者难以判断新模型主要省去了哪些测试时求解、使用了什么训练先验，何时仍应保留几何优化，以及“点图互相一致”与“重新解释实际二维观测”为何不是相同目标。
- 最小修订：在2.3.4补一段紧凑流程与三路对照：观测对应加重投影优化、成对点图加三维对齐、多视图联合预测加可选几何优化。比较输入条件、优化对象、监督来源、输出及成本。已有匹配细节回指2.4节，不要求展开完整摄影测量教材或实现COLMAP。
- 核验置信度：高。

1. 在2.4.2至2.4.3明确保留图像间语义检索与实例检索两种用途；现在的叶级例子几乎全部服务后者。优先补一个共用图库对照，不扩张模型清单。
2. 将2.3.4父节承诺的经典几何比较写成明确内容要求，补“对应、相机、点、重投影优化”的最小关系，再比较学习方法。
3. 有篇幅时再补LoFTR与两阶段候选入口。大纲337行提出的直接图像三维姿态比较也可补一句职责对照；未讲这条支线不等于需要扩写为完整人体重建综述。
