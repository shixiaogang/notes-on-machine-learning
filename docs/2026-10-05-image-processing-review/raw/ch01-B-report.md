# 第01章独立评审报告 B

## 主要发现

### CH01-B-01：任务地图没有完成同一街景的具体成果对照

- 严重程度：主要。
- 维度：图表呈现；深度理解与洞察中的输出解释。
- 位置：`tex/04-applications/02-image-processing/01-overview.tex:42-56`；`figures/vision/task-map.tex:9-24`；PDF物理第17页，图1.1，`fig:vision-task-map`。
- 原文短引：“各行表示一种成果及其主要核验关系”；图中第三行是“数量、距离、排序”，第五行是“编辑、描述、配声”。
- 可核验证据：大纲第77行要求用同一街景比较框、掩码、轨迹、深度、语言描述、增强图像及编辑结果，第107行还要求标明使用条件和后续入口。当前图只有“街景观测”文字框、五组名称和概括性标签，没有同一对象的框或掩码、带时间的轨迹、深度或距离表示、描述示例，也没有增强与编辑前后的保持关系、使用条件和后续入口。正文第42-48行给出了基本定义，但不能替代这项具体对照。
- 影响：第一次学习视觉应用的读者能记住任务名称，却不能从图中比较空间范围、像素归属、时间身份和媒体变化到底以什么形式返回。把数量、距离、排序合成一行，再用“尺度与相关性”统一标注，也没有指明哪个核验量属于哪个输出；同样，“条件与对应”没有展示描述的观测依据与编辑、配声的创作条件之别。
- 最小修订方向：保留教学构造的声明，在同一幅简化街景及少量连续帧上给出代表性输出小图或具体结果记录，使对象编号和来源保持一致；按输出补一项必要输入条件、核验对象和后续入口。无需展示真实模型结果，也无需在概述中增加完整训练过程。若仍保留成组行，应明确组内输出分别如何核验。
- 核验置信度：高。
- 判定性质：已确认的教学实现缺口，不据此断言正文建立了互斥的错误任务分类。第50行明确允许共享模型，已在第三遍中纳入判断。

### CH01-B-02：在线观测集合缺少时间轴与可用性的简化条件

- 严重程度：次要。
- 维度：内容与论证正确性；机制与条件；图文一致性。
- 位置：`01-overview.tex:28,173-183`；`figures/vision/observation-window.tex:6-17`；PDF物理第16、22-23页，式1.2、图1.2。
- 原文短引：前文规定“时间戳……表示拍摄或播放时刻”，式1.2随后把满足 `tau_t <= tau` 的帧直接定义为“时刻……能够使用的观测集合”；图内写“已到达历史／即时可用”。
- 可核验证据：一帧在9.9秒拍摄、10.2秒才到达系统，查询在10.0秒发起。按拍摄时间代入式1.2，该帧被纳入；按正文“已经到达”的条件，它尚不可用。若历史已被丢弃，拍摄或到达时间早于查询也不保证仍能读取原帧。第187行及第5章第31行已提醒摘要会丢失细节，但没有为式1.2补上同一时钟、到达延迟及历史留存的条件。
- 影响：把理想化的因果信息上界用于真实流式接口时，可能混淆事件时间、输入到达时间和实际保留内容。这里不否定“不读未来帧”的原则，也不要求概述展开传输系统。
- 最小修订方向：最简处理是在公式附近明确忽略采集、传输与解码延迟，时间戳与输入到达时刻在同一时间轴上，且该集合表示允许读取的信息上界，实际可访问内容还受采样与记忆限制；若不采用这些简化，则另用到达时刻筛选。图内“其余未来／离线才可用”同时限定为当前响应截止时刻之内的比较。
- 核验置信度：高。
- 判定性质：已确认的必要条件未明；理想同步、完整留存设定下公式成立，不将其报告为无条件的代数错误。

### CH01-B-03：两段历史叙述的引文覆盖范围不够明确

- 严重程度：次要。
- 维度：内容与论证正确性中的引文支持。
- 位置：`01-overview.tex:117,124`；PDF物理第20页，边注4、5；`tex/references.bib:666-674,7850-7857`。
- 原文短引：关于FCN、检测、实例分割、全景分割的一整段末尾只引 `vision-1411-4038`；关于DETR、CLIP、生成式视觉语言模型的一整段末尾只引 `radford2021`。
- 可核验证据：独立读取FCN原论文引言及第3节，支持从分类网络到密集类别图的描述，但不能用该2015年论文直接承载本段的全景分割历史线索。CLIP原论文第2.3、3.1.2节支持图文对比与候选类别匹配；DETR的集合监督应由其原论文第3.1节支持，生成式视觉语言接口另有来源。当前正文并未明确把这些能力归给FCN或CLIP，因此问题是引文作用域，不是已证实的模型能力误述。
- 影响：读者顺着当前边注查证，会在一篇论文中寻找它未承担的后续发展；也不容易区分作者对任务变化的综合与所引论文的贡献。
- 最小修订方向：将FCN和CLIP引文移动到各自直接支持的句子后；其余内容就近补相应一手引文，或给出已存在的具体方法小节入口。无需在概述重复完整书目或算法。
- 核验置信度：高。
- 判定性质：已确认的引用定位问题，未将“当前句末没有引用”扩大为“全书没有来源”。后续方法章确有相应引用。
