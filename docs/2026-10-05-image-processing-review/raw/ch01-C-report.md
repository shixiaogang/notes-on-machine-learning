# 第01章独立评审报告 C

## 主要发现

### CH01-C-01：历史交代了接口扩展，但重要转折的促成条件与代价不足

- 严重程度：主要。
- 维度：演进脉络。
- 性质：确定的解释缺口，不是已证实的事实错误，也不是要求补齐全部论文。
- 位置：`tex/04-applications/02-image-processing/01-overview.tex` L115–135，重点 L119、L124–126；对应大纲 `plans/image-processing-outline.md` L109–133。
- 原文短引：“低照度成像、图像转换及学习式压缩也在发展”；“约2020至2023年的若干代表路线进一步改变了应用接口”。
- 问题：正文清楚说明类别、密集输出、开放查询和用户提示增加了什么，但主要从“出现了什么新输出”描述转折。固定类别监督的限制、网页图文数据如何支持开放迁移、复原目标怎样分化为逐对保真与自然外观，以及潜空间生成为什么缓解计算约束，没有形成相应的历史联系。低照度、转换、压缩在 L119 被压缩为并列名称；大纲明确承诺的感知与失真取舍、潜空间生成在历史段中未实质展开。
- 外部证据：[CLIP 原文](https://arxiv.org/html/2103.00020) §1、§2.1–2.2 将固定标签和新增概念的标注成本，与自然语言监督、网页配对数据及规模联系起来；[感知失真论文](https://openaccess.thecvf.com/content_cvpr_2018/papers/Blau_The_Perception-Distortion_Tradeoff_CVPR_2018_paper.pdf) §1–3.1 区分对应原图的失真与输出自然分布，并说明评价目标变化；[潜扩散原始摘要](https://openaccess.thecvf.com/content/CVPR2022/html/Rombach_High-Resolution_Image_Synthesis_With_Latent_Diffusion_Models_CVPR_2022_paper.html) 明确将像素空间训练/推理成本与潜表示中的复杂度、细节保留取舍联系起来。访问层级分别为正文节选、正文节选、摘要，没有据摘要核验内部算法。
- 上下文复核：L48 已讲“看起来清晰”不等于事实保真，L117 已解释密集输出，L126 已给提示歧义，L187 已谈历史与细节预算。因此不能说本章“只有年份和模型清单”。第03章 L413–423 已讲感知失真框架，第04章 L27–64 已讲潜空间和空间控制，第07章 L72–118 已讲图文监督；缺口限于概述承担的历史综合，不是整部分没有相关机制。
- 影响：读者能复述应用范围变大，却较难解释为什么这些变化在相应研究条件下成为可能，以及为什么新接口不能简单取代原有专门方法。复原、生成和编码的历史地位也弱于识别接口扩展。这影响本章承诺的研究演进认识，不只是少列了几个名称。
- 最小修订方向：不新增大节。在现有历史段补两组简短、可追溯的“原约束—改变的条件—新增能力—代价”对照：一组连接固定类别监督与图文开放迁移；另一组连接保真/自然外观目标及潜表示的成本取舍。详细训练和理论继续回指第03、04、07章。无需强加 CNN→ViT 架构史、自监督方法大全或更多模型名。
- 核验置信度：高。

### CH01-C-02：部分史实和前沿工作缺少明确的本章引用入口

- 严重程度：次要。
- 维度：全面性与无偏性中的相关工作可追溯性。
- 性质：来源挂接不充分，不是论文不存在或书目漏项。
- 位置：`01-overview.tex` L124、L133、L168、L187。
- 原文短引：“原论文与固定版本在后续对应章节给出”；“Show-o2研究理解与生成能力的共享，LTX-2研究联合音视频生成”。
- 证据：L124 同段陈述 DETR、CLIP 和生成式视觉语言模型，但仅挂 `radford2021`；L133 的四项工作只笼统指向后文，L168、L187 也没有具体文献或语义化节号。CLIP 论文不是 DETR 或后续生成式模型的来源。独立访问 [DETR](https://arxiv.org/abs/2005.12872)、[Show-o2 v3](https://arxiv.org/abs/2506.15564v3)、[LTX-2 v1](https://arxiv.org/abs/2601.03233v1)、[Flash-VStream](https://arxiv.org/abs/2506.23825)、[TempoGround](https://arxiv.org/abs/2609.02359) 已确认题名、范围及公开时间。
- 上下文复核：上述文献确已进入 `tex/references.bib` 或后文章节，后文也有版本说明；L128 的新视角节号和 L147 的评价节号已提供有效入口，不列为同类缺陷。
- 影响：只阅读概述的读者需要自行搜索多个后文章节，才能区分原始论文、固定预印本版本及教材归纳；段尾单引也容易使证据覆盖范围显得不清楚。不改变目前任务地图和主要结论。
- 最小修订方向：在相应工作后挂接已有引用键，或按 L128 的方式给出精确小节入口；明确区分论文任务声明与作者据此提出的核验要求，不必增加书目数量。
- 核验置信度：高。
